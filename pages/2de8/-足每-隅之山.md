# 【足每】隅之山

**【足每】隅之山**是《山海经·[[东山经]]》東次三経所载的山。南水行九百里山上多草木、金玉、赭。有兽[[精精]]，如牛而马尾。（004-038）

## 原文出处

《[[东山经]]》東次三経：

> 又南水行九百里，曰【足每】隅之山，其上多草木，多金玉，多赭。有兽焉，其状如牛而马尾，名曰精精，其鸣自【讠交】。
>
> （004-038）

## 水行九百里

到达【足每】隅之山的方式不是走陆路是水行：

| 属性 | 内容 |
|------|------|
| 方向 | 南 |
| 方式 | 水行 |
| 距离 | 九百里 |

东山经中「水行」说明此山临水或在水域附近要坐船才能到。九百里是東次三経中较长的距离这座山不容易到达。（004-038）

## 精精

【足每】隅之山的异兽精精：

| 属性 | 内容 |
|------|------|
| 形态 | 如牛而马尾 |
| 鸣声 | 自【讠交】（自呼其名） |
| 名称 | 精精 |

牛身马尾两种家畜的混合体。「其鸣自【讠交】」是山海经常见的命名方式兽的叫声就是它的名字。叫「精精」所以名精精声音即名称。（004-038）

## 三多之山

山上的物产是三个「多」：

| 物产 | 类型 |
|------|------|
| 草木 | 植物 |
| 金玉 | 矿石 |
| 赭 | 红色矿物 |

草木说明此山不荒和東次三経许多「无草木」的荒山不同。金玉和赭都是矿产赭是红色矿物颜料，说明此山山体可能呈赤色。（004-038）
