# 【足支】踵之山

**【足支】踵之山**是《山海经·[[東山経]]》東次三経所载的山。流沙之后水行千里广员二百里无草木有大蛇多玉。山中有深泽广员四十里皆涌多大龟。有[[【鱼合】【鱼合】之鱼]]鲤形六足鸟尾。（004-037）

## 原文出处

《[[東山経]]》東次三経：

> 又南水行五百里，曰流沙，行五百里，有山焉，曰【足支】踵之山，广员二百里，无草木，有大蛇，其上多玉。有水焉，广员四十里皆涌，其名曰深泽，其中多大龟。有鱼焉，其状如鲤，而六足鸟尾，名曰【鱼合】【鱼合】之鱼，其名自訆。
>
> （004-037）

## 流沙之后

到达【足支】踵之山要穿越流沙先水行五百里到流沙再行五百里才到山：

| 路段 | 距离 | 地形 |
|------|------|------|
| 水行 | 五百里 | 水路 |
| 流沙 | 五百里 | 沙漠 |
| 到达 |  | 【足支】踵之山 |

水行加流沙共计一千里到达一座广员二百里的大山。东山経的山越往南越难到达从水行到流沙地形越来越极端。【足支】踵之山像是世界尽头的一座孤山沙漠之后的绿洲（虽然无草木）。（004-037）

## 二百里大山

【足支】踵之山广员二百里是山海経中面积最大的山之一：

| 属性 | 内容 |
|------|------|
| 面积 | 广员二百里 |
| 草木 | 无 |
| 蛇 | 有大蛇 |
| 矿产 | 多玉 |

二百里的范围无草木大蛇玉。荒凉巨大的山上只有蛇和玉像一座被蛇守护的玉山。山海経中明确标注面积的山很少标了的都不小【足支】踵之山是其中之一。（004-037）

## 深泽：四十里涌泉

山中有一处广员四十里的涌水名曰深泽：

| 属性 | 内容 |
|------|------|
| 名 | 深泽 |
| 面积 | 广员四十里 |
| 特征 | 皆涌（全部涌水） |
| 水产 | 多大龟 |

四十里的水全部在涌整片水域都在冒水。无草木的山里有一大片涌泉干燥的地表下有巨大的水源。深泽里多大龟大龟在涌水中像活的岛屿。（004-037）

## 【鱼合】【鱼合】之鱼

深泽中的异鱼集合了鱼、虫、鸟三种特征：

| 属性 | 内容 |
|------|------|
| 形状 | 如鲤 |
| 足 | 六足 |
| 尾 | 鸟尾 |
| 鸣声 | 自訆（叫自己的名字） |

鲤鱼的身体六只脚鸟的尾巴。六足是昆虫的数目鸟尾是飞禽的器官一条鱼融合了水陆空三界。在流沙尽头的涌泉里住着这种跨越三界的鱼世界尽头的生物也是最混合的。（004-037）

## 山海経における「広員N里」の巨山体系

【足支】踵之山の「広員二百里」は山海経全篇でも最大級の山体面積表記である。五蔵山経の大半の山は前山からの距離のみを記し、山自体の面積を明示しない。面積を明示される山は例外的存在であり、いずれも特殊な性格を持つ：

| 山 | 面積 | 経 | 特徴 |
|----|------|-----|------|
| **【足支】踵之山** | **広員二百里** | **東次三経** | **流沙後・深泽・大蛇** |
| [[帝都之山]] | 広員百里 | 北次三経 | 泰泽中の島山 |
| [[昆仑之丘]] | 方八百里 | 海内西経 | 帝之下都 |

面積を明示される山はいずれも到達困難な場所にある，【足支】踵之山は流沙の彼方、帝都之山は泰泽の水中、昆仑之丘は西方の果て。面積の明示は「この山は通常の山とは規模が違う」という編纂者の強調であり、到達困難性と巨大さの組み合わせが、これらの山を人間世界の外縁に位置する異界の地標として機能させている。（004-037）
