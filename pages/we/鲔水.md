# 鲔水

**鲔水**是《山海经·[[北山经]]》北次二经所载的河川，发源于[[白沙山]]山上，潜入山下——在三百里大砂漠中以地下潜流的形式存在。水中多白玉。（003-031）

## 原文出处

《[[北山经]]》北次二经：

> 又北三百五十里，曰白沙山，广员三百里，尽沙也，无草木鸟兽。鲔水出于其上，潜于其下，是多白玉。
>
> （003-031）

## 潜流

鲔水最独特之处在于「出于其上，潜于其下」——从山顶涌出，在山脚潜入地下：

| 要素 | 内容 |
|------|------|
| 起点 | 白沙山上 |
| 终点 | 白沙山下（潜入地下） |
| 流向 | 无地表流路 |
| 特征 | 潜流 |

《山海经》的河川通常有明确的流向和归宿——「某水出焉，而X流注于Y」。鲔水没有流向，没有汇入的河流或湖泽——它从地面消失了。出而即潜，现而即隐——鲔水是一条只有起点没有终点的水。（003-031）

## 三百里砂漠

鲔水的水源白沙山是北次二经中最极端的荒漠：

| 特征 | 描述 |
|------|------|
| 面积 | 广员三百里 |
| 地貌 | 尽沙也 |
| 草木 | 无 |
| 鸟兽 | 无 |

「尽沙也」——全部都是沙。三百里方圆一片沙海，没有一株草、一棵树、一只鸟、一头兽。在这种绝对的荒芜中，鲔水是唯一的生命痕迹——但它也潜入了地下，不肯留在地表。荒漠太彻底了，连水都要躲藏。（003-031）

## 白玉

鲔水中「多白玉」——在地下潜流中藏着白色的玉石：

| 地点 | 玉 |
|------|-----|
| 狐岐之山・胜水 | 多苍玉 |
| **白沙山・鲔水** | **多白玉** |
| 狂山・狂水 | 多美玉 |

三条相邻的水各含不同的玉——苍玉、白玉、美玉。白沙山是白色的沙，鲔水含白色的玉——「白」贯穿了山与水。砂漠虽然空无一物，地下却藏着珍宝。（003-031）

## 三山递变

鲔水所在的白沙山处于一个递变序列中——从有水到潜水到无水：

| 山 | 水 | 状态 |
|----|-----|------|
| 狐岐之山 | 胜水出焉，东北流注于汾水 | 地表流 |
| **白沙山** | **鲔水出于其上，潜于其下** | **潜流** |
| 尔是之山 | 无草木，无水 | 无水 |

胜水有完整的地表流路→鲔水从地表消失潜入地下→尔是之山彻底没有水。三座山从南向北排列，水一步步从可见变为不可见直至消失——北次二经在描绘一条水系消亡的渐变线。（003-031）

## 五藏山経の「潜流河川」：鲔水の「出于其上潜于其下」が示す地下水文の記録

鲔水の「出于其上、潜于其下」は五藏山経で地下潜流を明示する唯一の記述であり、山海経の通常の水文文法（「X水出焉、Y流注于Z」）から完全に逸脱する：

| 水文タイプ | 代表 | 記述パターン | 終着 | 出処 |
|----------|------|------------|------|------|
| 通常型 | 各山の河川 | X水出焉、Y流注于Z | 他の河川/海 | 各経 |
| 消滅型 | 荣水 | 出焉→穷焉 | 流れ尽きる | 011-003 |
| **潜流型** | **鲔水** | **出于其上、潜于其下** | **地下に消える** | **003-031** |

荣水は地表で「穷」（尽きる）が、鲔水は「潜」（潜る）——地下に入って存在し続ける。これは乾燥地帯の伏流水（ワジの地下水脈）の地理的記憶と考えられ、[[白沙山]]の「広員三百里、尽沙也」という砂漠記述と完全に整合する。

前後三山の水系消滅勾配（胜水＝地表流→鲔水＝潜流→尔是之山＝無水）は、北次二経がこの一帯の乾燥化を段階的に記録したことを示す。潜流中に「多白玉」が存在する記述は、地下水脈に沿った鉱物沈殿の観察を反映する可能性がある。（003-031）
