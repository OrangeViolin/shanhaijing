# 尾山

**尾山**是《山海经·[[大荒南经]]》所载的山峰。出现在[[不姜之山]]山群的末段——「有尾山。有翠山。」只有三个字，没有任何附加描述。（011-007）

## 原文出处

《[[大荒南经]]》：

> 又有隗山，其西有丹，其东有玉。又南有山，漂水出焉。有尾山。有翠山。
>
> （011-007）

## 不姜之山山群

尾山处于大荒南经最大的山群列举中——从不姜之山开始，一口气列出近十座山：

| 序 | 山 | 附加信息 |
|-----|------|---------|
| 首 | [[不姜之山]] | 黑水穷焉 |
| … | [[贾山]] | 汔水出焉 |
| … | [[言山]] | （无） |
| … | [[登备之山]] | （无） |
| … | [[恝恝之山]] | （无） |
| … | [[蒲山]] | 澧水出焉 |
| … | 隗山 | 西丹东玉 |
| … | 无名山 | 漂水出焉 |
| **…** | **尾山** | **（无）** |
| 末 | [[翠山]] | （无） |

山群越往后信息越少——开头有黑水、有水名，中间有丹有玉，到尾山只剩名字。（011-007）

## 尾即终结

「尾」——末端、尾巴。尾山是这个山群的倒数第二座：

| 字 | 义 |
|----|-----|
| 尾 | 末尾、终端 |

山群从不姜之山开始，到尾山进入尾声——山名暗示了它在山群中的位置。尾山之后只有翠山，再无其他——「尾」字本身就是一个结束信号。（011-007）

## 无信息之山

尾山没有任何附加记载：

| 项目 | 尾山 |
|------|------|
| 矿物 | 无 |
| 植物 | 无 |
| 水系 | 无 |
| 异兽 | 无 |
| 描述 | 无 |

大荒经中这类「名仅一见」的山很多——它们的存在本身就是记录。不需要说山上有什么，只需要说：这里有一座山叫尾山。名字就是全部信息。（011-007）
