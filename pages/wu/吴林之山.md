# 吴林之山

**吴林之山**是《山海经·[[中山经]]》中次一经所载的山峰。多葛草——全文仅此一句，中次一经中最简的一座山。（005-010）

## 原文出处

《[[中山经]]》中次一经：

> 又东百二十里，曰吴林之山，其中多囗草。
>
> （005-010）

## 葛草之山

吴林之山只有一种植物记载——葛草：

| 要素 | 内容 |
|------|------|
| 植物 | 葛草 |
| 矿物 | 无 |
| 异兽 | 无 |
| 水系 | 无 |

什么都没有——没有矿、没有兽、没有水、没有鸟。只有葛草。葛是古代最重要的纤维植物之一——葛根可食、葛茎可织布——是最基本的日用之物。吴林之山不产奇珍异宝，只长最朴素的生活植物。（005-010）

## 矿山与药山之间

吴林之山夹在两种截然不同的山之间——前面是矿，后面是药：

| 位置 | 山 | 特产 | PN |
|------|-----|------|----|
| 前 | 囗谷之山 | 赤铜 | 005-009 |
| **此** | **吴林之山** | **葛草** | **005-010** |
| 后 | [[牛首之山]] | 鬼草（服之不忧）、劳水（飞鱼，食已痔） | 005-011 |

囗谷之山产赤铜——金属矿山。牛首之山产鬼草——吃了忘忧的神药，还有能治痔的飞鱼。中间的吴林之山只有葛草——从矿到布到药，三座山代表了三种不同的人类需求：工具、衣物、医疗。吴林之山是最中间、最日常的那个。（005-009至005-011）

## 吴林

「吴林」——大的林子：

| 字 | 义 |
|----|-----|
| 吴 | 大（「吴」古义为大） |
| 林 | 树林 |

吴林即大林——一座长满大片林木的山。但记载说的是葛草而不是树——也许大林已经不是最显眼的特征了，漫山遍野的葛草才是这座山真正的面貌。名字说的是林，内容说的是草——名与实之间有了一层错位。（005-010）
