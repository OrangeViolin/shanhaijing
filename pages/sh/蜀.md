# 蜀

**蜀**是《山海经·[[海内東経]]》所载的地名。白水出蜀，东南注江，入江州城下。（014-012）

## 原文出处

《[[海内東経]]》：

> 白水出蜀，而东南注江，入江州城下。
>
> （014-012）

## 地域名水源

海内東経的水系记述中——大部分水源用山名标记（渭水出鸟鼠同穴山、颍水出少室）。蜀是少数以地域名作水源的例子：

| 水源类型 | 举例 |
|----------|------|
| 山名水源 | 渭水出鸟鼠同穴山 |
| 山名水源 | 颍水出少室 |
| 地域名水源 | 白水出蜀 |
| 地域名水源 | 沅水出象郡 |

白水的源流无法归于某一座山——只能指向一片地域。这说明蜀作为水源太过广阔，不像一座山那样精确可指。（014-012）

## 白水流路

白水从蜀出发——东南流注入江（长江）——在江州城下汇合：

| 属性 | 内容 |
|------|------|
| 水源 | 蜀 |
| 流向 | 东南 |
| 注入 | 江（长江） |
| 合流点 | 江州城下 |

从蜀到江州——四川盆地到长江的东南流路。海内東経的地理认识与实际地形相当吻合。（014-012）

## 山海经中的「蜀」字

「蜀」字在山海经中多次出现——每次含义不同：

| 名称 | 篇章 | 类型 |
|------|------|------|
| 蜀 | 海内東経 | 地名 |
| [[鹿蜀]] | 南山経 | 兽名 |
| 叔蜀国 | 大荒北経 | 国名 |

地名的蜀、兽名的蜀、国名的蜀——三个「蜀」字各不相关。同一个字在山海经中被多义使用。（014-012）
