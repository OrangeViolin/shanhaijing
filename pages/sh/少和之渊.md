# 少和之渊

**少和之渊**是《山海经·[[大荒南经]]》所载的渊。在[[不庭之山]]附近，有一处四方形的渊，四角互通，北边属于黑水，南边属于大荒。少和之渊是这处四方渊的北旁，[[从渊]]是南旁，从渊是「舜之所浴也」。（011-005）

## 原文出处

《[[大荒南经]]》：

> 大荒之中，有不庭之山，荣水穷焉。有人三身，帝俊妻娥皇，生此三身之国，姚姓，黍食，使四鸟。有渊四方，四隅皆送，北属黑水，南属大荒。北旁名曰少和之渊，南旁名曰从渊，舜之所浴也。
>
> （011-005）

## 四方之渊

这处渊不是普通的水潭，而是一个四方形的结构：

| 属性 | 内容 |
|------|------|
| 形状 | 四方（正方形） |
| 四隅 | 皆送（四角互通） |
| 北属 | 黑水 |
| 南属 | 大荒 |

「四隅皆送」，四个角都互相通连。不是封闭的池塘，是一个四角开放的水网，水从四面八方可以进出。北边连着黑水，南边通向大荒，这处渊是黑水和大荒之间的中转站。（011-005）

## 南北双渊

少和之渊与从渊南北对峙：

| 位置 | 渊名 | 性质 |
|------|------|------|
| **北旁** | **少和之渊** | **属黑水** |
| 南旁 | [[从渊]] | 舜之所浴 |

从渊是舜的沐浴之地，帝舜在南边的渊里洗浴。少和之渊在北旁，「少和」，小小的和谐。北渊安静，南渊是帝的浴场，两个渊分工不同，共同构成了一处圣水域。（011-005）

## 舜的圣域

少和之渊所在的不庭之山一带，密集出现与舜相关的地标：

| 地标 | 与舜的关系 | 条目 |
|------|-----------|------|
| 苍梧之野 | 舜之所葬 | 011-004 |
| **从渊** | **舜之所浴** | **011-005** |
| 三身之国 | 帝俊妻娥皇所生 | 011-005 |

舜的葬地在苍梧，舜的浴地在从渊，死与洁净相邻。少和之渊虽然不直接系于舜，但作为从渊的北旁对偶，它是舜之浴场的另一半。（011-004、011-005）

## 三身之国

同一段文字中记载了三身之国，帝俊和娥皇所生：

| 要素 | 内容 |
|------|------|
| 父 | 帝俊 |
| 母 | 娥皇 |
| 后代 | 三身之国 |
| 姓 | 姚 |
| 食 | 黍 |
| 役使 | 四鸟 |

三身之国、四方之渊、舜之浴所，不庭之山汇集了帝系谱系、圣水和沐浴仪式。少和之渊是这片圣域中安静的北端。（011-005）

## 大荒南経の「双渊対偶」：少和之渊と从渊が形成する聖水域の南北構造

少和之渊は[[渊四方]]の北旁として[[从渊]]（南旁・舜之所浴）と南北対偶を成し、山海経の渊の中で唯一の「主渊＋双附属渊」三体構造を形成する：

| 渊 | 位置 | 帰属域 | 機能 | 出処 |
|----|------|--------|------|------|
| [[渊四方]] | 中央 | 四隅皆送 | 集水の主渊 | 011-005 |
| **少和之渊** | **北旁** | **黒水** | **静的空間** | **011-005** |
| [[从渊]] | 南旁 | 大荒 | 舜之所浴（帝王沐浴） | 011-005 |

从渊が帝舜の沐浴という積極的機能を持つのに対し、少和之渊には具体的機能が記されない——「少和」（小さな調和）の名のみ。この非対称性は意図的であり、南が動（浴）・北が静（和）という陰陽的二分を反映する。

[[不庭之山]]一帯の帝系聖域（苍梧之野＝舜葬地→三身之国＝帝俊系→渊四方＝帝舜浴場）の中で、少和之渊は最も静かな存在——帝の死と帝の沐浴に挟まれた「小さな和」は、聖域の中の安息空間として位置づけられる。（011-004、011-005）
