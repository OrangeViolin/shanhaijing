# 石者之山

**石者之山**是《山海经·[[北山经]]》北次一经所载的山峰。无草木，多瑶碧。【氵此】水西流注于河。有异兽孟极——如豹，花纹额白身，善于潜伏。（003-021）

## 原文出处

《[[北山经]]》北次一经：

> 又北二百八十里，曰石者之山，其上无草木，多瑶碧。【氵此】水出焉，西流注于河。有兽焉，其状如豹，而文题白身，名曰孟极，是善伏，其鸣自呼。
>
> （003-021）

## 孟极

石者之山的异兽——孟极，一只善于隐藏的豹：

| 特征 | 描述 |
|------|------|
| 形态 | 如豹 |
| 额 | 文题（有花纹的额头） |
| 身 | 白身 |
| 习性 | 善伏（擅长潜伏） |
| 叫声 | 自呼（叫自己的名字） |

「善伏」——这是孟极最被强调的特征。不是善跑、善猎、善攀，而是善于「伏」——趴下、隐藏、伪装。白色的身体在无草木的瑶碧荒山上——白与青碧的色差让它无法融入环境，但它依然善于潜伏。（003-021）

## 行为序列

孟极处于北次一经中段一组特异行为兽的序列中：

| 山 | 兽 | 特异行为 |
|----|-----|---------|
| 丹熏之山 | 耳鼠 | 以其尾飞（用尾巴飞） |
| **石者之山** | **孟极** | **善伏（擅长潜伏）** |
| 边春之山 | 幽【安鸟】 | 善笑，见人则卧（见人就躺下） |

用尾巴飞→善于潜伏→见人就笑着躺下——三种完全不同的异常行为连续出现。北次一经在这段山列中关注的不是兽的形态而是兽的行为——每只兽都有一种独特的动作模式。（003-021）

## 瑶碧

石者之山无草木，但多瑶碧——瑶和碧都是美玉：

| 矿产 | 含义 |
|------|------|
| 瑶 | 美玉 |
| 碧 | 青色的玉 |

无草木的荒山上遍布美玉——石者之山是一座石头的山（名中有「石」），而石中最美的就是玉。「石者」——以石为本质的山，石中之精就是瑶碧。（003-021）

## 西流注于河

【氵此】水从石者之山西流汇入黄河：

| 要素 | 内容 |
|------|------|
| 水名 | 【氵此】水 |
| 流向 | 西流 |
| 汇入 | 河（黄河） |

北次一经的水系多西流入黄河或入【氵幼】泽——石者之山的【氵此】水也遵循这一模式。西流是朝向文明中心（黄河流域）的方向——孟极善伏于荒山，但水从荒山流向了人间。（003-021）
