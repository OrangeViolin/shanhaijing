# 苕山

**苕山**是《山海经·[[大荒南经]]》所载的山峰，位于[[颛顼]]国附近，是颛顼国七山系列的第一座。与宗山、姓山、壑山、[[陈州山]]、[[东州山]]、[[白水山]]连记。（011-644）

## 原文出处

《[[大荒南经]]》：

> 有国曰颛顼，生伯服，食黍。有鼬姓之国。有苕山。又有宗山。又有姓山，又有壑山。又有陈州山，又有东州山。又有白水山，白水出焉，而生白渊，昆吾之师所浴也。
>
> （011-644）

## 颛顼国七山系列

苕山是颛顼国地理区域中七座连记山峰的第一座。七山全部以「有X山」或「又有X山」的格式排列，极度精简，只有末尾的白水山附带了水系描述：

| 序号 | 山名 | 附加信息 |
|------|------|---------|
| **1** | **苕山** | **无** |
| 2 | 宗山 | 无 |
| 3 | 姓山 | 无 |
| 4 | 壑山 | 无 |
| 5 | [[陈州山]] | 无 |
| 6 | [[东州山]] | 无 |
| 7 | [[白水山]] | 白水出焉，生白渊，昆吾之师所浴也 |

前六座山只有名字，没有任何地形、物产、异类的记录。这种「纯名连记」在《山海经》中极为罕见——大荒经的山通常至少有一条附加信息。七山的功能不是描述地形，而是标记领地——它们是颛顼势力圈的地理锚点。（011-644）

## 筆頭山的位置意义

苕山是七山的第一座，紧接鼬姓之国之后。鼬姓之国是颛顼国旁的附属邦国，苕山在邦国之后、群山之前——它是从政治空间（邦国）进入地理空间（山脉）的转换点，也是颛顼领地地理描述的起点。（011-644）

## 从白水山回看苕山

七山系列的终点白水山有丰富的描写：白水出此，生白渊，昆吾之师所浴。这些信息暗示白水山是七山中最神圣的——昆吾之师的沐浴地。从苕山到白水山，七座山构成一条从「无信息」到「神圣叙事」的梯度。苕山在这条梯度的起点，是最世俗、最朴素的一端。（011-644）

## 颛顼的南方领地

颛顼国出现在大荒南经，「生伯服，食黍」。颛顼是北方之帝，但其后裔和领地遍布四方：

| 篇章 | 颛顼系存在 |
|------|-----------|
| **大荒南经** | **颛顼国+七山、[[季禺]]之国** |
| 大荒西经 | [[淑士]]国 |
| 大荒北经 | [[叔歜国]]、中【车扁】国 |
| 大荒西经 | 大荒之山（三面人） |

苕山所在的七山系列是颛顼在南方最完整的地理标记——不是一座山、一个邦国，而是一整片由七座山围成的领地。（011-644）

## 「苕」之名

「苕」是一种蔓生草本植物（凌霄花或苕子）。以草名命名的山在《山海经》中并不罕见，但苕是蔓生植物——攀附、蔓延、覆盖。以蔓草名为七山之首，或暗示颛顼势力从此山开始向四周蔓延。（011-644）

## 大荒经的「纯名连记」山群：苕山七山系列与同类模式

大荒经中存在一种独特的地理书写——连续列出多座山名但不附加任何描写。苕山所在的七山系列是最长的纯名连记：

| 经卷 | 关联势力 | 连记山数 | 末尾有描写 | 出处 |
|------|----------|----------|-----------|------|
| **大荒南经** | **颛顼国** | **7座** | **有（白水山）** | **011-644** |
| 大荒东经 | 少昊国 | 3座 | 有 | — |
| 大荒北经 | 黄帝系 | 2座 | 无 | — |

纯名连记的功能不是描述地理，而是标记领地——「有X山」的反复出现就像在地图上打钉子，宣示这片空间属于某个势力。七山系列的七次「又有」像七面旗帜，把颛顼的南方领地围了出来。

更值得注意的是系列末尾的突然丰富——前六座山只有名字，第七座白水山突然展开了完整叙事（白水出焉→白渊→昆吾之师所浴）。这种「枯→丰」的突变暗示七山是一条朝圣路径：从普通山峰（苕山）一路走到神圣之地（白水山），信息密度的递增对应着神圣性的递增。（011-644）
