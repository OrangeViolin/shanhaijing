# 盛山

**盛山**是《山海经·[[大荒东经]]》所载的山，与绮山、[[摇山]]、曾山、[[门户山]]、[[待山]]共六山并列于壎民之国条下。无独立描述。（015-031）

## 原文出处

《[[大荒东经]]》：

> 有壎民之国。有绮山。又有摇山。有曾山，又有门户山，又有盛山。又有待山。有五采之鸟。
>
> （015-031）

## 六山群

盛山是壎民之国条下六座山之一，以纯粹的山名列举方式出现：

| 序号 | 山名 | 描述 |
|------|------|------|
| 1 | 绮山 | 无 |
| 2 | [[摇山]] | 无 |
| 3 | 曾山 | 无 |
| 4 | [[门户山]] | 无 |
| 5 | **盛山** | **无** |
| 6 | [[待山]] | 无 |

六座山没有任何矿物、水系、动植物的记载——只有名字。这是大荒经典型的「山名列举」模式：用一连串山名勾勒出某个区域的地理轮廓，不做具体描写。山的意义不在个体，而在群体——六山共同构成壎民之国的地形骨架。（015-031）

## 五采之鸟

六山之后紧接「有五采之鸟」。五采之鸟是大荒东经中与帝俊关联的瑞鸟——更前方的条目记载「有五采之鸟相乡弃沙惟帝俊下友」。六山群出现在五采之鸟的领地内，暗示壎民之国的整个山域属于帝俊的圣域范围。盛山和其他五山是这片圣域的无名骨骼——没有自己的故事，只为圣域提供地形。（015-031）

## 盛之名

「盛」——盛满、丰盛。六山中「盛」是最具积极含义的山名——绮（华美）、摇（动摇）、曾（层叠）、门户（出入口）、盛（丰盛）、待（等待）——六个名字各有意象，合在一起如同一首极简的诗：华美之山、动摇之山、层叠之山、门户之山、丰盛之山、等待之山。（015-031）

## 大荒经的极简

大荒经的山岳记述与五藏山经截然不同。五藏山经的山有详尽的矿物、水系、动植物清单——一座山常常数十字乃至上百字。大荒经的山则只有名字——盛山全文仅「又有盛山」四字。这种极简不是简略，而是大荒经自身的叙事逻辑：大荒是已知世界的边缘，那里的山只有轮廓、没有细节。（015-031）

## 大荒経における山名列挙群の機能

盛山は壎民之国条下の六山群の一として、個別の描写を持たない「名のみの山」である。大荒経にはこのような山名列挙群が複数存在し、五蔵山経の山岳記述と対照すると、その叙述機能が明確になる：

| 記述類型 | 山あたりの情報量 | 機能 | 例 |
|---------|---------------|------|-----|
| 五蔵山経 | 鉱物・水系・動植物・距離 | 個別の地誌 | 「多金玉，無草木，沙水出焉」 |
| **大荒経・山名列挙** | **名のみ（「又有X山」）** | **領域の輪郭** | **盛山（四字）** |
| 大荒経・独立山 | 一～二特徴 | 神話的座標 | 「海水入焉」（天台高山） |

五蔵山経の山は実地調査的な詳細で記述されるが、大荒経の列挙群は名前だけで空間を区画する。壎民之国の六山（綺・揺・曾・門戸・盛・待）は各山の内実ではなく、六つの名が並ぶことで生まれる「多くの山がある聖域」という印象が目的である。これは大荒が既知世界の外縁であり、調査ではなく伝聞で記録された領域であることを反映する。盛山の「盛」は豊穣を意味するが、その豊穣は名前にのみ宿り、記述には現れない——大荒経の山は名前そのものが情報である。（015-031）
