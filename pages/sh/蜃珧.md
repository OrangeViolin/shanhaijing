# 蜃珧

**蜃珧**是《山海经·[[東山経]]》所载的贝类。产于[[峄皋之山]]的峄皋之水中——东流注于激女之水。（004-016）

## 原文出处

《[[東山経]]》：

> 峄皋之水出焉，东流注于激女之水，其中多蜃珧。
>
> （004-016）

## 蜃与珧

「蜃珧」是两种贝类的并称：

| 贝 | 特征 |
|----|------|
| 蜃 | 大蛤（大型双壳贝），蜃气楼之名由此而来 |
| 珧 | 刀形细长贝（壳可作刀鞘） |

蜃是圆的——珧是长的——两种形态截然不同的贝类并列出现——说明峄皋之水是贝类丰富的水域。（004-016）

## 峄皋之山的环境

蜃珧栖息的峄皋之水出自峄皋之山：

| 属性 | 内容 |
|------|------|
| 山 | 峄皋之山 |
| 山上 | 多金玉 |
| 山下 | 多白垩 |
| 水 | 峄皋之水，东流注于激女之水 |
| 水产 | 多蜃珧 |

山上有金玉——山下有白垩——水中有蜃珧。峄皋之山从上到下都有产出——矿物在上——泥土在下——贝类在水中。（004-016）

## 東次二経的简与繁

蜃珧在東次二経的异兽序列中独特——因为它是唯一的贝类，且没有任何形态描写：

| 山 | 生物 | 描写详度 |
|----|------|----------|
| 空桑之山 | 鸣蛇（蛇身四翼，见则大旱） | 详 |
| [[曹夕之山]] | 多鸟兽 | 简 |
| **峄皋之山** | **蜃珧** | **极简（只说「多」）** |
| [[葛山之首]] | [[珠鳖鱼]]（六足有珠，食之无疠） | 详 |

前有能预兆旱灾的鸣蛇——后有能治病的珠鳖鱼——蜃珧夹在两者之间——没有异形、没有预兆、没有药效——只有一个「多」字。它是東次二経异兽序列中最朴素的存在。（004-016）
