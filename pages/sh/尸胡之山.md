# 尸胡之山

**尸胡之山**は[[东山经]]に記載される山峰で、東次三経の首山である。北に殃山を望み、金玉・棘を産する。（004-031）

## 原文出处

《[[东山经]]》：

> 又东次三经之首，曰尸胡之山，北望殃山，其上多金玉，其下多棘。有兽焉，其状如麋而鱼目，名曰妴胡，其鸣自訆。
>
> （004-031）

> 凡东次三经之首，自尸胡之山至于无皋之山，凡九山，六千九百里。其神状皆人身而羊角。
>
> （004-040）

## 地理描述

尸胡之山は東次三経の首山で、北に殃山を望む。山上に金玉が多く、山下に棘（荊棘）が多い。異獣妴胡が棲む。麋鹿の形で魚の目を持ち、鳴き声で自らの名を呼ぶ。東次三経は九山・六千九百里で、山神はすべて人身羊角の姿。（004-031）

## 東次三経の経脈構造

| 項目 | 内容 |
|------|------|
| 首山 | **尸胡之山** |
| 末山 | 无皋之山 |
| 山数 | 九山 |
| 里程 | 六千九百里 |
| 山神形態 | 人身羊角 |
| 祭祀 | 牡羊一頭、糈に黍 |
| 神の出現兆 | 風雨水為敗 |

東次三経は東山経四経のうち山神が「人身羊角」という独自の形態を持つ経で、神が出現すると風雨による水害が起きる。尸胡之山は首山として経脈を統轄し、山名と異獣名（妴胡）が「胡」を共有する点が特徴的。妴胡の「魚目」は陸獣に水生動物の器官が備わる山海経特有の混合形態で、東山経が海に近い地域の山を記す性格を反映する。
