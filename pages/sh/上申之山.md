# 上申之山

**上申之山**是《山海经·[[西山经]]》西次四経所载的山。上无草木多硌石，兽多白鹿，鸟多当扈（以髯飞，食之不眴目）。汤水东流注于河。（002-067）

## 原文出处

《[[西山经]]》西次四経：

> 又北百二里，曰上申之山，上无草木，而多硌石，下多榛木苦，兽多白鹿。其鸟多当扈，其状如雉，以其髯飞，食之不眴目。汤水出焉，东流注于河。
>
> （002-067）

## 当扈

上申之山最奇特的存在，用胡须飞的鸟：

| 属性 | 内容 |
|------|------|
| 形态 | 如雉 |
| 飞行 | 以髯飞（用胡须飞） |
| 药效 | 食之不眴目（不眼花） |

不用翅膀，用胡须飞。山海经中独一无二的飞行方式。吃了还能治眼花，护目的鸟。（002-067）

## 荒上丰下

上申之山上下截然不同：

| 位置 | 状态 |
|------|------|
| 山上 | 无草木、多硌石 |
| 山下 | 多榛木苦 |

山上是荒石，山下有灌木。白鹿和当扈栖息在这样上荒下丰的环境里。（002-067）

## 三山三水入河

上申之山处在连续三山东流入黄河的水带中：

| 山 | 水 | 流向 |
|----|-----|------|
| 鸟山 | 辱水 | 东流注河 |
| **上申之山** | 汤水 | 东流注河 |
| 诸次之山 | 诸次之水 | 东流注河 |

三座山、三条水，全部东流入黄河。西次四経的这段是黄河支流密集带。（002-067）
