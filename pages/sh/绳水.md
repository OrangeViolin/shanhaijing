# 绳水

**绳水**是《山海经·[[北山经]]》北次三经所载的河川。出于[[碣石之山]]，东流注于河。水中多蒲夷之鱼。（003-088）

## 原文出处

《[[北山经]]》北次三经：

> 又北五百里，曰碣石之山。绳水出焉，而东流注于河，其中多蒲夷之鱼。基上有玉，其下多青碧。
>
> （003-088）

## 蒲夷之鱼

绳水中多蒲夷之鱼——以蒲（菖蒲）命名的鱼：

| 要素 | 内容 |
|------|------|
| 鱼名 | 蒲夷之鱼 |
| 栖息 | 绳水中 |
| 特征 | 无形态描写 |

「蒲夷」——蒲是水边的菖蒲草，夷可能指生活在蒲丛中的鱼。北次三经的水中产物多为矿物（金玉、青碧），绳水是少数记载生物的水——不是石头，是活的鱼。（003-088）

## 陆路之终

绳水出自碣石之山——北次三经陆路行程的最后一座山：

| 序 | 山 | 行程方式 |
|----|-----|---------|
| … | 伦山 | 陆路（又北五百里） |
| **最后** | **碣石之山** | **陆路（又北五百里）** |
| 下一 | 雁门之山 | **水行**（又北水行五百里） |
| 下一 | 帝都之山 | 水行 |

碣石之山之后，行程从「又北」变成了「又北水行」——不再走陆路了，改坐船了。绳水是陆地尽头的最后一条河——从这里开始，地面消失，只剩水路。（003-087至003-089）

## 碣石

碣石之山——碣石是柱形的石碑：

| 山产 | 内容 |
|------|------|
| 上 | 玉 |
| 下 | 青碧 |
| 水 | 绳水（蒲夷之鱼） |

碣石在历史上被认为在渤海湾——秦始皇曾东临碣石以观沧海。如果碣石之山在海边，那绳水就是一条流向大海的河。陆路的终点是海，绳水的终点也是海。（003-088）
