# 深泽

**深泽**是[[东山经]]东次三经记载的一处大型涌水湖泽，位于[[跂踵之山]]之上（004-274）。"广员四十里皆涌"，即方圆四十里的水面全部由地下泉水涌出。深泽中栖息[[大龟]]和六足鸟尾的异鱼。在以荒凉流沙为主调的东次三经中，深泽是少有的水量充沛、生物丰富的区域，形成了一处沙漠中的"涌泉绿洲"。

## 原文出处

《[[东山经]]》东次三经：

> 又南水行五百里，曰流沙，行五百里，有山焉，曰跂踵之山，广员二百里，无草木，有大蛇，其上多玉。有水焉，广员四十里皆涌，其名曰深泽，其中多大龟。有鱼焉，其状如鲤，而六足鸟尾，名曰【鱼合】【鱼合】之鱼，其名自叫。
>
> （004-274）

## 东次三经中的方位与路径

深泽位于东次三经山脉序列的中段。东次三经以[[尸胡之山]]为首山（004-268），全程以"水行"为主要交通方式，共记九山，总里程六千九百里（004-277）。到达深泽所在的跂踵之山，需要经过以下路径：

- [[尸胡之山]]（004-268）→ 南水行八百里 → 岐山（004-269）
- → 南水行七百里 → 诸【钅句】之山（004-270）
- → 南水行七百里 → 中父之山（004-271）
- → 东水行千里 → 胡射之山（004-272）
- → 南水行七百里 → [[孟子之山]]（004-273）
- → 南水行五百里 → [[流沙]]，行五百里 → [[跂踵之山]]（004-274）

从孟子之山到跂踵之山，经文特别标注了"流沙"这一地貌障碍。"南水行五百里，曰流沙，行五百里"，先水行五百里到达流沙，再穿越五百里流沙，才能抵达跂踵之山。流沙在《山海经》中反复出现，通常标志着进入极远之地的门槛。穿越流沙之后出现的深泽，在叙事上具有"险途之后的奖赏"的结构效果。

## "广员四十里皆涌"：涌水湖的规模

"广员四十里皆涌"是深泽最核心的特征。"广员"即面积，方圆四十里。"皆涌"意为整个水面都由地下泉水向上涌出，而非由河流汇入。

这一描述在《山海经》的水文记录中极为特殊。山经中记载的水体大多是"某水出焉，流注于某"的河流型态，有明确的源头和去向。深泽不同：它没有出水方向，没有注入的目标河流或大海，只有涌出。它是一个封闭的涌水系统，水从地下来，在原地积蓄成泽。

四十里见方的涌水湖在自然界中并非无据。内陆干旱地区的泉水湖确实存在地下水大面积涌出形成湖泊的地貌。深泽的描述可能保留了对这类地貌的远距离传闻，在传播过程中规模被夸大。

## 跂踵之山与深泽的对比

深泽所在的[[跂踵之山]]是一座"广员二百里，无草木，有大蛇，其上多玉"的荒山。二百里见方的范围内没有草木，只有大蛇盘踞，山上产玉。这是一幅极度荒凉的景象。

深泽以四十里之泽嵌入二百里之荒山，形成了鲜明的对比：

| 维度 | 跂踵之山 | 深泽 |
|------|---------|------|
| 面积 | 方二百里 | 方四十里 |
| 植被 | 无草木 | （未记载，但有水生生物） |
| 生物 | 大蛇 | 大龟、【鱼合】【鱼合】之鱼 |
| 资源 | 多玉 | 涌水 |
| 属性 | 干燥、危险 | 湿润、丰饶 |

荒山中有涌泉，涌泉中有异类。跂踵之山的大蛇代表陆地上的危险，深泽的大龟和异鱼代表水中的奇异。蛇与龟的并置在上古象征中具有特殊意义：玄武即蛇龟合体，是北方水神的形象。跂踵之山上蛇盘山顶、龟居水泽，某种程度上构成了"蛇龟共处"的地理格局。

## 深泽中的生物：大龟与六足鸟尾之鱼

深泽中记载了两种生物。

第一种是[[大龟]]。"其中多大龟"，没有更多描述。"多"字说明大龟不是偶然出现的个体，而是深泽中的优势物种。龟在上古中国具有占卜功能（甲骨即龟甲），"大龟"暗示深泽可能被视为一处产出占卜材料的神圣水域。

第二种是"其状如鲤，而六足鸟尾"的异鱼，名为【鱼合】【鱼合】之鱼。这种鱼的基础形态是鲤鱼，但长有六只脚和鸟一样的尾巴。"六足"在《山海经》异兽中反复出现，是异化程度的标志。"鸟尾"则跨越了鱼与鸟的分类边界。鱼有鸟尾、有脚可行，这是一种水陆两栖的混合生物。它以"其名自叫"的方式命名，叫声听起来像"鱼合鱼合"。

两种生物的搭配构成了深泽的生态画面：龟是真实的大型水生动物（虽然规格异常），鱼是完全虚构的混合生物。从龟到鱼，写实程度递减，异化程度递增。

## 东次三经的荒凉基调与深泽的例外

东次三经整体呈现出一种荒凉、险远的基调。九座山中，多数记载"无草木""多沙石"：

- 诸【钅句】之山："无草木，多沙石"（004-270）
- 中父之山："无草木，多沙"（004-271）
- 胡射之山："无草木，多沙石"（004-272）
- [[跂踵之山]]："无草木，有大蛇"（004-274）
- [[无皋之山]]："无草木，多风"（004-276）

在这片沙石遍布、草木不生的旷野中，深泽以"皆涌"的涌水打破了干燥的主调。它是东次三经中唯一一处有丰富水量的地点，也是唯一一处记载了多种水生生物的区域。深泽的存在赋予了东次三经一种叙事节奏上的起伏：连续的荒凉之后突然出现一片涌水湖，然后又迅速回归荒凉（后续的【足每】隅之山和无皋之山）。

东次三经的总结语为"是神也，见则风雨水为败"（004-277），意为这些山的神灵出现时会带来风雨水灾。深泽的涌水与这条总结呼应：水在东次三经中既是稀缺资源（大部分山无草木无水），又是潜在的灾害力量（神出则水为败）。深泽作为东次三经中最大的水体，处于"水的赐予"与"水的威胁"之间的张力地带。
