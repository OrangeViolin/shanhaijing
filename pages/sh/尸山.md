# 尸山

**尸山**は[[中山経]]中次五経に記載される山である。（005-052）

## 原文出処

> 又東十里，曰尸山，多蒼玉，其獸多【上鹿下京】。尸水出焉，南流注於洛水，其中多美玉。
> （005-052）

## 地理描述

尸山は[[历山]]の東十里に位置する。山には蒼玉が多く、獣には【上鹿下京】が多い。尸水がこの山から出て南に流れ洛水に注ぐ。水中には美玉が多い。

## 水系構造

尸水は尸山から発し、南へ流れて洛水に注ぐ。山名と水名が一致する定型。

| 要素 | 内容 |
|------|------|
| 水源 | 尸山 |
| 河川 | 尸水 |
| 流向 | 南 |
| 注入 | 洛水 |

## 玉の山

尸山は山に蒼玉が多く、水中に美玉が多い。山と水の両方に玉を産する「双玉」の山。蒼玉（青みがかった玉）と美玉の二種類が記され、玉の質の豊かさを示す。

## 前後の山

| 前 | [[历山]]（槐、玉） |
|------|------|
| **当項** | **尸山（蒼玉、【上鹿下京】、尸水→南流注于洛水、美玉）** |
| 後 | [[良余之山]]（楮柞、無石、余水→北流注于河、乳水→東南流注于洛） |

历山から尸山まで東十里、尸山から良余之山まで東十里と、極めて短い間隔で山が連続する。尸山は洛水のみに注ぐが、次の良余之山は河と洛水の両方に水系を持つ分水嶺。
