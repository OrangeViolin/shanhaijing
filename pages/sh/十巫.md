# 十巫

**十巫**是《山海经·[[大荒西経]]》所载的十位巫师群体。居[[灵山]]——从此升降，百药爰在。（016-016）

## 原文出处

### 大荒西経·灵山

> 有灵山，巫咸、巫即、巫盼、巫彭、巫姑、巫真、巫礼、巫抵、巫谢、巫罗十巫，从此升降，百药爰在。
>
> （016-016）

### 海内西経·开明东

> 开明东有巫彭、巫抵、巫阳、巫履、巫凡、巫相，夹【上穴下契】窳之尸，皆操不死之药以距之。
>
> （012-021）

### 海外西経·巫咸国

> 巫咸国在女丑北，右手操青蛇，左手操赤蛇。在登葆山，群巫所从上下也。
>
> （007-013）

## 十巫名单

大荒西経记载的十位巫师：

巫咸、巫即、巫盼、巫彭、巫姑、巫真、巫礼、巫抵、巫谢、巫罗。

「十」未必是精确数目——可能是神圣数字的象征，如十日、十二月。

## 升降与百药

十巫的核心活动——「从此升降」：从灵山上下往返于天地之间。

「升」通天——传递神意与祭祀。「降」临人，带回药物与启示。灵山不是普通山岳，是天地之间的垂直通道。「百药爰在」，一切草药的来源都归于灵山与十巫的往来。医药知识在山海经的神话逻辑中，是通天技术的直接产物。（016-016）

## 两组巫师

山海经记载了两组巫师群体——名单有交叉但不相同：

| | 灵山十巫 | 开明东六巫 |
|--|---------|-----------|
| 出处 | 大荒西経 | 海内西経 |
| 地点 | 灵山 | 开明东 |
| 活动 | 升降，百药 | 操不死之药，守【上穴下契】窳之尸 |
| 人数 | 十 | 六 |
| PN | 016-016 | 012-021 |

两组共有巫彭和巫抵——其余全不同。灵山十巫掌管百药、往返天地，开明东六巫手持不死之药、守护死者。两组巫师、两种职能，但巫彭和巫抵同时出现在两组中，说明这两位巫师地位最高。

## 巫咸的特殊地位

十巫之首巫咸在海外西経有独立形象——右手操青蛇、左手操赤蛇。双蛇是神权的标志，青赤对应阴阳。巫咸不仅是十巫之一，还有自己的国（巫咸国）。个体扩展为了神圣政治单位。（007-013）

## 三座灵山

山海经中有三座叫「灵山」的山——内容完全不同：

| 出处 | 内容 |
|------|------|
| 大荒西経 | 十巫升降、百药爰在 |
| 海内経 | 赤蛇在木上 |
| 中山経 | 多金玉、果树 |

十巫的灵山是天地通道——其他两座只是普通山岳。「灵」字带来圣性，因此产生同名。

## 巫彭与巫抵：跨组共现的核心巫师与两组巫的职能分化

灵山十巫与开明东六巫的名单大部分不重叠——唯有巫彭和巫抵同时出现在两组中。这种跨组共现标记了两位巫师的特殊地位：

| 巫师 | 灵山十巫 | 开明东六巫 | 跨组 |
|------|---------|-----------|------|
| 巫咸 | ✓ | — | 否（但有巫咸国） |
| 巫即 | ✓ | — | 否 |
| 巫盼 | ✓ | — | 否 |
| **巫彭** | **✓** | **✓** | **是** |
| 巫姑 | ✓ | — | 否 |
| 巫真 | ✓ | — | 否 |
| 巫礼 | ✓ | — | 否 |
| **巫抵** | **✓** | **✓** | **是** |
| 巫谢 | ✓ | — | 否 |
| 巫罗 | ✓ | — | 否 |
| 巫阳 | — | ✓ | 否 |
| 巫履 | — | ✓ | 否 |
| 巫凡 | — | ✓ | 否 |
| 巫相 | — | ✓ | 否 |

两组巫的职能截然不同——灵山十巫「升降」（通天），开明东六巫「操不死之药以距之」（守尸复活）。巫彭和巫抵同时兼任通天与复活两种职能，是巫师群体中的核心成员，既能往返天地传递百药，也能守护[[窥窳]]之尸施行复活术。

巫咸虽然不在开明东六巫之列，却有独立的邦国（[[巫咸国]]）和个人形象（双手操蛇），其地位通过政治化（立国）而非跨组共现来体现。三种路径标记核心巫师：巫咸靠立国，巫彭和巫抵靠跨组——三人是十巫中最重要的三位。（016-016、012-021、007-013）
