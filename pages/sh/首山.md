# 首山

**首山**是《山海经·[[中山経]]》中次五経所载的重要山。阴多楮柞——阳多瑀玞之玉。阴有机谷——多【鸟大】鸟（食之已垫）。为【鬼申】级圣山——太牢+干舞+鼓+璧的最高祭祀。同时是首阳山系（九山二百六十七里）的起点。（005-043、005-056、005-140）

## 原文出处

《[[中山経]]》中次五経：

> 东三百里，曰首山，其阴多楮柞，其草多【上艹下术】芫，其阳多瑀玞之玉，木多槐。其阴有谷，曰机谷，多【鸟大】鸟，其状如录，食之已垫。
>
> （005-043）

> 首山，【鬼申】也，其祠用【禾余】、黑牺太牢之具、蘖酿；干儛，置鼓；婴用一璧。
>
> （005-056）

> 凡首阳山之首，自首山至于丙山，凡九山，二百六十七里。
>
> （005-140）

## 【鬼申】级祭祀

首山是中次五経中被标为「【鬼申】」的圣山——祭祀规格极高：

| 祭品 | 内容 |
|------|------|
| 牲 | 黑牺太牢（黑色牺牲的牛羊豕） |
| 食 | 【禾余】（粳米） |
| 酒 | 蘖酿（麹酒） |
| 舞 | 干儛（盾舞） |
| 乐 | 置鼓 |
| 玉 | 婴用一璧 |

太牢是最高规格的牲——还要加上干舞和鼓——这不只是祭祀——是仪式表演。中山経中有这种规格的山极少——首山是其中之一。（005-056）

## 机谷与【鸟大】鸟

首山的阴面有一条谷——叫机谷——住着【鸟大】鸟：

| 属性 | 内容 |
|------|------|
| 谷名 | 机谷 |
| 鸟名 | 【鸟大】鸟 |
| 形状 | 如录（如鹿） |
| 药效 | 食之已垫（治湿病） |

鹿一样的鸟——吃了能治湿气引起的病。鸟在山的阴面谷中——阴面多湿——住在湿处的鸟能治湿病——环境和药效对应。（005-043）

## 双山系结节

首山同时属于两个山系——薄山之首（中次五経）和首阳山系：

| 山系 | 角色 | 范围 |
|------|------|------|
| 中次五経（薄山之首） | 【鬼申】山 | 苟林之山→阳虚之山，十六山 |
| 首阳山系 | 起点山 | 首山→丙山，九山二百六十七里 |

一座山在两个山系中各有角色——中次五経中是祭祀圣山——首阳山系中是起点。中山経的山系编排是重叠的——不是线性的。（005-043、005-140）
