# 圣木曼兑

**圣木曼兑**是《[[海内西经]]》记载的灵树,位于[[昆仑]][[开明兽]]北方,与[[离朱]]、[[木禾]]、柏树、[[甘水]]并列。别名[[挺木牙交]]。圣木曼兑是《山海经》全书中唯一以「圣」字冠名的树木,标志着昆仑北方灵树群中最高等级的神圣属性。（012-020）

## 原文出处

《[[海内西经]]》：

> 开明北有视肉、珠树、文玉树、囗【王干】琪树、不死树。凤凰、鸾鸟皆戴【拔扌换盾】。又有离朱、木禾、柏树、甘水、圣木曼兑,一曰挺木牙交。
> （012-020）

## 「圣木」之名与「曼兑」之义

「圣木」二字在《山海经》中仅此一见。全书记载灵树数十种,[[不死树]]以功能命名,[[珠树]]以形态命名,[[文玉树]]以纹饰命名,唯圣木曼兑直接以「圣」定性,将其置于神圣秩序的核心。

「曼兑」的语义,历来无定论。「曼」有柔长、延展之义;「兑」为八卦之一,象征口与言说,又通「悦」。若取「曼」为柔长,「兑」为悦泽,则圣木曼兑或指一种枝叶柔长、光泽悦目的圣树。

别名「挺木牙交」提供了另一条线索。「挺」为直立,「牙交」为枝条交错如牙齿般咬合。两个名称一柔一刚,一写气质,一写形态,分别捕捉了这棵树的不同侧面。

## 开明北方的两层灵树群

开明兽北方的灵物记载分为两层,构成昆仑最密集的神圣植物区：（012-020）

**第一层**（五大灵树 + 神鸟）：

| 灵树 | 属性 |
|------|------|
| [[視肉]]| 不朽肉芝,再生之物 |
| [[珠树]] | 宝珠之树,物质宝藏 |
| [[文玉树]] | 文采之玉树,纹饰之美 |
| 囗【王干】琪树 | 琪玉之树,稀世之珍 |
| [[不死树]] | 不死之源,生命永续 |

第一层以凤凰、鸾鸟栖息其间作为收束,强调此处是神鸟与灵树共居的圣域。

**第二层**（五种灵物）：

| 灵物 | 属性 |
|------|------|
| [[离朱]] | 目力极远的神兽 |
| [[木禾]] | 昆仑上的巨穗神谷 |
| 柏树 | 长寿常青之木 |
| [[甘水]] | 甘美之水 |
| 圣木曼兑 | 唯一冠「圣」之树 |

第二层的构成更为多元：离朱是神兽,木禾是神粮,柏树是长寿木,甘水是灵泉,圣木曼兑是圣树。五种灵物分属视觉（离朱）、食粮（木禾）、耐久（柏）、甘泉（甘水）、神圣（圣木）五种功能,构成自给自足的神圣生态系统。圣木曼兑位于序列末尾,以「圣」字为全组定性,是这组灵物的精神顶点。

## 昆仑四方结构中的位置

[[开明兽]]居[[昆仑]]之巅,「身大类虎而九首,皆人面,东向立昆仑上」,守护昆仑的四方空间。四方的配置各有侧重：

| 方位 | 核心内容 | 属性 |
|------|---------|------|
| 西 | [[凤凰]]、鸾鸟（戴蛇践蛇,膺有赤蛇）| 瑞兽与蛇的共生 |
| 北 | 灵树群 + 圣木曼兑 | 神圣植物的密集区 |
| 东 | 巫彭等六巫 + [[窫窳]]之尸 + [[不死之药]] | 巫术与复生 |
| 南 | 树鸟、蛟蝮蛇豹 | 凶兽与蛇类 |

北方是四方中灵树种类最多、密度最高的区域,从不朽（不死树）到宝藏（珠树）到神圣（圣木曼兑）,层层递进。东方的六巫「操不死之药」呼应北方不死树的永生主题,南方与西方则以兽蛇为主。圣木曼兑所在的北方,是昆仑空间结构中最偏向植物神圣性的区域。
