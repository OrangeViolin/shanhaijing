# 师鱼

**师鱼**是《山海经·[[北山経]]》北次三経所载的毒鱼。栖息于饶山的歴虢之水中——食之杀人。（003-085）

## 原文出处

《[[北山経]]》北次三経：

> 历虢之水出焉，而东流注于河，其中有师鱼，食之杀人。
>
> （003-085）

## 食之杀人

师鱼的记述只有四字结论——「食之杀人」：

| 属性 | 内容 |
|------|------|
| 栖地 | 饶山·歴虢之水 |
| 水系 | 东流注于河（黄河） |
| 食效 | **杀人** |

山海経的鱼类绝大多数记「食之已XX」——食之治某某病。师鱼是极少数反过来的——不治病——杀人。「食之杀人」是山海経中最直接的致死警告——没有缓冲——没有条件——吃了就死。（003-085）

## 药效与毒效的对比

师鱼在山海経鱼类中的特殊地位——它是反面：

| 类型 | 代表 | 效果 |
|------|------|------|
| 药效鱼 | 大多数鱼 | 已疫、已痔、已疥、已狂… |
| **毒鱼** | **师鱼** | **杀人** |

药效鱼是山海経博物学的正面——告诉你什么可以吃。师鱼是反面——告诉你什么绝不能吃。这种正反并存说明山海経的鱼类记述具有实用指南的性质。（003-085）

## 饶山

师鱼栖息的饶山是北次三経末段的荒凉之山：

| 属性 | 内容 |
|------|------|
| 到达方式 | 山行五百里，水行五百里 |
| 草木 | 无 |
| 矿产 | 多瑶碧 |
| 鸟 | 多【留鸟】 |

山行五百里加水行五百里——极其偏远。无草木但多瑶碧（美玉）——荒山而有宝。水中有杀人的毒鱼——山有美玉而水有剧毒——宝与险并存。（003-085）
