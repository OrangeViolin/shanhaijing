# 后土

**后土**是《山海经》中的土地之神：[[共工]]之子，处于炎帝系谱系的关键位置。他的后裔噎鸣生「岁十有二」（十二个月份），他本人也是[[夸父]]的祖父。后土是连接水神（共工）与追日者（夸父）的世系枢纽。

## 原文出处

### 海内经

> 共工生后土，后土生噎鸣，噎鸣生岁十有二。
>
> （018-037）

### 大荒北经

> 后土生信，信生夸父。
>
> （017-015）

## 世系位置

```
炎帝 → … → 祝融 → 共工 → 后土 → 噎鸣 → 岁十有二（月份之神）
                                 └── 信 → 夸父
```

后土是共工（水神）之子、夸父（追日者）之祖。从火（[[祝融]]）到水（共工）到土（后土），炎帝系完成了五行三元素的神性演变。

## 两系分岐

后土生出两条线——噎鸣和信：

| 系统 | 后裔 | 功能 |
|------|------|------|
| 时间线 | 噎鸣→岁十有二 | 创造月份（时间秩序） |
| 英雄线 | 信→[[夸父]] | 追逐太阳（空间极限） |

一条创造了时间——一条挑战了空间。后土作为分岐点，同时指向秩序的建立和秩序的挑战。（018-037、017-015）

## 两部经文的互补

海内经写后土的时间线——大荒北经写后土的英雄线：

| | 海内经 | 大荒北经 |
|--|--------|----------|
| 内容 | 后土→噎鸣→岁十二 | 后土→信→夸父 |
| 主题 | 月份起源 | 追日血脉 |
| PN | 018-037 | 017-015 |

同一个后土——两部经文各写一半。合在一起才是完整的后土。山海经把同一人物的信息分散在不同篇章——这是它的结构特征。（018-037、017-015）
