# 后土

**后土**是《山海经》中的土地之神——[[共工]]之子，处于炎帝系谱系的关键位置。他的后裔噎鸣生「岁十有二」（十二个月份），他本人也是[[夸父]]的祖父。后土是连接水神（共工）与追日者（夸父）的世系枢纽。

## 原文出处

引注：（018-037）

> 共工生后土，后土生噎鸣，噎鸣生岁十有二。

引注：（017-015）

> 后土生信，信生夸父。

## 世系位置

```
炎帝 → … → 祝融 → 共工 → 后土 → 噎鸣 → 岁十有二（月份之神）
                                 └── 信 → 夸父
```

后土是共工（水神）之子、夸父（追日者）之祖。从火（[[祝融]]）到水（共工）到土（后土），炎帝系完成了五行三元素的神性演变。

## 神话意义

后土兼具两条线索：**时间线**（噎鸣生岁十二——月份的起源）和**英雄线**（信生夸父——追日者的血脉来源）。作为土地之神，后土代表了大地的生育力——不仅生育后代，还「生育」了时间（月份）。这使后土成为炎帝系从自然力（火/水/土）向时间秩序过渡的关键节点。
