# 黑虫如熊状

**黑虫如熊状**は[[大荒北経]]に記載される獣である。熊のような姿をした黒い虫で、名を**猎猎**という。[[叔【蜀欠】国]]の近傍に棲息する。（017-007）

## 原文出処

《[[大荒北経]]》：

> 有黑虫如熊状，名曰猎猎。
> （017-007）

## 形態描述

熊に似た黒い体を持つ。「虫」は古語で動物全般を指すこともあり、実態は熊に似た獣と解される。

## 叔【蜀欠】国の文脈

猎猎は[[叔【蜀欠】国]]の条に付記される。叔【蜀欠】国は顓頊の子の国で、黍を食し虎・豹・熊・羆の四獣を使役する。

| 要素 | 内容 |
|------|------|
| 邦国 | [[叔【蜀欠】国]] |
| 系譜 | [[颛顼]]の子 |
| 食物 | 黍 |
| 使役獣 | 虎・豹・熊・羆 |
| 付近の異獣 | 猎猎（黒い熊状の虫） |

叔【蜀欠】国が使役する四獣の中に熊が含まれ、付近に熊状の黒虫（猎猎）が棲む。猎猎は使役獣の熊とは別個に記されるが、熊が身近な環境にいることと呼応する。「使四鳥」パターン（帝俊系の邦国に多い）に対して「使四獣」は顓頊系に見られ、猎猎はその獣的環境の一部として位置づけられる。
