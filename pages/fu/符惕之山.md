# 符惕之山

**符惕之山**是《山海经·[[西山经]]》西次三经所载的山峰。山上多棕【木丹】，山下多金玉。神[[江疑]]居于此。多怪雨，是风云生发之所。（002-109）

## 原文出处

《[[西山经]]》西次三经：

> 又西二百里，曰符惕之山，其上多棕【木丹】，下多金玉。神江疑居之。是山也，多怪雨，风云之所出也。
>
> （002-109）

## 怪雨风云

符惕之山是一座气象异常的山——「多怪雨，风云之所出也」：

| 特征 | 描述 |
|------|------|
| 怪雨 | 多 |
| 风云 | 从此山生出 |

「风云之所出」——风和云从这座山里产生。《山海经》中指定风或云的发源地极为罕见（[[中谷]]出条风是另一例）。符惕之山不只是被动承受天气，而是主动制造天气——它是风云的工厂。「怪雨」——不是普通的雨，是怪异的雨。神居其上，怪雨从天降——神的居所自然有超常的气象。（002-109）

## 神江疑

符惕之山的主人是神江疑：

| 要素 | 内容 |
|------|------|
| 身份 | 神 |
| 名号 | 江疑 |
| 居所 | 符惕之山 |

「神江疑居之」——江疑是这座山的常驻神灵。《山海经》中神「居」山意味着这是神的永久住所，不是路过。怪雨和风云很可能与江疑的神力有关——神在此居住，山就成了气象异常的中心。（002-109）

## 西方神域

符惕之山位于西次三经末段的神灵密集区——连续多座山各有一位大神：

| 山 | 居神 |
|----|------|
| 长留之山 | 白帝少昊 |
| 章莪之山 | 狰（异兽） |
| 阴山 | 天狗 |
| **符惕之山** | **神江疑** |
| [[三危之山]] | 三青鸟 |
| 【马鬼】山 | 神耆童 |
| 天山 | 帝江 |
| 【氵幼】山 | 神蓐收 |

少昊→江疑→耆童→帝江→蓐收——五位神灵在七座山内依次排列。符惕之山是这条神链的第二环——从帝王级（少昊）开始，到怪雨之神（江疑），再到钟磬之神（耆童），最后到浑沌歌舞之神（帝江）和西方之神（蓐收）。（002-109）

## 上棕下金

符惕之山的物产分为上下两层：

| 层 | 物产 |
|----|------|
| 山上 | 棕【木丹】 |
| 山下 | 金玉 |

棕和【木丹】是南方常见的树种——棕榈和紫檀。在西方深处的山上长着南方的树——这本身就是一种「怪」。山下有金玉——神的居所之下藏着最贵重的矿物。（002-109）

## 西次三経の「気象源山」：符惕之山の「風雲之所出」が示す山海経の気象起源論

「風雲之所出也」は五藏山経で気象現象の発生源を明示する最も直接的な記述であり、符惕之山は山海経の気象起源論の中で独自の位置を占める：

| 山 | 気象記述 | 原因 | 神の関与 | 出処 |
|----|---------|------|---------|------|
| **符惕之山** | **多怪雨、風雲之所出** | **神[[江疑]]居之** | **直接（常駐神）** | **002-109** |
| [[景山]] | 有鸟——見則天下大水 | 鸟の出現＝予兆 | 間接（獣の兆） | 003-068 |
| [[令丘之山]] | 多火 | 地質的 | なし | 001-037 |

景山の鸟は天候を「予告」するだけだが、符惕之山は風雲を「産出」する——予兆と発生源の違いは根本的である。「怪雨」という修飾も注目に値する——普通の雨ではなく異常な雨であり、神の居所から降る雨は超自然的性質を帯びる。

西次三経末段の神鎖（白帝少昊→江疑→耆童→帝江→蓐収）の中で、江疑は気象を司る神として位置づけられる。少昊が西方の帝王、蓐収が西方の刑神であるのに対し、江疑は西方の気象神——西次三経は西方世界の統治（少昊）・気象（江疑）・音楽（耆童）・混沌（帝江）・刑罰（蓐収）という五つの職能を五座の山に配分している。（002-109）
