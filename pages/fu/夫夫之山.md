# 夫夫之山

**夫夫之山**是《山海经·[[中山経]]》中次十二経（洞庭山系）所载的山。多黄金、青雄黄——神[[于儿]]居之——人身操两蛇——游于江渊——出入有光。四冢山之一。（005-195）

## 原文出处

《[[中山経]]》中次十二経：

> 又东一百五十里，曰夫夫之山，其上多黄金，其下多青雄黄，其木多桑楮，其草多竹、鸡鼓。神于儿居之，其状人身而身操两蛇，常游于江渊，出入有光。
>
> （005-195）

> 凡洞庭山之首，自篇遇之山至于荣余之山，凡十五山，二千八百里。……凡夫夫之山、即公之山，尧山、阳帝之山皆冢也。
>
> （005-204）

## 神于儿

夫夫之山的神——于儿——山海经中极少数「出入有光」的神：

| 属性 | 内容 |
|------|------|
| 形态 | 人身 |
| 持物 | 两手操蛇 |
| 习性 | 常游于江渊 |
| 特异 | 出入有光 |

人身操蛇是山海经神灵的常见标配——但「常游于江渊、出入有光」极为罕见。于儿不是守在山上的山神——而是在江水深渊中游弋的水神。每次出入水面都发出光芒——是一个发光的水中游神。（005-195）

## 四冢山

夫夫之山是洞庭山系四座冢山之一——冢是最高祭祀等级：

| 冢山 | 特征 |
|------|------|
| **夫夫之山** | 神于儿居之 |
| 即公之山 | — |
| 尧山 | 帝尧之名 |
| [[阳帝之山]] | 帝之名 |

四座冢山中——尧山和阳帝之山都冠帝王之名——夫夫之山和即公之山以普通名字跻身冢格——靠的是神灵（于儿）的分量。（005-204）

## 上下分层

| 位置 | 物产 |
|------|------|
| 山上 | 黄金 |
| 山下 | 青雄黄 |
| 木 | 桑、楮 |
| 草 | 竹、鸡鼓 |

黄金在上——青雄黄在下——颜色从金到青绿。桑可养蚕——楮可造纸——竹可编器——鸡鼓（一种药草）。物产丰富而实用。（005-195）
