# 【阝是】山

**【阝是】山**是《山海经·[[北山经]]》北次一经所载的山峰，经脉末山。多马有兽[[【犭幼】]]，状如豹而文首。【阝是】水出焉，东流注于泰泽，水中多龙龟。（003-025）

## 原文出处

《[[北山经]]》北次一经：

> 又北百七十里，曰【阝是】山，多馬。有獸焉，其狀如豹而文首，名曰【犭幼】。【阝是】水出焉，而東流注于泰澤，其中多龍龜。
>
> （003-025）

## 多马

【阝是】山最先提到的物产马：

| 属性 | 内容 |
|------|------|
| 产物 | 多马 |

山海经山经中记载「多马」的山不多马是人类最重要的役畜之一。【阝是】山多马这是一座与人类活动密切相关的山。（003-025）

## 【犭幼】

【阝是】山的异兽豹形文首：

| 属性 | 内容 |
|------|------|
| 名称 | [[【犭幼】]] |
| 形态 | 状如豹而文首 |

如豹猎食者的身形。文首头上有花纹。豹本身就有斑纹「文首」强调头部的纹饰特别突出。（003-025）

## 龙龟

【阝是】水中的异物龙龟：

| 要素 | 内容 |
|------|------|
| 水名 | 【阝是】水 |
| 流向 | 东流 |
| 注入 | 泰泽 |
| 水产 | 龙龟 |

龙龟龙与龟的合体。龙在水中，龟也在水中两种水族合为一物。水流入泰泽（大泽）龙龟栖息在通向大泽的水路中。（003-025）

## 经脉末山

【阝是】山是北次一经的最后一座山二十五山的终点：

| 要素 | 内容 |
|------|------|
| 起点 | 单狐之山 |
| 终点 | 【阝是】山 |
| 山数 | 二十五山 |
| 里程 | 五千四百九十里 |
| 山神 | 人面蛇身 |

作为末山，【阝是】山收束了北次一经的全部山列。经文紧接着给出总括二十五山的神都是人面蛇身，祭祀用雄鸡和彘。（003-025至003-026）
