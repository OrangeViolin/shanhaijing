# 【阝是】水

**【阝是】水**出《山海经·[[北山経]]》北次一経[[【阝是】山]]东流注于[[泰泽]]水中多龙龟。（003-025）

## 原文出处

《[[北山経]]》北次一経：

> 又北百七十里，曰【阝是】山，多马。有兽焉，其状如豹而文首，名曰【犭幼】。【阝是】水出焉，而东流注于泰泽，其中多龙龟。
>
> （003-025）

## 龙龟之水

【阝是】水中多龙龟龙与龟的合体：

| 属性 | 内容 |
|------|------|
| 水产 | 龙龟（多） |
| 流向 | 东流 |
| 注入 | 泰泽 |

龙龟龙头龟身或龟形带龙的特征。龙在天龟在水龙龟是天水合一的生物。【阝是】水中多龙龟不是一两只而是很多整条河里都是龙龟。（003-025）

## 泰泽汇流

【阝是】水东流注入[[泰泽]]泰泽是北次一経/北次三経的终极汇水区：

三条水从不同方向汇入泰泽【阝是】水从正西方东流是三条中最直接的一条。每条水带来不同的水产【氵襄】泽之水有【鱼巢】鱼【阝是】水有龙龟泰泽汇集了北方山脉的一切异兽。（003-025）

## 【阝是】山：北次一経末山

【阝是】水出自[[【阝是】山]]北次一経的最后一座山：

| 属性 | 内容 |
|------|------|
| 山名 | 【阝是】山 |
| 地位 | 北次一経末山（第25山） |
| 动物 | 多马，有【犭幼】（豹形文首） |
| 水系 | 【阝是】水 |

【阝是】山是北次一経二十五山的最后一座山上多马有豹形异兽水中多龙龟。末山的水流向泰泽整条经脉以泰泽为终点。（003-025）
