# 【钅享】于毋逢之山

**【钅享】于毋逢之山**是《山海经·[[北山経]]》北次三経所载的山。北望鸡号之山西望[[幽都之山]]浴水出焉有[[朋蛇]]赤首白身见则大旱。（003-091）

## 原文出处

《[[北山経]]》北次三経：

> 又北五百里，曰【钅享】于毋逢之山，北望鸡号之山，其风如【左风右三力】。西望幽都之山，浴水出焉。是有朋蛇，赤首白身，其音如牛，见则其邑大旱。
>
> （003-091）

## 朋蛇

朋蛇是一条赤白二色的蛇：

| 属性 | 内容 |
|------|------|
| 首 | 赤色 |
| 身 | 白色 |
| 声音 | 如牛 |
| 预兆 | 见则其邑大旱 |

赤首白身蛇叫得像牛出现就大旱。蛇本应与水相关这条蛇却预兆干旱。赤色的头火的颜色旱灾的象征。白色的身干枯的颜色旱的另一面。（003-091）

## 三望之山

这座山的描写不是从山本身开始而是从「望」开始：

| 方向 | 所望 |
|------|------|
| 北 | 鸡号之山 |
| 西 | [[幽都之山]] |

北望鸡号之山风像【左风右三力】（狂风）。西望幽都之山幽都是黑暗之地。这座山被放在了两座重要地标之间用「望」来定位像是一个瞭望台。山海経通常描写山的物产和动物【钅享】于毋逢之山先写看到什么再写住着什么。（003-091）
