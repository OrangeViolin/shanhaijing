# 【马鬼】山

**【马鬼】山**是《山海经》中至少四座同名山。[[西山経]]两座西次一経末山（临西海）和西次三経（神耆童居之）。[[中山経]]两座中次三経（有飞鱼）和中次九経（冢山）。中次十経的【马鬼】山更被称为「帝也」山海经中最高的祭祀等级。

## 原文出处

### 西次一経（末山）

> 又西二百五十里，曰【马鬼】山，是【钅享】于西海，无草木，多玉。【氵妻】水出焉，西流注于海。
>
> （002-019）

### 西次三経

> 又西一百九十里，曰【马鬼】山，其上多玉而无石。神耆童居之，其音常如钟磬。其下多积蛇。
>
> （002-057）

### 中次三経

> 又东十里，曰【马鬼】山，其上有美枣。正回之水出焉，而北流注于河。其中多飞鱼，其状如豚而赤文，服之不畏雷，可以御兵。
>
> （005-028）

### 中次九経

> 文山、勾【木尔】、风雨、【马鬼】之山，是皆冢也。
>
> （005-130）

### 中次十経（帝也）

> 【马鬼】山，帝也，其祠羞酒，太牢其巫祝二人儛，婴一璧。
>
> （005-140）

## 四山对比

| | 西次一経 | 西次三経 | 中次三経 | 中次九経 |
|--|---------|---------|---------|---------|
| 位置 | 临西海 |  |  |  |
| 物产 | 多玉 | 多玉无石 | 美枣、飞鱼 |  |
| 特殊 | 末山 | 耆童居之 | 御兵之鱼 | 冢山 |
| PN | 002-019 | 002-057 | 005-028 | 005-130 |

四座【马鬼】山各有不同但都与「玉」或「祭祀」相关。（002-019、002-057、005-028、005-130）

## 耆童之山

西次三経的【马鬼】山神[[耆童]]居之：

| 属性 | 内容 |
|------|------|
| 居者 | 神耆童 |
| 声音 | 常如钟磬 |
| 山下 | 多积蛇 |

这座山的声音永远像钟磬在响耆童的声音就是山的声音。山下堆满了蛇。神在山上蛇在山下。（002-057）

## 帝也

中次十経的【马鬼】山被称为「帝也」比「冢」更高一级的祭祀等级：

| 等级 | 含义 | 祭品 |
|------|------|------|
| 帝 | 最高 | 羞酒、太牢、巫祝二人舞、一璧 |
| 冢 | 次高 | 少牢具、一璧 |
| 普通 | 标准 | 一羊 |

帝需要两位巫祝跳舞。山海经中被称为「帝也」的山极少【马鬼】山是其中之一。（005-140）

## 飞鱼

中次三経的【马鬼】山有飞鱼如豚而赤文：

| 属性 | 内容 |
|------|------|
| 形态 | 如豚，赤色花纹 |
| 功效 | 服之不畏雷，可以御兵 |

吃了不怕雷还能防御兵器。一条鱼同时防天灾和人祸。（005-028）

## 同名四山的祭祀递阶：从普通山到「帝也」

四座【马鬼】山中，最引人注目的不是任何一座的物产或居者，而是它们在祭祀等级上的分化。西山经两座和中次三经一座都是普通山只有中次十经的【马鬼】山被冠以「帝也」，享受最高规格的祭祀：

| 山 | 篇章 | 祭祀等级 | 祭品规格 |
|------|------|---------|---------|
| 【马鬼】山 | 西次一经 | 普通 |  |
| 【马鬼】山 | 西次三经 | 普通 |  |
| 【马鬼】山 | 中次三经 | 普通 |  |
| 【马鬼】山 | 中次九经 | 冢 | 少牢、一璧 |
| **【马鬼】山** | **中次十经** | **帝** | **羞酒、太牢、二巫祝舞、一璧** |

同一个名字的山，祭祀等级从无到「冢」再到「帝」，跨越了《山海经》祭祀体系的全部层级。「帝也」意味着这座山被视为帝级存在不是供奉某位帝的庙，而是山本身就是帝。需要两位巫祝跳舞、太牢（牛羊猪全牲）、美酒、一块玉璧这是五藏山经中最隆重的祭礼。

西次三经的【马鬼】山有神[[耆童]]居住，却没有「帝」的祭格；中次十经的【马鬼】山没有记载任何居者，却获得了最高祭格。这说明「帝也」的等级不来自山上住着谁，而来自山本身的神圣性名为【马鬼】的山在不同山系中逐步积累神圣性，最终在中次十经达到顶点。（002-019、002-057、005-028、005-130、005-140）
