# 昆吾之山

**昆吾之山**是《山海经·[[中山经]]》中次二经所载的山峰。山上多赤铜。有异兽蠪蛭——如猪有角，音如号哭，食之不做恶梦。（005-022）

## 原文出处

《[[中山经]]》中次二经：

> 又西二百里，曰昆吾之山，其上多赤铜。有兽焉，其状如彘而有角，其音如号，名曰【上龙下虫】【虫氏】，食之不眯。
>
> （005-022）

## 赤铜

昆吾之山产赤铜——红色的铜：

| 要素 | 内容 |
|------|------|
| 矿产 | 赤铜 |
| 山名 | 昆吾 |

「昆吾」在古代与名剑相关——昆吾剑是传说中的神兵。昆吾之山产赤铜——铜是铸剑的原料。以「昆吾」命名的产铜之山，暗示这里是铸造神兵的矿源。赤铜是含杂质较少的高品位铜——红色代表纯度。（005-022）

## 蠪蛭

昆吾之山的异兽——蠪蛭：

| 特征 | 描述 |
|------|------|
| 形态 | 如猪 |
| 异处 | 有角 |
| 叫声 | 如号（号哭） |
| 药效 | 食之不眯（不做恶梦） |

「如彘而有角」——猪的身体上长着角。猪本没有角——角是多出来的武器。「其音如号」——叫声像号哭，是悲伤的声音。「食之不眯」——吃了就不做恶梦。一只号哭的有角猪能让人安眠——它把恶梦承担在自己的哭声里。（005-022）

## 伊水系的无水山

昆吾之山没有水系记载，夹在两座伊水支流山之间：

| 山 | 水 | 汇入 |
|----|-----|------|
| 阳山 | 阳水 | 北流注于伊水 |
| **昆吾之山** | **无** | **—** |
| 荔山 | 荔水 | 北流注于伊水 |

阳水入伊、荔水入伊——两条水从两座山北流汇入伊水。昆吾之山夹在中间却不出水——它是伊水支流网中的一个空洞。有铜无水——矿山不出水，只出金属。（005-022）

## 一山一异

中次二经的这段山列中，每座山各有一种特异的存在：

| 山 | 异物 | 性质 |
|----|------|------|
| 鲜山 | 鸣蛇——四翼如磬，见则大旱 | 凶兆 |
| 阳山 | 化蛇——人面豺身鸟翼，见则大水 | 凶兆 |
| **昆吾之山** | **蠪蛭——猪形有角，不眯** | **药效** |
| 荔山 | 芒草——可以毒鱼 | 实用 |

从凶兆（大旱、大水）到药效（不恶梦）到实用（毒鱼）——异物的性质从危险转为有益。昆吾之山是这条转折线上的转折点——从预示灾难变成提供安眠。（005-022）
