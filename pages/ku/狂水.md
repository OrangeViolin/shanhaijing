# 狂水

**狂水**是《山海经》中两条同名异水。[[北山经]]——出[[狂山]]，西流注于浮水，多美玉（003-033）。[[中山经]]——出[[大【上非下古】之山]]阳面，西南流注于[[伊水]]，多三足龟（005-077）。

## 原文出处

### 北山经（狂山）

> 又北三百八十里，曰狂山，无草木，是山也，冬夏有雪。狂水出焉，而西流注于浮水，其中多美玉。
>
> （003-033）

### 中山经（大【上非下古】之山）

> 其阳狂水出焉，西南流注于伊水，其中多三足龟，食者无大疾，可以已肿。
>
> （005-077）

## 两条狂水

同名「狂」——产物完全不同：

| | 北山经狂水 | 中山经狂水 |
|--|-----------|-----------|
| 源山 | [[狂山]] | [[大【上非下古】之山]] |
| 流向 | 西流 | 西南流 |
| 注入 | 浮水 | [[伊水]] |
| 水产 | 美玉（矿物） | 三足龟（药物） |
| 源山环境 | 无草木冬夏有雪 | 多玉多草 |

一条出矿——一条出药。一条来自冰封荒山——一条来自温带丰山。「狂」字也许形容水流的猛烈——同样猛烈的水在不同的环境里产出不同的东西。（003-033、005-077）

## 三足龟

中山经狂水的特产——异形却有药效：

| 属性 | 内容 |
|------|------|
| 形态 | 三足（缺一足） |
| 药效 | 食者无大疾、可以已肿 |

三只脚的龟——残缺的身体却能治病。这是山海经常见的模式：异形反而有药力。（005-077）
