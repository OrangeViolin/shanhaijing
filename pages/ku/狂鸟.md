# 狂鸟

**狂鸟**是《山海经·[[大荒西经]]》所载的神鸟。五彩之鸟，头戴冠。（016-020）

## 原文出处

《[[大荒西经]]》：

> 有五采之鸟，有冠，名曰狂鸟。
>
> （016-020）

## 五彩有冠

狂鸟的两个特征——五彩和有冠：

| 特征 | 描述 |
|------|------|
| 色彩 | 五采（五彩） |
| 头饰 | 有冠 |

「五采之鸟」——《山海经》中五彩鸟通常与凤凰类关联。「有冠」——头上有冠是鸟中的王者标志。凤凰的核心特征之一就是有冠。狂鸟以五彩和冠两项凤凰特征自居，但它不叫凤——它叫「狂」。（016-020）

## 「狂」之名

「狂」——疯狂、放纵、不羁：

| 五彩鸟 | 名字 | 性格 |
|--------|------|------|
| 凤凰 | 凤 | 祥瑞 |
| [[鸣鸟]] | 鸣 | 仰天而鸣 |
| **狂鸟** | **狂** | **狂放** |

凤凰是秩序的象征，鸣鸟是歌唱的象征，狂鸟是失序的象征。同样是五彩之鸟，凤凰端庄，狂鸟狂放——它拥有凤凰的外表（五彩有冠）却不拥有凤凰的品性。（016-020）

## 前后文脉

狂鸟夹在两个非凡的存在之间：

| 位置 | 内容 |
|------|------|
| 前 | 石夷——处西北隅，司日月之长短 |
| **此** | **狂鸟——五彩有冠** |
| 后 | 大泽之长山、白氏之国 |

石夷是掌管日月长短（昼夜节律）的神人——宇宙秩序的守护者。狂鸟紧跟在秩序之神后面出现——秩序与狂放的并置。石夷司理天象的规律，狂鸟以「狂」打破规律——两者形成张力。（016-020）

## 极简记述

狂鸟的全部记载只有一句话——「有五采之鸟，有冠，名曰狂鸟」：

| 项目 | 有无 |
|------|------|
| 形态 | 五彩有冠 |
| 大小 | 无 |
| 叫声 | 无 |
| 习性 | 无 |
| 凶兆/祥兆 | 无 |

没有凶兆也没有祥兆——狂鸟不预示任何事情。它只是存在——五彩有冠地存在于大荒之西。不服务于任何预兆系统，不承担任何象征功能——「狂」就是自由存在本身。（016-020）
