# 昆仑南渊

**昆仑南渊**是《山海经·[[海内西经]]》所载的水域。昆仑之南——深三百仞。[[开明兽]]身大如虎而九首皆人面，东向立于昆仑之上。（012-018）

## 原文出处

《[[海内西经]]》：

> 昆仑南渊深三百仞。开明兽身大类虎而九首，皆人面，东向立昆仑上。
>
> （012-018）

## 深三百仞

昆仑南渊深三百仞——昆仑山系中唯一有深度数据的水域：

| 要素 | 数据 |
|------|------|
| 方位 | 昆仑之南 |
| 深度 | 三百仞 |

三百仞——极深的水。昆仑之虚「高万仞」，南渊「深三百仞」——山高万仞，水深三百仞，一上一下，构成昆仑的垂直维度。南面是深渊——从南方接近昆仑，首先遇到的是一道深不见底的水障。（012-018）

## 开明兽

开明兽守在昆仑之上——九首皆人面，东向而立：

| 特征 | 内容 |
|------|------|
| 身 | 大类虎 |
| 首 | 九首，皆人面 |
| 朝向 | 东向 |
| 位置 | 立昆仑上 |

九个人脸的虎身巨兽——面朝东方站着。东方是日出的方向——开明兽的九张人脸都朝着日出处。「开明」——打开光明——名字本身就指向东方和光。它站在昆仑上，背后是南面的深渊。（012-018）

## 昆仑四方

昆仑南渊是海内西经描述昆仑四方的起点——从南开始顺时针巡游：

| 方位 | 内容 |
|------|------|
| **南** | **深渊三百仞，开明兽** |
| 西 | 凤凰、鸾鸟，戴蛇践蛇 |
| 北 | 视肉、珠树、不死树 |
| 东 | 巫彭等六巫，操不死之药 |

南（深渊与守兽）→西（瑞鸟）→北（不死之物）→东（巫与不死药）——昆仑的四面各有不同的属性。南面最险——深渊加守兽。北面最丰——不死树和视肉。南面拦住外人，北面藏着至宝。（012-018至012-021）
