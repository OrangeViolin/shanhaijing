# 隗山

**隗山**は山海経に2箇所登場する同名の山。

## 原文出処

> 又東五百里，曰隗山，谷多金錫。
> （005-050）

## 地理描述

隗山は谷に金と錫が多い山である。記述は簡潔で、鉱物資源のみが言及される。

## 中次五経の隗山

中次五経に記される。（005-050）東五百里に位置し、谷に金と錫が多い。中次五経の山々の中でも特に簡潔な記述で、獣・鳥・水系の記載がない。

## 大荒南経の隗山

[[大荒南経]]に「又有隗山，其西有丹，其東有玉」と記される。（011-007）[[不姜之山]]山群の一つで、西に丹（朱砂）、東に玉を産する。同じ山群に[[蒲山]]（[[澧水]]の源）・[[尾山]]・翠山が並ぶ。中次五経の隗山（金錫）とは産物が異なる。

## 二同名山の比較

| 項目 | 中次五経の隗山 | 大荒南経の隗山 |
|------|---------------|---------------|
| 出典 | 中山経（line 336） | 大荒南経（line 630） |
| 位置 | 東五百里 | [[不姜之山]]山群内 |
| 産物 | 金・錫（谷） | 丹（西）・玉（東） |
| 記述量 | 一文のみ | 山群の一として列挙 |
| 周辺 | 記載なし | 蒲山・尾山・翠山・言山・登備之山 |

両者とも鉱物を産する山であるが、中次五経は金属（金錫）、大荒南経は非金属（丹・玉）と、鉱物の種類が異なる。中次五経の隗山は山系内で孤立した簡潔な記述であるのに対し、大荒南経の隗山は不姜之山を中心とする密集山群の一員として東西の鉱物配置（西丹・東玉）が明記される。

## 不姜之山山群の構成

大荒南経の隗山が属する山群は、黒水の窮まる不姜之山を起点とする。

| 山名 | 産物・特徴 |
|------|-----------|
| [[不姜之山]] | 黒水の終点 |
| [[贾山]] | 汔水の源 |
| 言山 | 記載なし |
| 登備之山 | 記載なし |
| 恝恝之山 | 記載なし |
| [[蒲山]] | 澧水の源 |
| 隗山 | 西に丹、東に玉 |
| [[尾山]] | 記載なし |
| 翠山 | 記載なし |

九山が連続して列挙される密集地帯であり、多くの山は名前のみで産物の記載がない。隗山は丹と玉の東西配置が明記される数少ない山であり、この山群内で鉱物情報の核をなす。
