# 嵩山

**嵩山**是五岳之中岳。《山海经·[[海内東経]]》记「颖水出[[少室]]，少室山在雍氏南」——[[少室]]山是嵩山的西峰——颖水的源头。（014-012）

## 原文出处

《[[海内東経]]》：

> 颖水出少室，少室山在雍氏南，入淮西鄢北。一曰缑氏。
>
> （014-012）

## 少室与颖水

海内東経以水系来记录嵩山——少室山是颖水的水源：

| 属性 | 内容 |
|------|------|
| 山 | 少室（嵩山西峰） |
| 水 | 颖水 |
| 位置 | 雍氏南 |
| 入处 | 淮西鄢北 |

「颖水出少室」——嵩山在海内東経中的存在方式是作为水源——不是作为圣山或祭祀场所——而是水系地理的一个节点。少室山在雍氏（今河南登封）的南面。（014-012）

## 中山経的祭祀格

嵩山在中山経中以太室和少室的双峰形态出现——享受最高规格的祭祀：

| 峰 | 地位 | 祭祀 |
|----|------|------|
| 太室 | 东峰 | 太牢之具，婴以吉玉 |
| 少室 | 西峰 | 太牢之具，婴以吉玉 |

中次七経末尾记「苦山少室太室皆冢也」——三山都是主峰（冢）——享太牢大祭。山神「皆人面而三首」——三头人面的神格。海内東経只记水源——中山経记祭祀——同一座山在两经中的叙事功能完全不同。
