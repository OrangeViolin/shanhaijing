# 【土熏】民之国

**【土熏】民之国**是《山海经·[[大荒東経]]》所载的国。周围有綦山、摇山、【融虫换曾】山、门户山、盛山、待山六座山，有五采之鸟。（015-031）

## 原文出处

《[[大荒東経]]》：

> 有【土熏】民之国。有綦山。又有摇山。有【融虫换曾】山，又有门户山，又有盛山。又有待山。有五采之鸟。
>
> （015-031）

## 六山环绕

【土熏】民之国的独特之处是周围列出了六座山，大荒経中少见的密集山群：

| 山 |
|----|
| 綦山 |
| 摇山 |
| 【融虫换曾】山 |
| 门户山 |
| 盛山 |
| 待山 |

一个国被六座山环绕，大荒経的国通常只提到一两座山或不提山。六山连续列举，暗示这个国处于山地密集的区域。山名各有特色，门户山暗示出入口，盛山暗示丰盛，但经文没有进一步描述每座山的特征。（015-031）

## 五采之鸟

六山之后提到「有五采之鸟」，五色的鸟：

| 属性 | 内容 |
|------|------|
| 鸟 | 五采之鸟 |
| 含义 | 五色=祥瑞 |

五采（五色）之鸟是山海経中的瑞禽标记，与凤鸟类似。六山+五色鸟，山多鸟美，【土熏】民之国是一个物产丰富的区域。经文对国民本身没有任何描述，全部笔墨给了地理环境。（015-031）
