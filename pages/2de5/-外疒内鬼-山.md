# 【外疒内鬼】山

**【外疒内鬼】山**是《山海经·[[中山経]]》中次六経所载的山。阴面多[[瑀玞之玉]]西有[[帙谷]]谷中有[[【令鸟】【要鸟】]]山鸡形长尾赤如丹火青喙服之不眯。交觞之水出于阳南流于洛俞随之水出于阴北流注于谷水。（005-059）

## 原文出处

《[[中山経]]》中次六経：

> 又西十里，曰【外疒内鬼】山，其阴多【王雩】【王孚】之玉。其西有谷焉，名曰帙谷，其木多柳楮。其中有鸟焉，状如山鸡而长尾，赤如丹火而青喙，名曰【令鸟】【要鸟】，其鸣自呼，服之不眯。交觞之水出于阳，而南流于洛；俞随之水出于其阴，而北流注于谷水。
>
> （005-059）

## 丹火之鸟

[[帙谷]]中的[[【令鸟】【要鸟】]]是中山経最艳丽的鸟之一：

| 属性 | 内容 |
|------|------|
| 形状 | 如山鸡 |
| 尾 | 长尾 |
| 颜色 | 赤如丹火 |
| 喙 | 青色 |
| 鸣声 | 自呼（叫自己的名字） |
| 药效 | 服之不眯（不嗜睡） |

全身赤如丹火唯独喙是青色。红中一点青极强的视觉对比。山鸡形加长尾像孔雀开屏的轮廓。服之不眯吃了不会嗜睡和[[冉遗之鱼]]（食之使人不眯）功效相同。山海経中「不眯」药效的生物极少丹火之鸟是其中之一。（005-059）

## 南北分水

【外疒内鬼】山是一座分水山两条水从山的阴阳两面分别流向南北：

| 水 | 出处 | 流向 | 注入 |
|----|------|------|------|
| 交觞之水 | 山之阳（南面） | 南流 | 洛水 |
| 俞随之水 | 山之阴（北面） | 北流 | 谷水 |

阳面水南流入洛阴面水北流入谷水。洛水和谷水都是中原大河【外疒内鬼】山正好骑在分水岭上。一座山两条水南北分流这是典型的秦岭式分水格局。中次六経记录的正是洛水流域的山系。（005-059）

## 中次六経における分水山の構造

中次六経は洛水流域の山系を記録するが、【外疒内鬼】山のように阳面と阴面から異なる水系へ水を送る「分水山」は特殊な地理的位置を占める：

| 山 | 阳面水 | 阴面水 | 分水 |
|----|--------|--------|------|
| [[缟羝之山]] |  |  | 非分水 |
| **【外疒内鬼】山** | **交觞之水→洛** | **俞随之水→谷水** | **南北分水** |
| [[廆山]] |  |  | 非分水 |

中次六経の大半の山は一方向に水を流すが、【外疒内鬼】山は洛水系と谷水系の分水嶺に位置する。山経において分水山は地理的結節点であり、その山に配置される異類（【令鸟】【要鸟】）も二つの水系が出会う特別な場所にふさわしい存在として記述される。交觴・俞随という二つの水名はいずれも他に用例がなく、この山の固有水として命名されている。（005-059）
