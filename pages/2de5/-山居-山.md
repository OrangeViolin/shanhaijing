# 【山居】山

**【山居】山**是《山海经·[[中山経]]》中次九経（岷山山系）所载的山。江水出焉东流注于大江。水中多怪蛇木多【木猷】杻梅梓兽多[[夔牛]]、犀、[[兕]]等大型兽。有鸟名[[窃脂]]赤身白首可以御火。（005-117）

## 原文出处

《[[中山経]]》中次九経：

> 又东一百五十里，曰【山居】山。江水出焉，东流注于大江，其中多怪蛇，多囗鱼，其木多【木猷】杻，多梅梓，其兽多夔牛、囗、【上召中比下大】、犀、兕。有鸟焉，状如【号鸟】而赤身白首，其名曰窃脂，可以御火。
>
> （005-117）

## 江水之源

【山居】山是江水（长江支流）的源头之一：

| 属性 | 内容 |
|------|------|
| 水名 | 江水 |
| 流向 | 东流 |
| 注入 | 大江 |
| 水中 | 怪蛇、囗鱼 |

江水从【山居】山流出东入大江。水中多怪蛇不是一般的蛇是「怪蛇」品种繁多异形各异。岷山山系（中次九経）是长江上游区域多座山的水汇入大江【山居】山是其中之一。（005-117）

## 大兽之山

【山居】山的兽类极为丰富且多大型兽：

| 兽 | 特征 |
|----|------|
| [[夔牛]] | 山海経名兽 |
| 【上召中比下大】 |  |
| [[犀]] | 大型兽 |
| [[兕]] | 大型兽 |

夔牛、犀、兕全是大型兽。一座山同时有这么多大兽的情况在山海経中并不多见。岷山山系的山普遍物产丰富【山居】山的兽尤其密集。（005-117）

## 窃脂：御火之鸟

【山居】山的异鸟窃脂可以御火：

| 属性 | 内容 |
|------|------|
| 名 | [[窃脂]] |
| 形状 | 如【号鸟】 |
| 身 | 赤身 |
| 首 | 白首 |
| 功效 | 可以御火 |

赤色的身体白色的头像【号鸟】的样子。「可以御火」能防火。赤身的鸟却能御火红色通常关联火但这只红鸟反而克火。（005-117）
