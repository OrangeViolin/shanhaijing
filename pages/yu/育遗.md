# 育遗

**育遗**是《山海经·[[南山经]]》南次三経所载的谷。旄山之尾的南面——多怪鸟，凯风自是出。（001-033）

## 原文出处

《[[南山经]]》南次三経：

> 又东四百里，至于旄山之尾。其南有谷，曰育遗，多怪鸟，凯风自是出。
>
> （001-033）

## 无名的怪鸟

山海经写异鸟的惯例——「有鸟焉其状如某某其名曰某某」——先写形态再给名字。育遗打破了这个惯例：

| 惯例写法 | 育遗写法 |
|----------|----------|
| 有鸟焉 | 多怪鸟 |
| 其状如… | 无形态描写 |
| 其名曰… | 无名字 |

「多怪鸟」——没有形态、没有名字、只有「怪」和「多」。山海经中异鸟不被命名的情况极其罕见——育遗的鸟群多到无法逐一命名，或者怪到无法归类。（001-033）

## 凯风发源地

育遗是凯风的发源处——凯风即南风：

| 属性 | 内容 |
|------|------|
| 地形 | 谷 |
| 位置 | [[旄山]]之尾南 |
| 物产 | 多怪鸟 |
| 气象 | 凯风自是出 |

一个谷地能生风——南次三経把育遗写成了南风的源头。怪鸟栖于风源——鸟与风共存于同一个谷里。（001-033）

## 鳳凰之后

育遗的前一站是[[丹穴之山]]——鳳凰栖息地（001-031）。从丹穴之山到育遗——从名鸟到无名之鸟：

| | 丹穴之山 | 育遗 |
|--|---------|------|
| 鸟 | [[鳳凰]] | 怪鸟（无名） |
| 数量 | 一只 | 多 |
| 属性 | 见则天下安宁 | 凯风自是出 |

鳳凰是山海经中最有名的鸟——育遗的怪鸟是山海经中最无名的鸟。南次三経把至高的一鸟和无名的群鸟排在相邻的位置——从秩序到未知。（001-031、001-033）
