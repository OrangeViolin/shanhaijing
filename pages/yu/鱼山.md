# 鱼山

**鱼山**是《山海经·[[大荒北经]]》所载的山峰。与齐州之山、君山、【上两先下鬲】山、鲜野山四山并列——五座山一口气列出，鱼山排在最后。没有任何产物、水系或异兽的记载。（017-024）

## 原文出处

《[[大荒北经]]》：

> 有山名曰齐州之山、君山、【上两先下鬲】山、鲜野山、鱼山。
>
> （017-024）

## 五山并列

鱼山是五山列举中的末座：

| 序 | 山名 | 附加信息 |
|-----|------|---------|
| 一 | 齐州之山 | 无 |
| 二 | 君山 | 无 |
| 三 | 【上两先下鬲】山 | 无 |
| 四 | 鲜野山 | 无 |
| **五** | **鱼山** | **无** |

五座山全部没有描述——连一个字的补充都没有。大荒经的列举体把五座山压缩成一句话——它不关心山上有什么，只关心这里有这些山。（017-024）

## 叙事间隔

五山列举位于两段叙事之间，起到地理间隔的作用：

| 位置 | 内容 | 性质 |
|------|------|------|
| 前 | 融父山——犬戎系谱（黄帝→苗龙→融吾→弄明→白犬→犬戎） | 族群起源 |
| **此** | **齐州五山** | **地理列举** |
| 后 | 一目民——威姓，少昊之子 | 异族 |

犬戎的故事讲完，插入五座山的名字，然后开始讲一目民——山是两段异族叙事之间的分隔符。大荒经用山群来标记地理距离——五座山的名字意味着：从犬戎到一目民之间隔了这么远。（017-023至017-025）

## 鱼之名

「鱼」——以鱼命名的山：

| 联想 | 可能性 |
|------|--------|
| 形态 | 山形如鱼 |
| 生态 | 山附近多鱼 |
| 方位 | 近水之山 |

大荒北经没有解释为什么叫鱼山——但「鱼」是水中之物，鱼山可能是靠近水域的山。在五山中，鱼山的名字最具画面感——齐州、君、鲜野都是抽象的，只有「鱼」能让人看到具体的东西。（017-024）
