# 余峨之山

**余峨之山**是《山海经·东山经》所载山岳，位于东山经山系南段。山上多梓楠，山下多荆杞，植被茂密，为异兽[[犰狳]]的栖息地。杂余之水从此山流出，东注黄水。

## 原文出处

东山经（004-019）：

> 又南三百八十里，曰余峨之山，其上多梓楠，其下多荆杞。杂余之水出焉，东流注于黄水。有兽焉，其状如菟而鸟喙，鸱目蛇尾，见人则眠，名犰狳，其鸣自叫，见则螽蝗为败。

## 地理方位

余峨之山在东山经山系中居南段，距前一站山岳南行三百八十里。与北侧无草木的卢其之山（004-022）和南侧同样无草木的杜父之山（004-020）相比，余峨之山是此段山系中植被最为丰富的一座。

## 物产与栖居生灵

| 类别 | 内容 |
|------|------|
| 山上植被 | 梓、楠（优质乔木） |
| 山下植被 | 荆、杞（灌木丛） |
| 水系 | 杂余之水，东流注于黄水 |
| 异兽 | [[犰狳]]——状如菟而鸟喙、鸱目蛇尾 |

犰狳是余峨之山记载的唯一异兽。此兽见人则眠（装死），出现则预示螽蝗灾害。其自呼其名的习性（「其鸣自叫」）是《山海经》异兽的常见特征。余峨之山丰富的荆杞灌木恰为犰狳提供了适宜的栖息环境。
