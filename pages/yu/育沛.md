# 育沛

**育沛**是《山海经·[[南山経]]》鹊山系所载的水生物。栖于[[招摇之山]]的丽旨之水中——佩戴则不生瘕疾（腹部疾病）。（001-001）

## 原文出处

《[[南山経]]》：

> 丽【上鹿下旨】之水出焉，而西流注于海，其中多育沛，佩之无瘕疾。
>
> （001-001）

## 佩之无瘕疾

育沛的形态不详——山海経只记了它的功效：

| 属性 | 内容 |
|------|------|
| 栖地 | 招摇之山·丽旨之水 |
| 水系 | 西流注于海 |
| 用法 | 佩（佩戴） |
| 功效 | 无瘕疾 |

「瘕疾」是腹部的肿块或寄生虫病。育沛不是吃的——是佩戴的——像护身符一样挂在身上就能防病。具体是什么——石头？贝壳？水草？——原文不说——只说「多育沛」——水中到处都是。（001-001）

## 招摇之山的四种宝物

育沛是招摇之山四种实用产物中的最后一种：

| 产物 | 类型 | 用法 | 功效 |
|------|------|------|------|
| [[祝余]] | 草 | 食 | 不饥 |
| [[迷谷]] | 木 | 佩 | 不迷 |
| [[【犭生】【犭生】]] | 兽 | 食 | 善走 |
| **育沛** | **水生** | **佩** | **无瘕疾** |

食之不饥——佩之不迷——食之善走——佩之无瘕疾。四种产物涵盖了草木兽水四界——功效各异但都实用。「食」与「佩」两种用法交替——祝余食、迷谷佩、【犭生】【犭生】食、育沛佩。招摇之山是山海経全书的第一座山——开篇就展示了完整的博物学体系。（001-001）

## 山海経的起点

育沛出现在山海経全书的第一条记述中——招摇之山是南山経之首鹊山系的首座：

| 层级 | 内容 |
|------|------|
| 全书 | 山海経 |
| 篇 | 南山経（全书第一篇） |
| 山系 | 鹊山系（南山経第一个山系） |
| 山 | 招摇之山（鹊山系第一座山） |
| 水 | 丽旨之水（招摇之山的水） |
| **生物** | **育沛（丽旨之水中的水生物）** |

育沛是山海経全书最早出现的水生物——虽然形态不详——但它在山海経的博物志中占据了最初的位置。（001-001）
