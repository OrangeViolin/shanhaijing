# 云山

**云山**是《山海经·[[中山経]]》中次十二経所载的山。无草木——有桂竹——甚毒——伤人必死。（005-191）

## 原文出处

《[[中山経]]》：

> 又东南五十里，曰云山，无草木。有桂竹，甚毒，伤人必死，其上多黄金，其下多瑶琈之玉。
>
> （005-191）

## 桂竹甚毒

云山最核心的记载是桂竹——一种致命的竹子：

| 属性 | 内容 |
|------|------|
| 植被 | 无草木（除桂竹外） |
| 特产 | 桂竹 |
| 毒性 | 甚毒，伤人必死 |
| 山上 | 多黄金 |
| 山下 | 多瑶琈之玉 |

山上无草无木——只有桂竹。桂竹「甚毒」——毒到什么程度？「伤人必死」——只要被它伤到就必死无疑。这是《山海经》中致死性最明确的植物——没有「或许」「可能」——是「必死」。（005-191）

## 中次十二経的荒山地带

云山处于中次十二経开头的一组荒山之中：

| 山 | 特征 | PN |
|----|------|-----|
| 篇遇之山 | 无草木，多黄金 | 005-190 |
| **云山** | **无草木，桂竹甚毒，多黄金·瑶琈之玉** | **005-191** |
| 龟山 | 多谷柞·黄金·青雄黄·扶竹 | 005-192 |

篇遇之山和云山都「无草木」——两座连续的荒山。但云山比篇遇之山更可怕——篇遇之山只是荒——云山不仅荒还有致命的毒竹。龟山开始恢复植被（多谷柞）——荒寂地带在云山之后结束。（005-191）

## 黄金与毒竹

云山有一个矛盾的组合——山上多黄金——山下多美玉——但山中有致命的毒竹。珍宝与毒物共存——想要取黄金和美玉——就必须面对桂竹的威胁。「伤人必死」是对贪财者的最直接警告——财富被毒物守护。（005-191）
