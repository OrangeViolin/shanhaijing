# 禹攻共工国山

**禹攻共工国山**是《山海经·[[大荒西经]]》所载的山——[[禹]]攻伐[[共工]]国的战场所在。与不周负子山、寒署之水、湿山、幕山同处一段。（016-001）

## 原文出处

《[[大荒西经]]》：

> 西北海之外，大荒之隅，有山而不合，名曰不周负子，有两黄兽守之。有水曰寒署之水。水西有湿山，水东有幕山。有禹攻共工国山。
>
> （016-001）

## 以战争命名的山

禹攻共工国山的名字就是一个完整的叙事——「禹攻共工国」：禹攻打共工国。这是《山海经》中最长的山名之一，也是唯一一座以战争事件命名的山。

| 元素 | 内容 |
|------|------|
| 禹 | 治水英雄、夏王 |
| 攻 | 军事行动 |
| 共工 | 水神/叛逆者 |
| 国 | 共工的国 |
| 山 | 战场所在 |

山名本身就是一座纪念碑——它不描述山的形状或产物，而是记录发生在这里的事件。禹在这里攻打了共工的国，从此这座山就以这场战争命名。（016-001）

## 不周山旁

禹攻共工国山紧邻不周负子山——「有山而不合，名曰不周负子」。不周山是共工怒触天柱的神话现场：

| 事件 | 主角 | 地点 |
|------|------|------|
| 共工触天柱 | 共工 | 不周山 |
| **禹攻共工** | **禹** | **禹攻共工国山** |

两个关于共工的神话在同一个地理空间重叠：共工撞断了不周山（天柱）——然后禹来讨伐共工的国。天柱断裂是宇宙的灾难，禹的讨伐是秩序的修复。不周山记录了共工的破坏，禹攻共工国山记录了禹的惩罚——两座山合成了一个完整的故事：破坏与修复。（016-001）

## 大荒西经的开篇

禹攻共工国山位于大荒西经的第一条——整个大荒西经从这里开始：

| 行 | 条目 | 主题 |
|----|------|------|
| **016-001** | **不周负子、禹攻共工国山** | **宇宙大战** |
| 016-002 | 淑士国 | 颛顼之子 |
| 016-003 | 女娲之肠 | 女娲化神 |
| 016-004 | 石夷 | 西方风神 |

大荒西经以宇宙大战开篇——禹伐共工、不周山断裂。此后是颛顼之后裔、女娲的遗体化神、西方风神——从宇宙战争到神谱到风神。禹攻共工国山是西方世界的第一个坐标，这意味着西方大荒在《山海经》的叙事中是以战争和灾难为底色的。（016-001）

## 寒署之水与双山

禹攻共工国山周围的地理布局：

| 要素 | 位置 |
|------|------|
| 不周负子山 | 大荒之隅 |
| 寒署之水 | 中间 |
| 湿山 | 水西 |
| 幕山 | 水东 |
| **禹攻共工国山** | 同区 |

寒署之水——寒冷与暑热同名的水。水的两侧分列湿山和幕山——对称排布。禹攻共工国山在这个对称结构附近——战场位于天柱断裂处、寒热之水旁、湿幕双山间。这是一个充满宇宙级象征的空间。（016-001）

## 山海经中以事件命名的地名：禹攻共工国山的叙事性命名

《山海经》中绝大多数地名以自然属性命名（颜色、形状、矿物、植物），极少以历史事件命名。禹攻共工国山是叙事性命名的极端案例：

| 地名 | 命名逻辑 | 包含信息 | 出处 |
|------|----------|----------|------|
| **禹攻共工国山** | **战争事件** | **人物+动作+对象+地点** | 大荒西经（016-001） |
| [[帝尧台]] | 人物活动 | 帝尧+台 | 大荒南经 |
| [[帝喾竹林]] | 所属+植被 | 帝喾+竹林 | 大荒南经 |
| [[黄帝女魃]] | 人物关系 | 黄帝+女魃 | 大荒北经 |

帝尧台、帝喾竹林等名称只包含「谁的什么」，禹攻共工国山却包含了完整的叙事要素：谁（禹）、做了什么（攻）、对谁（共工国）、在哪里（山）。五个字压缩了一场战争——这不是一个地名，而是一句凝固在地图上的历史。

这种命名方式意味着：对于命名者来说，这座山除了这场战争之外没有其他值得记录的特征——它没有异兽、没有矿产、没有水系，唯一的身份就是「禹曾在这里打败共工」。山成为了事件的容器。（016-001）
