# 妪山

**妪山**是《山海经·[[中山経]]》中次十一経所载的山。山上多美玉——山下多金——草多鸡谷。山海经中唯一以「妪」（母亲/老妇）命名的山。（005-174）

## 原文出处

《[[中山経]]》中次十一経：

> 又东七十里，曰妪山，其上多美玉，其下多金，其草多鸡谷。
>
> （005-174）

## 上玉下金

妪山的矿产上下分层：

| 位置 | 矿产 |
|------|------|
| 山上 | 美玉 |
| 山下 | 金 |

美玉在上、金在下——中山经常见的阴阳/上下二分记述。妪山的矿产不在阴阳面——而在上下层。（005-174）

## 鸡谷药草

妪山的草以鸡谷为主。鸡谷在[[兔床之山]]（005-147）有详细描写：

| 属性 | 内容 |
|------|------|
| 根 | 如鸡卵 |
| 味 | 酸甘 |
| 功效 | 食之利于人 |

鸡谷的根像鸡蛋——味道酸甜——吃了对人有益。妪山「多鸡谷」——说明这里是鸡谷的集中产地。（005-174）

## 唯一的「妪」山

「妪」字意为母亲、老妇。山海经数百座山中——只有这一座以「妪」命名。多药草的山叫「妪」——母亲与养育——药草与治疗——名字和物产之间有隐约的呼应。

## 静山

妪山没有水系、没有兽、没有鸟——只有矿和草。前后对比：

| 山 | 特点 |
|----|------|
| [[丰山]] | 封石、桑、羊桃 |
| **妪山** | 美玉、金、鸡谷 |
| [[鲜山]] | 有兽【犭多】即（赤喙赤目白尾，见则有火） |

前山是实用植物——后山有预兆猛兽——妪山夹在中间，安静地产玉、产金、产药草。（005-174）
