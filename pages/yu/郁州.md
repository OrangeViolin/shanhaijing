# 郁州

**郁州**是《山海经·[[海内东经]]》所载[[都州]]的别名。都州位于海中，是一座海中岛屿。（014-007）

## 原文出处

《[[海内东经]]》：

> 都州在海中。一曰郁州。
>
> （014-007）

## 海中之岛

「都州在海中」——都州是一座海中的岛屿。《山海经》中「在海中」的地物不多，都州（郁州）是其中之一：

| 地物 | 位置 | 性质 |
|------|------|------|
| **都州（郁州）** | **在海中** | **岛屿** |
| 琅邪台 | 在渤海间 | 台/岬 |
| 韩雁 | 在海中 | 岛屿 |

海中之岛——在以陆地山川为主的《山海经》中，海岛是稀有的地理类型。都州和韩雁都在海中，构成了海内东经中的海岛群。（014-007）

## 都州与郁州

「一曰郁州」——都州又叫郁州。两个名字的含义不同：

| 名称 | 字义 |
|------|------|
| 都州 | 都＝聚集之处 |
| **郁州** | **郁＝草木茂盛** |

「都」强调人的聚集——一个人口中心；「郁」强调植被的茂盛——一座绿色的岛。同一座岛，两种视角：有人看到了人，有人看到了树。（014-007）

## 韩雁的基准

都州（郁州）是韩雁的方位基准：

| 地物 | 定位 |
|------|------|
| **都州** | **基准点** |
| 韩雁 | 在海中，都州南 |

韩雁「在海中，都州南」——以都州为参照来定位韩雁的位置。都州是海内东经海上地理的定位中心——海中的其他岛屿以它为坐标原点。（014-007）

## 历史地理

郁州在后世对应江苏连云港的云台山一带。古代云台山是海中孤岛，后来因泥沙淤积而与大陆相连。《汉书·地理志》也有「郁州」的记载——海内东经的这条记录与现实地理高度吻合：

| 时期 | 状态 |
|------|------|
| 《山海经》时代 | 海中孤岛 |
| 后世 | 陆续与大陆相连 |
| 今天 | 连云港市内陆地形 |

从海岛变成陆地——郁州的变迁是中国海岸线变化的活标本。（014-007）
