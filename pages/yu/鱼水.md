# 鱼水

**鱼水**是《山海经》中两部经文记载的水。[[北山経]]北次一経——出虢山之尾，西流注于河，多文贝（003-007）。[[海外南経]]——[[长臂国]]捕鱼水中（006-022）。

## 原文出处

### 北山経

> 又北四百里，至于虢山之尾，其上多玉而无石。鱼水出焉，西流注于河，其中多文贝。
>
> （003-007）

### 海外南経

> 长臂国在其东，捕鱼水中，两手保操一鱼。一曰在周饶东，捕鱼海中。
>
> （006-022）

## 两种鱼水

北山経写地理——海外南経写民俗：

| | 北山経 | 海外南経 |
|--|--------|---------|
| 性质 | 地理水系 | 捕鱼场所 |
| 内容 | 源山、流向、注入、水产 | 长臂国人在水中捕鱼 |
| 水产 | 文贝 | 鱼（两手各操一鱼） |
| 异说 | 无 | 一曰捕鱼海中 |
| PN | 003-007 | 006-022 |

北山経的鱼水是一条具体的河——从虢山之尾流出，西流入黄河。海外南経的「鱼水」可能只是「有鱼的水」——异说直接改成了「海中」。水名从专名滑向通名。（003-007、006-022）

## 虢山之尾

鱼水发源于虢山之尾——虢山本身和虢山之尾是两个条目：

| | 虢山 | 虢山之尾 |
|--|------|---------|
| 矿产 | 阳多玉、阴多铁 | 多玉而无石 |
| 水系 | 伊水，西流注河 | 鱼水，西流注河 |
| 水产 | — | 文贝 |

同一座山的两端——各出一条河——都西流入黄河。虢山之尾「多玉而无石」——全是玉、没有石头——水中的文贝也许就生长在这种纯玉质的河床里。（003-007）

## 长臂国的捕鱼

海外南経的长臂国在[[周饶国]]之东——以长臂捕鱼为特征：

| 属性 | 内容 |
|------|------|
| 位置 | 周饶国之东 |
| 体态 | 长臂 |
| 生业 | 捕鱼 |
| 姿态 | 两手各操一鱼 |

身体的异形直接变成生存优势——臂长所以能抓鱼。「鱼水」在这里不是河名——是有鱼的水。（006-022）
