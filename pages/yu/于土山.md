# 于土山

**于土山**は[[大荒西经]]に記載される山である。桃山・桂山とともに列挙される。（016-023）

## 原文出処

《[[大荒西经]]》：

> 有桃山。有【上亡下虫】山。有桂山。有于土山。
> （016-023）

## 地理描述

于土山は大荒西経の簡潔な列挙に登場し、桃山・桂山と並ぶ。個別の地理特徴は記されていない。

## 四山の列挙

于土山は桃山・【上亡下虫】山・桂山とともに四山が一文に列挙される。大荒経に多い「山名リスト」型の記述。

| 山名 | 備考 |
|------|------|
| 桃山 | 果樹名を冠する |
| 【上亡下虫】山 | 読み不詳 |
| 桂山 | 南方の名木・桂を冠する |
| **于土山** | 列挙の末尾 |

## 文脈配置

| 前 | 女子之国 |
|------|------|
| **当項** | **桃山・【上亡下虫】山・桂山・于土山** |
| 後 | 丈夫之国 |

四山は女子之国と丈夫之国の間に挟まれて記される。両国は対をなす異国で、その間の山群は境界的な地理として機能する。大荒西経の異国と山群が交互に記される構成の一例。
