# 余【上山下我】之山

**余【上山下我】之山**是《山海经·[[东山经]]》东次二经所载的山峰。上多梓【左木右丹】，下多荆杞，有兽[[犰狳]]，见人则眠，见则螽蝗为败。杂余之水出焉，东流注于黄水。（004-019）

## 原文出处

《[[东山经]]》东次二经：

> 又南三百八十里，曰余【上山下我】之山。其上多梓【左木右丹】，其下多荊杞。雜余之水出焉，東流注于黃水。有獸焉，其狀如菟而鳥類喙，鴟目蛇尾，見人則眠，名犰狳，其鳴自【讠交】，見則螽蝗為敗。
>
> （004-019）

## 犰狳

余【上山下我】之山的异兽，合四类于一身：

| 部位 | 来源 |
|------|------|
| 身 | 如兔 |
| 喙 | 鸟 |
| 目 | 鸱（猫头鹰） |
| 尾 | 蛇 |

兔的身体、鸟的嘴、猫头鹰的眼、蛇的尾，四种动物合在一起。犰狳是一个拼贴出来的生物，哺乳类、禽类、猛禽、爬虫各取一部分。（004-019）

## 见人则眠

犰狳见到人时的反应，睡觉：

| 属性 | 内容 |
|------|------|
| 行为 | 见人则眠 |
| 叫声 | 自呼其名 |
| 凶兆 | 见则螽蝗为败 |

大多数山海经异兽见人就跑，犰狳见人就睡。这是一种极其特异的反应，也许是装死，也许是真的不在乎人类。但它出现就意味着蝗灾，一个睡觉的兽带来了最大规模的农业灾害。越平静的凶兆越可怕。（004-019）

## 螽蝗为败

犰狳出现的后果，蝗灾：

| 凶兆类型 | 灾害 |
|----------|------|
| 见则 | 螽蝗为败 |

螽蝗，蝗虫，古代最可怕的农业灾害之一。犰狳出现→蝗虫成灾→庄稼毁灭。一只安静睡觉的小兽预告着铺天盖地的蝗群，安静与毁灭的反差。（004-019）

## 杂余之水

余【上山下我】之山的水系：

| 要素 | 内容 |
|------|------|
| 水名 | 杂余之水 |
| 流向 | 东流 |
| 注入 | 黄水 |

水名「杂余」与山名「余【上山下我】」共享一个「余」字，山与水同名，这是山经常见的命名模式。（004-019）
