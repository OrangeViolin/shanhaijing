# 蜮民之国

**蜮民之国**是《山海经·[[大荒南経]]》所载的邦国。桑姓——食黍——射蜮是食。有人名蜮人——弓射黄蛇。（011-016）

## 原文出处

《[[大荒南経]]》：

> 有人曰凿齿，有蜮山者，有蜮民之国，桑姓，食黍，射蜮是食。有人方【扌干】弓射黄蛇，名曰蜮人。
>
> （011-016）

## 射蜮为食

蜮民之国的核心生业——用弓射蜮为食物来源：

| 属性 | 内容 |
|------|------|
| 姓 | 桑 |
| 农耕 | 食黍 |
| 狩猎 | 射蜮是食 |
| 动作 | 弓射黄蛇 |

既食黍（农耕）又射蜮（狩猎）——双重生业。山海经中对邦国生业用具体动作描写的极少——「方【扌干】弓射黄蛇」是罕见的动态画面。（011-016）

## 蜮人的姿态

「有人方【扌干】弓射黄蛇」——蜮人正拉弓射黄蛇。这是一个定格的动作——不是描述习惯，是捕捉了一个瞬间。山海经的邦国通常只记姓、食、用——蜮民之国多了一帧画面。（011-016）

## 凿齿同区

蜮民之国和[[凿齿]]出现在同一段经文里——同一个空间：

| 存在 | 性质 |
|------|------|
| [[凿齿]] | 凶恶之人（被羿射杀） |
| 蜮山 | 蜮所在之山 |
| 蜮民之国 | 射蜮为食之国 |

凿齿是被射的——蜮人是射手。同一片大荒南方——暴力和狩猎的空间。（011-016）

## 南方暴力带

蜮民之国前后是一条暴力意象密集的地带：

| PN | 内容 |
|-----|------|
| 011-016 | 凿齿 + 蜮民（射蜮） |
| 011-017 | [[宋山]]（蚩尤所弃桎梏化为枫木） |

凿齿→射蜮→蚩尤桎梏——大荒南方的这段是血与暴力的序列。（011-016、011-017）
