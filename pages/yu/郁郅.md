# 郁郅

**郁郅**是《山海经·[[海内東経]]》所载的地名。泾水的水源——长城北山——在郁郅长垣之北。（014-012）

## 原文出处

《[[海内東経]]》：

> 泾水出长城北山，山在郁郅长垣北，北入渭。戏北。
>
> （014-012）

## 郁郅长垣

郁郅有「长垣」——长长的城墙：

| 属性 | 内容 |
|------|------|
| 地名 | 郁郅 |
| 设施 | 长垣（长城墙） |
| 北方 | 长城北山（泾水源头） |

「长垣」是防御设施——长长的墙垣。长城北山在郁郅长垣之北——泾水从那座山发源。郁郅是墙内的世界——长城北山是墙外的世界——泾水从墙外流向墙内。（014-012）

## 泾渭水系

郁郅是泾水水源地域的标志——泾水与渭水构成一组干支关系：

| 河 | 水源 | 流向 | 注入 |
|----|------|------|------|
| 泾水 | 长城北山 | 北流 | 入渭（戏北） |
| 渭水 | 鸟鼠同穴山 | 东流 | 注河（华阴北） |

泾水从长城北山发源——北流入渭。渭水从鸟鼠同穴山发源——东流注入黄河。泾水是渭水的支流——郁郅处于泾水上游——是关中水系的北部源头地带。（014-012）

## 海内東経的水系序列

郁郅出现在海内東経大规模河川记述的关中段落中：

| 河川 | 区域 |
|------|------|
| 潁水（出少室） | 中原 |
| 汝水（出天息山） | 中原 |
| **泾水（出长城北山，在郁郅长垣北）** | **关中北部** |
| 渭水（出鸟鼠同穴山） | 关中 |
| 白水（出蜀） | 蜀 |

从中原的潁水·汝水——到关中的泾水·渭水——再到蜀地的白水——海内東経的视线从东向西推进。郁郅是这条视线进入关中时第一个出现的地名。（014-012）
