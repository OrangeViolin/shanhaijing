# 流黄辛氏之国

**流黄辛氏之国**是《山海经·[[海内経]]》所载的邦国。方三百里——出尘土——有[[巴遂山]]——[[渑水]]出焉。（018-015）

## 原文出处

《[[海内経]]》：

> 有国名曰流黄辛氏，其域中方三百里，其出是尘土。有巴遂山，渑水出焉。
>
> （018-015）

## 三百里尘土

「方三百里」——山海経中最大的邦国之一。但产出物只有尘土：

| 属性 | 内容 |
|------|------|
| 面积 | 方三百里 |
| 产出 | 尘土 |
| 山 | 巴遂山 |
| 水 | 渑水 |

三百里的大国——什么宝物都没有——只产尘土。别的国产金玉珍兽——这个国产细土。面积越大——产出越荒凉——反差越强。（018-015）

## 「流黄辛氏」

「流黄」可能是硫黄——「辛氏」是苦辛之地的氏族。硫黄加苦辛——暗示火山性的荒凉地质。尘土是唯一的产物——硫黄和苦辛的地方长不出别的东西。名字已经说明了这片土地的性质。（018-015）

## 巴国圈的南方边境

流黄辛氏之国紧接在[[巴国]]之后：

| 条目 | 位置 | PN |
|------|------|-----|
| [[巴国]] | 巴人谱系 | 018-014 |
| **流黄辛氏之国** | 方三百里尘土 | 018-015 |
| 朱卷之国 | 有黑蛇青首食象 | 018-016 |
| 赣巨人 | 人面长臂黑身 | 018-017 |

从巴国的人文谱系——到流黄辛氏的荒凉国——再到黑蛇食象和黑身巨人。流黄辛氏之国是通常邦国和异界存在之间的过渡——从这里开始——世界变得越来越陌生。（018-015）
