# 陵鱼

**陵鱼**是《山海经·[[海内北経]]》所载的海中异族。人面——手足——鱼身——在海中。有人的面孔和四肢但身体是鱼形。（013-028）

## 原文出处

《[[海内北経]]》：

> 陵鱼人面，手足，鱼身，在海中。
>
> （013-028）

## 半人半鱼

陵鱼的形态是人与鱼的拼合——三个人类特征加一个鱼类特征：

| 部位 | 属性 |
|------|------|
| 面 | 人面 |
| 肢 | 手足（有手有足） |
| 身 | 鱼身 |
| 居 | 海中 |

「人面，手足，鱼身」——六字三层。面是人的——肢是人的——但身体是鱼。陵鱼有手有足——这与[[氐人国]]的「人面鱼身无足」形成区别。氐人国无足——陵鱼有足——陵鱼比氐人更接近人类。（013-028）

## 海内北経的海中序列

陵鱼处于海内北経末段的海中异物列举中：

| 存在 | 性质 |
|------|------|
| **陵鱼** | 人面手足鱼身 |
| 大【鱼便】 | 居海中 |
| [[明组邑]] | 海中聖地 |
| [[蓬莱山]] | 海中仙山 |
| [[大人之市]] | 海中市场 |

从异族（陵鱼）到巨鱼（大【鱼便】）到聖地（明组邑、蓬莱山）到市场（大人之市）——海内北経末段是一幅远海图景。陵鱼排在最前——是进入海中世界的第一站。（013-028）

## 人鱼类存在

山海経中有多种人鱼形态的存在——陵鱼是其中有手有足的一种：

| 存在 | 篇章 | 形态 | 差异 |
|------|------|------|------|
| **陵鱼** | 海内北経 | 人面手足鱼身 | 有足 |
| [[氐人国]] | 海内南経 | 人面鱼身无足 | 无足 |
| [[人鱼]] | 西山経等 | 水中生物 | 药效记述 |

「陵」有登陆之意——陵鱼有手有足——或许能上岸。鱼身而能登陆——这是最接近陆地的海中鱼人。（013-028）
