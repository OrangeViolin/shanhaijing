# 列襄

**列襄**是《山海经·[[海内经]]》记载的南方国名。与[[禺中之国]]并列，位于南海之外黑水青水之间。两国仅存其名，无系谱、无物产、无异人，夹在叵木之水与灵山赤蛇的记述之间，是南方极域异域叙事链上的一环。（018-012）

## 原文出处

《[[海内经]]》：

> 有禺中之国。有列襄之国。有灵山，有赤蛇在木上，名曰【左虫右上而右下大】蛇，木食。
>
> （018-012）

前文：

> 南海之外，黑水青水之间，有木名曰叵木，若水出焉。
>
> （018-011）

## 黑水青水之间的空间定位

海内经以"南海之外，黑水青水之间"来框定这片区域，是全经中最南的异域空间之一。黑水、青水在山海经体系中是南方边界的标志性水名：

| 要素 | 内容 |
|------|------|
| 方位 | 南海之外 |
| 边界 | 黑水与青水之间 |
| 先出现 | 叵木（若水之源） |
| 并列之国 | 禺中之国、列襄之国 |
| 后接 | 灵山（十巫升降，百药爰在） |

叵木是异域植物，若水从它发源，这一条之后紧接两个国名，再之后是灵山的赤蛇。叙述从植物到人国到蛇，再到巫医之山，空间上由荒野向神圣地标递进。（018-011、018-012）

## 名只存焉的国

列襄之国与禺中之国一同构成海内经中最简省的国家描述模式，"有X之国"，仅此一句。对比同区间其他条目：

| 条目 | 描述层次 |
|------|----------|
| 叵木 | 植物名+水名（若水出焉） |
| **禺中之国** | 仅国名 |
| **列襄之国** | 仅国名 |
| 灵山 | 地名+赤蛇名（食木） |
| 盐长之国 | 国名+居民特征（鸟首，名鸟氏） |

同一区间，盐长之国有鸟首之人可描述，列襄之国和禺中之国却只有名字。这不一定意味着信息遗失，在海内经的叙述逻辑中，南方极域的国名本身就是边界标记，用以指示地理序列中的位置，而非记录具体信息。（018-012、018-013）

## "列襄"字义与解读

"列襄"二字的含义历代注家分歧：一说"列"为排列、分立，"襄"有辅佐或高升之意，合指分列助役之国；一说与"列"地（有实际地望的地名）有关。然而海内经南方异域的国名多为音译或存古，字义解读往往难以确证。"列襄"作为南方边域国名，其功能更多是地理坐标性的，而非语义性的。

## 位置链：叵木到九丘

从叵木（018-011）到九丘（018-014），海内经构建了一段南方神话地理的链条：

| PN | 条目 | 要素 |
|----|------|------|
| 018-011 | 叵木 | 若水之源 |
| 018-012 | 禺中之国、列襄之国 | 名只存焉 |
| 018-012 | 灵山 | 赤蛇木食 |
| 018-013 | 盐长之国 | 鸟首之人 |
| 018-014 | 九丘 | 水络之，大皋过，黄帝所为 |

列襄之国嵌入这一链条的第二环，其前是若水之源的异木，其后是十巫升降的圣山。两个无名之国填充了从原始植物到神祇空间之间的过渡地带，使链条的节奏完整。（018-011 至 018-014）

## 海内经南方链条中「空壳国名」的节奏功能

列襄与[[禺中之国]]在叵木和灵山之间只占据一句经文，但它们的存在对叙事节奏至关重要：

| PN | 条目 | 信息类型 | 节奏角色 |
|----|------|---------|---------|
| 018-011 | 叵木 | 植物＋水源 | 场景设定 |
| **018-012** | **禺中、列襄** | **仅国名** | **过渡/留白** |
| 018-012 | [[灵山]] | 赤蛇＋木食 | 神异升级 |
| 018-013 | [[盐长之国]] | 鸟首之人 | 异人展开 |

如果从叵木直接跳到灵山，叙事会从「若水之源的异木」骤然切入「赤蛇食木的圣山」，信息密度的跳跃太大。两个空壳国名插入其间，提供了一个信息真空带，读者在「有禺中之国、有列襄之国」这一句中获得片刻停顿，然后灵山的异象才展开。这种「详→空→详」的节奏不是信息遗失的副产品，而是大荒经/海内经编者常用的叙事呼吸，空壳国名是标点符号，不是残缺的正文（018-011, 018-012, 018-013）。
