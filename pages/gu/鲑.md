# 鲑

**鲑**是《山海经·[[南山経]]》所载的异兽——栖于[[柢山]]。牛形——蛇尾——有翼——翼在腋下——陵居（住在高处）。冬死而复生——食之无肿疾。（001-005）

## 原文出处

《[[南山経]]》南次一経：

> 有兽焉，其状如牛，陵居，蛇尾有翼，其羽在腋下，其音如留牛，其名曰鲑，冬死而复生，食之无肿疾。
>
> （001-005）

## 冬死而复生

鲑最特异的生态是季节性死而复生：

| 属性 | 内容 |
|------|------|
| 形状 | 如牛 |
| 居所 | 陵居（山陵高处） |
| 尾 | 蛇尾 |
| 翼 | 有翼，在腋下 |
| 声音 | 如留牛 |
| 生态 | 冬死而复生 |
| 药效 | 食之无肿疾 |

山海経中「冬死而复生」的兽只此一例。每年冬天死去——来年再活——周期性的死亡与复活。像蛇的冬眠——但经文明确说「死」不说「蛰」。一头牛大小的兽——每年死一次——然后复活。（001-005）

## 翼在腋下

鲑有翼——但翼不在背上而在腋下。牛形——蛇尾——腋下长翅膀：

| 部位 | 特征 | 来源物种 |
|------|------|----------|
| 身 | 如牛 | 牛 |
| 尾 | 蛇尾 | 蛇 |
| 翼 | 在腋下 | 鸟（异位） |

翼在腋下意味着翅膀被身体遮盖——不像鸟那样展开在背部。牛形的体重加上腋下的小翼——飞行可能性极低。翼的功能也许不是飞——而是某种形态标记。山海経的有翼之兽不一定能飞——翼是异能的象征。（001-005）

## 鲑与赤鲑

山海経中「鲑」出现两次——性质完全不同：

| 项目 | 南山経·柢山 | 北山経·敦薨之山 |
|------|------------|----------------|
| 名称 | 鲑 | 赤鲑 |
| 类型 | 异兽（陵居） | 水产（水中） |
| 形态 | 牛形蛇尾有翼 | 无描述（仅名） |
| 生态 | 冬死而复生 | — |
| 药效 | 食之无肿疾 | — |
| PN | 001-005 | 003-017 |

南山経的鲑是住在山顶的牛形异兽——北山経的赤鲑是河源水中的鱼类。同名异物——一个在山上一个在水里。「赤鲑」加了颜色前缀——暗示与「鲑」有别。（001-005、003-017）
