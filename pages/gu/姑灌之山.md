# 姑灌之山

**姑灌之山**是《山海经·[[北山经]]》北次二経所载的山。无草木——冬夏有雪。（003-039）

## 原文出处

《[[北山经]]》北次二経：

> 又北四百里，曰姑灌之山，无草木。是山也，冬夏有雪。
>
> （003-039）

## 冬夏有雪

「冬夏有雪」——不是冬天才有雪，夏天也有：

| 属性 | 内容 |
|------|------|
| 草木 | 无 |
| 气候 | 冬夏有雪 |
| 水系 | 无记载 |
| 异物 | 无记载 |

万年积雪——雪线以上的高山。整部北山经只有姑灌之山和[[空桑之山]]（003-076）两座山有「冬夏有雪」的记载——这是极北的极寒地标。（003-039）

## 极简之山

姑灌之山的记述极其简短——只有两个信息：无草木、冬夏有雪。没有矿产、没有水系、没有异兽——冰雪封住了一切。这是北次二経中最空白的一座山。（003-039）

## 双灌连山

姑灌之山和下一站[[湖灌之山]]共享「灌」字：

| | 姑灌之山 | [[湖灌之山]] |
|--|---------|-----------|
| 草木 | 无 | 有（推测） |
| 矿产 | 无 | 玉、碧 |
| 兽 | 无 | 多马 |
| 水系 | 无 | 湖灌之水→海 |
| 气候 | 冬夏有雪 | 无特殊记载 |

同为「灌」字山——一座冰封空白，一座矿产丰富。姑灌是极寒的顶点——湖灌是解冻的起点。（003-039）
