# 鲧

**鲧**是《山海经》中最具悲剧色彩的人物之一。他为拯救苍生窃取天帝的[[息壤]]堵塞洪水，因「不待帝命」被[[祝融]]杀于羽郊。死后尸体不腐，腹中生出[[禹]]——儿子继承了他未竟的使命，以不同的方法最终成功。鲧是失败者，但也是成功者的父亲。

## 原文出处

引注：（018-031）

> 黄帝生骆明，骆明生白马，白马是为鲧。

引注：（018-038）

> 洪水滔天。鲧窃帝之息壤以堙洪水，不待帝命。帝命祝融杀鲧于羽郊。鲧复生禹。帝乃命禹卒布土以定九州。

引注：（017-005）

> 有鲧攻程州之山。

## 世系

```
黄帝 → 骆明 → 白马（鲧） → 禹
```

鲧即「白马」，[[黄帝]]的三世孙。「白马是为鲧」——动物化身是上古图腾崇拜的遗痕。鲧作为黄帝后裔治水，是血脉使命的体现。

## 事迹

### 窃息壤

「洪水滔天」——灾难的描写只有四个字，紧接着就是鲧的行动。鲧窃取天帝所藏的[[息壤]]（能自行增殖的神土）堙塞洪水。关键词是「窃」和「不待帝命」——不是方法错了，而是程序违规。详见[[鲧窃息壤]]。

### 被杀

天帝命[[祝融]]杀鲧于羽郊（[[羽山]]）。执行者是南方之神祝融。这不是战争或冲突，而是「帝命」的执行，是天帝秩序对僭越行为的制度性惩罚。

### 腹中生禹

「鲧复生禹」——鲧死后，[[禹]]从其腹中诞生。传世文献补充细节：鲧死三年不腐，剖之以吴刀，禹从腹中跃出。这一「父体孕育」的母题在中国神话中极为罕见，与[[女娲]]的「肠化十神」属同一类型——创造者/先行者的身体成为新生命的孵化器。

### 攻程州之山

大荒北经另载「有鲧攻程州之山」，是鲧以攻山形象出现的孤证。「攻山」可能对应治水神话的另一版本——凿山导水。

## 鲧的悲剧结构

鲧的故事是一个完美的悲剧，每一个要素都朝向注定的失败：

1. **动机正当**：洪水滔天，苍生受难——鲧不是为了私利
2. **工具最好**：息壤能无限增殖——不是能力不足
3. **方法错误**：堵塞法对抗无限的水——方向性错误
4. **程序违规**：「不待帝命」——即使目的正当，手段未获授权
5. **身死事未成**：被杀于羽郊——最彻底的失败
6. **但——生出了成功者**：禹继承使命，改堵为疏，终于成功

鲧的失败不是终结，而是为成功积蓄的前奏。没有鲧的堵塞法失败，就不会有禹的疏导法成功——失败是正确方法论的必要前提。

## 神话意义

**普罗米修斯式的英雄**：鲧窃息壤与普罗米修斯盗火高度同构——半神为人类利益窃取至高神之物，遭到惩罚。但两者结局不同：普罗米修斯被解救，鲧以死亡孕育继承者。中国神话不需要外来的救赎——失败者的身体本身就是救赎。

**「不待帝命」的永恒困境**：鲧的罪不是治水，而是「不待帝命」。这提出了一个伦理难题：面对紧急灾难，是等待授权还是先行行动？《山海经》的叙述不做道德判断——它只记录鲧的选择和鲧的代价。

**第一代与第二代**：鲧是「第一代」——试错者、铺路者、以失败为后人提供教训的人。在所有英雄叙事中，「第一代」往往不被歌颂，但没有他们的失败就没有后来者的成功。
