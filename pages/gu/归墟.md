# 归墟

**归墟**是东海之外的无底深渊，天下之水皆注入此处而水位永不上涨。
《列子·汤问》称其为「归墟」，《山海经·大荒东经》以「大壑」之名记载。
它是《山海经》宇宙的东部极限：再往东，大地终结，万水坠入无尽深渊。

## 原文出处

引注：（015-001）

> 东海之外大壑，少昊之国。少昊孺帝颛顼于此。

《列子·汤问》补充了归墟的核心特征：

> 渤海之东不知几亿万里，有大壑焉，实惟无底之谷，其下无底，名曰归墟。八纮九野之水，天汉之流，莫不注之，而无增无减焉。

## 无底深渊的物理学

归墟最核心的特征是「注之而无增无减」。
天下所有河流、所有降水、乃至天河（银河）之水，全部倾泻于此。
水量持续增加，水位永远不变。

这意味着归墟不是一个容器，而是一个吞噬机制。
它不储水，它消灭水。
水进入归墟之后，不是被储存，而是从存在中消失。

| 特征 | 描述 |
|------|------|
| 位置 | 东海之外，不知几亿万里 |
| 形态 | 无底之谷 |
| 功能 | 天下之水皆归于此 |
| 异常 | 水量无限注入而无增无减 |

## 五山镇压归墟

《列子·汤问》记载了归墟中漂浮五座仙山的传说。
岱舆、员峤、方壶、瀛洲、蓬莱五山原本在归墟中随波漂流，无所依附。

天帝命禺强驱使十五只巨鳌，以三鳌为一组，轮流负载五山。
龙伯之国有巨人，举足数步即至归墟，一钓而连六鳌。
失去鳌背支撑的岱舆、员峤二山随即沉入北极，不知所终。

这段叙事揭示了归墟的另一面：它不仅吞噬水，也吞噬山。
任何失去支撑的固态之物，进入归墟都会被吞没。
五仙山的存续依赖人为维护（巨鳌托举），而非归墟本身的稳定。
归墟是毁灭的力场，一切存在于其中的事物都在对抗沉没。

## 东西对称：归墟与昆仑

《山海经》的宇宙结构以东西轴为核心骨架。

- 西极：[[昆仑之丘]]，高耸入天，是众水之源
- 东极：归墟（大壑），深不见底，是众水之终

昆仑发水，归墟收水。
水从西方最高处流出，经过大地，最终坠入东方最低处。
这构成了一个完整的宇宙水循环模型。

但这个循环有一个断裂：水到了归墟之后去了哪里？
「无增无减」意味着水并未积累。
如果水没有回到昆仑，那么水源终将枯竭。

先秦思想者似乎并不关心这个逻辑漏洞。
归墟的功能不是解释水循环，而是为宇宙设定一个绝对终点。
所有流动的事物都需要一个终结之处，归墟就是那个终结。

有趣的是，《庄子·秋水》提出了另一种解释：「天下之水，莫大于海。万川归之，不知何时止而不盈。」
庄子的海「不盈」与归墟的「不增」异曲同工。
但庄子将其归因于蒸发消散（「尾闾泄之，不知何时已而不虚」）。
归墟则拒绝任何解释，直接宣布：水到了这里就不存在了。
这是神话的力量所在：它不需要合理，只需要有力。

## 归墟与少昊之国

《大荒东经》将大壑与[[少昊]]之国放在同一条目。
少昊是东方之帝，金天氏，五帝之一。
他的国度位于东海之外、大壑之旁。

这个地理安排有深意。
少昊主西方之金（在五行方位说中），却被安置于东极。
一种解释是：少昊原本是东夷集团的首领，后被纳入华夏五帝体系时被重新分配了方位。
《山海经》保留了他作为东方首领的原始记忆。

帝[[颛顼]]幼年在少昊之国受教养（「少昊孺帝颛顼于此」）。
东极大壑之旁，既是宇宙的边界，也是帝王的摇篮。
终结之地同时是起源之地，这是《山海经》空间观的辩证特征。

少昊之国的存在还暗示了一个可能：大壑并非纯粹的毁灭之地。
如果连帝王的国都都能建在大壑之旁，那么深渊的危险或许是可以被驯服的。
少昊和他的子民与深渊共存，在世界尽头建立了文明。
这比单纯的「无底深渊」意象要复杂得多。

## 「归」字的哲学意涵

归墟之「归」值得单独分析。
在先秦语境中，「归」有回家、归宿、归结之意。
《易经》「归妹」、《诗经》「之子于归」，都指向一种终局性的到达。

天下之水「归」于墟，意味着水找到了自己的终极归宿。
不是中途停留，不是暂时蓄积，而是彻底到家。
墟（废墟、空虚）是水的家。
这个命名暗含一种冷酷的宇宙观：万物的归宿是空无。
河流奔腾万里，最终归于虚无。
这与《庄子》「万物方生方死」的哲学构成了微妙的呼应。

## 神话意义

**宇宙的排水口**：归墟是《山海经》对「水往何处去」的终极回答。
不是蒸发，不是循环，而是消失。
万水归墟而无增无减，意味着存在本身有一个底部的出口。
物质可以从宇宙中被永久移除。
这是一种与现代物理黑洞概念惊人相似的直觉。

**极限作为叙事边界**：归墟标定了《山海经》地理叙事的东部终止线。
再往东，没有更多的山、更多的国、更多的怪物。
只有无底深渊。
宇宙不是无限的，它有边，边上是虚空。
归墟这个名字本身就说明了一切：万物最终都要「归」于「墟」（废墟、虚无）。

**东方的双重性格**：在《山海经》中，东方既是日出之地，也是万水消亡之所。
[[汤谷]]和[[扶桑]]代表东方的新生与光明。
归墟代表东方的深渊与终结。
同一个方向同时承载希望和毁灭，这是先秦宇宙观中罕见的矛盾统一。
太阳每日从东方升起，万水每日向东方坠落。
生与灭在东极交汇，构成了宇宙最深层的节律。
