# 姑囗之山

**姑囗之山**是《山海经·[[中山经]]》中次七经所载的山峰。帝女死于此山，其名女尸，死后化为囗草——黄花，实如菟丘，服之能令人倾慕。（005-360）

## 原文出处

《[[中山经]]》：

> 又东二百里，曰姑囗之山。帝女死焉，其名曰女尸，化为囗草，其叶胥成，其华黄，其实如菟丘，服之媚于人。
>
> （005-360）

## 帝女之死与植物化身

帝女死于姑囗之山，化为囗草。这是一则完整的植物起源神话：神的死亡→身体变为植物→植物具有超自然功效。

| 要素 | 内容 |
|------|------|
| 死者 | 帝女（天帝之女） |
| 死后之名 | 女尸 |
| 化身 | 囗草 |
| 草的特征 | 叶胥成（叶片对生），华黄，实如菟丘 |
| 功效 | 服之媚于人 |

「服之媚于人」是《山海经》中唯一的媚药功效记录。五藏山经记载了大量草药的功效（已疟、不蛊、不字、不聋），但「媚于人」——使人获得魅力——在性质上完全不同于治病驱邪。这种功效来自帝女的神力：帝女之美在死后化入草中，服用者因此获得吸引他人的能力。（005-360）

## 帝系圣地群

姑囗之山位于中次七经的帝系圣地群中。前两座山都与「帝台」有关：

| 山 | 距离 | 帝系关联 | 功能 |
|------|------|------|------|
| 休囗之山 | — | 帝台之棋、帝台之石 | 祷百神、服之不蛊 |
| 鼓钟之山 | 东300里 | 帝台之所以觞百神 | 焉酸草可为毒 |
| **姑囗之山** | **东200里** | **帝女死焉** | **囗草服之媚于人** |
| 苦山 | 东20里 | — | 无条草服之不字 |

三座山构成从帝台（祭祀空间）到帝女（死亡与变容）的叙事递进。休囗之山和鼓钟之山是帝的祭祀之地，姑囗之山是帝女的殒命之地——从神圣仪式转向神圣死亡。（005-360）

## 与精卫的结构对称

帝女死后变容的故事在《山海经》中还有一例：[[精卫]]。两者的结构高度相似：

| 要素 | 姑囗之山·帝女 | 发鸠之山·[[精卫]] |
|------|------|------|
| 身份 | 帝女 | [[炎帝]]之女（女娃） |
| 死因 | 未记（「死焉」） | 溺于东海 |
| 化身 | 植物（囗草） | 动物（鸟） |
| 死后行为 | 被动（被人服用） | 主动（衔石填海） |
| 功效 | 媚于人（吸引力） | 填海（复仇意志） |

两位帝女都在死后获得了新的存在形式。但方向相反：精卫从被动的溺死转为主动的填海，姑囗之山的帝女从主动的生命转为被动的草药。一个是「失败而转化为永恒行动」，一个是「死亡而转化为永恒功用」。（005-360）

## 山海经中的「死后化植物」与「死后化动物」：两种帝女变容的对称

《山海经》记载了两位帝女的死后变容——姑囗之山的帝女化为植物（囗草），发鸠之山的女娃化为动物（精卫鸟）。两者构成一组精确的对称：

| 维度 | 姑囗之山·帝女 | 发鸠之山·女娃（[[精卫]]） |
|------|-------------|---------------------|
| 身份 | 帝女 | 炎帝少女 |
| 死因 | 未记（「死焉」） | 溺于东海 |
| 化身类别 | 植物（囗草） | 动物（精卫鸟） |
| 化身特征 | 黄花，实如菟丘 | 乌形，文首白喙赤足 |
| 死后行为 | 被动（被人服用） | 主动（衔木石填海） |
| 功效/目标 | 媚于人（给予魅力） | 以堙于东海（复仇/意志） |
| 出处 | 中次七経（005-360） | 北次三経（003-065） |

两种变容的方向完全相反。精卫从无助的溺亡者变成主动的复仇者——死亡激发了行动。帝女从有生命的人变成被动的草药——死亡消解了意志。一个向动（化鸟飞翔填海），一个向静（化草等人采食）。

但两者在一个层面上完全一致：帝女之死不是终结，而是转化。死亡释放了帝女体内的神力——精卫的神力表现为永不停止的意志（填海），帝女的神力表现为永恒的魅力（媚于人）。两种神力一刚一柔、一动一静，共同构成了《山海经》对「帝系女性死后命运」的完整想象。（005-360、003-065）
