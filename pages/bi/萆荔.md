# 萆荔

**萆荔**是[[西山经]]西次一经记载的药草，生于[[小华之山]]。形如乌韭（一种石上蕨类），生长在岩石上，赤色的茎蔓攀附树木而生，食之治心痛。（002-004）

## 原文出处

《[[西山经]]》西次一经：

> 其草有萆荔，状如乌韭，而生于石上，赤缘木而生，食之已心痛。
> （002-004）

## 双重生境

萆荔最独特的生态是「生于石上，赤缘木而生」，展示了一种两段式的生长过程：先在石上着生，然后以赤色的茎蔓攀附树木继续生长。这种生态类似现实中的附生植物（如石斛、络石），先以岩石为基质发芽，再以气生根攀缘至树干。

| 特征 | 内容 |
|------|------|
| 形状 | 如乌韭 |
| 第一生境 | 石上 |
| 第二生境 | 赤缘木（红色茎蔓攀木） |
| 药效 | 食之已心痛 |

## 乌韭之形

乌韭是古代对某类深色蕨类植物的通称，多生于潮湿石面。萆荔「状如乌韭」表明它具有蕨类植物的叶形，但不像乌韭那样只附着于石面，而是进一步攀上树木。「赤」色的茎蔓使萆荔在绿色的石苔和树干之间格外醒目。

## 心痛之药

萆荔的药效是「已心痛」，即治疗心痛。山海经中药效植物大多针对外部症状（癣、痈、疠），能治心痛的极少。心痛可指胸部疼痛或心脏不适，萆荔是山海经中罕见的作用于身体内部器官的药草。

## 小华之山的物产

萆荔所在的小华之山是西次一经第四山，物产丰富：

| 类别 | 物产 |
|------|------|
| 木 | 荆杞 |
| 兽 | 牛（多） |
| 矿（阴） | 磬石（乐器用石） |
| 矿（阳） | 珍玉 |
| 鸟 | 赤鷩（防火之鸟） |
| 草 | **萆荔**（治心痛） |

小华之山是华山系列的分支（小华相对于大华），磬石和珍玉的共产说明它是一座音乐与珍宝之山。萆荔在这座山上以石上草的身份低调存在，却拥有治疗心脏的独特药力。
