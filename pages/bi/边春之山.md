# 边春之山

**边春之山**是《山海经·[[北山经]]》北次一经所载的山峰。多葱、葵、韭、桃、李——北次一经中唯一大量记载食用植物的山。有异兽幽【安鸟】——善笑，见人则卧。杠水西流注于【氵幼】泽。（003-010）

## 原文出处

《[[北山经]]》北次一经：

> 又北百一十里，曰边春之山，多葱、葵、韭、桃、李。杠水出焉，而西流注于【氵幼】泽。有兽焉，其状如禺而文身，善笑，见人则卧，名曰幽【安鸟】，其鸣自呼。
>
> （003-010）

## 五种食用植物

边春之山的植物——全部可以吃：

| 植物 | 类型 |
|------|------|
| 葱 | 调味蔬菜 |
| 葵 | 食用蔬菜 |
| 韭 | 调味蔬菜 |
| 桃 | 水果 |
| 李 | 水果 |

三种蔬菜加两种水果——边春之山是一座天然的菜园和果园。北次一经的其他山大多「无草木」或只有矿产，边春之山却列出了五种食用植物——在荒山链中突然出现一座可以养活人的山。（003-010）

## 幽【安鸟】

边春之山的异兽——善笑，见人就躺下：

| 特征 | 描述 |
|------|------|
| 形态 | 如禺（猿），文身 |
| 习性一 | 善笑 |
| 习性二 | 见人则卧 |
| 叫声 | 自呼 |

「善笑，见人则卧」——这只猿形兽擅长笑，看到人就躺下来。不是逃跑、不是攻击、不是叫喊——而是笑着躺下。幽【安鸟】是《山海经》中最有「表情」的异兽之一——在一座满是食用植物的山上，有一只看到人就笑着躺下的兽。（003-010）

## 行为序列

幽【安鸟】处于北次一经中段一组异常行为兽的序列中：

| 山 | 兽 | 行为 |
|----|-----|------|
| 丹熏之山 | 耳鼠 | 以其尾飞（用尾巴飞） |
| [[石者之山]] | [[孟极]] | 善伏（擅长潜伏） |
| **边春之山** | **幽【安鸟】** | **善笑，见人则卧** |
| [[蔓联之山]] | 足訾 | 见人则呼（见人就叫） |

用尾巴飞→善于潜伏→笑着躺下→见人就叫——四只兽四种完全不同的行为模式。北次一经在这段山列中不再描述兽的形态，而是聚焦于它们的动作——每只兽都有一个签名动作。（003-008至003-011）

## 杠水

杠水西流注于【氵幼】泽——与灌题之山的匠韩之水同入一泽：

| 山 | 水 | 去向 |
|----|-----|------|
| **边春之山** | **杠水** | **西流入【氵幼】泽** |
| 灌题之山 | 匠韩之水 | 西流入【氵幼】泽 |

两条水从不同的山流向同一个泽——【氵幼】泽是这段山列的水系终点。单张之山的栎水还会南流汇入杠水——杠水是这个小水系的主干。（003-010、003-013）

## 北方荒山链中的「食用植物绿洲」：边春之山的农业信号

北次一经二十五山中，绝大多数山的记载要么「无草木」，要么只有矿产（金、玉、铁），极少记载可食用的植物。边春之山是显著的例外——五种植物全部可食：

| 山 | 植物记载 | 可食性 |
|----|---------|--------|
| 单狐之山 | 机木 | 不可食 |
| 敦薨之山 | 棕、楠、茈草 | 药用 |
| **边春之山** | **葱、葵、韭、桃、李** | **全部可食** |
| [[蔓联之山]] | 无草木 | — |
| 灌题之山 | 无草木 | — |

三种蔬菜（葱、葵、韭）+ 两种水果（桃、李）的组合不是野生植被的自然分布——这更像是人工种植的农产品清单。《山海经》在描述一座山的植被时，通常用「多草木」或记载特定的树种（楠、柏、桑等），而边春之山列出的是厨房里的蔬果。

「边春」之名也暗示了特殊性——「边」是边缘，「春」是生长的季节。在北方荒山的边缘地带出现一座「春天之山」，仿佛是冻土中一块永恒的春天。幽【安鸟】「善笑，见人则卧」的行为也与这座山的温和气质一致——不攻击、不逃跑，只是笑着躺下——在食物充足的山上，连异兽都是温和的。（003-010）
