# 表池

**表池**是《山海经·[[海内西经]]》所载的水域。位于[[昆仑]][[开明兽]]的南方——池边树木丛生，蛟、蝮、蛇、【虫隹】、豹等猛物聚集，还有[[鸟秩树]]、[[诵鸟]]、[[视肉]]。（012-023）

## 原文出处

《[[海内西经]]》：

> 开明南有树鸟，六首；蛟、蝮、蛇、【虫隹】、豹、鸟秩树，于表池树木，诵鸟、【隼鸟】视肉。
>
> （012-023）

## 开明四方

表池位于昆仑开明兽的南方——海内西经以开明兽为中心，描绘了昆仑的四个方向：

| 方位 | 内容 | 主题 |
|------|------|------|
| 北 | 珠树、文玉树、不死树、视肉 | 仙树群 |
| 东 | 六巫操不死药复活【上穴下契】窳 | 复活仪式 |
| 西 | 凤凰、鸾鸟 | 瑞鸟 |
| **南** | **表池——蛟蝮豹、树鸟诵鸟、视肉** | **百物聚池** |

北方是不死之树，东方是不死之药，西方是瑞鸟，南方是万物杂聚的池——四方各有侧重。表池是四方中生物种类最多的一处——猛兽、毒蛇、鸟、树、不死之肉全在一起。（012-020至012-023）

## 表之义

「表」——外面、表面：

| 字 | 义 |
|----|-----|
| 表 | 外、表面 |
| 池 | 水池 |

「表池」——外面的池。昆仑的核心是开明兽守卫的内部圣域——表池在南面，是圣域的外层。它不在最里面，在表面——是昆仑向外展开的一面。表池是昆仑由内向外的过渡地带。（012-023）

## 百物同在

表池周围的生物极其杂多：

| 类别 | 生物 |
|------|------|
| 水兽 | 蛟 |
| 毒蛇 | 蝮、蛇、【虫隹】 |
| 猛兽 | 豹 |
| 鸟 | 树鸟（六首）、诵鸟、【隼鸟】 |
| 植物 | 鸟秩树、树木 |
| 不死 | 视肉 |

蛟和豹是猛物，蝮和蛇是毒物，树鸟六首是异鸟，视肉是不死之肉——猛、毒、异、不死，四种性质的生物围着同一个池。表池不分类、不排斥——什么都收。这是昆仑南面的生态：不筛选，全部共存。（012-023）
