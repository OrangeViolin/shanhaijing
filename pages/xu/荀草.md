# 荀草

**荀草**是《山海经·[[中山经]]》中次三经所载的异草，生于[[青要之山]]（帝之密都）。状如蒫，方茎，黄华，赤实，根如藁本。服之美人色。（005-314）

## 原文出处

《[[中山经]]》中次三经：

> 有草焉，其状如蒫，其茎方，黄华赤实，其本如藁本，服之美人色。
>
> （005-314）

## 服之美人色

荀草唯一的功效——「服之美人色」：服食之后使人容色变美。这是《山海经》中极少数以美容为功效的药草：

| 药效类型 | 代表植物 | 功效 |
|---------|---------|------|
| 辟邪 | 薰草 | 佩之不蛊 |
| 治病 | 鬼草 | 服之不忧 |
| **美容** | **荀草** | **服之美人色** |

大多数山海经药草治病或辟邪，荀草却让人变美——它不治疗任何疾病，只改变人的外貌。在古代，「美色」不仅是审美，更是权力——美貌意味着受宠、意味着地位。一株能让人变美的草，其价值不亚于任何治病的仙药。（005-314）

## 帝之密都

荀草生长在[[青要之山]]——经文称之为「帝之密都」（天帝的秘密都城）。帝的密都中生长着美容仙草——这不是普通山野中的药草，而是天帝秘境中的珍品。只有进入帝之密都才能找到荀草——它被神圣的空间守护着。（005-314）

## 形态

荀草的形态描述极为精确：

| 部位 | 特征 |
|------|------|
| 整体 | 如蒫 |
| 茎 | 方形（四棱） |
| 花 | 黄色 |
| 果实 | 赤色 |
| 根 | 如藁本 |

方茎——四棱形的茎干，在圆茎为主的植物世界中格外醒目。黄花赤实——从花到果的颜色由黄变赤，暖色逐渐加深。根如藁本——藁本是一种芳香药草的根，暗示荀草的根部也有香气。一株方茎、黄花、红果、芳根的草——每个部位都有鲜明的特征。（005-314）
