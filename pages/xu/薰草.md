# 薰草

**薰草**是《山海经·[[西山经]]》西次一经所载的药草，生于浮山。麻叶方茎，赤华黑实，气味如蘼芜，佩戴可以治疗疠疫。（002-063）

## 原文出处

《[[西山经]]》：

> 又西百二十里，曰浮山，多盼木，枳叶而无伤，木虫居之。有草焉，名曰薰草，麻叶而方茎，赤华而黑实，臭如蘼芜，佩之可以已疠。
>
> （002-063）

## 形态与功效

| 特征 | 描述 |
|------|------|
| 叶 | 麻叶（如大麻叶，掌状裂片） |
| 茎 | 方茎（四棱茎） |
| 花 | 赤华（红花） |
| 果 | 黑实（黑色果实） |
| 气味 | 臭如蘼芜（芳香如蘼芜草） |
| 用法 | 佩之（佩戴于身） |
| 功效 | 已疠（治疗疠疫） |

薰草的使用方式是「佩之」而非「食之」——不是服用，而是佩戴。这种通过佩戴芳香植物来治病驱邪的方式，在古代中国有深厚传统：端午佩艾草、兰汤沐浴、佩香囊辟疫。薰草以浓烈的蘼芜般香气驱散疠气，属于芳香疗法。（002-063）

## 「已疠」：西次一经的疫病防治

疠是恶性传染病（疫病），在古代是最恐怖的灾难之一。西次一经此段集中了多种疾病治疗功效的植物：

| 山 | 草/物 | 功效 | 用法 |
|------|------|------|------|
| 石脆之山 | 草（如韭） | 已疥（治皮癣） | 食之 |
| 英山 | 肥遗鸟 | 已疠、杀虫 | 食之 |
| 竹山 | 黄囗草 | 已疥、已胕 | 浴之 |
| **浮山** | **薰草** | **已疠** | **佩之** |

四座山四种疗法——食、浴、佩——覆盖了古代医药的主要给药途径。薰草与英山的肥遗鸟功效相同（已疠），但一个是佩戴的草，一个是食用的鸟，构成草药与动物药的对偶。（002-063）

## 「臭如蘼芜」

蘼芜是古代著名的芳香植物（「臭」在古文中为气味之义，非恶臭）。薰草以蘼芜般的浓香著称，而「薰」字本身就含有芳香熏蒸之义。名如其实：薰草就是能薰散疫气的芳草。蘼芜在《诗经》《楚辞》中多次出现，是高洁芳香的象征。薰草以蘼芜为比，暗示它不仅有药效，更有超越实用的文化意涵。（002-063）
