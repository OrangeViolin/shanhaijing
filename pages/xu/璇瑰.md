# 璇瑰

**璇瑰**是《山海经·[[大荒西经]]》所载[[沃之野]]的宝玉。与甘华、瑶碧、琅【王千】等众多产物并列——楽园中的极上宝石。（016-017）

## 原文出处

《[[大荒西经]]》：

> 爰有甘华、璇瑰、甘【木且】、瑶碧、白木、白柳、视肉、琅【王千】、白丹、青丹、多银铁。
>
> （016-017）

## 璇与瑰

两个字都指美玉，叠加后是极致的珍贵：

| 字 | 义 |
|----|-----|
| 璇 | 美玉，璇玑（北斗星名）之璇 |
| 瑰 | 珍奇、瑰丽 |

「璇」用于北斗七星之「璇玑」——是天上的玉。「瑰」是地上最珍奇之物。璇瑰——天上的美加地上的奇，合为一块石头。（016-017）

## 沃之野

璇瑰所在的沃之野是《大荒西经》中的完美乐园：

| 属性 | 沃之野 |
|------|--------|
| 食 | 凤鸟之卵 |
| 饮 | 甘露 |
| 味 | 凡其所欲其味尽存 |
| 鸟 | 鸾凤自歌，凤鸟自舞 |
| 兽 | 百兽相群 |

想要什么味道就有什么味道——沃之野是《山海经》中最完美的楽园。璇瑰是这个楽园的宝石——在一个什么都不缺的地方，连石头都是最美的。（016-017）

## 产物序列

璇瑰在沃之野产物列表中排第二：

| 序 | 产物 | 类别 |
|----|------|------|
| 一 | 甘华 | 植物 |
| **二** | **璇瑰** | **宝玉** |
| 三 | 甘【木且】 | 植物 |
| 四 | 瑶碧 | 宝玉 |
| 五 | 白木 | 植物 |
| … | … | … |

植物→宝玉→植物→宝玉——产物列表交替排列，植物和宝石穿插出现。璇瑰是第一块出场的宝石——在所有宝玉中排在最前面。（016-017）
