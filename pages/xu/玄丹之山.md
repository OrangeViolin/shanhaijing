# 玄丹之山

**玄丹之山**是《山海经·[[大荒西经]]》所载的山。有五色之鸟，人面有发。有青鸨、黄鹗、青鸟、黄鸟。这些鸟集聚的国家将会灭亡。（016-031）

## 原文出处

《[[大荒西经]]》：

> 行玄丹之山。有五色之鸟，人面有发。爰有青鸨、黄鹗、青鸟、黄鸟，其所集者其国亡。
>
> （016-031）

## 亡国之鸟

玄丹之山的核心是一个恐怖的凶兆——「其所集者其国亡」：

| 要素 | 内容 |
|------|------|
| 主体 | 五色之鸟（人面有发） |
| 随从 | 青鸨、黄鹗、青鸟、黄鸟 |
| 凶兆 | 集聚之国必亡 |

这些鸟不是一只、两只，而是一群——五色之鸟带着四种随从鸟集体降临。它们落在哪个国家，哪个国家就会灭亡。这是《山海经》中最严重的凶兆之一——不是水旱、不是疫病、不是战争，而是直接的国家灭亡。（016-031）

## 人面有发

五色之鸟「人面有发」——拥有人的面孔和头发。

| 特征 | 描述 |
|------|------|
| 面 | 人面 |
| 发 | 有发（有人的头发） |
| 身 | 鸟身（五色） |

人面鸟身在《山海经》中并不罕见，但「有发」极为特殊——大多数人面异类不记载头发，五色之鸟特别标注了它有头发。一张有头发的人脸长在五色的鸟身上——它比普通的人面鸟更像人，更接近人的样子。越接近人的怪物越令人恐惧——五色之鸟几乎是一个长了翅膀的人头。（016-031）

## 玄丹之名

「玄」——黑色。「丹」——红色。玄丹之山以黑与红两种颜色命名：

| 色 | 象征 |
|----|------|
| 玄（黑） | 幽暗、死亡、北方 |
| 丹（红） | 鲜血、火焰、南方 |

黑与红是最不祥的颜色组合——黑色的幽暗加红色的鲜血。山以「玄丹」为名，山上的鸟带来亡国的凶兆——山名本身就预告了灾祸。（016-031）

## 创世与毁灭

玄丹之山紧接在常羲浴月之后：

| 行 | 条目 | 性质 |
|----|------|------|
| 016-030 | 常羲浴月 | 创世（帝俊妻生十二月） |
| **016-031** | **玄丹之山** | **毁灭（亡国凶兆）** |
| 016-032 | 孟翼攻颛顼之池 | 冲突 |

常羲为月亮沐浴——这是创世的行为，十二个月亮从这里诞生。紧接着就是五色之鸟的亡国凶兆。大荒西经在这里将创造与毁灭并置：月亮的诞生与国家的灭亡仅一山之隔。（016-031）

## 四种随从鸟

五色之鸟之外还有四种鸟——青鸨、黄鹗、青鸟、黄鸟——形成青黄交替的色彩序列：

| 鸟 | 色 |
|----|------|
| 青鸨 | 青 |
| 黄鹗 | 黄 |
| 青鸟 | 青 |
| 黄鸟 | 黄 |

青、黄、青、黄——严格交替。五色之鸟是首领，四种鸟是它的随从。五色之鸟有人面，四种随从鸟可能是普通鸟形。一个人面鸟带着四只彩色鸟降临——亡国的使团。（016-031）
