# 璇玉

**璇玉**是《山海经·[[中山経]]》中次五経所载的美玉。产于[[升山]]的黄酸之水中——黄酸之水北流注于河。升山为冢山——太牢祭祀。（005-013）

## 原文出处

《[[中山経]]》中次五経：

> 又东北二十里，曰升山，其木其多楮柞棘，其草多【上艹下诸】蕙，多寇脱。黄酸之水出焉，而北流注于河，其中多璇玉。
>
> （005-013）

## 璇之名

「璇」不是普通的玉名——而是天文祭祀级的美称：

| 属性 | 内容 |
|------|------|
| 名 | 璇玉 |
| 产地 | 升山·黄酸之水 |
| 「璇」的含义 | 美玉、北斗七星第二星（璇玑） |

「璇」字用于北斗第二星「璇玑」——与天文和祭祀直接关联。璇玉产自冢山的水中——冢山是山系中等级最高的山——用太牢和吉玉祭祀。主山产天文级美玉——山的神圣等级和产物的格级对应。（005-013）

## 升山：冢山与璇玉

升山是中次五経的冢山——祭祀规格最高：

| 属性 | 内容 |
|------|------|
| 山名 | 升山 |
| 地位 | 冢山 |
| 木 | 楮、柞、棘 |
| 草 | 【上艹下诸】、蕙、寇脱 |
| 水 | 黄酸之水（北流注河） |
| 玉 | 璇玉 |

草木丰富——水流入黄河——产璇玉。冢山同时拥有植被、水系和宝玉——是山系中最完整的山。璇玉在水中——被黄酸之水自然冲刷打磨——水流造就美玉。（005-013）

## 璇玉与璇瑰

山海経中有两个「璇」字的玉——分属不同语境：

| 名 | 出处 | 语境 | PN |
|----|------|------|-----|
| **璇玉** | 中次五経·升山 | 地理产物（山水中） | 005-013 |
| [[璇瑰]] | 大荒西経·沃之野 | 乐园宝物 | 016-017 |

璇玉是具体山水中的产物——有山名、水名、流向。璇瑰是乐园（沃之野）的宝物——属于神话世界。同一个「璇」字——一个扎根地理——一个飘在神话。山经的璇是可以找到的——荒经的璇是可以想象的。（005-013）
