# 宣余之水

**宣余之水**是《山海经·[[中山经]]》中次三经所载的河川，发源于风雨之山，东流注于江（长江）。水中多蛇。（004-034）

## 原文出处

《[[中山经]]》中次三经：

> 又东一百五十里，曰风雨之山，其上多白金，其下多石涅，其木多【木取】【木单】，多杨。宣余之水出焉，东流注于江，其中多蛇，其兽多闾麋，多【上鹿下主】豹虎，其鸟多白【乔鸟】。
>
> （004-034）

## 多蛇之水

宣余之水最突出的特征是「其中多蛇」。《山海经》的河流通常记载鱼类，以蛇作为水中主要生物的河流极为少见。水蛇的大量存在暗示这是一条温暖、水流缓慢的河流——适合蛇类栖息的湿热环境。（004-034）

## 风雨之山的丰富生态

宣余之水的源山风雨之山拥有中次三经中最丰富的生态记载：

| 类别 | 产物 |
|------|------|
| 矿产（上） | 白金 |
| 矿产（下） | 石涅 |
| 木 | 【木取】、【木单】、杨 |
| 水中 | 蛇 |
| 兽 | 闾麋、【上鹿下主】、豹、虎 |
| 鸟 | 白【乔鸟】 |

矿产、树木、水蛇、四种兽、白鸟——风雨之山的信息量在中次三经中名列前茅。宣余之水流经的是一片生态极为丰富的区域。（004-034）

## 长江水系

宣余之水「东流注于江」——汇入长江。中次三经的这一段山列多条河流都流入长江：

| 山 | 水 | 流向 |
|----|-----|------|
| 岐山 | 【氵咸】水 | 东南流注于江 |
| **风雨之山** | **宣余之水** | **东流注于江** |

两条相邻的水都流入长江，说明中次三经的这一区域位于长江以北、靠近长江的山地——可能对应今天的川鄂山区。（004-034）

## 通向熊山

风雨之山的下一座山是玉山，再下一座是熊山——「有穴焉，熊之穴，恒出神人。夏启而冬闭」。宣余之水的蛇、风雨之山的豹虎——这一带的荒野气息为熊山的神秘洞穴做了铺垫。（004-034）
