# 暴山

**暴山**是《山海经》[[中山经]]中次十二经（洞庭山系）记载的山。位于[[洞庭之山]]东南一百八十里，植被极为多样，矿产丰富，鹿科动物密集，以自然地志描写为核心，无神话附记。（005-197）

## 原文出处

《[[中山经]]》中次十二经：

> 又东南一百八十里，曰暴山，其木多棕、【木丹】、荆、芑、竹、箭、【上竹下媚】、菌，其上多黄金玉，其下多文石铁，其兽多麋、鹿、【上鹿下旨】、就。
> （005-197）

## 植被：八种植物的极密记录

暴山的植物记述是中山经中植物物种数最多的山之一，连续列举八种：

| 植物名 | 类属 |
|--------|------|
| 棕 | 棕榈科，棕树 |
| 【木丹】 | 木本植物，具体种类待考 |
| 荆 | 荆条，灌木 |
| 芑 | 苦菜或野黍，草本 |
| 竹 | 禾本科竹亚科 |
| 箭 | 细竹，箭竹 |
| 【上竹下媚】 | 竹类 |
| 菌 | 菌类植物 |

八种植物涵盖乔木（棕）、灌木（荆）、草本（芑）、竹类（竹、箭、【上竹下媚】）、真菌（菌）五个层次，代表了亚热带山地生态系统的垂直分布完整性。洞庭山系地处今湖南，棕榈、竹类、荆条均为该地区典型植被，记述与实际地理高度吻合。

对比相邻各山的植被记述：[[洞庭之山]]（005-196）只列【木且】、梨、橘、【木繇】四种，即公之山（005-198）列柳、杻、檀、桑四种。暴山八种是前后两山的两倍，说明编纂者将暴山视为洞庭山系的植被核心聚集地。

## 矿产：上下分布的双层结构

暴山的矿产记述具有明确的垂直分层：

- 山上：黄金、玉
- 山下：文石、铁

「山上多黄金玉，山下多文石铁」是中山经矿产记述的一种常见格式，但暴山的两层各含两种矿产，共四种，比大多数山（通常仅一种）要丰富。黄金与玉的组合出现于山顶，属于贵重礼器材料；文石（有纹理的石材）与铁的组合出现于山麓，属于建筑与器械材料，体现了从高贵到实用的垂直价值梯度。

## 鹿科动物：四种集中栖居

暴山的兽类记述只列鹿科动物，连续四种：麋、鹿、【上鹿下旨】、就。

麋（麋鹿，四不像）和鹿是先秦文献中最常见的猎物。【上鹿下旨】和「就」是中山经记载的两种具体鹿类，前者可能为獐或麝，后者待考。四种鹿科动物同时密集出现，反映洞庭山南段在当时是重要的鹿群栖息地，与今洞庭湖周边历史上丰富的麋鹿分布记录相互印证。

## 在洞庭山系中的位置

暴山是中次十二经从[[洞庭之山]]（005-196）向东南延伸的第一站，连接神话核心区与自然地志区。

[[洞庭之山]]（005-196）是帝之二女（即[[湘君]][[湘夫人]]）的居所，「常游于江渊。澧沅之风，交潇湘之渊，是在九江之间，出入必以飘风暴雨，是多怪神」，充满神话色彩与超自然气象。

暴山（005-197）紧随其后，记述完全转向自然地志：无神、无怪，只有植被、矿产、动物的客观列举。这种转变并非偶然，中次十二经的编纂显示出从神话核心（洞庭）向外围自然区（即公之山、尧山、江浮之山等）递进的结构逻辑，暴山是这个转变的起点。

即公之山（005-198）紧接暴山，出现龟形怪兽「蓐（名曰蓐，是可以御火）」，暴山的纯自然地志性质使其在神话（洞庭）与异兽（即公）之间充当过渡缓冲。

## 洞庭山系的祭祀体系

中次十二经末（005-200）记录了洞庭山系的统一祭祀规定：

> 凡洞庭山之首，自篇遇之山至于荣余之山，凡十九山，二千八百里。其神状皆鸟身而龙首。其祠：毛用一雄鸡、一牝豚刮，糈用秔。凡夫夫之山、即公之山、尧山、阳帝之山皆冢也，其祠：皆肆瘗，祈用酒，毛用少牢，婴毛一吉玉。洞庭、荣余山神也，其祠：皆肆瘗，祈酒太牢祠，婴用圭璧十五，五采惠之。

暴山属于一般山（非冢山、非山神），适用普通祭祀规格：毛用一雄鸡一牝豚，糈用稻米精。这与洞庭、荣余（山神级，圭璧十五）和夫夫之山等（冢山级，少牢）形成明显的祭祀等级差异，暴山的植被与矿产丰富并未给予其更高的神圣地位。

## 暴山的「纯自然地志」属性

暴山是中次十二经中极少数完全不包含异兽、神灵或超自然事件的山条之一。在[[洞庭之山]]（帝之二女、怪神、飘风暴雨）与即公之山（蓐兽、御火药效）之间，暴山以纯粹的植被-矿产-动物三段式记录构成一个「去神话化」的节点：

| 山名 | 神话要素 | 自然要素 | 出处 |
|------|---------|---------|------|
| [[洞庭之山]] | 帝之二女、怪神、飘风暴雨 | 澧沅、九江 | 005-196 |
| **暴山** | **无** | **蕙棠/金玉/麋鹿等** | **005-197** |
| 即公之山 | 蓐兽（御火） | 无 | 005-198 |

《山海经》中每一座「纯自然」的山都在叙事中承担缓冲功能，使读者从神话的高密度中暂时松弛，为下一波异兽的出现做准备。暴山的四种鹿科动物（麋、鹿、【上鹿下旨】、就）是《山海经》中同一山条记录鹿种最多的案例，以动物多样性替代了神话奇异性，使洞庭山系的自然生态维度得到充分展示（005-197）。
