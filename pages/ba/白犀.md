# 白犀

**白犀**是[[中山经]]中次八经记载的兽类，群栖于[[琴鼓之山]]。山海经中唯一以白色冠名的犀牛，与毒鸟[[鸩]]共栖于中次八经的末山。（005-112）

## 原文出处

《[[中山经]]》中次八经：

> 其兽多豕鹿，多白犀，其鸟多鸩。
> （005-112）

## 白色之犀

山海经中犀牛出现频繁，通常以「犀兕」并记，指犀牛与野牛两种大型兽共栖。白犀是唯一以色彩冠名的犀牛。「白」可能指白色的毛皮、白色的角，或整体偏白的体色。

犀角在古代中国被视为辟邪灵物，白色又是山海经中与灵性、珍贵相关的色彩（白玉、白金、[[白鹿]]）。白犀兼具犀的大型兽格和白色的灵性标记，是犀牛中的特异品种。

## 琴鼓之山的生态

琴鼓之山是中次八经（荆山之首）的末山，白犀与多种动植物矿产共存：

| 类别 | 物产 |
|------|------|
| 兽 | 豕、鹿、白犀 |
| 鸟 | [[鸩]]（毒鸟） |
| 木 | 楮、柞、椒、柘 |
| 矿 | [[白珉]]（山上）、洗石（山下） |

白犀与鸩是琴鼓之山最引人注目的两种动物。白犀是大型危险兽，鸩是以毒闻名的鸟。两者共栖说明琴鼓之山是一座动物资源丰富但危险性极高的山。

## 中次八经末山的收束

琴鼓之山是中次八经二十三山、二千八百九十里山列的终点（005-113）。作为末山，琴鼓之山汇集了丰富的物产：四种树木、两种矿石、三种兽、一种鸟。白犀作为「多」产的大兽出现在末山，为整条山列的动物谱系画上句号。

中次八经的神灵形态为「鸟身而人面」，祭祀用雄鸡一只祈瘗。鸟身人面的山神与琴鼓之山的毒鸟鸩之间构成呼应：山神以鸟为身，末山以毒鸟为标志。
