# 白鸟

**白鸟**是《[[大荒西经]]》记载的鸟,栖息于[[金门之山]]附近。白色身体,青色翅膀,黄色尾巴,黑色嘴喙,四种颜色集于一身。与[[比翼之鸟]]、[[天犬]]（赤犬）同列于金门之山条目。（016-035）

## 原文出处

《[[大荒西经]]》：

> 有金门之山,有人名曰黄【女巨】之尸。有比翼之鸟。有白鸟,青翼,黄尾,玄喙。有赤犬,名曰天犬,其所下者有兵。
>
> （016-035）

## 四色与五行

白鸟的白、青、黄、玄（黑）四色,恰好对应五行中的金（白）、木（青）、土（黄）、水（黑）四色,唯独缺少火（赤）。而同一条目中紧接着记载的[[天犬]]是赤犬,补全了缺失的赤色。白鸟与天犬合在一起,白、青、黄、黑、赤五色齐备,五行全数到场。

这不太可能是巧合。金门之山的记述将五行之色分配到两个生物身上:四色归鸟,一色归犬。鸟主天,犬主地,天上四色,地上一色,构成天多地少的不对称配置。五色在一个山条内完成闭合,这在《山海经》中极为罕见。

## 金门之山的四重存在

金门之山条目记载了四种存在,各有不同性质:

| 存在 | 类别 | 特征 | 预兆 |
|------|------|------|------|
| 黄【女巨】之尸 | 人尸 | 仅记名字 | 无 |
| [[比翼之鸟]] | 鸟 | 二鸟一体飞行 | 无 |
| 白鸟 | 鸟 | 白体青翼黄尾玄喙 | 无 |
| [[天犬]] | 兽 | 赤色 | 「其所下者有兵」 |

四者中只有天犬带有预兆,且是兵祸之凶兆。白鸟没有任何吉凶描述,只记录形态。《山海经》多数异鸟都附带「见则」或「食之」的功效预兆,白鸟却是纯粹的形态记录。这种纯描述性的鸟在全书中属于少数。白鸟的沉默与天犬的凶兆形成对照:一个只有颜色,一个只有灾祸。

## 昆仑门户

金门之山的下一条就是昆仑之丘:「西海之南,流沙之滨,赤水之后,黑水之前,有大山,名曰昆仑之丘。」（016-036）[[西王母]]在昆仑居住,有弱水之渊环绕,炎火之山围护。金门之山在文本序列上直接位于昆仑之前,「金门」之名暗示这是通往昆仑的门户。

金门之山汇集人尸、灵鸟、神兽四种存在,加上五色齐备的色彩结构,整座山像一个仪式性的入口:在进入昆仑圣域之前,先经过这个五色具足、灵物聚集的门槛。白鸟作为携带四色的鸟,是这个门槛上最醒目的色彩载体。

## 大荒西经的鸟类谱系

大荒西经记载了多种异鸟,白鸟的色彩定义方式在其中独树一帜:

- [[比翼之鸟]]:以行为定义（二鸟合飞）
- 白鸟:以四色配色定义（白、青、黄、玄）
- [[天犬]]虽名犬,但与鸟类并列

白鸟是大荒西经中唯一以多色配色为核心特征的鸟。其他鸟要么以单色命名（如青鸟）,要么以行为命名（如比翼之鸟）,白鸟却用四个色彩词逐一描述翼、尾、喙的颜色,这种精细的色彩记录手法说明编纂者对白鸟的关注点在于它的视觉呈现。
