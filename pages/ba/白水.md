# 白水

**白水**是《山海经》中两部经文记载的水。[[大荒南経]]出[[白水山]]，生[[白渊]]，[[昆吾]]之师所浴（011-021）。[[海内東経]]出蜀，东南注[[江]]，入江州城下（014-012）。

## 原文出处

### 大荒南経

> 又有白水山，白水出焉，而生白渊，昆吾之师所浴也。
>
> （011-021）

### 海内東経

> 白水出蜀，而东南注江，入江州城下。
>
> （014-012）

## 两种白水

神话之水和地理之水同名异质：

| | 大荒南経 | 海内東経 |
|--|---------|---------|
| 源头 | 白水山 | 蜀 |
| 流向 | 生白渊 | 东南注江 |
| 终点 | 白渊（昆吾之师浴处） | 江州城下 |
| 性质 | 神话水系 | 实地理水系 |
| PN | 011-021 | 014-012 |

大荒南経的白水流入白渊成为昆吾之师沐浴的圣水。海内東経的白水从蜀地流出注入长江。一条是圣浴之水一条是实际的河流。（011-021、014-012）

## 白水→白渊→昆吾

大荒南経的白水形成三段链条：

| 阶段 | 内容 |
|------|------|
| 源 | 白水山 |
| 汇 | 白渊 |
| 用 | 昆吾之师所浴 |

「昆吾之师」昆吾的军队或师从者。昆吾是[[颛顼]]系的后裔同段经文就有「有国曰颛顼」。白水从白色的山流出、汇成白色的渊、供颛顼后裔的师众沐浴整条水系都是「白」的。（011-021）

## 颛顼空间

白水山周围是颛顼系的地理空间同段经文密集排列地名：

> 有国曰颛顼，生伯服，食黍。有鼬姓之国。有苕山。又有宗山。又有姓山，又有壑山。又有陈州山，又有东州山。又有白水山……

十余个地名连续列出白水山是这组地名的最后一个。颛顼国、众山、白水山全在同一片空间。（011-021）
