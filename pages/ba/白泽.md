# 白泽

**白泽**是中国神话中最具「知识」的瑞兽：能说人话，通晓天下一万一千五百二十种鬼神精怪的名称、形态和趋避方法。[[黄帝]]巡狩至东海时遇白泽，记录其所述而成《白泽图》，一部实用版鬼神百科。

## 原文出处

白泽不直接见于《山海经》经文。其详细记载主要出自《云笈七签》卷一〇〇引《轩辕本纪》及《瑞应图》等后世文献。但白泽的神话根基与《山海经》的知识体系一脉相承。《山海经》中已有「此山万物尽有」（016-036）的万物汇聚母题，以及「天地鬼神，是食是飨」（002-042）的鬼神知识体系，白泽正是这一知识传统的人格化延伸。

## 核心能力

| 能力 | 描述 |
|------|------|
| 能言 | 说人话，异兽中极罕见 |
| 通晓万物 | 知道 11,520 种精怪 |
| 命名 | 知道每种精怪的真名 |
| 趋避 | 知道如何驱逐每种精怪 |

白泽的力量不在于武力，而在于**信息**。它掌握了所有精怪的「真名」。在上古世界观中，知道精怪的名字就能控制它。《山海经》自身即是这一逻辑的实践：每记一兽，必先命名，名定则性定。

## 与黄帝的关联

白泽向[[黄帝]]口述万物，这一关系并非偶然。《山海经》中黄帝是上古知识秩序的建立者：「黄帝是食是飨」昆仑玉膏（002-042），「黄帝生禺【豸虎】」（015-023）建立东海神系。黄帝问白泽，本质是最高统治者向知识之兽索取治世所需的信息。

## 关联实体

- [[黄帝]]：向白泽问道的帝王
- [[开明兽]]：同为高智慧神兽，「开明兽身大类虎而九首，皆人面」（012-018），守护昆仑
- [[陆吾]]：同为具有人面特征的守护兽

## 神话意义

**知识即权力的原型**。白泽是「百科全书」的活体化身。在鬼神遍地的世界中，掌握所有鬼神真名的存在就是最强大的存在，不需要战斗，只需要「知道」。《白泽图》作为趋吉避凶手册，本质上就是一部实用版《山海经》。

**与《山海经》的镜像关系**。《山海经》记录万物形状与征兆，白泽口述万物名称与趋避，两者是同一知识体系的不同载体。白泽是《山海经》世界观内部的「元注释」。
