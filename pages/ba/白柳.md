# 白柳

**白柳**是[[大荒西经]]记载的[[沃之野]]产物，白色的柳树。与[[白木]]并列为沃之野白色系树木，是西方理想郷豊饶与清净的植物标记。（016-017）

## 原文出处

《[[大荒西经]]》：

> 爰有甘华、璇瑰、甘柤、瑶碧、白木、白柳、视肉、琅玕、白丹、青丹、多银铁。
> （016-017）

## 沃之野的产物序列

白柳出现在沃之野产物的长列举中，与各类宝物并列：

| 类别 | 产物 |
|------|------|
| 花果 | 甘华、甘柤 |
| 宝石 | 璇瑰、瑶碧、琅玕 |
| 树木 | [[白木]]、**白柳** |
| 灵物 | [[视肉]] |
| 丹药 | 白丹、青丹 |
| 金属 | 银、铁 |

白柳与白木紧邻排列，两种白色树木构成一组。在宝石、灵物、丹药、金属的华丽阵列中，树木以白色呼应宝石的光泽和丹药的纯净。

## 白色系植物的意义

山海经中以「白」冠名的植物稀少。白木和白柳作为一对白色树木出现在沃之野，「白」在此不仅是颜色，更是理想郷清净属性的标记。

沃之野的特征是「凡其所欲其味尽存」（所有想要的味道都有），鸾鸟自歌、凤鸟自舞、百兽相与群居。这是一片万物和谐的乐土。白柳的白色与这种清净和谐一致：白是无染之色，柳是柔顺之木。

## 沃之野：西方极乐

沃之野是大荒西经中西方理想郷的极致：

| 要素 | 内容 |
|------|------|
| 食 | 凤鸟之卵，甘露 |
| 居 | 沃之国，沃民 |
| 邻 | 王母之山、壑山、海山 |
| 动物 | 鸾凤自歌舞，百兽群居 |
| 植物 | 白木、白柳、甘华、甘柤 |
| 矿宝 | 璇瑰、瑶碧、琅玕、银铁 |

海外西经的「诸夭之野」也有鸾鸟自歌、凤鸟自舞的记述（007-018），与沃之野构成海外经与大荒经中西方乐土的对应版本。白柳在两个版本中都是这片乐土物产的一部分。

## 柳之性质

柳在古代中国是水边常见的树木，性柔韧，枝条下垂。白柳保留了柳的柔软特性，加上白色的超凡外表，是一种兼具凡间柳树形态和仙境色彩的植物。在沃之野这样百兽和鸣、万味俱全的乐土中，白柳与甘华（甜花）、甘柤（甜果）共同构成植物层面的完美：花是甜的，果是甜的，树是白的。
