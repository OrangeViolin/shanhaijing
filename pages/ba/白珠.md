# 白珠

**白珠**は[[西山経]]に記載される宝物である。[[数历之山]]から流れ出る楚水の中に多く産する。（002-023）

## 原文出処

《[[西山経]]》：

> 楚水出焉，而南流注于渭，其中多白珠。
> （002-023）

## 解説

数历之山から南に流れて渭水に注ぐ楚水の中に産する白い真珠。西山経には各地の水系に珠玉が産する記述が多い。

## 数历之山と楚水

数历之山は西次二経の第三山で、山上に黄金、山下に銀が多く、鸚鵡が棲む。楚水がここから南に流れて渭水に注ぐ。渭水は西山経の主要河川で、多くの支流が金玉や珠を産出する。

| 要素 | 内容 |
|------|------|
| 産出水域 | 楚水 |
| 水源の山 | [[数历之山]] |
| 流向 | 南 |
| 注入 | 渭水 |
| 山の鉱物 | 黄金・銀 |

## 西次二経の水産資源

西次二経は鈐山から始まる山列で、各山の水系に珍しい産物が記される。泰冒之山の浴水には藻玉と白蛇、数历之山の楚水には白珠、高山の泾水には馨石と青碧がある。白珠はこの水系資源群の一環として位置づけられる。
