# 巴国

**巴国**是《[[海内经]]》所载的西南邦国，拥有《山海经》中最完整的四代建国谱系：[[大皞]]→咸鸟→乘厘→后照。后照"是始为巴人"，是巴族的始祖。这条谱系将东方之帝大皞的血脉延伸至西南巴蜀，是《山海经》民族起源叙事中的典型案例。

## 原文出处

> 西南有巴国。大【白皋】生咸鸟，咸鸟生乘厘，乘厘生后照，后照是始为巴人。
>
> （018-014）

## 地理描述

《海内经》以"西南有巴国"一语定位，未给出更具体的山水方位。在《海内经》的叙事排列中，巴国紧邻[[流黄辛氏]]之国和[[巴遂山]]："有国名曰流黄辛氏，其域中方三百里，其出是尘土。有巴遂山，渑水出焉。"（018-015）[[巴遂山]]与巴国共享"巴"字，暗示两者在地理和族群上的关联。

从先秦历史地理看，巴国对应今四川东部、重庆一带的古巴国。《华阳国志·巴志》记载巴国疆域"东至鱼复，西至僰道，北接汉中，南极黔涪"，是西南地区最重要的古国之一。

## 谱系分析

### 四代传承结构

巴国谱系为《山海经》中少数完整保存四代以上世系的记载：

| 世代 | 人物 | 说明 |
|------|------|------|
| 第一代 | 大【白皋】（大皞/太皞） | 东方之帝，伏羲系统的上古帝王 |
| 第二代 | 咸鸟 | 大皞之子，名中含"鸟"，呼应东方鸟图腾 |
| 第三代 | 乘厘 | 咸鸟之子，过渡世代 |
| 第四代 | 后照 | "是始为巴人"，巴族始祖 |

"是始为巴人"的句式在《山海经》中具有特定功能,标记一个族群的起源时刻。类似表述见于其他建国谱系，如"后稷是播百谷"等，将某一人物确认为特定技艺或族群的始创者。

### 东方血脉与西南建国的矛盾

巴国谱系中最引人注目的是方位矛盾：始祖大皞是传统的东方之帝（与春天、东方、木德相关），但巴国位于"西南"。这种东方血统建立西南邦国的叙事模式，有几种可能的解读：

其一，反映了上古族群迁徙的历史记忆,大皞后裔从东方迁往西南并建国。其二，《山海经》的谱系编排将所有重要邦国都追溯到少数几位上古帝王（帝俊、黄帝、大皞等），方位矛盾是这种"中心化谱系"策略的自然结果。其三，大皞本身可能并非专属于东方的帝王，其在《山海经》体系中的方位属性与后世五行体系的配置未必一致。

### 与其他建国谱系的比较

《海内经》集中记载了多个邦国的建国谱系，可作横向对比：

| 邦国 | 始祖追溯 | 中间世代 | 建国者 |
|------|---------|---------|--------|
| 巴国 | 大皞 | 咸鸟→乘厘 | 后照 |
| 朝鲜 | 帝俊 | 无 | 无 |
| 氐羌 | 炎帝 | 无 | 无 |

巴国的谱系比其他邦国更为详细，保留了两个中间世代（咸鸟、乘厘），这在《山海经》的建国叙事中属于罕见的完整保存。

## 咸鸟与鸟图腾

咸鸟之名含"鸟"字，与大皞系统的鸟图腾传统呼应。《左传·昭公十七年》记载少皞"以鸟名官"，少皞与大皞（太皞）同属东方帝系。巴国始祖谱系中出现鸟名人物，可能反映了巴族与东方鸟图腾族群的文化联系。考古发现的三星堆青铜鸟和巴蜀符号中的鸟形纹，或可作为旁证。

## 谱系深度与邦国重要性的关系

《山海经》中建国谱系的详细程度并不均匀,这种差异本身就是信息。通过比较谱系的代际深度,可以窥见编纂者对各邦国的关注程度:

| 谱系深度 | 邦国 | 始祖 | 备注 |
|---------|------|------|------|
| 四代(最详) | **巴国** | 大皞 | 咸鸟→乘厘→后照 |
| 三代 | [[苗民]] | [[颛顼]] | 驩头→苗民 |
| 两代 | [[氐羌]] | 炎帝 | 直接"炎帝之孙" |
| 一代(直系) | 多数国族 | 帝俊/黄帝 | "帝俊生X" |

巴国四代谱系的完整保存意味着两种可能: 其一,巴族本身保存了完整的口传世系,被《山海经》编纂者如实收录; 其二,编纂者有意为巴国构建了更长的谱系链,以强调其与东方帝系的血脉距离(四代的间隔正好解释了从东方到西南的"迁移时间")。

与[[苗民]]的三代谱系(颛顼→驩头→苗民)相比,巴国多出一个中间世代(乘厘),但苗民的谱系在每一代都附有具体的异形特征(驩头鸟喙,苗民有翼),而巴国的中间世代(咸鸟、乘厘)仅有姓名,缺乏形态描述。两种谱系各有侧重: 苗民谱系记录"变化"(从帝到鸟人的形态渐变),巴国谱系记录"延续"(从帝到人的名号传承)。

## 西南邦国集群: 巴国的区域位置

《海内经》的西南区域集中了一批邦国和地理实体,巴国并非孤立存在:

| 邦国/地名 | 特征 | 与巴国的关系 |
|-----------|------|-------------|
| **巴国** | 大皞后裔,后照始祖 | 核心 |
| [[巴遂山]] | 渑水发源 | 共享"巴"字,地理关联 |
| [[流黄辛氏]] | 域中方三百里 | 文本紧邻巴国 |
| [[都广之野]] | 后稷播百谷 | 同属西南区域的神话核心地 |
| [[朱卷之国]] | 未详 | 上下文邻近 |

这一区域在《海内经》中构成了西南方向的"建国带",多个邦国的始祖谱系在此集中出现。巴国是其中谱系最完整的一个,可以视为这一区域叙事的锚点。

与[[都广之野]]的对比尤为有趣: 都广之野是[[后稷]]"播百谷"之地,代表农业文明的起源; 巴国是后照"始为巴人"之地,代表族群的建立。两者同在西南,一个关于技艺的发明,一个关于民族的诞生,共同构成《海内经》西南叙事的双重主题。

## 海内经西南区域的邦国集群

巴国并非《海内经》中孤立的西南邦国。其上下文环境包括：

- 前文：[[九丘]]（陶唐之丘、叔得之丘等九丘以水相络）和窫窳
- 后文：[[流黄辛氏]]之国（域中方三百里）、[[巴遂山]]（渑水出焉）、[[朱卷之国]]

这些邦国和地理实体在文本中紧密排列，构成《海内经》对西南区域的集中描述。巴国是这一区域叙事的核心锚点。

## 静默的建国：巴国与《山海经》战争叙事的距离

《山海经》中许多邦国的记载与战争密切相关。[[苗民]]因三苗作乱而遭[[帝尧]]讨伐（016-030），[[蚩尤]]与[[黄帝]]在涿鹿发生大战，[[共工]]触山是争帝战败的后果。与这些充满冲突张力的叙事相比，巴国谱系的记载极为平静，没有战争、没有灾难、没有神异，只是四代人物名号的依次传递。

这种"静默的建国"在《山海经》中颇为罕见。大多数邦国的起源不是与神灵冲突相关，便是与天地灾变相连。巴国的安静建立，或许恰恰反映了巴族自身的文化特性，或者是编纂者所能获得的巴族史料仅限于世系名号，历史细节早已失传。

后照"是始为巴人"的措辞不含任何传奇色彩，他既没有发明什么技艺（如[[般]]发明弓矢），也没有立下什么功绩（如[[后稷]]播百谷）。他的唯一功能是成为第一个巴人。这种纯粹的族群起源叙事，与《山海经》惯常的神话英雄模式形成鲜明对比。

## 巴国谱系与[[成汤]]灭夏的叙事时序

从《山海经》整体的时间叙事看，巴国谱系属于远古建国时代，与大皞、[[帝俊]]等上古帝王同属神话纪元。而[[成汤]]伐夏桀（016-040）则将叙事推进到历史时期的王朝更替。两者虽都出现在《海内经》及相关经卷中，却属于截然不同的时间层次。

巴国的存在使《山海经》的西南叙事具备了族源维度：这片土地上的人从哪里来？答案是从东方之帝大皞的血脉迁徙而来。这一答案与[[成汤]]所代表的王朝政治逻辑平行存在，前者解释"人是谁"，后者叙述"谁统治谁"，共同构成《山海经》处理人类文明起源的两种视角。

## 巴国谱系中"照"的命名逻辑

后照之名含"照"字，意为光照、照耀。从名字序列看：大皞（皞即"皓"，白色光亮）→咸鸟（鸟，上天之物）→乘厘（乘，上升之意）→后照（照，光明）。四代名字中隐藏着一条从光明到高空到照耀的意象链，与大皞作为东方之帝、光明之主的属性一脉相承。

乘厘之"厘"在古文中有多义：治理、福祉。作为过渡世代，乘厘的名字暗示他是族群从游徙状态走向稳定治理的中间人。而后照以"照耀"为名，最终完成了建族的过程。名字的语义演变构成了一条从光明帝系到人间建国的叙事暗线。

## 关联实体

- [[大皞]]：巴国谱系的起源帝王，东方之帝
- [[巴遂山]]：与巴国共享"巴"字的山名，渑水发源地
- [[流黄辛氏]]：《海内经》中与巴国相邻的西南邦国
- [[都广之野]]：同属海内经西南区域的重要地理实体
- [[后稷]]：海内经另一位始祖型人物
- [[苗民]]: 另一个拥有完整谱系的颛顼后裔国族,可作谱系对照
- [[颛顼]]: 苗民的始祖帝王,与大皞分属不同帝系
- [[成汤]]: 同属《海内经》叙事范围的历史王朝人物，与巴国处于不同时间层
- [[般]]: 《山海经》另一位有具体技艺发明的始祖型人物
- [[黄帝]]: 与大皞并列的上古帝王，代表不同的谱系源头
