# 白水山

**白水山**是《山海经·[[大荒南经]]》所载的山。白水从山中流出，形成白渊[[昆吾]]之师在此沐浴。（011-021）

## 原文出处

《[[大荒南经]]》：

> 又有白水山，白水出焉，而生白渊，昆吾之师所浴也。
>
> （011-021）

## 军团之浴

「昆吾之师所浴也」昆吾氏的军队在此沐浴。「师」是军队不是一个人的沐浴，而是整支军队的集体净身：

| 要素 | 内容 |
|------|------|
| 谁 | 昆吾之师（昆吾氏军团） |
| 在哪 | 白渊 |
| 做什么 | 浴（沐浴/禊祓） |

古代军队出征前或大战之后在圣水中沐浴净身这是一种军事祭祀。白水山的白渊是昆吾氏军团的净身圣地白色的水洗去战争的污秽、赋予军队神圣的力量。（011-021）

## 三重白色

白水山的色彩高度统一山名白、水名白、渊名白：

| 名称 | 色 |
|------|------|
| 白水山 | 白 |
| 白水 | 白 |
| 白渊 | 白 |

三层白色叠加白色从山贯穿到水再到渊。白色是纯净和圣洁的颜色白水山是一座以纯白为底色的圣地。军队在白色的渊中洗浴白色的水净化了他们。（011-021）

## 沐浴圣地的谱系

大荒南经记载了不止一处帝王级的沐浴地：

| 沐浴地 | 使用者 | 性质 |
|--------|--------|------|
| 从渊 | 舜 | 帝王之浴 |
| **白渊** | **昆吾之师** | **军团之浴** |

舜浴于从渊是帝王个人的净身，昆吾之师浴于白渊是军队集体的净身从帝王到军团，大荒南经在南方世界中布置了不同级别的圣浴之所。（011-021）

## 颛顼国的八山

白水山是颛顼国条目下八座山的最后一座：

| 序号 | 山名 |
|------|------|
| 1 | 苕山 |
| 2 | 宗山 |
| 3 | 姓山 |
| 4 | 壑山 |
| 5 | 陈州山 |
| 6 | 东州山 |
| 7 | **白水山** |

前六山只有名字，没有任何描述。到白水山突然有了详细记载白水、白渊、昆吾之浴。白水山是颛顼国诸山中唯一有内容的山它是这组山列的终点和高潮。（011-021）
