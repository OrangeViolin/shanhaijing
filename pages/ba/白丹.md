# 白丹

**白丹**是《山海经·[[大荒西経]]》所载[[沃之野]]的产物。白色丹砂与[[青丹]]成对出现。（016-017）

## 原文出处

《[[大荒西経]]》：

> 西有王母之山，壑山、海山。有沃之国，沃民是处。沃之野，凤鸟之卵是食，甘露是饮。凡其所欲其味尽存。爰有甘华、璇瑰、甘【木且】、瑶碧、白木、白柳、视肉、琅【王千】、白丹、青丹、多银铁。鸾凤自歌，凤鸟自舞，爰有百兽，相群是处，是谓沃之野。
>
> （016-017）

## 沃之野产物表

白丹在沃之野的产物清单中处于鉱物层的起始位置：

| 层 | 产物 |
|----|------|
| 植物 | 甘华、甘【木且】、白木、白柳 |
| 宝玉 | [[璇瑰]]、瑶碧、琅【王千】 |
| 灵物 | [[视肉]] |
| 鉱物 | **白丹**、[[青丹]]、银、铁 |

产物清单从植物到宝玉到灵物到鉱物层层递进。白丹和青丹排在银铁之前丹砂类鉱物的地位高于金属。（016-017）

## 白丹与青丹

白与青两种丹砂成对：

| | 白丹 | [[青丹]] |
|--|------|---------|
| 颜色 | 白 | 青 |
| 性质 | 丹砂类 | 丹砂类 |
| 位置 | 沃之野产物表 | 沃之野产物表 |

丹砂在古代是炼丹术的核心材料白丹青丹以颜色区分，暗示沃之野的丹砂品类丰富。两色并列楽园连鉱物都成双成对。（016-017）

## 沃之野的完美

沃之野是山海经最大的楽园凡其所欲其味尽存：

| 层面 | 内容 |
|------|------|
| 食 | 凤鸟之卵 |
| 饮 | 甘露 |
| 物产 | 植物+宝玉+灵物+鉱物 |
| 声 | 鸾凤自歌 |
| 舞 | 凤鸟自舞 |
| 兽 | 百兽相群 |

白丹是这个完美世界中的一个细节连鉱物都要列出白丹青丹两种颜色。沃之野的「凡其所欲其味尽存」不是空话产物清单就是证据。（016-017）
