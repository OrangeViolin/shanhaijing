# 白木

**白木**是[[大荒西经]]记载的[[沃之野]]产物之一。与[[白柳]]、白丹同属沃之野的白色系列，在甘华、璇瑰、瑶碧、视肉、琅玕等理想郷瑞物中占据一席。（016-017）

## 原文出处

《[[大荒西经]]》：

> 爰有甘华、璇瑰、甘【木且】、瑶碧、白木、白柳、视肉、琅【王千】、白丹、青丹、多银铁。
> （016-017）

## 沃之野的产物谱系

沃之野的产物可按类型分为四组：

| 类别 | 产物 |
|------|------|
| 植物 | 甘华、甘【木且】、**白木**、[[白柳]] |
| 宝石 | 璇瑰、瑶碧、琅【王千】 |
| 矿物 | 白丹、青丹、银、铁 |
| 灵物 | [[视肉]] |

白木与白柳并列，同为白色系树木。甘华、甘【木且】以「甘」冠名，强调甜美与滋养；白木、白柳以「白」冠名，强调色彩的圣洁。「甘」系与「白」系构成沃之野植物的两条命名轴线。

## 三白：白木、白柳、白丹

沃之野产物中有三个以「白」冠名的条目：白木、白柳、白丹。白木和白柳是植物，白丹是矿物（白色丹砂）。三者的「白」字在这段文本中密集出现，构成了沃之野的白色基调。

白色在古代中国的五行体系中对应西方和金。沃之野位于大荒西经，即西方的理想郷。白色产物在西方之地集中出现，与五行方位一致。沃之野不是随机的乐土，而是一座严格属于西方的乐土，其产物的色彩编码遵循五行逻辑。

## 沃之野的完整生态

白木所在的沃之野是山海经中最丰饶的理想郷之一。完整的生态包括：

| 层次 | 内容 |
|------|------|
| 食物 | 凤鸟之卵、甘露 |
| 植物 | 甘华、甘【木且】、白木、白柳 |
| 宝石矿物 | 璇瑰、瑶碧、琅玕、白丹、青丹、银铁 |
| 灵物 | 视肉（不死之肉） |
| 瑞兽 | 鸾鸟自歌、凤鸟自舞、百兽群居 |
| 居民 | [[沃民]]，凡所欲其味尽存 |

「凡其所欲其味尽存」是沃之野的核心定义：一切所需都已具备。白木作为这套完整生态中的一棵树，其存在本身就是「尽存」的证明。（016-017）
