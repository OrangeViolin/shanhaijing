# 共山

**共山**是《山海经·[[海内東経]]》所载的山。[[济水]]从共山南东丘流出，绝[[鉅鹿泽]]，注渤海，入[[潦阳]]。古代四大河川（江、河、淮、济）之一济水的源流山。（014-012）

## 原文出处

《[[海内東経]]》：

> 济水出共山南东丘，绝钜鹿泽，注渤海，入潦阳。
>
> （014-012）

## 四大河川之源

共山是济水的源头，济水与江、河、淮并列为古代四大水系：

| 属性 | 内容 |
|------|------|
| 水 | 济水 |
| 出处 | 共山南东丘 |
| 途经 | 绝鉅鹿泽 |
| 归宿 | 注渤海，入潦阳 |

「南东丘」，共山南面的东丘，经文精确到山的某一丘。「绝鉅鹿泽」，济水横穿华北平原的巨大湿地，海内東経河川记述中罕见地标明了途中经路。（014-012）

## 渤海注入河川群

海内東経末段连续记载五条注入渤海的河流，共山是其中最重要的源流山：

| 河流 | 水源 | 入处 |
|------|------|------|
| 汾水 | 上窳北 | 皮氏南 |
| 沁水 | 井陉山东 | 怀东南 |
| **济水** | **共山南东丘** | **潦阳** |
| 【上虍下乎】沱水 | 晋阳城南 | 越章武北 |
| 漳水 | 山阳东 | 章武南 |

五条河流从西到东依次排列，汾、沁在西，济水居中，【上虍下乎】沱、漳在东。济水「绝鉅鹿泽」是五条中唯一标明途中经路的，强调济水穿越大泽的特殊性。「济」之名至今留存于济南、济宁等地名中。（014-012）
