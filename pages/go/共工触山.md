# 共工触山

**共工触山**是《山海经》宇宙论中最关键的灾难事件。水神[[共工]]与[[颛顼]]争夺帝位失败后，怒触[[不周山]]（天柱），导致天向西北倾斜、地向东南塌陷——一个失败者的暴怒重塑了整个世界的物理结构。

## 原文出处

引注：（017-017）

> 共工之臣名曰相繇，九首蛇身，自环，食于九土。

《山海经》对共工触山事件本身的直接记载较简略，完整叙事见《淮南子·天文训》：「昔者共工与颛顼争为帝，怒而触不周之山，天柱折，地维绝。天倾西北，故日月星辰移焉；地不满东南，故水潦尘埃归焉。」但[[不周山]]、共工、[[颛顼]]等核心元素均出自《山海经》地理与谱系框架。

## 事件经过

1. [[共工]]（水神）与[[颛顼]]（黄帝之孙）争夺帝位
2. 共工一方战败
3. 共工盛怒之下，以头撞击[[不周山]]——天地之间的支柱
4. 天柱折断，天地结构永久改变
5. 天向西北方向倾斜——日月星辰因此向西北运行
6. 地向东南方向塌陷——河水因此向东南流入大海
7. [[女娲]]随后炼[[五色石]]补天、斩鳌足立四极

## 一个动作改变整个宇宙

《山海经》中没有哪个事件的「因果不对称」比共工触山更极端：

| 原因 | 结果 |
|------|------|
| 一个人以头撞一座山 | 天地永久倾斜 |
| 一次争帝失败的情绪发泄 | 日月星辰改变运行方向 |
| 一瞬间的暴怒 | 所有河流永远向东南流 |

这种不对称恰恰是神话的力量所在：一个足够愤怒的个体可以改变宇宙的基本参数。共工不是有计划地破坏天地——他只是在输掉一切之后，用最原始的方式（头撞）表达最极端的抗议。

## 「原因论」事件体系

共工触山属于《山海经》的「原因论」叙事——用神话事件解释自然现象的成因：

| 事件 | 解释的自然现象 |
|------|-------------|
| **共工触山** | 天倾西北、地陷东南、河流东流 |
| [[女娲补天]] | 天有裂隙（需要修补）、四极重立 |
| [[后羿射日]] | 天上为什么只有一个太阳 |
| [[鲧窃息壤]] | 洪水为什么那么难治 |

## 共工事件链

共工触山不是孤立事件，它引发了一系列连锁反应：

```
共工 vs 颛顼 争帝
    ↓ 共工战败
共工怒触不周山
    ↓ 天柱折断
天倾西北、地陷东南
    ↓ 天地破损
女娲补天（炼五色石、斩鳌足）
    ↓ 共工残党继续为害
相柳食于九土、制造毒泽
    ↓ 禹治水
禹杀相柳 → 三仞三沮 → 众帝之台
```

从争帝到建台，整条叙事链贯穿了《山海经》多个经卷和多代主角。

## 神话意义

共工触山是《山海经》中最具哲学张力的事件。破坏者无意中成为了世界的塑造者——没有共工的暴怒，天地就不会倾斜，河流就不会东流，日月就不会西行。我们生活的世界——不完美的、不对称的、有方向的。是一个失败者的怒火造就的。这比「完美创世」的叙事更深刻：世界不是被设计成这样的，它是被一个愤怒的失败者撞成这样的。
