# 勾【木尔】之山

**勾【木尔】之山**是《山海经·[[中山経]]》中次九経（岷山山系）所载的山。上多玉——下多黄金，木多栎柘，草多芍药。岷山山系四座冢山之一。（005-123）

## 原文出处

《[[中山経]]》中次九経：

> 又东三百里，曰勾【木尔】之山，其上多玉，其下多黄金，其木多栎柘，其草多芍药。
>
> （005-123）

> 文山、勾【木尔】、风雨、【马鬼】之山，是皆冢也，其祠之：羞酒，少牢具，婴毛一吉玉。
>
> （005-130）

## 芍药之山

勾【木尔】之山多芍药——山海経中极少明确记载芍药的山：

| 属性 | 内容 |
|------|------|
| 山上 | 玉 |
| 山下 | 黄金 |
| 木 | 栎、柘 |
| 草 | 芍药 |

玉在上——金在下，上下皆宝。芍药是名贵药草，也是美花。一座既有金玉又有芍药的山，兼具财富和美，难怪是冢山。山海経的冢山物产通常丰富，勾【木尔】之山不例外。（005-123）

## 岷山系四冢

岷山山系（中次九経）有四座冢山——祭祀等级高于普通山：

| 冢山 | 祭祀 | PN |
|------|------|-----|
| 文山 | 少牢+酒+吉玉 | — |
| **勾【木尔】之山** | 少牢+酒+吉玉 | 005-123 |
| 风雨之山 | 少牢+酒+吉玉 | — |
| 【马鬼】之山 | 少牢+酒+吉玉 | — |

四座冢山用相同的祭祀——少牢（羊和豕）加酒加吉玉。岷山山系十六山中有四座冢山，冢山密度在中山経各山系中属于较高水平。四座冢山的存在说明岷山山系是中山経中神圣等级最高的山系之一。（005-130）

## 岷山山系

勾【木尔】之山所在的岷山山系规模宏大：

| 项目 | 内容 |
|------|------|
| 首山 | 女几之山 |
| 末山 | 贾超之山 |
| 山数 | 十六山 |
| 里程 | 三千五百里 |
| 山神 | 马身龙首 |
| 冢山 | 四座 |

山神全是马身龙首——马的身体龙的头，岷山山系的神是融合了力量和神圣的混合体。三千五百里十六山，平均每山两百多里，间距适中。（005-130）
