# 龙首之山

**龙首之山**是《山海经·[[西山经]]》西次二経所载的山。阳面多黄金和铁——苕水东流注于泾水，多美玉。（002-026）

## 原文出处

《[[西山经]]》西次二経：

> 又西二百里，曰龙首之山，其阳多黄金，其阳多铁。苕水出焉，东流注于泾水，其中多美玉。
>
> （002-026）

## 金铁同阳

通常山海经写矿产——贵金属在阳面、贱金属在阴面。龙首之山打破了这个规律：

| 位置 | 矿产 |
|------|------|
| 阳面 | 黄金 |
| 阳面 | 铁 |

黄金和铁——两种性质完全不同的金属——都在同一面。贵贱不分、共存于阳——这是西次二経中少见的矿产配置。（002-026）

## 苕水与泾水

苕水从龙首之山东流注入泾水：

| 属性 | 内容 |
|------|------|
| 水名 | 苕水 |
| 流向 | 东流 |
| 注入 | 泾水 |
| 水产 | 美玉 |

泾水是渭水的支流——关中平原的主要河川。龙首之山属于泾水源流域的山群。（002-026）

## 龙首之名

「龙首」——龙头形的山。山海经以动物身体部位命名的山不少——虎首之山、牛首之山、龙首之山——都是用动物的头来形容山容。（002-026）
