# 登备之山

**登备之山**是《[[大荒南经]]》记载的一座山，位于大荒之中，属于[[不姜之山]]山群。该山群以不姜之山为首，包括[[贾山]]、[[言山]]、登备之山、[[恝恝之山]]、[[蒲山]]、[[隗山]]、[[尾山]]、[[翠山]]等多座山，集中分布在[[黑水]]尽头的区域。（011-007）

## 原文出处

引注：（011-007）

> 大荒之中，有不姜之山，黑水穷焉。又有贾山，汔水出焉。又有言山。又有登备之山。有恝恝之山。又有蒲山，澧水出焉。又有隗山，其西有丹，其东有玉。又南有山，漂水出焉。有尾山。有翠山。

## 不姜之山山群的结构

不姜之山山群是《大荒南经》中最密集的山名列举段落之一。在短短一段原文中，连续出现了至少十座山名。这种高密度的列举方式与五山经（南山经、西山经、北山经、东山经、中山经）的叙述风格截然不同。

五山经中每座山都有独立的物产、水系、异兽记录；大荒经中许多山只留下名字，不附任何描述。登备之山就属于后者，原文仅以"又有登备之山"五字带过，没有水系、没有矿产、没有生物。

在九座山中，有具体描述的只有四座（不姜之山、贾山、蒲山、隗山），其余五座（言山、登备之山、恝恝之山、尾山、翠山）只保留了名字。登备之山是这五座"仅存名字"的山之一。

## "登备"之名的含义

"登备"二字的含义不详，历代注家未见专门讨论。拆开来看：

"登"有攀登、上升之义，也有成熟、完备之义（如"五谷丰登"）。"备"有齐备、防备之义。"登备"组合在一起，可能指一座"高而完备"的山，也可能指一座"登临可备（防御）"的山。但这些都是推测，《山海经》中许多山名的命名逻辑已经不可考。

在大荒经的山名中，有些山名带有明显的描述性（如[[恝恝之山]]，"恝恝"是一种声音或状态），有些山名则像地方固有名称的音译。登备之山的命名风格更接近后者，可能是某个古地名的记音。

## 黑水尽头的地理意义

不姜之山山群的地理定位标志是"黑水穷焉"，即[[黑水]]在此处终结。"穷"字在《山海经》中表示水流到达终点、消失不再流动。

[[黑水]]是《山海经》中反复出现的重要水系，在多篇经文中被提及。大荒南经的"黑水穷焉"意味着黑水从北方或西方流来，在大荒南方的不姜之山一带耗尽。水流终结之处往往是地形的尽头，要么是沙漠吞噬了水量，要么是水流渗入地下。不姜之山山群位于这样一个水系消亡的区域，地理上具有"边界"的含义。

登备之山作为不姜之山山群的成员，共享这一"黑水尽头"的地理定位。它所处的环境是大荒之中、水系消亡之处，与五山经中那些有明确水系出入的山截然不同。

## 大荒南经的叙事节奏

登备之山所在的段落（011-007）位于《大荒南经》的前半部分。在此之前，经文依次记载了不庭之山（荣水穷焉）、成山（甘水穷焉），然后是不姜之山山群。三个段落都以"水穷焉"的格式标记地理位置，构成一条从东到西（或从北到南）的山脉扫描线。

在不姜之山山群之后，《大荒南经》转入人文记录：

> 有盈民之国，於姓，黍食。又有人方食木叶。
>
> （011-008）从山群到国族，叙事节奏发生了切换。登备之山所在的段落因此是一个"地理总览"的段落，其功能是在进入人文叙事之前，快速铺陈大荒南方的地形骨架。

## 与五山经山岳的对比

大荒经中的山与五山经中的山在记录精度上存在根本差异。以登备之山和[[高是之山]]（北次三经）为例：

| 维度 | 高是之山 | 登备之山 |
|------|----------|----------|
| 距离 | "又北三百里" | 无 |
| 水系 | 滋水南流入虖沱，寇水东流入河 | 无 |
| 物产 | 木多棕，草多条 | 无 |
| 异兽 | 无（但邻山有） | 无 |
| 文字量 | 约40字 | 5字 |

五山经的每座山都有精确的里程、方位和物产记录，像一份实地勘测报告。大荒经的山则像一份远距离观察的地名清单，只保留名字和大致方位。这一差异反映了两种经文的信息来源和编纂目的不同：五山经可能基于实际的山地调查记录，大荒经可能基于远方传闻或神话叙事的地理框架。

登备之山处于大荒经这一"远方传闻"层次，它的存在感不在于自身的物产和地形，而在于它作为不姜之山山群的一员，参与构成了大荒南方的地理骨架。

## 不姜之山山群的整体定位

不姜之山山群在《大荒南经》中的位置，介于"不庭之山、成山"段落和"盈民之国、不死之国"段落之间。前者是地理记录（山和水），后者是人文记录（国和民）。不姜之山山群是大荒南方地理骨架的最后一个大型山脉节点。

从山群内部看，[[不姜之山]]（黑水穷焉）、[[贾山]]（汔水出焉）、[[蒲山]]（澧水出焉）三座山有水系记录，构成了山群的水文骨架。登备之山、[[言山]]、[[恝恝之山]]等无水系记录的山，则像是填充在水文骨架之间的地形节点。它们共同构成了一个完整的山群图景：有水有山，有详有略，主从分明。
