# 芘蠃

**芘蠃**は[[南山経]]に記載される水棲生物である。[[洵山]]から流れ出る洵水が南に流れて閼の沢に注ぐ中に多く棲む。（001-023）

## 原文出処

《[[南山経]]》：

> 洵水出焉，而南流注于閼之澤，其中多芘蠃。
> （001-023）

## 解説

洵山の洵水に棲む生物として名のみ記される。具体的な形態描写はなく、水中に多く存在するとだけ伝えられる。

## 名称の解釈

「蠃」は螺（巻貝）の古字で、芘蠃は何らかの巻貝の類と推定される。「芘」は草冠を持ち、植物に関連する字だが、ここでは貝の名の一部として用いられる。

## 洵山の環境

洵山は南次二経に属し、[[咸阴之山]]の東四百里に位置する。山の陽面に金が多く、陰面に玉が多い。山には【羊患】（羊に似て口がなく殺せない獣）が棲む。洵水は南流して閼之沢に注ぐ。

| 要素 | 内容 |
|------|------|
| 棲息水域 | 洵水 |
| 水源の山 | [[洵山]] |
| 流向 | 南 |
| 注入 | 閼之沢 |

## 沢に注ぐ水の生物

洵水は河ではなく沢（湖沼）に注ぐ。沢に注ぐ水域は流速が緩やかで、巻貝の生息に適した環境。山海経で沢に注ぐ水系に水生物が記される例は比較的珍しい。
