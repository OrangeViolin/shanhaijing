# 平逢之山

**平逢之山**是《山海经·[[中山经]]》中次六经缟【羊氐】山系的首山。南望伊洛，东望谷城之山。无草木，无水，多沙石。山中有双首之神[[骄虫]]——螫虫之主，蜂蜜之庐。祭祀用一雄鸡，禳而勿杀。（005-057）

## 原文出处

《[[中山经]]》中次六经：

> 中次六经缟【羊氐】山之首，曰平逢之山，南望伊洛，东望谷城之山，无草木，无水，多沙石。有神焉，其状如人而二首，名曰骄虫，是为螫虫，实惟蜂蜜之庐，其祠之，用一雄鸡，禳而勿杀。
>
> （005-057）

## 骄虫

平逢之山的守护神——双首的蜂蜜之神：

| 特征 | 描述 |
|------|------|
| 形 | 如人而二首（两个头） |
| 名 | 骄虫 |
| 身份 | 螫虫（能蛰人的虫） |
| 居所 | 蜂蜜之庐 |
| 祭法 | 用一雄鸡，禳而勿杀 |

骄虫是螫虫之主——一切能蛰人的虫都归它管。但它同时也是蜂蜜之庐——蜂蜜的宿所。蛰人的毒和甜蜜的蜜出自同一位神——害与恩共存于一身。祭祀时「禳而勿杀」——用鸡来祈禳，但不杀鸡。这是《山海经》中极罕见的不杀牺牲的祭法。（005-057）

## 荒凉首山

平逢之山的荒凉程度在中山经首山中罕见：

| 要素 | 有无 |
|------|------|
| 草 | 无 |
| 木 | 无 |
| 水 | 无 |
| 沙石 | 多 |

无草、无木、无水——什么都没有，只有沙石。一座经脈的首山通常应该是最丰饶的——但平逢之山像一片荒漠。在这样的荒凉之上，却住着一位神——骄虫不需要草木和水，它只需要蜂蜜。（005-057）

## 南望伊洛

「南望伊洛，东望谷城之山」——两个方向的地标明确了平逢之山的位置：

| 方向 | 地标 |
|------|------|
| 南 | 伊洛（伊水和洛水） |
| 东 | 谷城之山 |

伊洛是洛阳附近的实在地名——中次六经以洛阳为参照系，这是《山海经》中与现实地理对应最清晰的段落之一。平逢之山站在伊洛之北——中原腹地的一座荒山。（005-057）

## 缟【羊氐】山系

平逢之山是中次六经整条山系的起点：

| 位置 | 山 | 特色 |
|------|-----|------|
| **首** | **平逢之山** | **骄虫双首神** |
| 二 | 缟【羊氐】之山 | 无草木，多金玉 |
| 三 | 【外疒内鬼】山 | 【令鸟】【要鳥】鸟 |
| … | … | … |
| 末 | 阳华之山 | 门水、杨水 |

中次六经共十四山、七百九十里。「岳在其中，以六月祭之，如诸岳之祠法，则天下安宁」——这条山系中含有一座岳级圣山。平逢之山作为首山，以骄虫的双重性（害与恩）为整条经脈定下了基调。（005-057）

## 「禳而勿杀」：山海经中最温和的祭法与骄虫的双重神性

「禳而勿杀」——用雄鸡做祈禳仪式，但不杀这只鸡——是五藏山经中最独特的祭祀方式。绝大多数山神的祭祀都涉及杀牲（宰杀祭品），骄虫是极少数不要求血祭的神：

| 祭法 | 是否杀牲 | 牺牲 | 山/神 |
|------|---------|------|-------|
| 太牢 | 杀 | 牛羊猪 | 【马鬼】山（帝也）（005-140） |
| 少牢 | 杀 | 羊猪 | 冢山系统 |
| 一羊 | 杀 | 羊 | 多数普通山 |
| 白鸡不糈 | 杀 | 白鸡 | 厘册山系（005-328） |
| **禳而勿杀** | **不杀** | **雄鸡（活）** | **平逢之山/骄虫（005-057）** |

「勿杀」打破了祭祀的基本逻辑——祭祀通常以牺牲（杀生）换取神的保佑。骄虫不要求杀生，只要求「禳」（祈禳仪式）。这与骄虫的双重性直接相关：它既是「螫虫」（蛰人的毒虫之主），又是「蜂蜜之庐」（甜蜜的守护者）。毒与蜜同出一源——如果对骄虫施以杀牲之祭，可能只激活它的毒虫面；不杀而禳，则既安抚了毒虫之性，也保全了蜂蜜之恩。

平逢之山「无草木，无水，多沙石」——一座荒凉至极的山上住着一位不需要血祭的温和之神。荒凉与温和的反差使平逢之山成为中次六经中最耐人寻味的首山。（005-057）
