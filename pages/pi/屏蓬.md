# 屏蓬

**屏蓬**是[[大荒西经]]记载的双首异兽，左右各有一头。位于日月没入之地附近，与[[天犬]]、[[比翼之鸟]]等大荒西方异物同域。（016-034）

## 原文出处

《[[大荒西经]]》：

> 有兽，左右有首，名曰屏蓬。
> （016-034）

## 左右双首

屏蓬的核心特征是「左右有首」。与通常的双首异兽不同（头部前后排列或上下叠生），屏蓬的两个头分列左右两侧，形成完全的左右对称。这种构型使屏蓬的正面视角呈现两头并立的形象，任何方向的威胁都有一个头能直接面对。

| 特征 | 内容 |
|------|------|
| 头部 | 左右各一首 |
| 对称性 | 左右对称 |
| 体型 | 未记 |
| 药效/预兆 | 无 |

山海经中另有双首异兽并并（海外南经，一身两首）和屏翳（风伯），但屏蓬以「左右」明确标注头部方位，是双首异兽中空间描述最精确的一个。

## 日月没入之域

屏蓬出现在大荒西经描述日月没入之山的段落附近。大荒西经的西极是太阳和月亮落下的地方，屏蓬栖息于这片黄昏永恒的边缘地带。

同一区域聚集了多种大荒西方的标志性异物：

| 实体 | 特征 | PN |
|------|------|-----|
| **屏蓬** | 左右双首 | 016-034 |
| [[天犬]] | 赤犬，降之处有兵 | 016-035 |
| [[比翼之鸟]] | 一翼一目，相合而飞 | 016-035 |

天犬是兵乱凶兆，比翼之鸟是合体飞行的奇鸟，屏蓬是左右分裂的双首兽。三者共同构成大荒西极的异物群，各以不同的身体异常标记这片世界的尽头。

## 「屏蓬」之名

「屏」有屏障、遮蔽之义，「蓬」有蓬松散乱之义。屏蓬之名可能描述这只双首兽的行为：左右两头如屏障般覆盖两侧视野，蓬松的毛发或体态使其外形散乱膨大。
