# 漂水

**漂水**是《山海经·[[大荒南经]]》所载的河川，出一座未命名的山——「又南有山，漂水出焉」。（011-007）

## 原文出处

《[[大荒南经]]》：

> 又南有山，漂水出焉。
>
> （011-007）

## 无名之山

漂水最特殊的地方不在水本身，而在它的源头——一座没有名字的山。经文只说「又南有山」，不说山叫什么：

| 同条其他水 | 源山 | 有无山名 |
|-----------|------|---------|
| 汔水 | 贾山 | 有 |
| 澧水 | 蒲山 | 有 |
| **漂水** | **（又南有山）** | **无** |

同一条经文中的其他河流都有明确的源山名，唯独漂水的源山无名。这座山的名字在流传中遗失了——或者编纂者从未知道它的名字。漂水成为识别这座山的唯一标记：那座无名之山，就是漂水流出的山。（011-007）

## 九山密集

漂水的无名源山处于大荒南经一段极为密集的山名列举中：

| 山名 | 水系 |
|------|------|
| 不姜之山 | 黑水穷焉 |
| 贾山 | 汔水出焉 |
| 言山 | — |
| 登备之山 | — |
| 恝恝之山 | — |
| 蒲山 | 澧水出焉 |
| 隗山 | — |
| **（无名山）** | **漂水出焉** |
| 尾山 | — |
| 翠山 | — |

十座山一气呵成——其中三座有水、一座是水的终点（黑水穷焉）。漂水的无名源山夹在有名的隗山和尾山之间，是这条密集山链中唯一的缺名环节。（011-007）

## 漂之名

「漂」——漂浮、漂流。水以「漂」命名，暗示水流缓慢而漫散——不是急流直下，而是在平地上漫漂。也许漂水在低洼处漫流成片，没有明确的河道——一条漂散在大荒中的水。（011-007）
