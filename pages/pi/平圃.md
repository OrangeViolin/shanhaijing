# 平圃

**平圃**是《山海经·[[西山経]]》西次三経所载的圣地。在[[槐江之山]]上——「实惟帝之平圃」——神[[英招]]司之。天帝的庭园。（002-045）

## 原文出处

《[[西山経]]》西次三経：

> 又西三百二十里，曰槐江之山。丘时之水出焉，而北流注于【氵幼】水。其中多蠃母，其上多青雄黄，多藏琅玕、黄金、玉，其阳多丹粟，其阴多采黄金银。实惟帝之平圃，神英招司之，其状马身而人面，虎文而鸟翼，徇于四海，其音如榴。
>
> （002-045）

## 帝之平圃

平圃是天帝的庭园——「帝之平圃」四字定义了这个空间的性质：

| 属性 | 内容 |
|------|------|
| 名 | 平圃 |
| 所有者 | 帝（天帝） |
| 所在 | 槐江之山 |
| 管理者 | 神英招 |

「圃」是园——「平圃」是平坦的园——天帝的平地花园。不是山顶——是山上的一片平地——帝在山上有一座平坦的庭园。与昆仑并列的天帝圣地。（002-045）

## 英招

管理平圃的神英招形态极其华丽：

| 部位 | 形态 |
|------|------|
| 身 | 马 |
| 面 | 人 |
| 纹 | 虎文 |
| 翼 | 鸟翼 |
| 活动 | 徇于四海 |
| 声 | 如榴 |

马身+人面+虎纹+鸟翼——四种动物的合体。「徇于四海」——巡行天下四海——不只守在平圃——而是代表天帝巡视四方。一个四合体的巡天之神——管理天帝的花园。（002-045）

## 槐江之山的丰饶

平圃所在的槐江之山产物极其丰富：

| 产物 | 位置 |
|------|------|
| 琅玕 | 山中 |
| 黄金 | 山中 |
| 玉 | 山中 |
| 丹粟 | 阳面 |
| 采黄金银 | 阴面 |
| 青雄黄 | 山上 |

琅玕+黄金+玉+丹粟+金银——几乎所有的珍贵矿物都在这座山上。天帝的庭园当然要建在最富有的山上。（002-045）

## 四方眺望

槐江之山能望见四方的圣地和异域：

| 方位 | 所见 |
|------|------|
| 南 | [[昆仑]]——其光熊熊，其气魂魂 |
| 西 | 大泽——后稷所潜 |
| 北 | 诸【囟此】——鹰【颤去页加鸟】所宅 |
| 东 | 恒山四成——穷鬼居之 |

南望昆仑能看到光和气——西望大泽后稷藏在那里——北望有鹰的栖息地——东望恒山有穷鬼。从平圃可以俯瞰四方——天帝的花园是一个观测天下的制高点。（002-045）

## 西次三経における天帝聖地の階層構造

平圃は西次三経に配置された天帝の聖地の一つであり、昆仑・嬴母之山と共に聖域の階層構造を形成する：

| 聖地 | 山 | 称号 | 司神 | PN |
|------|-----|------|------|-----|
| **帝之平圃** | **[[槐江之山]]** | **天帝の庭園** | **[[英招]]（馬身人面虎文鳥翼）** | **002-045** |
| 天之九德 | [[嬴母之山]] | 天帝の道徳体 | [[長乗]]（人身豹尾） | 002-048 |
| 帝之下都 | [[昆仑之丘]] | 天帝の地上宮殿 | [[陆吾]]（虎身九尾人面） | 002-046 |

三聖地は西次三経の後半に集中し、平圃→嬴母→昆仑の順に配列される。平圃は「圃」（庭園）であり最も人間的な空間、嬴母は「九德」（道徳）であり抽象的な空間、昆仑は「下都」（宮殿）であり最も政治的な空間である。各聖地の司神も四合体（英招）→二合体（長乗）→三合体（陆吾）と異なる複合度を持つ。西次三経は天帝の権力空間を庭園・道徳・宮殿の三層で構成し、それぞれに異なる守護神を配置した。（002-045）
