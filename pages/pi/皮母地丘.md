# 皮母地丘

**皮母地丘**是《山海经·[[大荒東経]]》所载的丘。大荒东南隅——仅有名字——没有其他描述。（015-003）

## 原文出处

《[[大荒東経]]》：

> 大荒东南隅有，名皮母地丘。
>
> （015-003）

## 东南隅的座标

皮母地丘是大荒东南角的定位点——极简的记述：

| 属性 | 内容 |
|------|------|
| 名 | 皮母地丘 |
| 位置 | 大荒东南隅 |
| 物产 | 无记述 |
| 居民 | 无记述 |

没有物产——没有居民——没有神——只有位置和名字。大荒経用四隅来标定世界的边界——皮母地丘标定了东南角。「皮母地」含义不详——可能是非汉语的音译地名。（015-003）

## 大荒東経的开篇序列

皮母地丘处于大荒東経从少昊之国到日出山的过渡位置：

| 顺序 | 内容 | 性质 |
|------|------|------|
| 015-001 | 少昊之国（东海之外） | 帝的领地 |
| 015-002 | 甘山·甘水·甘渊 | 水系地理 |
| **015-003** | **皮母地丘（东南隅）** | **方位座标** |
| 015-004 | 大言山（日月所出） | 日出山系列起点 |

从少昊之国→甘山水系→东南隅座标→日出山——皮母地丘是大荒東経从神话叙事转入日出山地理列举的分界点。标定了东南角之后——叙述转向「日月所出」的一连串东方圣山。（015-003）
