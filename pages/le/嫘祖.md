# 嫘祖

**嫘祖**是[[黄帝]]的正妃，来自西陵氏。《山海经》中她的核心功能是世系传承——嫘祖生昌意，昌意居若水（[[弱水]]），生韩流，韩流生[[颛顼]]。后世传说她发明养蚕缫丝，被尊为蚕桑文明的始祖。

## 原文出处

引注：（018-016）

> 黄帝妻雷祖，生昌意。昌意降处若水，生韩流。

## 在帝系中的位置

```
黄帝 + 嫘祖
    └── 昌意 → 韩流 → 颛顼
```

嫘祖是黄帝到[[颛顼]]世系传承的关键人物。没有嫘祖，黄帝系就断了——昌意、韩流、颛顼都经由她传承。

## 神话意义

嫘祖是《山海经》帝系中以世系传承定义身份的女性——不同于[[女娲]]（创世/补天）或[[羲和]]（御日），嫘祖的功能是生育帝系的下一代。后世将蚕桑发明归于她，使她从单纯的帝妃升格为文明技术的赐予者。
