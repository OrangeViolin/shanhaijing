# 【氵委】山

**【氵委】山**是《山海经·[[中山经]]》中次一经所载的山。上多赤铜，阴多铁。（005-005）

## 原文出处

《[[中山经]]》中次一经：

> 又東十五里，曰【氵委】山，其上多赤銅，其陰多鐵。
>
> （005-005）

## 双金属

【氵委】山的矿产铜铁分层：

| 位置 | 矿物 |
|------|------|
| 山上 | 赤铜 |
| 山阴 | 铁 |

赤铜在山上铁在山的北面（阴面）。铜和铁分居山的不同位置上下之外还有阳阴的区分。赤铜是纯度较高的铜中山经山脉的常见矿产。（005-005）

## 简洁之山

【氵委】山的记述极其精简整条记录只有一句话：

| 信息 | 内容 |
|------|------|
| 方位 | 东十五里 |
| 矿物 | 赤铜、铁 |
| 水系 | 无 |
| 异物 | 无 |

没有水系、没有异兽异鸟、没有药草只有方位和矿物。中山经中像这样极简的山很少。大多数山至少有一条水或一种异物【氵委】山什么都没有，只有金属。一座纯粹的矿山。（005-005）
