# 【氵綦】水

**【氵綦】水**出《山海经·[[北山経]]》北次三経沮洳之山南流注于河。（003-063）

## 原文出处

《[[北山経]]》北次三経：

> 东三百里，曰沮洳之山，无草木，有金玉。【氵綦】水出焉，南流注于河。
>
> （003-063）

## 荒山之水

【氵綦】水发源的沮洳之山无草木只有金玉：

| 属性 | 内容 |
|------|------|
| 源山 | 沮洳之山 |
| 山上草木 | 无 |
| 山上矿产 | 金、玉 |
| 流向 | 南流 |
| 汇入 | 河（黄河） |

寸草不生的山金玉藏在石头里一条水直奔黄河。没有异兽没有异鸟没有水中生物的记载。极简的水系从一座极简的山流出。（003-063）

## 沮洳之名

「沮洳」潮湿低洼之地。山名叫「沮洳」却无草木。湿地该有的植物全没有只有矿物和一条水。名字和实际的反差和蛊尾之山（名不祥而实平静）类似。（003-063）
