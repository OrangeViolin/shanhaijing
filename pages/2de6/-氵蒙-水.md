# 【氵蒙】水

**【氵蒙】水**出《山海经·[[西山経]]》西次三経[[【圭阝】山]]南流注于洋水多黄贝有[[嬴鱼]]，见则大水。（002-078）

## 原文出处

《[[西山経]]》西次三経：

> 又西二百六十里，曰【圭阝】山。其上有兽焉，其状如牛，【虫胃】毛，名曰穷奇，音如【犭皋】狗，是食人。【氵蒙】水出焉，南流注于洋水，其中多黄贝；嬴鱼，鱼身而鸟翼，音如鸳鸯，见则其邑大水。
>
> （002-078）

## 黄贝与嬴鱼

【氵蒙】水中宝物和灾兆并存：

| 水产 | 性质 |
|------|------|
| 黄贝 | 宝物（黄色贝壳） |
| [[嬴鱼]] | 灾兆（见则大水） |

黄贝是安静的宝物嬴鱼是危险的预兆。同一条水里富贵和灾难同时存在。（002-078）

## 嬴鱼

嬴鱼鱼身鸟翼声如鸳鸯：

| 属性 | 内容 |
|------|------|
| 身体 | 鱼身 |
| 翼 | 鸟翼 |
| 声音 | 如鸳鸯 |
| 预兆 | 见则其邑大水 |

鱼长了翅膀叫声像鸳鸯出现就意味着洪水。鱼本身是水中之物长了翅膀还是预兆更多的水。（002-078）

## 穷奇之山的水

【氵蒙】水发源的[[【圭阝】山]]山上有食人的[[穷奇]]。山上食人水中兆灾【圭阝】山从陆地到水域都是危险的。（002-078）
