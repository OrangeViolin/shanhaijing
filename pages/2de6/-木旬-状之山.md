# 【木旬】状之山

**【木旬】状之山**是《山海经·[[东山经]]》東次一経所载的山。山上多金玉，山下多青碧石一兽一鸟一鱼，三种异物各有异能。（004-003）

## 原文出处

《[[东山经]]》東次一経：

> 又南三百里，曰【木旬】状之山，其上多金玉，其下多青碧石。有兽焉，其状如犬，六足，其名曰从从，其鸣自【讠交】。有鸟焉，其状如鸡而鼠毛，其名曰【上此下虫】鼠，见则其邑大旱。【氵只】水出焉，而北流注于湖水，其中多箴鱼，其状如囗，其喙如箴，食之无疫疾。
>
> （004-003）

## 三种异物

一座山同时有兽、鸟、鱼三种异物各司其能：

| 异物 | 类型 | 形态 | 异能 |
|------|------|------|------|
| [[从从]] | 兽 | 如犬六足 | 鸣声自呼其名 |
| [[【上此下虫】鼠]] | 鸟 | 如鸡鼠毛 | 见则大旱 |
| 箴鱼 | 鱼 | 喙如箴 | 食之无疫疾 |

从从是灾兽六足犬形。【上此下虫】鼠是灾鸟出现就大旱。箴鱼却是药鱼吃了不生瘟疫。同一座山上灾与药并存陆上有凶兆，水里有解药。（004-003）

## 灾与药

【上此下虫】鼠带来大旱箴鱼防治疫疾。一灾一药，一空一水：

| | 【上此下虫】鼠 | 箴鱼 |
|--|-------------|------|
| 域 | 山上（陆） | 水中 |
| 性质 | 凶兆（大旱） | 药用（无疫疾） |
| 形态 | 如鸡鼠毛 | 喙如箴 |

山海经的灾药共存不少但【木旬】状之山的特殊在于灾和药分属不同的元素。旱在陆上，药在水里仿佛水系是对旱灾的天然制衡。（004-003）

## 【氵只】水

【氵只】水从【木旬】状之山北流注入[[湖水]]：

| 属性 | 内容 |
|------|------|
| 源山 | 【木旬】状之山 |
| 流向 | 北流 |
| 注入 | [[湖水]] |
| 水产 | 箴鱼 |

箴鱼在【氵只】水中喙如针，食之无疫疾。一座出旱兆的山，却流出一条药鱼之河。（004-003）
