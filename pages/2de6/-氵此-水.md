# 【氵此】水

**【氵此】水**出《山海经·[[西山経]]》西次三経长沙之山北流注于[[【氵幼】水]]无草木多青雄黄。（002-040）

## 原文出处

《[[西山経]]》西次三経：

> 西北三百里，曰长沙之山。【氵此】水出焉，北流注于【氵幼】水，无草木，多青雄黄。
>
> （002-040）

## 荒凉之水

【氵此】水流过的地方寸草不生：

| 属性 | 内容 |
|------|------|
| 源山 | 长沙之山 |
| 流向 | 北流 |
| 汇入 | [[【氵幼】水]] |
| 草木 | 无 |
| 矿物 | 多青雄黄 |

没有草木只有青雄黄。青雄黄是含砷的矿物有毒。有毒矿物遍布草木不生【氵此】水流经一片有毒的荒地。（002-040）

## 西次三経开篇

【氵此】水的源山长沙之山是西次三経的第二座山（首山[[崇吾之山]]之后）。西次三経从崇吾之山开始崇吾之山有蛮蛮（见则大水）紧接着就是无草木、多毒矿的长沙之山。西次三経的开头笼罩在灾水和毒矿的阴影中。（002-040）
