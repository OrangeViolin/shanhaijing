# 【氵宛】水

**【氵宛】水**是《山海经·[[西山经]]》西次四经所载的河流。出[[英【革是】之山]]，北流注于[[陵羊之泽]]。水中多[[冉遗之鱼]]。（002-076）

## 原文出处

《[[西山经]]》西次四经：

> 又西三百五十里，曰英【革是】之山，上多漆木，下多金玉，鳥獸盡白。【氵宛】水出焉，而北流注于陵羊之澤。是多冉遺之魚，魚身蛇首六足，其目如觀耳，食之使人不眯，可以御凶。
>
> （002-076）

## 白色之山的水

【氵宛】水发源的英【革是】之山鸟兽尽白：

| 要素 | 内容 |
|------|------|
| 源山 | [[英【革是】之山]] |
| 山上特征 | 鸟兽尽白 |
| 流向 | 北流 |
| 终点 | [[陵羊之泽]] |

鸟兽尽白整座山的动物都是白色的。这不是一两只白化个体是全山皆白。【氵宛】水从这座全白的山流出流向陵羊之泽。（002-076）

## 冉遗之鱼

【氵宛】水的特产冉遗之鱼：

| 属性 | 内容 |
|------|------|
| 身体 | 鱼身蛇首六足 |
| 眼睛 | 如马耳 |
| 药效 | 食之使人不眯，可以御凶 |

鱼身蛇的头六只脚。眼睛长得像马耳朵。吃了不做噩梦还能避凶。冉遗之鱼是山海经中形态最复杂的鱼之一鱼蛇兽三合一体。（002-076）
