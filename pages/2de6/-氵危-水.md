# 【氵危】水

**【氵危】水**是《山海经·[[中山经]]》中次八経所载的河流。出[[宜诸之山]]，南流注于漳水中多白玉。（005-094）

## 原文出处

《[[中山经]]》中次八経：

> 又东北二百里，曰宜诸之山，其上多金玉，其下多青【镬钅换丹】。【氵危】水出焉，而南流注于漳，其中多白玉。
>
> （005-094）

## 白玉之水

【氵危】水的水中物是白玉矿物而非生物：

| 属性 | 内容 |
|------|------|
| 源山 | [[宜诸之山]] |
| 流向 | 南流 |
| 注入 | 漳 |
| 水产 | 白玉 |

山上有金玉水中也有白玉。宜诸之山是内外皆玉的山山上的玉和水里的玉相呼应。（005-094）

## 宜诸之山

【氵危】水发源的宜诸之山上下矿产分明：

| 位置 | 矿产 |
|------|------|
| 山上 | 金玉 |
| 山下 | 青【镬钅换丹】 |

金玉在上丹砂类矿物在下。山的矿产通过【氵危】水的白玉延伸到水中矿脉从山体贯通到水系。（005-094）
