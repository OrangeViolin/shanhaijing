# 【氵方】水

**【氵方】水**出《山海经·[[南山経]]》南次一経[[箕尾之山]]南流注于【氵育】多白玉。（001-009）

## 原文出处

《[[南山経]]》南次一経：

> 又东三百五十里，曰箕尾之山，其尾【骏去马换足】于东海，多沙石。【氵方】水出焉，而南流注于【氵育】，其中多白玉。
>
> （001-009）

## 末山之水

【氵方】水发源于箕尾之山南次一経（鹊山之首）的末山：

| 属性 | 内容 |
|------|------|
| 源山 | [[箕尾之山]] |
| 流向 | 南流 |
| 汇入 | 【氵育】 |
| 水产 | 白玉 |

箕尾之山「其尾【骏去马换足】于东海」山尾伸入东海是南次一経走到尽头的山。从这座临海之山流出的水不向东入海而向南流入【氵育】。（001-009）

## 白玉之水

【氵方】水中多白玉与箕尾之山「多沙石」形成对比：

| 位置 | 物产 |
|------|------|
| 山上 | 沙石 |
| 水中 | 白玉 |

山是荒凉的多沙石但水里藏着白玉。表面贫瘠内里有宝。南次一経以[[招摇之山]]开头（临西海）以箕尾之山结尾（临东海）从西海到东海【氵方】水是这条路线终点的最后一条水。（001-009）
