# 【氵焦】水

**【氵焦】水**出《山海经·[[中山経]]》中次七経常【上丞下灬】之山东北流注于河多苍玉。（005-068）

## 原文出处

《[[中山経]]》中次七経：

> 又西九十里，日常【上丞下灬】之山，无草木，多垩，【氵焦】水出焉，而东北流注于河，其中多苍玉。【上艹下甾】水出焉，而北流注于河。
>
> （005-068）

## 苍玉之水

【氵焦】水中多苍玉苍是青灰色：

| 属性 | 内容 |
|------|------|
| 源山 | 常【上丞下灬】之山 |
| 流向 | 东北流 |
| 注入 | 河（黄河） |
| 水中物 | 多苍玉 |

同一座山出两条水【氵焦】水东北流[[【上艹下甾】水]]北流都注入黄河。但只有【氵焦】水产苍玉【上艹下甾】水什么都没有。同源不同产两条水的价值不同。（005-068）

## 不毛之山的双水

常【上丞下灬】之山「无草木，多垩」不长任何植物只有白色的垩土。但这座不毛之山出两条水一条还产苍玉。山上荒凉水中富饶。地表一无所有地下全是宝物。（005-068）
