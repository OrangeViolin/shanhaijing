# 游戏之山

**游戏之山**は[[中山経]]中次十一経に記載される山である。（005-158）

## 原文出処

> 又東南三十里，曰游戲之山，多杻【僵亻換木】谷，多玉，多封石。
> （005-158）

## 地理描述

游戏之山は杻や【僵亻換木】の木が多く、玉と封石が多い。名前が独特で、「游戲」（遊び）の山という命名が興味深い。

## 山名の特異性

山海経の山名は地形・産物・動物に由来するものが大多数を占める中で、「游戲」（遊ぶ・戯れる）という行為を冠する山名は極めて珍しい。神仙が遊ぶ場とする解釈や、地名としての固有名とする見方がある。

## 産物

| 産物 | 分類 |
|------|------|
| 杻 | 樹木 |
| 【僵亻換木】 | 樹木 |
| 谷 | 樹木（楮） |
| 玉 | 鉱物 |
| 封石 | 鉱物 |

樹木三種と鉱物二種が記され、動物・河川の記載はない。封石は中山経に頻出する鉱物で、[[服山]]にも「多封石」と記される。

## 前後の山

| 前 | [[高前之山]]（帝台之漿、金、赭） |
|------|------|
| **当項** | **游戏之山（杻、玉、封石）** |
| 後 | [[从山]]（松柏、竹、从水、三足鼈） |

高前之山の「帝台之漿」（飲めば心痛を治す）から游戏之山を経て从山の三足鼈へと、この区間は神秘的な要素が連続する。
