# 【火军】诸之山

**【火军】诸之山**是《山海经·[[中山经]]》中次二经（注山之首）所载的首山。上多桑，兽多[[闾麋]]，鸟多[[【曷鸟】]]。（005-017）

## 原文出处

《[[中山经]]》中次二经：

> 中次二經注山之首，曰【火军】諸之山，其上多桑，其獸多閭麋，其鳥多【曷鳥】。
>
> （005-017）

## 三多

【火军】诸之山的物产三个「多」：

| 类别 | 产物 | 特征 |
|------|------|------|
| 木 | 桑 | 蚕桑之树 |
| 兽 | [[闾麋]] | 大型鹿类 |
| 鸟 | [[【曷鸟】]] | 经文常见鸟类 |

桑树、鹿群、飞鸟这是一座温和的、有人间气息的山。桑是养蚕的树有桑就有丝，有丝就有人。作为首山，【火军】诸之山以温和的面貌开启了中次二经的山列。（005-017）

## 首山

【火军】诸之山是中次二经的「注山之首」九山经脉的起点：

| 要素 | 内容 |
|------|------|
| 经脉 | 中次二经（济山之首） |
| 范围 | 【火军】诸之山至蔓渠之山 |
| 山数 | 九山 |
| 里程 | 一千六百七十里 |
| 山神 | 人面鸟身 |

九座山的神都是人面鸟身祭祀用毛物和吉玉，投而不糈。【火军】诸之山作为首山，设定了整条经脉的基调。（005-017）
