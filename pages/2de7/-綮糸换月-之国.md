# 【綮糸换月】之国

**【綮糸换月】之国**（无【綮糸换月】之国）是《山海经·[[海外北経]]》所载的国。在[[长股之国]]的东面其为人无【綮糸换月】（无肠）。（008-002）

## 原文出处

《[[海外北経]]》：

> 无【綮糸换月】之国在长股东，为人无【綮糸换月】。
>
> （008-002）

## 无肠之人

「为人无【綮糸换月】」这个国家的人没有肠：

| 属性 | 内容 |
|------|------|
| 国名 | 无【綮糸换月】之国 |
| 特征 | 无【綮糸换月】（无肠） |
| 方位 | 长股东 |

【綮糸换月】即肠无【綮糸换月】就是没有肠。山海経的海外之国以身体缺失或异形命名无【綮糸换月】之国是内脏缺失型。没有肠食物直通而过吃了就排不消化。这不是疾病是整个国家的人的共同特征。（008-002）

## 海外北経的身体异形

海外北経有多个身体异形的国无【綮糸换月】之国是其中之一：

| 国 | 异形部位 | 类型 | PN |
|----|----------|------|-----|
| [[长股之国]] | 股（腿） | 肢体异长 | 008-001 |
| **无【綮糸换月】之国** | 【綮糸换月】（肠） | 内脏缺失 | 008-002 |

长股是外在的异形（长腿）无【綮糸换月】是内在的异形（无肠）。从外到内海外北経的叙事深入身体内部。两国紧邻一东一西形成外/内异形的对偶。（008-001008-002）

## 极简条目

「无【綮糸换月】之国在长股东为人无【綮糸换月】」全文十四字：

| 要素 | 内容 |
|------|------|
| 国名 | 有 |
| 方位 | 有（长股东） |
| 特征 | 有（无【綮糸换月】） |
| 物产 | 无 |
| 动植物 | 无 |

三要素名、位、特征没有多余的信息。海外経的国名条目通常都很简短说清名字、位置、特征就够了。（008-002）
