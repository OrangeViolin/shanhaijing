# 【犭才】山

**【犭才】山**是《山海经·[[東山経]]》東次一経所载的山。上无草木下多水多堪【予予】之鱼。有兽状如夸父而彘毛音如呼见则天下大水。（004-009）

## 原文出处

《[[東山経]]》東次一経：

> 又南三百里，曰【犭才】山，其上无草木，其下多水，其中多堪【予予】之鱼。有兽焉，其状如夸父而彘毛，其音如呼，见则天下大水。
>
> （004-009）

## 大水之兽

【犭才】山唯一记载的兽是水灾的凶兆：

| 属性 | 内容 |
|------|------|
| 形状 | 如夸父 |
| 毛 | 彘毛（猪毛） |
| 鸣声 | 如呼 |
| 凶兆 | 见则天下大水 |

像夸父一样的体形长着猪毛叫声像人在呼喊。它一出现不是一地大水是「天下」大水。这个凶兆的规模是全天下级别的不同于[[化蛇]]的「其邑大水」（只是当地发水）。（004-009）

## 上荒下水

【犭才】山的地形是上下分裂的：

| 层面 | 内容 |
|------|------|
| 山上 | 无草木 |
| 山下 | 多水 |
| 水中 | 堪【予予】之鱼 |

山上光秃山下全是水。荒凉的山顶和丰沛的山脚地表的干与水下的湿形成反差。堪【予予】之鱼住在山下的水中而大水之兽住在山上。预兆大水的兽住在无水的山顶住在水里的反而不是凶兆反差叙事。（004-009）
