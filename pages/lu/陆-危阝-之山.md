# 陆【危阝】之山

**陆【危阝】之山**是《山海经·[[中山经]]》中次八经所载的山峰。上多【王雩】【王孚】之玉，下多垩——木多杻【左木加疆右边】。（005-096）

## 原文出处

《[[中山经]]》中次八经：

> 又東北二百里，曰陸【危阝】之山，其上多【王雩】【王孚】之玉，其下多垩，其木多杻【左木加疆右边】。
>
> （005-096）

## 上玉下垩

陆【危阝】之山的产物——上下分明：

| 位置 | 产物 |
|------|------|
| 山上 | 【王雩】【王孚】之玉 |
| 山下 | 垩（白土） |
| 山间 | 杻、【左木加疆右边】 |

【王雩】【王孚】之玉——两种名贵的玉石。垩——白色粘土，涂料和建材的原料。玉在上、土在下——从珍贵到实用，垂直分布。（005-096）

## 简洁之山

陆【危阝】之山的记载极为简短——无水系、无异兽、无药效植物：

| 有 | 无 |
|----|-----|
| 玉 | 水系 |
| 垩 | 异兽 |
| 杻木 | 药效植物 |

中次八经的山列中有些山记载丰富（如[[宜诸之山]]有水有玉），有些山只记矿物和树木。陆【危阝】之山属于后者——安静的产出之山，没有故事只有资源。（005-096）
