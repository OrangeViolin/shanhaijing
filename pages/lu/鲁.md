# 鲁

**鲁**是《山海经·[[海内東経]]》所载的地名。[[泗水]]出鲁东北——南流——西南过湖陵西——东南注东海——入淮阴北。泗水的水源地。（014-012）

## 原文出处

《[[海内東経]]》：

> 泗水出鲁东北，而南，西南过湖陵西，而东南注东海，入淮阴北。
>
> （014-012）

## 泗水之源

鲁是泗水的发源地——经文以国名标记水源：

| 属性 | 内容 |
|------|------|
| 水 | 泗水 |
| 出处 | 鲁东北 |
| 流程 | 南→西南过湖陵西→东南注东海 |
| 入处 | 淮阴北 |

泗水从鲁的东北发源——先南流——再西南过湖陵——最后东南入海在淮阴北。四次转向——海内東経中流路记述最详细的河流之一。（014-012）

## 实地理

鲁对应春秋时代的鲁国——周公旦的封国——今山东省曲阜一带：

| 属性 | 内容 |
|------|------|
| 对应 | 春秋鲁国 |
| 位置 | 今山东省曲阜 |
| 性质 | 实在地名 |

海内東経用国名来标记河流水源——「泗水出鲁」与「赣水出聂都」「郁水出象郡」同格——都是以地名定位水源的写法。鲁不是神话地名——是可以对应实际地理的行政名。（014-012）
