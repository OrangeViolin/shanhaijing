# 陆山

**陆山**是《[[北山经]]》北次三经记载的一座山，在高是之山以北三百里。产美玉，【姜阝】水发源于此，东流注入[[河]]（黄河）。陆山是北次三经中段"东流注河"水系连续带的核心山之一。（003-222）

## 原文出处

《[[北山经]]》北次三经：

> 又北三百里，曰陆山，多美玉。美玉【姜阝】水出焉，而东流注于河。
>（003-222）

## 北次三经的位置

北次三经沿太行山脉及其以北方向延伸，陆山处于该经中北段，夹在高是之山与沂山之间。

| 顺序 | 山名 | 间距 | 要点 |
|------|------|------|------|
| 220行 | 童戎之山 | - | 皋涂之水出，东流注于液水 |
| 221行 | 高是之山 | 北300里 | 滋水出南流；【氵寇】水出东流注河 |
| **222行** | **陆山** | **北300里** | **多美玉；【姜阝】水出，东流注河** |
| 223行 | 沂山 | 北200里 | 般水出，东流注河 |
| 224行 | [[燕山]] | 北120里 | 多婴石；燕水出，东流注河 |
| 225行 | 饶山 | 北山行500里水行500里 | 多瑶碧；历虢之水出，东流注河 |

陆山处于连续五山"东流注河"的第二位（高是之山的【氵寇】水、陆山的【姜阝】水、沂山的般水、燕山的燕水、饶山的历虢之水），构成北次三经中段密集的黄河支流群。

## 美玉与水名的一体化命名

陆山原文的特殊之处在于水名与山产直接连用：**"多美玉。美玉【姜阝】水出焉"**。"美玉"在句中被用作水名的前缀，形成"产美玉之山、美玉水东流"的叙述。

《山海经》中以山产命名水系者有数处：
- 陆山：美玉【姜阝】水（以玉命名）
- 景山：景水（以山名命名）

但将山产形容词直接冠于水名之前，构成复合词式水名，陆山的"美玉【姜阝】水"是较为特殊的案例。这种命名方式暗示该水确实因产玉质河床或沿岸产玉而得名，美玉与水系在实地有直接关联。

【姜阝】，从姜从阝（邑旁），字形特殊，部分本作"姜水"，或与姜姓部族的地理分布相关。姜姓是上古重要族群，炎帝系统，姜水（陕西渭水流域）是其祖源之水，北次三经的【姜阝】水或为姜姓部族北迁后命名的同源水名。

## 美玉产区

陆山以"多美玉"为主要记述，在北次三经的玉矿分布中占有一席之地：

| 山名 | 玉石记录 |
|------|----------|
| 景山 | 有美玉 |
| 绣山 | 有玉、青碧 |
| 维龙之山 | 有碧玉，其阳有金 |
| 陆山 | 多美玉 |
| [[燕山]] | 多婴石（嬰玉） |
| 饶山 | 多瑶碧 |
| 碣石之山 | 有玉，多青碧 |

陆山所在的北次三经中北段形成了一条玉石带，从绣山经景山、维龙之山、陆山到燕山，沿黄河西岸向北分布。陆山的美玉，其上游为维龙之山的碧玉，其下游为燕山的婴石，三山构成了一条玉质递进的玉矿走廊。

## 东流注河的地理意义

陆山的【姜阝】水东流注入黄河，这一记述属于北次三经"东流注河"水系的组成部分。

北次三经大致沿今太行山脉及吕梁山脉向北延伸，这一带山脉的河流多为向东或向东南流入黄河或海河水系。《山海经》对北次三经水系的记录，在方向上与实际地形高度吻合。陆山的【姜阝】水东流，意味着该山位于黄河以西、水系向东排泄的高地地带，符合山西中部或北部山区的地理特征。

饶山之后的水系需要"北山行五百里水行五百里"才能到达，暗示陆山所在的段落（高是之山到饶山之间）是北次三经中连续山行路段，地势较为平稳，可连续陆路行进，不需绕水路。

## 山名"陆"的解读

"陆"在古汉语中本义为高平之地，与山地的陡险形象相对，指地势平坦的高地或高台。《说文》："陆，高平地也。"

以"陆"命名的山，可能指其山顶或山势以高平台地为特征，而非尖峰峻岭。北次三经中段地处太行山脉与黄土高原接壤地带，平台山地（塬、台地）常见，陆山或为此类地形的代表。

"陆"字也与古代行路相关，"陆行"即陆路行进，北次三经在描述饶山路段时特别区分"山行"与"水行"，陆山所在区段正是纯山路段，"陆山"或反映了旅行者对该段以陆路为主的地形记忆。

## 北次三经的水文密度

北次三经全经四十六山，记有明确出水（包含水名和流向）的山在二十座以上，是《山海经》中水文记录最密集的经之一。陆山作为其中一座有水名的山，参与构建了北次三经的完整水网图谱。

高是之山以北的连续五山（陆山在其中）均有东流入河的水系，形成北次三经水文记录的高密度段，这一段在全经的水文图谱中呈现出密集并列的并流结构，如同黄河西岸的多条手指向东伸向主干。
