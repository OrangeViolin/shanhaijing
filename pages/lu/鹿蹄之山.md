# 鹿蹄之山

**鹿蹄之山**是《山海经·[[中山经]]》中次四经（厘山之首）所载的首山。上多玉，下多金——甘水出下，北流注于[[洛水]]，水中多泠石。（005-032）

## 原文出处

《[[中山经]]》中次四经：

> 中次四經厘山之首，曰鹿蹄之山，其上多玉，其下多金。甘水出下，而北流注於洛，其中多泠石。
>
> （005-032）

## 上玉下金

鹿蹄之山的矿物——上下分层：

| 位置 | 产物 |
|------|------|
| 山上 | 玉 |
| 山下 | 金 |
| 水中 | 泠石 |

玉在上、金在下——贵重之物垂直分布。甘水从山下流出——金与水在山脚汇合。泠石——冷性之石，标记甘水的水质特征。（005-032）

## 甘水入洛

甘水从鹿蹄之山流出——北流注入洛水：

| 要素 | 内容 |
|------|------|
| 水名 | 甘水 |
| 流向 | 北流 |
| 注入 | [[洛水]] |

洛水是中山经多条经脉的主干河流——反复出现。甘水是洛水的支流之一——鹿蹄之山因此属于洛水流域。首山出水入洛——定下了整条经脉的水系归属。（005-032）

## 九山之首

鹿蹄之山统领中次四经——九山一千六百七十里：

| 要素 | 内容 |
|------|------|
| 范围 | 鹿蹄之山至[[玄扈之山]] |
| 山数 | 九山 |
| 里程 | 一千六百七十里 |
| 山神 | 人面兽身 |
| 祭法 | 毛用一白鸡，祈而不糈，以采衣之 |

九山的神都是人面兽身——用白鸡祭祀，只祈祷不供糈米，用彩布做衣。鹿蹄之山作为首山，这套祭法从它开始适用于整条经脉。（005-032）

## 鹿蹄之名

「鹿蹄」——鹿的蹄印：

| 字 | 义 |
|----|-----|
| 鹿 | 鹿 |
| 蹄 | 蹄印 |

山以鹿蹄命名——也许山上有像鹿蹄印的石头，也许这座山是鹿群出没的地方。山上有闾麋之类的鹿属动物是中山经常见的记载——鹿蹄之山以鹿为名，以鹿为灵。（005-032）
