# 奥水

**奥水**是《山海经·[[中山经]]》中次十一经所载的河川，发源于奥山，东流注于视水。奥山上多柏、杻、【僵亻换木】（良材），阳面多【王雩】【王孚】之玉。（005-185）

## 原文出处

《[[中山经]]》中次十一经：

> 又东三百里，曰奥山，其上多柏杻【僵亻换木】，其阳多【王雩】【王孚】之玉。奥水出焉，东流注于视水。
>
> （005-185）

## 山水同名

奥山与奥水同名「奥」贯穿了山和水：

| 名称 | 类型 | 特征 |
|------|------|------|
| 奥山 | 山 | 多良材美玉 |
| 奥水 | 水 | 东流注于视水 |

「奥」深远、幽深。奥山奥水是一对以「深」命名的山水深山出深水。（005-185）

## 视水支流

奥水是汇入视水的多条支流之一中次十一经后半段以视水为主干：

| 山 | 水 | 汇入 |
|----|-----|------|
| 鲵山 | 鲵水（潜流） |  |
| 雅山 | 澧水 |  |
| 宣山 | 沦水 |  |
| **奥山** | **奥水** | **视水** |

中次十一经的后半段有多条水东流，视水作为集水河川接收这些支流。奥水是明确标注「东流注于视水」的一条它为视水输送从深山流出的水。（005-185）

## 静穏之山

奥山没有异兽、异鸟、药物的记载只有树木和玉：

| 项目 | 有无 |
|------|------|
| 草木 | 柏、杻、【僵亻换木】 |
| 矿产 | 【王雩】【王孚】之玉 |
| 异兽 | 无 |
| 异鸟 | 无 |
| 药效 | 无 |

柏、杻、【僵亻换木】都是实用的良材柏木坚韧耐腐，杻和【僵亻换木】是硬木。没有怪兽、没有凶兆、没有药效奥山是一座安静的木材山和玉石山。在中次十一经充满异类的山列中，奥山的素朴是一种休息。（005-185）

## 三百里间距

奥山与前山丑阳之山相距三百里中次十一经中较大的间距：

| 区间 | 距离 |
|------|------|
| 丑阳之山→奥山 | 东三百里 |
| 奥山→服山 | 东三十五里 |

三百里的长距离之后是三十五里的短距离奥山像是一个远处的独立点。三百里的荒野之后到达一座安静的良材山远而静，深而幽名副其实的「奥」。（005-185）
