# 宜诸之山

**宜诸之山**是《山海经·[[中山经]]》中次八经所载的山峰。上多金玉，下多青【镬钅换丹】；【氵危】水南流注于漳水，水中多白玉。（005-094）

## 原文出处

《[[中山经]]》中次八经：

> 又東北二百里，曰宜諸之山，其上多金玉，其下多青【鐵釒換丹】。【氵危】水出焉，而南流注于漳，其中多白玉。
>
> （005-094）

## 双玉之山

宜诸之山的玉，山上有、水中也有：

| 位置 | 产物 |
|------|------|
| 山上 | 金玉 |
| 山下 | 青【镬钅换丹】 |
| 水中 | 白玉 |

金玉在山上，要爬上去采。白玉在水中，要潜下去捞。一座山的宝物分布在最高处和最低处，中间是青【镬钅换丹】。从上到下：金玉→青【镬钅换丹】→白玉，三层矿物垂直排列。（005-094）

## 漳水支流

【氵危】水从宜诸之山发源，南流注入漳水：

| 要素 | 内容 |
|------|------|
| 水名 | 【氵危】水 |
| 流向 | 南流 |
| 注入 | 漳水 |
| 物产 | 白玉 |

漳水是中次八经的主干河流，多条支流汇入。【氵危】水是其中之一，携带白玉南下。白玉在水中被冲刷，越冲越圆润，这是水中玉与山上玉的区别。（005-094）

## 神山与实山

宜诸之山前后，神话与实录交替：

| 位置 | 山 | 特征 | PN |
|------|-----|------|----|
| 前 | 骄山 | 神【上单左下虫右下虫】围出入有光 | 005-092 |
| **此** | **宜诸之山** | **纯矿物水系，无神无兽** | **005-094** |
| 后 | 纶山 | 多梓【木丹】桃枝 | 005-095 |

骄山有神，出入发光。宜诸之山无神无兽，只有矿物和水。中次八经在有神的山和无神的山之间交替，不是每座山都有故事，有些山只是安静地出产金玉。（005-092至005-095）
