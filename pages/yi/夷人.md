# 夷人

**夷人**是《山海经·[[海内西经]]》所载的民族。在[[东胡]]之东——全文仅此一句。（012-010）

## 原文出处

《[[海内西经]]》：

> 夷人在东胡东。
>
> （012-010）

## 一句

「夷人在东胡东」——山海经中最短的民族条目之一：

| 有 | 无 |
|----|-----|
| 方位（东胡东） | 姓 |
| — | 食性 |
| — | 身体特征 |
| — | 异兽异鸟 |

没有姓，没有吃什么，没有长什么样——只知道在东胡的东面。夷人的全部存在就是一个方位关系。（012-010）

## 东方连锁

夷人处于海内西经的东北方位连锁中——每一条都在前一条的东面：

| 条目 | 方位 | 附加信息 |
|------|------|---------|
| [[东胡]] | 大泽东 | 无 |
| **夷人** | **东胡东** | **无** |
| [[貊国]] | 汉水东北 | 地近于燕，灭之 |
| 孟鸟 | 貊国东北 | 文赤黄青，东乡 |

东胡→夷人→貊国→孟鸟——一层层向东推。东胡和夷人都没有附加信息，貊国有历史事件（被燕灭），孟鸟有视觉描写（赤黄青）。越往东信息越多——夷人是信息最少的一环。「夷」本就是东方异族的总称——在东胡的东面再放一个叫「夷」的，是东方之外还有东方。（012-009至012-012）
