# 肄水

**肄水**是《山海经·[[海内东经]]》所载的河川，发源于临晋西南，东南流入海，在番禺之西入海。支流潢水从桂阳西北山流入肄水。（014-012）

## 原文出处

《[[海内东经]]》：

> 肄水出临晋西南，而东南注海，入番禺西。潢水出桂阳西北山，东南注肄水，入敦浦西。
>
> （014-012）

## 岭南大河

肄水从临晋流到番禺——这是一条横跨岭南的大河。番禺即今日广州一带，肄水被认为是珠江水系西江的古称：

| 要素 | 描述 |
|------|------|
| 源头 | 临晋西南 |
| 流向 | 东南 |
| 入海处 | 番禺西 |
| 支流 | 潢水（出桂阳西北山） |

肄水流经的区域从内陆的临晋一直到沿海的番禺——流域覆盖了今天广西到广东的广大区域。（014-012）

## 主流与支流

海内东经在记载肄水时紧接着补充了它的支流潢水：

| 河流 | 源头 | 归宿 |
|------|------|------|
| **肄水** | **临晋西南** | **入海（番禺西）** |
| 潢水 | 桂阳西北山 | 入肄水（敦浦西） |

先说主流、再说支流——这是海内东经记载水系的标准格式。编纂者不仅知道肄水的流向，还知道它有一条叫潢水的支流从桂阳方向汇入——对岭南水文的认知相当具体。（014-012）

## 海内东经大水系总览

肄水处于海内东经一段包罗全国的水系大目录中。在这份目录中，河流从北到南逐一列举：

| 水系区域 | 代表河流 |
|---------|---------|
| 黄河水系 | 渭水、泾水、洛水、汾水 |
| 淮河水系 | 淮水、颖水、汝水 |
| 长江水系 | 汉水、白水、沅水、赣水 |
| **珠江水系** | **肄水、潢水** |
| 东部入海 | 泗水、郁水 |

肄水是这份水系目录中最南的大河之一——它标记了古代中国地理认知的南方边界。编纂者知道在遥远的南方，有一条大河从内陆流到番禺入海。（014-012）
