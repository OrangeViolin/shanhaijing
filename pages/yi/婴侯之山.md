# 婴侯之山

**婴侯之山**是《山海经·[[中山经]]》中次十一经所载的山峰。山上多封石，山下多赤锡。与前方的[[婴山]]名称相近、都以矿产为主——构成一对矿物双山。（005-166）

## 原文出处

《[[中山经]]》中次十一经：

> 又东二十里，曰婴侯之山，其上多封石，其下多赤锡。
>
> （005-166）

## 封石

婴侯之山的山上矿产——封石：

| 矿产 | 位置 | 含义 |
|------|------|------|
| 封石 | 山上 | 自然叠起的柱状石 |
| 赤锡 | 山下 | 红色锡矿 |

「封石」——自然堆叠成柱的石头，如封土一般隆起。《山海经》中记载封石的山极少——这是一种具有特殊形态的石头，不是矿物价值而是视觉形态让它被记录。（005-166）

## 赤锡

山下多赤锡——红色的锡矿：

| 色彩 | 矿物 |
|------|------|
| 赤 | 锡 |

赤锡是红色的锡矿物（或朱砂系矿物）——「赤」强调的不是锡的冶金价值，而是它的颜色。山上的封石是形态，山下的赤锡是色彩——婴侯之山从上到下，一个讲形状，一个讲颜色。（005-166）

## 婴山双峰

婴侯之山与前方的婴山名称相近，构成矿物双山：

| 山 | 间距 | 矿产 |
|----|------|------|
| [[婴山]] | — | 青【左丹右上萑右下又】、金玉 |
| 虎首之山 | 东三十里 | 苴【木周】椐（植物） |
| **婴侯之山** | **东二十里** | **封石、赤锡** |

婴山产青色颜料和金玉，婴侯之山产封石和赤锡——两座「婴」山各有各的矿物组合，中间隔了一座以植物为主的虎首之山。从婴山到婴侯之山，矿物从贵重（金玉）转向稀奇（封石、赤锡）。（005-164至005-166）

## 极简山

婴侯之山只有矿产记载——没有任何生物和水系：

| 项目 | 有无 |
|------|------|
| 草木 | 无 |
| 水系 | 无 |
| 异兽 | 无 |
| 异鸟 | 无 |

两行矿产，仅此而已——婴侯之山是一座纯粹的矿石之山。它存在的意义就是封石和赤锡——两种不常见的矿物标本，如同地质标签一般标注在这座山上。（005-166）
