# 句余之山

**句余之山**是《山海经·[[南山经]]》南次二经所载的山峰，无草木而多金玉。（001-016）

## 原文出处

《[[南山经]]》：

> 又东四百里，曰句余之山，无草木，多金玉。
>
> （001-016）

## 与瞿父之山的镜像

句余之山与前一站[[瞿父之山]]的经文几乎完全相同：「无草木，多金玉」。两山相距仅四百里（001-015 → 001-016），物产记录一字不差。这种紧邻山峰的完全重复在《山海经》中极为罕见——大多数相邻的山即使类似也会有微小差异（不同的矿产、不同的水系方向）。瞿父与句余的完全相同，使这段经路读起来像是在穿越一片无尽的荒漠。（001-016）

## 南次二经的荒凉梯度

句余之山之后，南次二经进入更深层的荒凉：

| 山 | 记录内容 | 荒凉程度 |
|------|---------|---------|
| [[瞿父之山]] | 无草木，多金玉 | 荒芜但有矿 |
| **句余之山** | 无草木，多金玉 | 荒芜但有矿 |
| [[仆勾之山]] | 多金玉，无鸟兽，无水 | 荒芜，无生命，无水 |
| [[咸阴之山]] | 无草木，无水 | 荒芜，无矿，无水 |
| 洵山 | 多金玉 | 恢复矿产 |

从瞿父/句余的「无草木多金玉」，到仆勾的「无鸟兽无水」，再到[[咸阴之山]]的「无草木无水」——每一步都减少一项存在：先去植被，再去生物，最后去水。咸阴之山是南次二经的荒凉极值：什么都没有。句余之山在这个梯度中处于「还有矿可记」的阶段，再往前就连矿也不值得提了。（001-016）
