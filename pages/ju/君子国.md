# 君子国

**君子国**是《山海经·[[海外東経]]》所载的邦国。衣冠带剑——食兽——使二大虎在旁——其人好让不争。有薰华草——朝生夕死。（009-005）

## 原文出处

《[[海外東経]]》：

> 君子国在其北，衣冠带剑，食兽，使二大虎在旁，其人好让不争。有薰华草，朝生夕死。一曰在肝榆之尸北。
>
> （009-005）

## 好让不争

君子国的核心——四个字：好让不争。但这四个字的背景并不柔弱：

| 属性 | 内容 |
|------|------|
| 服饰 | 衣冠带剑 |
| 食物 | 食兽 |
| 侍从 | 二大虎 |
| 性格 | 好让不争 |

穿着正式的衣冠——佩着剑——吃兽肉——身边还有两头大老虎。这不是软弱的人——而是有剑不用、有虎不逞的人。好让不争不是因为不能争——是能争而不争。（009-005）

## 薰华草

君子国中有薰华草——朝生夕死：

| 属性 | 内容 |
|------|------|
| 名称 | 薰华草 |
| 生命周期 | 朝生夕死 |

一天之内生死轮回。放在「好让不争」的君子国中——这不是灾异——是寓言。好让不争的人旁边长着朝生夕死的草——人生如薰华——何必争。（009-005）
