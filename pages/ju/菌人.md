# 菌人

**菌人**是《山海经·[[大荒南经]]》所载的小人。有小人，名曰菌人。（011-028）

## 原文出处

《[[大荒南经]]》：

> 有小人，名曰菌人。
>
> （011-028）

## 一句话小人

菌人的全部记载——只有一句话：

| 信息 | 有无 |
|------|------|
| 名字 | 菌人 |
| 体型 | 小人 |
| 形态 | 无 |
| 食性 | 无 |
| 习俗 | 无 |
| 国名 | 无 |

山海经其他小人——[[周饶国]]有「三尺」的身高、[[焦侥之国]]有「幾姓」的族属。菌人什么都没有——只有「小人」和「菌人」四个字。山海经中最简的记载之一。（011-028）

## 菌之名

「菌」——蘑菇：

| 联想 | 含义 |
|------|------|
| 菌 = 蘑菇 | 像蘑菇一样小 |
| 菌 = 菌类 | 从地面冒出来 |

菌人——蘑菇一样的小人。蘑菇矮小、从地里冒出——小人也是。名字本身就在说「小」——菌人不需要更多描述。（011-028）

## 两座楽园之间

菌人的位置——夹在两座富饶之山中间：

| 位置 | 内容 | PN |
|------|------|----|
| 前 | 盖犹之山：甘果、彩马、视肉 | 011-027 |
| **中** | **菌人** | **011-028** |
| 后 | [[南类之山]]：遗玉、青马、百谷 | 011-029 |

前面是果树遍地的山——后面是百谷齐备的山。菌人夹在两座丰饶之山中间——楽园里的小小住民。（011-027、011-028、011-029）
