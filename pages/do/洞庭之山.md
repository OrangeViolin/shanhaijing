# 洞庭之山

**洞庭之山**是《山海经·[[中山経]]》中次十二経（洞庭山系）所载的神山。帝之二女居此——常游于江渊。澧沅之风交潇湘之渊——在九江之间——出入必以飘风暴雨。多怪神——状如人而载蛇。与[[荣余之山]]同为山神居所——受太牢加圭璧十五最高祭祀。（005-196、005-204）

## 原文出处

《[[中山経]]》中次十二経：

> 又东南一百十里，曰洞庭之山，其上多黄金，其下多银铁，其木多【木且】梨橘【木繇】，其草多兰、蘪芜、芍药、芎【上艹下穷】。帝之二女居之，是常游于江渊。澧沅之风，交潇湘之渊，是在九江之间，出入必以飘风暴雨，是多怪神，状如人而载蛇。
>
> （005-196）

> 洞庭、荣余山神也，其祠：皆肆瘗，祈酒太牢祠，婴用圭璧十五，五采惠之。
>
> （005-204）

## 帝之二女

洞庭之山住着帝的两个女儿——后世[[娥皇]]、[[女英]]传说的原型：

| 属性 | 内容 |
|------|------|
| 居者 | 帝之二女 |
| 活动 | 常游于江渊 |
| 伴随 | 出入必以飘风暴雨 |

帝（帝舜或帝尧）的两个女儿住在这里——常在江中的深渊游泳。每次进出——必定伴随狂风暴雨。她们不是被困在山上——而是自由进出——但每次移动都引发天气剧变。山海経中这是自然现象的记录——不带感情——后世楚辞才把飘风暴雨变成了哀情。（005-196）

## 香草之山

洞庭之山的植物全是香草和果木——极尽芬芳：

| 类型 | 植物 |
|------|------|
| 木 | 【木且】、梨、橘、【木繇】 |
| 草 | 兰、蘪芜、芍药、芎【上艹下穷】 |
| 金属 | 山上黄金、山下银铁 |

兰——蘪芜——芍药——芎穷——全是香草和药草。帝之二女住在香草丛中——后世楚辞的「香草美人」传统在这里有了地理根基。（005-196）

## 怪神与人蛇

洞庭之山多怪神——人形而头上载蛇：

| 属性 | 内容 |
|------|------|
| 形态 | 如人而载蛇 |
| 特征 | 多（不止一个） |

人形——头上顶着蛇。不是人面蛇身——而是完整的人加上蛇的装饰。蛇是南方水域神格的标记——洞庭在九江之间——是典型的南方水域。（005-196）

## 最高祭祀

洞庭之山与[[荣余之山]]共享山海経中最高级的祭祀：

| 祭品 | 内容 |
|------|------|
| 牲 | 太牢（牛羊豕） |
| 玉 | 圭璧十五枚 |
| 衣 | 五采惠之 |

圭璧十五枚——山海経中没有第二座山用这么多玉器。五采之衣——五色的衣服覆盖供品。帝之二女的居所配得上最豪华的祭祀。（005-204）

## 潇湘之渊

「澧沅之风交潇湘之渊」——四条水的名字点出了洞庭之山的地理位置：

| 水 | 关系 |
|----|------|
| 澧水 | 风来处 |
| 沅水 | 风来处 |
| 潇水 | 渊所在 |
| 湘水 | 渊所在 |

澧沅的风和潇湘的渊交汇——九江之间。这是洞庭湖周边实在的水文地理——山海経用四条水名精确定位了这座山。（005-196）
