# 牡山

**牡山**是《山海经·[[中山经]]》中次四经所载的山。山上多文石，山下多竹箭竹篠。兽多【牛乍】牛、【羊咸】羊，鸟多赤鷩。（005-039）

## 原文出处

《[[中山经]]》中次四经：

> 又西三百里，曰牡山，其上多文石，其下多竹箭竹【上竹下媚】，其兽多【牛乍】牛、【羊咸】羊，鸟多赤【上敝下鸟】。
>
> （005-039）

## 牡山之名

「牡」——雄性。牡山是以雄性命名的山。山上有牛有羊——【牛乍】牛和【羊咸】羊，像一座天然的牧场。以「牡」（雄性牲畜）命名一座牛羊聚集的山，名实相符。（005-039）

## 文石与竹

牡山的物产呈现上下分层：

| 位置 | 产物 |
|------|------|
| 山上 | 文石（有花纹的石头） |
| 山下 | 竹箭、竹篠 |

文石是有美丽纹路的石材——装饰性矿物。竹箭和竹篠是制作箭矢和细竹器的原料——实用性植物。山上观赏，山下实用——牡山的物产从美学到功能齐全。（005-039）

## 赤鷩

牡山的鸟是赤鷩——红色的鷩雉：

| 特征 | 描述 |
|------|------|
| 种类 | 鷩（雉鸟） |
| 颜色 | 赤色（红色） |

赤鷩在《山海经》中多次出现——夸父之山也有赤鷩。这种红色的雉鸟是中山经山区的常见鸟类。牡山的赤鷩配合文石的花纹——红色与花纹，牡山是一座色彩丰富的山。（005-039）

## 经脉末段

牡山位于中次四经的末尾区域：

| 山 | 位置 | 特征 |
|----|------|------|
| 熊耳之山 | 末段 | 浮濠之水入洛、人鱼、葶苎 |
| **牡山** | **倒数第二** | **文石、竹箭、牛羊、赤鷩** |
| 囗举之山 | 末山 | 雒水入玄扈之水 |

熊耳之山有人鱼和毒鱼草（葶苎），牡山有牛羊和赤鷩——从水中的异鱼到山上的家畜，从神异转向日常。牡山是中次四经接近尾声时的一座平静之山——没有凶兆，没有异物，只有石、竹、牛、羊和红色的鸟。（005-039）
