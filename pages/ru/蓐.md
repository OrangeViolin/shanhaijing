# 蓐

**蓐**は[[中山経]]中次十一経に記載される瑞獣である。（005-199）

## 原文出処

> 有兽焉，其状如龟，而白身赤首，名曰蓐，是可以御火。
> （005-199）

## 形態描述

蓐は亀に似た姿で、白い身体と赤い首を持つ。火を防ぐ（御火）ことができるという特殊な能力を持つ瑞獣である。

[[即公之山]]に棲息する。御火の能力は防災・防火の象徴として重要であり、中山経の異獣の中でも実用的な瑞兆を持つ存在である。

## 与蓐收之辨

「蓐」作为兽名仅见于即公之山一处，但「蓐收」是西方之神，两者不可混淆：

| | 蓐（兽） | [[蓐收]]（神） |
|---|---|---|
| 出处 | 中次十一经（005-199） | 西次三经（002-041）、海外西经（008-003） |
| 性质 | 龟形瑞兽，白身赤首 | 西方秋神，左耳有蛇，乘两龙 |
| 能力 | 御火 | 司日落之气，掌秋杀之权 |
| 栖息地 | [[即公之山]] | [[【氵幼】山]] |

## 御火异兽比较

山海经中具有御火能力的生物不止一种：

- **蓐**：龟形，白身赤首，即公之山（005-199）
- **【民鸟】**：翠形，赤喙，[[符禺之山]]（002-005）

两者均以「可以御火」标注，但形态截然不同——蓐为爬行龟形，【民鸟】为飞禽翠形。御火功能在山海经中属于罕见标注，暗示这些山区可能存在火灾风险。
