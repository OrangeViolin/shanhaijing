# 王屋之山

**王屋之山**是《山海经·[[北山経]]》北次三経所载的山。多石——【氵联】水西北流注于泰泽。（003-051）

## 原文出处

《[[北山経]]》北次三経：

> 又北百里，曰王屋之山，是多石。【氵联】水出焉，而西北流注于泰泽。
>
> （003-051）

## 泰泽水系

【氵联】水不流入黄河——西北流注于泰泽：

| 属性 | 内容 |
|------|------|
| 源山 | 王屋之山 |
| 流向 | 西北流 |
| 汇入 | 泰泽 |

北次三経大多数水都流入河（黄河）——东流注于河、南流注于河、北流注于河。王屋之山的水偏偏西北流入泰泽——是这条经脉中的异类。王屋之山属于另一个水系。（003-051）

## 多石之山

王屋之山的物产只有一个字——石：

| 内容 | 有无 |
|------|------|
| 草木 | 未记 |
| 异兽 | 无 |
| 矿物 | 石（未指定种类） |
| 水 | 【氵联】水 |

不是金——不是玉——不是铜铁——只是「石」。连是什么石头都没说。前后的山都有异兽（阳山有领胡和象蛇——景山有酸與）——王屋之山什么动物都没有——只有石头和一条水。（003-051）

## 愚公移山

后世「愚公移山」的故事以王屋山为舞台。但山海经中的王屋之山远比寓言简单——只有石头和水——一座安静的、不入黄河的山。（003-051）
