# 王亥

**王亥**是《山海经》中罕见的历史性人物——商族先祖，甲骨文中可考证的早期商王之一。他的故事是《山海经》中最接近「历史事件」的叙事：托牛于有易部落和河伯，被有易人杀害，牛群被夺。这不是神话中的宇宙冲突，而是一起发生在族群之间的商业/政治纠纷。

## 原文出处

引注：（015-025）

> 有人曰王亥，两手操鸟，方食其头。王亥托于有易、河伯仆牛。有易杀王亥，取仆牛。

## 事件经过

| 阶段 | 内容 |
|------|------|
| 出场 | 王亥「两手操鸟，方食其头」——持鸟食其头的姿态 |
| 托牛 | 将仆牛（用于放牧的牛群）托付给有易部落和[[河伯]] |
| 被杀 | 有易人杀害王亥 |
| 夺牛 | 有易取走仆牛 |

这是一个完整的「信任→背叛→掠夺」故事。王亥信任有易，将最重要的资产（牛群）交给对方保管，却被对方杀害并夺产。

## 「两手操鸟，方食其头」

王亥出场时的姿态——双手抓着鸟，正在吃鸟头。这个描写的意义不明确，可能的解读：

| 解读 | 含义 |
|------|------|
| 图腾标志 | 商族以鸟（玄鸟）为图腾，「操鸟」暗示王亥的商族身份 |
| 牧人的日常 | 放牧者在野外捕食禽鸟充饥 |
| 仪式姿态 | 某种祭祀活动中的程式化动作 |

商族起源于玄鸟（「天命玄鸟，降而生商」），王亥手持鸟的姿态可能是商族图腾崇拜的视觉表达。

## 历史性

王亥在甲骨文中被称为「高祖亥」或「王亥」，是商代王室认定的重要先祖。《竹书纪年》等文献也有王亥被有易杀害的记载，与《山海经》的叙事高度一致。这使王亥成为《山海经》中少数可以与考古证据（甲骨文）互证的人物之一。

## 牛与商族

「仆牛」——用于放牧/运输的牛群。王亥以畜牧起家，后世「商」字本身可能与王亥的贩牛活动有关（「商人」一词的早期含义就是商族从事贸易的人）。王亥被杀后牛群被夺，暗示早期族群之间因牲畜资源引发的暴力冲突。

## 神话意义

**从神话到历史的过渡**：王亥的故事没有任何超自然元素——没有神力、没有变形、没有天帝干预。一个人把牛交给另一群人保管，被杀了，牛被抢了。这是《山海经》中最「现实」的叙事，暗示大荒经的编纂材料中混入了真实的族群记忆。

**信任的成本**：在一个没有契约法的世界里，「托」是一种基于信任的行为。王亥信任有易，付出了生命的代价。这个故事可能是先秦商业伦理的一个负面教材——不要把核心资产无保护地交给他人。
