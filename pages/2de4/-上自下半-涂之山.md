# 【上自下半】涂之山

**【上自下半】涂之山**是西山经中的一座山，蔷水和涂水两条河从此出发。阳面多丹粟，阴面多银和黄金，山上多桂木。物产中的生物都带有「人体化」特征。

## 原文出处

引注：（002-016）

> 西南三百八十里，曰【上自下半】涂之山，蔷水出焉，西流注于诸资之水；涂水出焉，南流注于集获之水。其阳多丹粟，其阴多银、黄金，其上多桂木。

## 物产

| 类别 | 物产 |
|------|------|
| 水系 | [[蔷水]]（→诸资之水）、[[涂水]]（→集获之水） |
| 矿物 | 丹粟、银、黄金 |
| 植物 | 桂木、无条（可毒鼠） |
| 白石 | 囗（可毒鼠） |
| 兽 | [[【犭婴】如]]（鹿状马足人手四角） |
| 鸟 | [[数斯]]（鸱状人足，食之已瘿） |

【犭婴】如有「人手」，数斯有「人足」这座山的异物都朝人体方向变异。
