# 海山

**海山**是《山海经·[[大荒西经]]》所载的山峰，与[[王母之山]]、[[壑山]]三山并列。三山之间展开沃之野——凤鸟之卵是食、甘露是饮的理想乐土。（016-017）

## 原文出处

《[[大荒西经]]》：

> 西有王母之山，壑山、海山。有沃之国，沃民是处。沃之野，凤鸟之卵是食，甘露是饮。凡其所欲其味尽存。爰有甘华、璇瑰、甘【木且】、瑶碧、白木、白柳、视肉、琅【王千】、白丹、青丹、多银铁。鸾凤自歌，凤鸟自舞，爰有百兽，相群是处，是谓沃之野。
>
> （016-017）

## 三山乐土

海山与王母之山、壑山构成沃之野的地理骨架：

| 山 | 含义 |
|----|------|
| 王母之山 | 西王母之山（神母） |
| 壑山 | 谷之山（大地） |
| **海山** | **海之山（水域）** |

神母、大地、海——三种自然要素构成乐土的三根支柱。海山代表水的力量——在干旱的西方大荒中，有一座以「海」命名的山意味着这里不缺水。（016-017）

## 沃之野

三山环绕的空间是沃之野——《山海经》中最完美的理想国：

| 要素 | 内容 |
|------|------|
| 食 | 凤鸟之卵 |
| 饮 | 甘露 |
| 珍物 | 甘华、璇瑰、瑶碧、琅【王千】、白丹、青丹 |
| 矿产 | 银、铁 |
| 声 | 鸾凤自歌 |
| 舞 | 凤鸟自舞 |
| 兽 | 百兽相群 |

「凡其所欲其味尽存」——想要什么味道就有什么味道。这不是一个需要劳动的地方——凤凰自己唱歌、自己跳舞、百兽自己聚群。万物自足、万味皆备——沃之野是一个不需要人为努力的天堂。海山是这个天堂的一部分。（016-017）

## 灵山之后

海山所在的沃之野紧跟在灵山之后：

| 位置 | 内容 |
|------|------|
| 前 | 灵山——十巫从此升降，百药爰在 |
| **此** | **三山（王母、壑、海）——沃之野** |
| 后 | 三青鸟——赤首黑目 |

灵山是十巫升降天地的通道——巫咸、巫即、巫盼等十位大巫在此往来于天人之间。灵山之后就是沃之野——从巫的世界到乐土的世界，大荒西经在此展开了西方最神圣的空间序列。（016-017）

## 无描述之山

海山本身没有单独的描述——它只作为三山之一被提及：

| 项目 | 有无 |
|------|------|
| 地形 | 无 |
| 矿产 | 无（归入沃之野总述） |
| 水系 | 无 |

海山的个体性完全融入了沃之野的整体性——它不需要自己的描述，因为沃之野的一切都是它的。三山不是三个独立的点，而是一个乐土的三面。（016-017）

## 沃之野与都广之野：山海经两大乐土的比较

沃之野（海山所在）和[[都广之野]]（海内经）是《山海经》中两处最完美的理想国。两者在不同方位构建了各自的乐土图景：

| 维度 | 沃之野 | 都广之野 |
|------|--------|---------|
| 方位 | 西方（大荒西経） | 中央（海内経） |
| 食物 | 凤鸟之卵、甘露 | 百谷自生，冬夏播琴 |
| 音乐 | 鸾凤自歌，凤鸟自舞 | 鸾鸟自歌，凤鸟自舞 |
| 珍物 | 璇瑰、瑶碧、琅【王千】、白丹青丹 | 甘华、百果 |
| 通天设施 | 无 | [[建木]]（百仞无枝） |
| 出处 | 016-017 | 018-008 |

两处乐土几乎共享了「鸾凤自歌，凤鸟自舞」这一句——凤鸟的自发歌舞是乐土的标配声景。但沃之野更侧重物质丰饶（矿物、金属、甘露），都广之野更侧重农业丰收（百谷自生）。沃之野是「想要什么味道就有什么味道」的极致消费天堂，都广之野是「百谷不种自生」的极致农业天堂。

海山作为沃之野三山骨架之一，与[[王母之山]]和[[壑山]]共同支撑了这片西方乐土的空间结构。三山以「神母+大地+水域」的三元组合构成完整的自然基础——而沃之野的万物自足正建立在这个基础之上。（016-017、018-008）
