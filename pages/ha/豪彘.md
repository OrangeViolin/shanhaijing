# 豪彘

**豪彘**是《山海经·[[西山経]]》西次一経所载的异兽。栖息于[[竹山]]——形状如豚而白毛——毛大如笄而黑端。白毛黑梢的猪形兽。（002-008）

## 原文出处

《[[西山経]]》西次一経：

> 有兽焉，其状如豚而白毛，大如笄而黑端，名曰豪彘。
>
> （002-008）

## 形态

豪彘的描写集中在毛发——白底黑梢的双色毛：

| 属性 | 内容 |
|------|------|
| 体形 | 如豚 |
| 毛色 | 白 |
| 毛大小 | 如笄（发簪） |
| 毛端 | 黑 |

「大如笄」——毛粗得像发簪——这不是普通的细毛——是粗硬的刺毛。白毛黑端——根部白色、尖端黑色——色彩鲜明。「豪」本义就是长而硬的毛——豪彘即「硬毛之猪」。从形态看极可能是豪猪（箭猪）类动物的实录。（002-008）

## 竹山的物产

豪彘栖息的竹山是物产极丰的山——矿物、植物、水生物齐备：

| 层次 | 物产 |
|------|------|
| 山上 | 乔木 |
| 山阴 | 铁 |
| 山阳 | 竹箭、苍玉 |
| 草 | 黄囗（浴之已疥，可已【月付】） |
| 水中 | 水玉、[[人鱼]] |
| 兽 | **豪彘** |

黄囗治皮肤病——人鱼治痴疾——竹山是多种药效资源的聚集地。豪彘本身没有药效记述——纯粹以形态被记录——白毛黑端的外观足以引起记录者的注意。（002-008）

## 命名

「豪」= 硬毛，「彘」= 猪。名字直接描述了这种动物的核心特征——硬毛的猪。山海経的异兽命名常取声音或功能——豪彘取形态——是较为写实的命名方式。现代汉语「豪猪」一词与「豪彘」同构——可见这一命名传统延续至今。（002-008）
