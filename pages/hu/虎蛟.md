# 虎蛟

**虎蛟**是《山海经·[[南山経]]》南次三経所载的异鱼。栖息于[[祷过之山]]的浪水中——鱼身而蛇尾——声如鸳鸯——食之不肿——可以已痔。（001-030）

## 原文出处

《[[南山経]]》南次三経：

> 其中有虎蛟，其状鱼身而蛇尾，其音如鸳鸯，食者不肿，可以已痔。
>
> （001-030）

## 形态与药效

虎蛟是鱼与蛇的拼合体——名字带「虎」却声如鸳鸯：

| 属性 | 内容 |
|------|------|
| 形 | 鱼身蛇尾 |
| 音 | 如鸳鸯 |
| 名 | 虎蛟（虎=凶猛或虎纹） |
| 药效 | 食之不肿，可已痔 |

「虎」的凶名与「鸳鸯」的柔声——名凶而声柔。鱼身接蛇尾——水中之物接陆上之物。双重药效——消肿和治痔——虎蛟是药食两用的异鱼。（001-030）

## 祷过之山

虎蛟栖息的祷过之山是南次三経的重要山——物产极丰：

| 层次 | 物产 |
|------|------|
| 山上 | 金玉 |
| 山下 | 犀、兕、象 |
| 山中鸟 | [[瞿如]]（如【交鸟】，白首三足人面） |
| 水中鱼 | **虎蛟** |

浪水从祷过之山流出——南流注于海——虎蛟在水中。同山的瞿如是三足人面之鸟——虎蛟是鱼身蛇尾之鱼——一山的异物都是跨类拼合。（001-030）

## 南次三経的药效到瑞兆

祷过之山的下一座山是[[丹穴之山]]——[[鳳凰]]栖息地——「见则天下安宁」：

| 山 | 核心异物 | 意义 |
|----|----------|------|
| 祷过之山 | 虎蛟 | 药效（治肿治痔） |
| 丹穴之山 | 鳳凰 | 天下安宁 |

从药鱼到瑞鸟——从治个人之病到安天下之宁——南次三経在两座相邻的山之间完成了格局的飞跃。虎蛟是这一飞跃的起点。（001-030、001-031）
