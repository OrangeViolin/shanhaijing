# 讙头国

**讙头国**是《山海经·[[海外南経]]》所载的异族邦国。国民人面有翼——鸟喙——正在捕鱼。一说在[[毕方]]东。（006-009）

## 原文出处

《[[海外南経]]》：

> 讙头国在其南，其为人人面有翼，鸟喙，方捕鱼。一曰在毕方东。或曰讙朱国。
>
> （006-009）

《[[大荒南経]]》：

> 有人焉，鸟喙，有翼，方捕鱼于海。大荒之中，有人名曰讙头。鲧妻士敬，士敬子曰琰融，生讙头。头人面鸟喙，有翼，食海中鱼，杖翼而行。维宜芑苣，穑是食。有讙头之国。
>
> （011-023）

## 人面·鸟喙·有翼

讙头国民的形态是人与鸟的混合体：

| 部位 | 特征 |
|------|------|
| 面 | 人面 |
| 嘴 | 鸟喙 |
| 身 | 有翼 |
| 行动 | 杖翼而行（以翼为杖行走） |
| 食性 | 食海中鱼·芑苣 |

人的脸——鸟的嘴——背上有翼。但翼不用来飞——而是「杖翼而行」——用翼当拐杖走路。这是一种退化的飞翔器官——翼变成了行走的辅助工具。捕鱼不是用翼——是用鸟喙。（006-009, 011-023）

## 鲧的后裔

大荒南経记载了讙头的完整系谱：

| 世代 | 人物 | 关系 |
|------|------|------|
| 第一代 | [[鲧]] | 治水英雄 |
| — | 士敬 | 鲧之妻 |
| 第二代 | 琰融 | 士敬之子 |
| 第三代 | **讙头** | **琰融之子** |

讙头是鲧的孙辈。鲧是治水神话的主角——他的正统后裔是禹——但旁系后裔却变成了鸟人。治水英雄的家族中分出一支鸟喙有翼的异族——这是《山海经》系谱中最意外的分支之一。（011-023）

## 渔猎与农耕并用

讙头国民的食性兼具两种：

| 食物 | 来源 |
|------|------|
| 海中鱼 | 渔猎（鸟喙捕鱼） |
| 芑苣 | 农耕（穑是食） |

「方捕鱼」——正在捕鱼——海外南経捕捉的是一个动态瞬间。大荒南経进一步说「食海中鱼」并加上「维宜芑苣，穑是食」——不仅捕鱼——还种植谷物。鸟人也会务农——捕鱼与种地并行。（006-009, 011-023）

## 海外南経的位置

讙头国在海外南経中紧邻毕方鸟：

| PN | 内容 |
|----|------|
| 006-008 | [[毕方]]（火鸟） |
| **006-009** | **讙头国（鸟喙有翼·捕鱼）** |
| 006-010 | [[厌火国]]（兽身黑色·口吐火） |

毕方是火鸟——讙头是鸟人——厌火国是吐火之兽。三者连续——从鸟到鸟人到兽——讙头国是鸟与人之间的过渡形态。（006-009）
