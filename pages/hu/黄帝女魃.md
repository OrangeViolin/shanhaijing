# 黄帝女魃

**黄帝女魃**是《山海经·[[大荒北经]]》所载的旱神。[[黄帝]]与[[蚩尤]]战于冀州之野时，黄帝降下天女魃止住了蚩尤的暴风雨，扭转战局。但魃从此不能回天，所居之处不降雨——胜利的功臣成了永恒的流放者。（017-013）

## 原文出处

《[[大荒北经]]》：

> 有人衣青衣，名曰黄帝女魃。【嗤去口】尤作兵伐黄帝，黄帝乃令应龙攻之冀州之野。应龙畜水。【嗤去口】尤请风伯雨师，纵大风雨。黄帝乃下天女曰魃，雨止，遂杀【嗤去口】尤。魃不得复上，所居不雨。叔均言之帝，后置之赤水之北。叔均乃为田祖。魃时亡之，所欲逐之者，令曰："神北行！"先除水道，决通沟渎。
>
> （017-013）

## 战争七步

黄帝与蚩尤之战是一场围绕水的攻防——魃是决定胜负的转折点：

| 阶段 | 行动者 | 行为 |
|------|--------|------|
| 一 | [[蚩尤]] | 作兵伐黄帝 |
| 二 | [[黄帝]] | 令[[应龙]]攻之冀州之野 |
| 三 | 应龙 | 畜水（蓄水备战） |
| 四 | 蚩尤 | 请[[风伯]][[雨师]]纵大风雨 |
| 五 | **黄帝** | **下天女曰魃** |
| 六 | **魃** | **雨止** |
| 七 | — | 遂杀蚩尤 |

蚩尤的武器是风雨——他请来风伯雨师制造暴风雨。黄帝的对策是旱——降下能止雨的天女。这场战争的实质是水与旱的较量：蚩尤放水，魃收水。（017-013）

## 悲剧

魃止住了雨、赢得了战争——但代价是永远回不了天：

| 阶段 | 魃的状态 |
|------|---------|
| 战前 | 天女（在天上） |
| 战时 | 下凡止雨 |
| 战后 | 不得复上（回不了天） |
| 后果 | 所居不雨（走到哪里哪里干旱） |

「魃不得复上」——五个字写尽悲剧。她是天上的神女，为父（黄帝）出征，胜利后却被困在人间。更残酷的是：她的本质是旱——走到哪里，哪里就不下雨。一个活的旱灾，行走在大地上。（017-013）

## 安置与逃亡

[[叔均]]向帝进言，将魃安置在赤水之北——但魃不安分：

| 事件 | 内容 |
|------|------|
| 进言者 | 叔均 |
| 安置地 | 赤水之北 |
| 魃的反应 | 时亡之（时常逃跑） |
| 驱逐方式 | 喊「神北行！」 |
| 配套措施 | 先除水道，决通沟渎 |

魃被流放到赤水之北——北方荒远之地。但她时常逃跑，于是人们喊「神北行」来驱赶她——命令旱神回到北方去。在喊口号之前要先疏通水道和沟渠——驱赶旱神的仪式与水利工程结合在一起。（017-013）

## 叔均与田祖

「叔均乃为田祖」——叔均因此成为农业之祖：

| 人物 | 角色 |
|------|------|
| 叔均 | 进言安置魃 → 成为田祖 |
| 魃 | 旱神 → 农业的威胁 |

控制旱灾的人成为农业之神——因为农业最怕的就是旱。叔均把旱神管住了，所以叔均就是管住旱灾、保障丰收的人——田祖。魃的悲剧和叔均的功业是同一件事的两面。（017-013）

## 衣青衣

魃的外貌描述只有四个字——「衣青衣」：

| 特征 | 描述 |
|------|------|
| 装束 | 青衣 |

青色的衣服——青是天的颜色，也是干旱时天空的颜色（无云的蓝天）。一个穿着青天之色的女子，走到哪里天就放晴——不是祥瑞的晴，是旱灾的晴。（017-013）

## 黄帝战蚩尤中「功臣不可复归」的叙事模式

魃不是黄帝阵营中唯一在胜利后遭受代价的功臣。将黄帝方三位战将的战后命运对比：

| 功臣 | 战时贡献 | 战后命运 | 代价 | PN |
|------|---------|---------|------|-----|
| **女魃** | **止蚩尤之雨** | **不得复上，所居不雨** | **永久流放** | **017-013** |
| [[应龙]] | 畜水攻蚩尤 | 杀蚩尤与夸父后不得复上 | 永久滞留人间 | 017-012 |
| 黄帝本人 | 指挥全局 | 胜利后继续统治 | 无 | 017-013 |

魃与[[应龙]]的命运惊人地平行：都是天界存在（天女、天龙），都为黄帝下凡作战，都在胜利后「不得复上」。两者的区别在于代价的性质：应龙滞留导致人间多水（龙行雨），魃滞留导致人间无水（旱灾）——一个带来过多的水，一个带去全部的水。黄帝本人则毫无代价。这一叙事结构揭示了大荒北经对战争的认知：发动战争的统帅不付代价，执行战争的功臣承担永久的流放。「不得复上」四字同时出现在魃和应龙的叙事中，是大荒北经刻意设置的对称结构（017-012, 017-013）。
