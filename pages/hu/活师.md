# 活师

**活师**は[[東山経]]に記載される水棲生物である。杻山から流れ出て食水に注ぐ湖水の中に多く棲む。（004-002）

## 原文出処

《[[東山経]]》：

> 又南三百里，曰杻山，其上有玉，其下有金。湖水出焉，東流注于食水，其中多活師。
> （004-002）

## 解説

活師は古注では蝌蚪（オタマジャクシ）に比定される。蛙の幼生で、湖水中に大量に棲息していた。

## 杻山と湖水

活師が棲む湖水は杻山から東に流れて食水に注ぐ。杻山は東次一経の第二山で、山上に玉、山下に金があり、鉱物と水産の両方が記される山である。

| 要素 | 内容 |
|------|------|
| 棲息水域 | 湖水 |
| 水源の山 | 杻山 |
| 流向 | 東 |
| 注入 | 食水 |
| 山の鉱物 | 玉（上）・金（下） |

## 東次一経の水棲生物

東次一経は【木敕】【上牛左下虫右下虫】之山から竹山まで十二山の山列で、各山の水系にそれぞれ特徴的な生物が棲む。首山の食水には鳙鳙之鱼（梨牛に似た姿で豚のように鳴く魚）が棲み、杻山の湖水には活師が多い。活師はこの経で最も日常的な生物で、異形の怪魚が続く中で素朴な存在感を持つ。

## 「活師」の語義

「活」は生き生きとした様、「師」は衆（多数）の意。大量に群れて動き回る蝌蚪の生態をそのまま名としたもので、山海経の生物名の中では珍しく写実的な命名である。
