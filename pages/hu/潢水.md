# 潢水

**潢水**是《山海经·[[海内东经]]》所载的河川。发源于桂阳西北山，东南注[[肄水]]，入敦浦西。（014-012）

## 原文出处

《[[海内东经]]》：

> 潢水出桂阳西北山，东南注肄水，入敦浦西。
>
> （014-012）

## 源流

潢水的路线——从桂阳到肄水：

| 要素 | 内容 |
|------|------|
| 源 | 桂阳西北山 |
| 流向 | 东南 |
| 注入 | 肄水 |
| 合流点 | 敦浦西 |

桂阳在今湖南南部、南岭北侧——潢水从南岭山脉发源，向东南流过岭南，汇入肄水。肄水最终在番禺（今广州）入海——潢水是珠江水系上游的一条支流。「入敦浦西」标注了具体的合流地点——海内东经的河川记载精确到合流点。（014-012）

## 岭南三水

潢水是海内东经岭南水系三条河的最后一条——从干流到支流逐级细分：

| 序 | 水 | 源 | 入 |
|----|-----|-----|-----|
| 1 | 郁水 | 象郡 | 西南注南海，入须陵东南 |
| 2 | [[肄水]] | 临晋西南 | 东南注海，入番禺西 |
| **3** | **潢水** | **桂阳西北山** | **东南注肄水，入敦浦西** |

郁水直接入南海——大河。肄水也直接入海——中河。潢水注入肄水——支流。三水的记述从大到小——先说入海的干流，再说汇入干流的支流。海内东经的水系总览用这种从大到小的结构描绘了岭南的完整水网。（014-012）

## 水系总览中的位置

潢水处于海内东经大水系总览的尾段——从中原转向南方再转向北方：

| 区域 | 代表水系 |
|------|----------|
| 南方大江 | 岷三江、浙江 |
| 淮水系 | 颖水、汝水 |
| 西北 | 泾水、渭水 |
| **岭南** | **郁水、肄水、潢水** |
| 北方 | 洛水、汾水、济水、漳水 |

潢水是岭南段的收尾——岭南三水写完之后，笔锋转向北方的洛水和汾水。整个水系总览的结构是一个大圈——从南方大江出发，经中原淮河，到西北渭泾，下岭南，再回北方。潢水在圈的底部。（014-012）
