# 淮阴

**淮阴**是《山海经·[[海内東経]]》所载的地名。泗水从鲁的东北发源——南流——西南过湖陵西——东南注入东海——在淮阴的北面入海。（014-012）

## 原文出处

《[[海内東経]]》：

> 泗水出鲁东北，而南，西南过湖陵西，而东南注东海，入淮阴北。
>
> （014-012）

## 泗水的终点标记

淮阴是泗水入海的方位基准：

| 属性 | 内容 |
|------|------|
| 河川 | 泗水 |
| 源头 | 鲁东北 |
| 入海 | 东海 |
| 入海位置 | 淮阴北 |

「入淮阴北」——在淮阴的北面入海。「淮阴」即淮水之南岸（阴=南）——地名本身就标明了与淮水的关系。泗水实际上先汇入淮水、再入海——淮阴正是泗水与淮水交汇的区域。（014-012）

## 泗水的曲折流路

泗水的流路描述是海内東経中最详细的——记录了多次方向转换：

| 段落 | 流向 | 经过 |
|------|------|------|
| 起源 | 出鲁东北 | — |
| 第一段 | 而南 | — |
| 第二段 | 西南 | 过湖陵西 |
| 第三段 | 东南 | 注东海 |
| 终点 | — | 入淮阴北 |

南→西南→东南——三次转弯。大多数河川只记「出XX，入YY」——泗水却详细记录了转弯点和经由地。这种精度说明编者对泗水流域非常熟悉——泗水流经鲁地（孔子故乡）——是中原文明的核心水域。（014-012）

## 海内東経水系中的位置

泗水在海内東経的河川目录中处于中段：

| 河川 | 特征 |
|------|------|
| 淮水 | 出余山，入海淮浦北 |
| 颖水 | 出少室，入淮西鄢北 |
| **泗水** | **出鲁东北，入淮阴北** |
| 郁水 | 出象郡，入须陵东南 |

淮水和颖水在前——泗水紧随其后——三者构成了中原东部的主要水系网络。泗水入淮阴——颖水入鄢——都以地名来标定入水点——海内東経用实际地名构建了一张精确的水文地图。（014-012）
