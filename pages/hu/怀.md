# 怀

**怀**是《山海经·[[海内東経]]》所载的地名。沁水从井陉山东流出——东南注河——入怀东南。（014-012）

## 原文出处

《[[海内東経]]》：

> 沁水出井陉山东，东南注河，入怀东南。
>
> （014-012）

## 沁水入河之地

怀是沁水与黄河合流处的地理基准：

| 属性 | 内容 |
|------|------|
| 地名 | 怀 |
| 水 | 沁水（入其东南） |
| 沁水源头 | 井陉山东 |
| 沁水流向 | 东南注河 |

沁水从井陉山东方发源——东南流——在怀的东南方注入黄河。怀是河岸上的地标——沁水在它的东南面汇入大河。今河南焦作一带。（014-012）

## 黄河中流域三河

怀处于海内東経黄河中流域三条支流的连续记载之中：

| 河 | 水源 | 入河处 |
|----|------|--------|
| 汾水 | [[上窳]]北 | 皮氏南 |
| **沁水** | **井陉山东** | **怀东南** |
| [[济水]] | 共山南东丘 | 绝钜鹿泽，注渤海 |

汾水→沁水→济水——三条河从北到南依次排列——都注入黄河或渤海。每条河的入河点都用一个地名来标定——汾水用皮氏——沁水用怀——济水用潦阳。怀是这组地理座标中的中间一环。（014-012）
