# 黄囗

**黄囗**是《山海经·[[西山经]]》西山首经所载的药草，生于竹山。形如樗（臭椿），叶如麻，白花赤实。浴之治疥疮，又可治肿。（002-062）

## 原文出处

《[[西山经]]》：

> 又西五十二里，曰竹山，其上多乔木，其阴多铁。有草焉，其名曰黄囗，其状如樗，其叶如麻，白华而赤实，其状如赭，浴之已疥，又可以已【月付】。
>
> （002-062）

## 外用双效药草

黄囗的药效通过「浴」（外洗）来实现，治疗两种皮肤/体表疾病：

| 药效 | 病症 | 使用方式 |
|------|------|---------|
| 已疥 | 疥疮（螨虫感染） | 浴（外洗） |
| 已【月付】 | 肿胀 | 浴（外洗） |

《山海经》中大多数药效植物通过「食」（内服）来治病，黄囗以「浴」来治病是相对少见的外用方式。疥疮和肿胀都是体表疾病，用草药煎水外洗是合理的治疗途径——黄囗是一种天然的药浴原料。（002-062）

## 形态特征

黄囗的形态描写极其详细，五个层面的特征依次展开：

| 层面 | 描述 | 参照物 |
|------|------|--------|
| 整体形状 | 如樗（臭椿） | 乔木形态 |
| 叶 | 如麻 | 掌状裂叶 |
| 花 | 白华 | 白色花朵 |
| 实 | 赤实 | 红色果实 |
| 实之质感 | 如赭 | 赭石般的质地 |

白花赤实的色彩对比（白→红）使黄囗在视觉上非常醒目。果实「如赭」——赭是红色矿物颜料，暗示果实不仅颜色红，质地也像矿石般坚硬粗糙。（002-062）

## 竹山的丰富物产

黄囗生长的竹山是西山首经中物产最丰富的山之一。同一座山上还记录了：

| 物产 | 类型 |
|------|------|
| **黄囗** | **药草（治疥治肿）** |
| 丹水 | 东南流注于洛水，多水玉、人鱼 |
| 竹水 | 北流注于渭，多苍玉 |
| 豪彘 | 兽，豚形白毛黑端 |

竹山有两条水（竹水→渭，丹水→洛）、一种药草、一种异兽——在西山首经前段的小型山中，竹山的信息密度异常高。黄囗是这座丰饶之山的药用资源。（002-062）

## 「黄」之名

「黄囗」以「黄」字开头，但花是白的、果是赤的——并非黄色。「黄」可能指茎或根的颜色（未在经文中描述的部位），也可能是药效层面的命名——黄色在五行中对应土/脾，暗示此草与脾土系统相关。（002-062）
