# 虎首之山

**虎首之山**是《山海经·[[中山经]]》中次十一経所载的山。多苴、【木周】、椐，三种实用木材，此外一无所记。（005-164）

## 原文出处

《[[中山经]]》中次十一経：

> 又东三十里，曰虎首之山，多苴【木周】椐。
>
> （005-164）

## 极简之山

虎首之山的记述只有一句，是中次十一経中最简洁的山之一：

| 有 | 无 |
|----|-----|
| 苴、【木周】、椐 | 无矿产 |
| | 无异兽 |
| | 无异鸟 |
| | 无水系 |

没有金玉、没有异兽、没有水系，只有三种树木。山海经大部分山都有多种物产，虎首之山只有植物。（005-164）

## 婴山对之间

虎首之山夹在两座「婴」字山之间：

| 山 | 物产 | PN |
|----|------|-----|
| [[婴山]] | 金玉、青【铁换丹】 | 005-163 |
| **虎首之山** | 苴、【木周】、椐 | 005-164 |
| [[婴侯之山]] | 封石、赤锡 | 005-165 |

前后两山都是矿产山，虎首之山是纯植物山。两座「婴」字山夹着一座「虎首」，名字也打破了前后的对称。（005-164）

## 虎首之名

山以「虎首」命名，即虎头形的山。猛兽之名配上最温和的物产（木材），名实之间有落差。（005-164）
