**杂余之水**，出[[余【上山下我】之山]]，东流注于[[黄水]]。

== 地理 ==

杂余之水出余【上山下我】之山，东流注于黄水。余【上山下我】之山上多梓【左木右丹】，下多荆杞。

== 物产 ==

山有兽，状如菟而鸟喙，鸱目蛇尾，见人则眠，名[[犰狳]]，见则螽蝗为败。

== 語義 ==

「杂余」は混じり合った余りの意で、雑多な水の合流を示唆する。余【上山下我】之山から東流して黄水に注ぐ。中次四経の水系に属する。

== 経路上の位置 ==

中次四経の山列において：[[葛山之首]]（又南三百八十里）→[[余【上山下我】之山]]（又南三百八十里）→[[杜父之山]]（又南三百里）→[[耿山]]（又南三百里）。杂余之水は余【上山下我】之山から東流して黄水に注ぐ唯一の水系。

[[犰狳]]は四種の動物（兎・鳥・鳶・蛇）の部分を合成した異獣で、人を見ると眠る（装死行動）という独特の習性をもつ。この行動は現代のアルマジロ（犰狳）の丸まり防御と対比されることがある。「螽蝗為敗」は蝗害の前兆で、農業社会にとって深刻な凶兆である。

== 黄水 ==

杂余之水が注ぐ「黄水」は中次四経の受水河川。黄河ではなく、中次四経の地域的な河川名と考えられる。黄色い水＝泥水の意で、黄土地帯を流れる水を示唆する。
