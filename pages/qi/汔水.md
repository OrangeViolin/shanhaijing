# 汔水

**汔水**是《山海经·[[大荒南经]]》所载的河川，从贾山中流出。与同条的黑水（穷焉）、澧水、漂水并列。（011-007）

## 原文出处

《[[大荒南经]]》：

> 大荒之中，有不姜之山，黑水穷焉。又有贾山，汔水出焉。又有言山。又有登备之山。有恝恝之山。又有蒲山，澧水出焉。又有隗山，其西有丹，其东有玉。又南有山，漂水出焉。有尾山。有翠山。
>
> （011-007）

## 「汔」之名

「汔」的字义是水将尽、几乎干涸：

| 字 | 义 |
|----|-----|
| 汔 | 水将尽、几乎 |

一条以「水尽」命名的水——从贾山中涌出。名字说水要干了，但它偏偏正在流出——「汔水出焉」。这是一条名与实矛盾的水——将尽未尽之水。（011-007）

## 水的消与生

同一条文中，水经历了消亡和诞生的循环：

| 山 | 水 | 状态 |
|----|-----|------|
| 不姜之山 | 黑水穷焉 | 消亡（水在此尽） |
| **贾山** | **汔水出焉** | **诞生（水从此出）** |
| 蒲山 | 澧水出焉 | 诞生 |
| 南方无名山 | 漂水出焉 | 诞生 |

黑水在不姜之山穷尽——紧接着汔水从贾山涌出。水消失了又重新出现——大荒中的水循环。「汔」（将尽）接在「穷」（已尽）之后——尽了的水以将尽之名重新涌出，仿佛水在反复死亡和复活。（011-007）

## 九山密集

汔水所在的贾山是大荒南经中罕见的九山连续列举之一：

| 山 | 水/特产 |
|----|--------|
| 不姜之山 | 黑水穷焉 |
| **贾山** | **汔水出焉** |
| 言山 | — |
| 登备之山 | — |
| 恝恝之山 | — |
| 蒲山 | 澧水出焉 |
| 隗山 | 西丹东玉 |
| 无名南山 | 漂水出焉 |
| 尾山、翠山 | — |

九座山被一口气列出——大荒经的「山名清单」模式。九山中只有三山有水（汔水、澧水、漂水），其余只有名字。汔水是这份清单中第一条涌出的水——九山之中的首源。（011-007）
