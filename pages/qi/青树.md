# 青树

**青树**是《山海经·[[大荒西経]]》所载的神树。生于西海之外[[方山]]之上——名**柜格之松**——日月从此出入。（016-009）

## 原文出处

《[[大荒西経]]》：

> 西海之外，大荒之中，有方山者，上有青树，名曰柜格之松，日月所出入也。
>
> （016-009）

## 日月所出入

青树的功能是天文级的——日月从这棵树出入：

| 属性 | 内容 |
|------|------|
| 位置 | 西海之外·方山上 |
| 名 | 柜格之松 |
| 色 | 青 |
| 功能 | 日月所出入 |

注意是「出入」——不只是入——日月从这里出也从这里入。这比大荒西経后文的[[丰沮玉門]]（「日月所入」只记入不记出）更根本——青树是日月循环的完整枢纽。（016-009）

## 东西宇宙树

青树与大荒東経的[[扶木]]（扶桑）构成东西对称的宇宙树体系：

| 方位 | 树 | 功能 | 立地 |
|------|-----|------|------|
| 东 | [[扶木]]（扶桑） | 日出 | 汤谷 |
| **西** | **青树（柜格之松）** | **日月出入** | **方山** |

扶桑在东方——日从扶桑升起。青树在西方——日月从青树出入。东升西落——两棵宇宙树撑起了天地间日月运行的两端。（016-009）

## 柜格之松

「柜格」是树的专名——「松」是树种：

| 词素 | 含义 |
|------|------|
| 柜格 | 专名（含义不详） |
| 松 | 常绿针叶树 |

松是常绿树——四季不凋——象征永恒。日月每天出入的宇宙树用永不落叶的松——恰如日月的循环永不停歇。「青」也是松的颜色——青松——常青——永续。（016-009）

## 方山

青树立于方山之上——「方」是正方形：

| 属性 | 内容 |
|------|------|
| 名 | 方山 |
| 位置 | 西海之外，大荒之中 |
| 特产 | 青树（柜格之松） |

「方山」——正方形的山——工整而稳定。宇宙树需要一个稳固的基座——方山是完美的底座。在大荒的混沌之中——一座方正之山——上立一棵青松——日月从此出入——秩序生于混沌之中。（016-009）
