# 青耕

**青耕**是《山海经·[[中山经]]》中次十一经所载的异鸟，栖于堇理之山。形如鹊，青身白喙白目白尾。可以御疫（防御瘟疫）。鸣声自叫其名。（004-042）

## 原文出处

《[[中山经]]》中次十一经：

> 又西北一百里，曰堇理之山，其上多松柏，多美梓，其阴多丹【镬钅换丹】，多金，其兽多豹虎。有鸟焉，其状如鹊，青身白喙，白目白尾，名曰青耕，可以御疫，其鸣自叫。
>
> （004-042）

## 青与白

青耕的配色是一青三白——青色身体配三处白色：

| 部位 | 颜色 |
|------|------|
| 身体 | 青色 |
| 喙 | 白色 |
| 眼睛 | 白色 |
| 尾巴 | 白色 |

青色的身体是主调，白色的嘴、眼、尾是点缀——像一只青瓷鸟描了白边。与同经的婴勺（白身赤目赤喙）恰好相反：婴勺是白底红点，青耕是青底白点。（004-042）

## 御疫

青耕的功效是「御疫」——防御瘟疫：

| 灵鸟 | 功效 | 对抗 |
|------|------|------|
| **青耕** | **御疫** | **瘟疫** |
| 【奇鸟】【余鸟】 | 御凶 | 凶事 |
| 鸾鸟 | 天下安宁 | 乱世 |

在瘟疫横行的古代，御疫是最珍贵的能力之一。青耕不是治病（「已」疾），而是防御（「御」疫）——它的存在本身就是一道屏障。有青耕的地方，瘟疫不敢靠近。（004-042）

## 堇理之山

青耕栖息的堇理之山是一座丰饶而危险的山：

| 类别 | 产物 |
|------|------|
| 树木 | 松柏、美梓 |
| 矿物 | 丹【镬钅换丹】、金 |
| 兽 | 豹、虎 |
| **鸟** | **青耕** |

松柏梓木——上等树材；丹砂和金——珍贵矿物；豹和虎——猛兽。堇理之山有财富也有危险。青耕就栖息在这座豹虎出没的山上，像一个安静的守护者——豹虎威胁身体，青耕守护不受瘟疫侵害。（004-042）

## 自叫其名

「其鸣自叫」——鸣声就是自己的名字「青耕」。在山中听到「青耕、青耕」的鸟鸣，就知道这只御疫之鸟在附近：

| 鸟 | 鸣声方式 |
|----|---------|
| **青耕** | **自叫（叫自己名字）** |
| 婴勺 | 自呼（呼自己名字） |
| 鹦鹉 | 能言 |

「自叫」和婴勺的「自呼」是同一类型的鸣叫——鸟以自己的名字为歌。中次十一经中至少有两种鸟以此方式鸣叫——它们在山间呼喊着自己的名字，让人知道它们的存在。（004-042）
