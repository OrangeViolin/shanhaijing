# 漆吴之山

**漆吴之山**是《山海经·[[南山经]]》南次二经的末山。处于东海，望丘山——其光载出载入，是惟日次。无草木，多博石，无玉。自[[柜山]]至于漆吴之山，凡十七山，七千二百里。（001-027、001-028）

## 原文出处

### 南山经（山体）

> 東五百里，曰漆吳之山，無草木，多博石，無玉。處于東海，望丘山，其光載出載入，是惟日次。
>
> （001-027）

### 南山经（总括）

> 凡南次二經之首，自櫃山至于漆吳之山，凡十七山，七千二百里。其神狀皆龍身而鳥首。其祠：毛用一壁瘞，糈用【禾餘】。
>
> （001-028）

## 日次

漆吴之山最特殊的属性——太阳的宿所：

| 属性 | 内容 |
|------|------|
| 位置 | 东海 |
| 现象 | 光载出载入 |
| 称号 | 日次 |

「日次」——太阳住的地方。光载出载入——太阳从这里升起又落回来。整个南山经——只有漆吴之山与太阳有关。处于东海——东方尽头的山，正是太阳升起的位置。（001-027）

## 首末对照

南次二经从西到东——首山与末山完全相反：

| | 首山[[柜山]] | 末山漆吴之山 |
|--|------------|------------|
| 方位 | 西 | 东（东海） |
| 植被 | 有 | 无草木 |
| 矿物 | 白玉、丹粟 | 博石（无玉） |
| 异物 | 狸力、朱鸟 | 无 |
| 特殊 | 三地标定位 | 日次 |

柜山什么都有——漆吴之山什么都没有，只有博石和日次。越往东越荒凉——但越荒凉越接近太阳。万物褪尽——只剩太阳的光。（001-027、001-028）
