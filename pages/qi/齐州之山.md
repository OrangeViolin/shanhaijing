# 齐州之山

**齐州之山**は[[大荒北经]]に記載される山である。君山、鲜野山、鱼山と並んで列挙される。（015-024）

## 原文出処

《[[大荒北经]]》：

> 有山名曰齐州之山、君山、【上两先下鬲】山、鲜野山、鱼山。
> （015-024）

## 地理描述

齐州之山は大荒北経の記述中、融父山・犬戎の記事の後に位置する。君山、鲜野山、鱼山とともに列挙されるが、個別の地理特徴は記されていない。

## 五山群の構造

齐州之山を筆頭に、[[君山]]・【上两先下鬲】山・[[鲜野山]]・[[鱼山]]の五山が一文に列挙される。山海経の大荒経には、このように複数の山名を並列列挙する「山名リスト」型の記述が散見される。個別の産物・怪物の描写を持たず、名のみが記される。

| 山名 | 備考 |
|------|------|
| **齐州之山** | 筆頭に置かれる |
| [[君山]] | 同名の山が他経にも出現 |
| 【上两先下鬲】山 | 読み不詳 |
| [[鲜野山]] | 同経で他にも言及 |
| [[鱼山]] | 魚の字を冠する |

## 前後の文脈

五山群の直前には融父山と犬戎の来歴（黄帝→苗龙→融吾→弄明→白犬→犬戎）が記され、直後には一目の民（威姓、少昊之子）が続く。山名リストは物語性の強い段落を区切る地理的挿入として機能している。

## 「齐州」の名

「齐州」は後世の齐州（山東）との関連が指摘されることがある。大荒北経は北方の大荒を記すが、山東方面の地名が混在するのは大荒経の地理観の特徴。
