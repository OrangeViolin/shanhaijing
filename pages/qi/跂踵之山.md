# 跂踵之山

**跂踵之山**是《山海经·[[东山经]]》东次三经所载的山。广袤二百里，无草木，有大蛇，多玉。有水广四十里皆涌，名深泽，中多大龟。有鮥鮥之鱼——鲤形六足鸟尾，其名自叫。（004-037）

## 原文出处

《[[东山经]]》东次三经：

> 又南水行五百里，曰流沙，行五百里，有山焉，曰跂踵之山，广员二百里，无草木，有大蛇，其上多玉。有水焉，广员四十里皆涌，其名曰深泽，其中多大龟。有鱼焉，其状如鲤，而六足鸟尾，名曰鮥鮥之鱼，其名自叫。
>
> （004-037）

## 流沙彼端

到达跂踵之山需要穿越流沙——「又南水行五百里，曰流沙，行五百里」：

| 阶段 | 距离 |
|------|------|
| 水行 | 五百里 |
| 流沙 | 五百里 |
| **到达跂踵之山** | — |

先走五百里水路，再穿越五百里流沙——总计一千里的漫长旅程才能到达。跂踵之山是一座远离常人世界的山，被流沙与海水双重阻隔。这种极端的路程说明它处于东次三经的边缘地带。（004-037）

## 深泽

跂踵之山最奇异的地理是深泽——「广员四十里皆涌」：

| 特征 | 描述 |
|------|------|
| 面积 | 广四十里 |
| 状态 | 皆涌（全部涌动） |
| 生物 | 多大龟 |

四十里宽的水面全部在涌动——不是平静的湖泊，而是整个水面都在翻涌冒泡。深泽之「深」暗示水极深，涌动可能来自地下水源的持续喷涌。一座二百里的荒山上，有一个四十里的沸腾泽地——山是静的（无草木），水是动的（皆涌）。大龟在翻涌的深水中栖息——只有极大的龟才能在这种水域中存活。（004-037）

## 鮥鮥之鱼

深泽中的鮥鮥之鱼是多重跨物种的混合体：

| 特征 | 来源 |
|------|------|
| 体形 | 如鲤（鱼） |
| 足 | 六足（兽/虫） |
| 尾 | 鸟尾（鸟） |
| 声音 | 自叫其名 |

鱼身、六足、鸟尾——三类动物合于一身。六足超越了四足的常规——比陆地动物还多两条腿。「其名自叫」——鮥鮥之鱼会叫出自己的名字「鮥鮥」。一条会走路、有鸟尾巴、能叫出自己名字的鱼——它不像鱼，更像一个自我意识清晰的生物。（004-037）

## 大蛇与玉

跂踵之山「无草木，有大蛇，其上多玉」——荒凉的山上只有两样东西：大蛇和玉。

| 存在 | 性质 |
|------|------|
| 大蛇 | 危险 |
| 玉 | 珍贵 |

没有树、没有草——只有大蛇盘踞在玉石之间。要采玉就必须面对大蛇——危险与财富共存。二百里的荒山上遍布玉石和大蛇，如同一座由蛇守卫的巨型玉矿。（004-037）

## 跂踵之名

「跂踵」——跂是踮起脚尖，踵是脚后跟。「跂踵」意为踮脚又落踵——行走的姿态。也许这座山的地形迫使行走者不断踮脚又落下——崎岖不平的地面使人步履蹒跚。或者「跂踵」指山形如同抬起的脚跟——一座如足跟般隆起的巨山。（004-037）
