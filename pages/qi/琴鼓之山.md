# 琴鼓之山

**琴鼓之山**是《山海经·[[中山経]]》中次八経（荊山山系）的末山。白珉、洗石——多白犀——多鸩。荊山山系从[[景山]]到琴鼓之山——共二十三山——二千八百九十里。（005-112、005-113）

## 原文出处

《[[中山経]]》中次八経：

> 又东南二百里，曰琴鼓之山，其木多楮柞椒柘，其上多白珉，其下多洗石，其兽多豕鹿，多白犀，其鸟多鸩。
>
> （005-112）

> 凡荆山之首，自景山至琴鼓之山，凡二十三山，二千八百九十里。其神状皆鸟身而人面。其祠：用一雄鸡祈瘗，用一藻圭，糈用【禾余】。骄山，冢也，其祠：用羞酒少牢祈瘗，婴毛一璧。
>
> （005-113）

## 白犀与鸩

琴鼓之山的动物是两个极端——珍贵与危险并存：

| 动物 | 性质 |
|------|------|
| 豕、鹿 | 普通兽 |
| 白犀 | 珍稀大兽 |
| 鸩 | 剧毒之鸟 |

白犀是稀有的大型动物——鸩是有名的毒鸟。珍兽和毒鸟住在同一座山上。末山的动物最丰富——从普通到珍稀到危险——荊山山系在结尾处达到生态的高峰。（005-112）

## 荊山山系总括

琴鼓之山是末山——山系总括附在这里：

| 项目 | 内容 |
|------|------|
| 首山 | [[景山]] |
| 末山 | 琴鼓之山 |
| 山数 | 二十三山 |
| 总里程 | 二千八百九十里 |
| 山神形态 | 鸟身人面 |
| 普通祭祀 | 雄鸡一只 + 藻圭 |
| 冢山祭祀 | [[骄山]]：羞酒 + 少牢 + 璧 |

二十三座山——鸟身人面的神——从景山走到琴鼓之山——近三千里。只有骄山一座冢山享受高格祭祀——其余山全用一只鸡。（005-113）
