# 青丹

**青丹**是《山海经·[[大荒西经]]》所载[[沃之野]]的产物。青色的丹砂——与[[白丹]]成对出现。（016-017）

## 原文出处

《[[大荒西经]]》：

> 爰有甘华、璇瑰、甘【木且】、瑶碧、白木、白柳、视肉、琅【王千】、白丹、青丹、多银铁。
>
> （016-017）

## 白丹与青丹

白丹和青丹紧挨着出现——一白一青的丹砂对：

| 丹 | 色 |
|----|-----|
| [[白丹]] | 白 |
| **青丹** | **青（蓝绿）** |

丹是丹砂——红色的矿石。白丹是白色的丹，青丹是青色的丹——丹砂本该是红的，却有了白和青两种变色。沃之野的丹不按常理来——什么颜色的丹都有。（016-017）

## 沃之野产物序列

青丹处于沃之野产物清单的末尾——从植物到宝玉到矿物：

| 类别 | 产物 |
|------|------|
| 植物 | 甘华、甘【木且】、白木、白柳 |
| 宝玉 | [[璇瑰]]、瑶碧、琅【王千】 |
| 珍物 | [[视肉]] |
| **矿物** | **白丹、青丹、银、铁** |

沃之野是「凡其所欲其味尽存」的完美乐园——想要什么味道都有。产物从甜的果子到美的玉石到有用的矿物，层层递进。青丹在最后一层——乐园的最深处是矿脉。（016-017）
