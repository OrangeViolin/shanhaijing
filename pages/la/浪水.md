# 浪水

**浪水**は[[南山経]]南次三経に記載される河川である。[[祷过之山]]から流れ出て南に流れ、海に注ぐ。（001-018）

## 记载

### 南山经·南次三经

> 祷过之山……浪水出焉，而南流注于海。其中有虎蛟，其状鱼身而蛇尾，其音如鸳鸯，食者不肿，可以已痔。

浪水出祷過之山，南流注于海。水中有虎蛟，鱼身蛇尾，音如鸳鸯，食之不肿且可治痔。祷過之山上多金玉，有瞿如鳥，状如【交鸟】而白首，三足人面。

## 虎蛟の薬効

浪水中に棲む[[虎蛟]]は魚の体に蛇の尾を持つ異獣で、鳴き声は鴛鴦に似る。食すと腫れを防ぎ、痔を治す薬効がある。

| 要素 | 内容 |
|------|------|
| 棲息水域 | 浪水 |
| 形態 | 魚身蛇尾 |
| 鳴声 | 鴛鴦の如し |
| 薬効 | 不腫・已痔 |

## 南次三経の海注河川

浪水は南次三経の第二山（祷過之山）から流れ出る。南次三経は天下虞之山から始まり、多くの河川が「南流注于海」と記される海洋指向の山列。浪水はその最初の海注河川であり、南次三経の海洋的性格を象徴する。祷過之山自体も金玉・犀・兕・象と豊かな資源を持つ南方の大山である。
