# 琅邪

**琅邪**是《山海经·[[海内东经]]》所载的地名。琅邪台在渤海之间，琅邪之东——北面有山。（014-008）

## 原文出处

《[[海内东经]]》：

> 琅邪台在渤海间，琅邪之东。其北有山，一曰在海间。
>
> （014-008）

## 琅邪台

琅邪台是琅邪的标志性建筑——在渤海之间，琅邪的东面：

| 要素 | 内容 |
|------|------|
| 位置 | 渤海间 |
| 方位 | 琅邪之东 |
| 北 | 有山 |
| 异说 | 一曰在海间 |

「一曰在海间」——另一种说法是琅邪台在海中。山海经忠实地记录了两种说法——一说在渤海之间，一说在海中。琅邪台是岸上的还是海中的，原文不做判断。（014-008）

## 海岸地名链

琅邪处于海内东经的海岸地名序列中——从海中岛屿到海岸到海中：

| 位置 | 地名 | 性质 |
|------|------|------|
| 前 | 都州 | 在海中（一曰郁州） |
| **此** | **琅邪台** | **渤海间** |
| 后 | 韩雁 | 在海中，都州南 |
| 后 | 始鸠 | 在海中 |

都州（海中）→琅邪台（渤海间）→韩雁（海中）→始鸠（海中）——海内东经在这一段像是一张海岸航行图，标记着海中的岛和岸边的台。琅邪是其中唯一明确在陆地一侧的地标。（014-007至014-010）

## 实地

琅邪是山海经中与历史地理对应最清晰的地名之一——秦代设琅琊郡，在今山东临沂：

| 时代 | 事件 |
|------|------|
| 山海经 | 琅邪台在渤海间 |
| 秦 | 秦始皇东巡至琅琊，立石刻 |
| 秦 | 设琅琊郡 |

山海经记载的琅邪，和秦始皇登临的琅琊，指向同一个地方。山海经中大多数地名无法确指，琅邪是少数可以直接在地图上找到的。（014-008）
