# 琅邪台

**琅邪台**是《山海经·[[海内東経]]》所载的地理实体。在渤海间——琅邪之东——其北有山。（014-008）

## 原文出处

《[[海内東経]]》：

> 琅邪台在渤海间，琅邪之东。其北有山，一曰在海间。
>
> （014-008）

## 方位

琅邪台的定位用两个坐标——渤海和琅邪：

| 属性 | 内容 |
|------|------|
| 大范围 | 渤海间 |
| 相对位置 | 琅邪之东 |
| 北 | 有山 |
| 异说 | 在海间 |

「渤海间」——位于渤海沿岸区域。「琅邪之东」——在琅邪的东面。琅邪对应今山东省琅琊一带——琅邪台在其东——面向大海的高台。「一曰在海间」——异传说它在海中——台可能突入海中或三面环海。（014-008）

## 海内東経的实地理列

琅邪台处于海内東経从神话向实地理过渡的关键位置：

| 顺序 | 条目 | 性质 |
|------|------|------|
| 前 | 雷泽·雷神 | 神话（龙首人头） |
| 前 | [[都州]] | 海中岛屿 |
| **当** | **琅邪台** | 实在地名 |
| 后 | 韩雁 | 海中 |
| 后 | 始鸠 | 海中 |
| 后 | [[会稽山]] | 实在地名 |

从雷神（神话）到都州（半神话）到琅邪台（实地理）——海内東経在这一段完成了从神到地的转换。琅邪台是实地理列的起点——之后的韩雁、始鸠、会稽山都是可以对应真实地理的条目。（014-008）
