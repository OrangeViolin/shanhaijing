# 琅鸟

**琅鸟**是《山海经·[[大荒北経]]》所载的鸟。栖于[[附禺之山]]——与青鸟、玄鸟、黄鸟并列——「皆出卫于山」——帝[[颛顼]]葬地的空中护卫。（017-001）

## 原文出处

《[[大荒北経]]》：

> 东南海之外，大荒之中，河水之间，附禺之山，帝颛顼与九嫔葬焉。爰有【丘鸟】久、文贝、离俞、鸾鸟、皇鸟、大物、小物。有青鸟、琅鸟、玄鸟、黄鸟、虎、豹、熊、罴、黄蛇、视肉、【王千】瑰、瑶碧，皆出卫于山。
>
> （017-001）

## 四色鸟群

琅鸟与三种颜色的鸟构成四鸟组合：

| 鸟 | 色 |
|----|-----|
| 青鸟 | 青 |
| **琅鸟** | 琅（玉色） |
| 玄鸟 | 玄（黑） |
| 黄鸟 | 黄 |

青→琅→玄→黄——四种色调。「琅」取自琅玕——一种美玉——琅鸟是玉色的鸟。四色鸟群是附禺之山的空中护卫——「皆出卫于山」。（017-001）

## 天地护卫

附禺之山的护卫由空中和地上两组构成：

| 类别 | 成员 |
|------|------|
| 空中 | 青鸟、**琅鸟**、玄鸟、黄鸟 |
| 地上 | 虎、豹、熊、罴 |
| 蛇 | 黄蛇 |
| 灵物 | 视肉、【王千】瑰、瑶碧 |

四鸟+四兽+黄蛇+灵物——天地间的立体护卫体系。四鸟守空——四兽守地——黄蛇通天地——灵物镇山。帝颛顼的葬地需要如此庞大的护卫阵容。（017-001）

## 帝颛顼葬地

附禺之山是帝颛顼与九嫔的葬地——「东南海之外大荒之中河水之间」：

| 属性 | 内容 |
|------|------|
| 葬者 | 帝颛顼与九嫔 |
| 位置 | 大荒之中，河水之间 |
| 灵物 | 鸾鸟、皇鸟、文贝等 |

帝王葬地配瑞物+护卫——琅鸟是这套护卫体系的一员。玉色的鸟守护帝王的墓——色如美玉——圣洁而华贵。（017-001）
