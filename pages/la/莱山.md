# 莱山

西山経西次二経の末山（終点）。[[钤山]]から始まる十七山、四千一百四十里の山系を締めくくる。

## 物産

樹木は檀・楮が多い。

## 罗罗鳥

> 其鸟多罗罗，是食人。

罗罗という鳥が群棲し、人を食うとされる。西山経系の食人鳥の一つ。

## 山系の総括

西次二経は钤山に始まり莱山に終わる。十神は人面馬身、七神は人面牛身四足一臂で飛獣の神と称される。

## 西次二経末尾の祭祀

莱山で締めくくられる西次二経の祭祀法：十神には少牢（羊・豚）を用い白菅を席とする。（002-038）七神（飛獣之神）には雄鶏一羽を用い、钤して糈を供えず、毛彩を用いる。

## 海内北経の逢莱山

[[海内北経]]に「逢莱山在海中」と記される（009-036）。海中に浮かぶ山で、明組邑・大人之市と並んで列挙される。莱山と逢莱山が同一かは不明だが、「莱」の名を共有する。

## 西次二経の構造における位置

| 項目 | 内容 |
|------|------|
| 首山 | [[钤山]] |
| 末山 | 莱山 |
| 山数 | 十七山 |
| 総距離 | 四千一百四十里 |
| 十神 | 人面馬身 |
| 七神 | 人面牛身四足一臂（飛獣之神） |

西次二経は西山経三系のうち最長の山列で、十神と七神の二系統の山神が共存する。莱山は末山として経の区切りを示し、末尾の祭祀総括の基点となる。逢莱山（海内北経）が海中の仙山であるのに対し、本莱山は食人鳥が棲む険しい山であり、同名ながら性格は対照的。
