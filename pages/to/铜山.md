# 铜山

**铜山**是《山海经·[[中山経]]》中次八経所载的山。山上多金银铁——树木多楮柞杻粟橘——兽多矛勺。（005-099）

## 原文出处

《[[中山経]]》：

> 又东百三十里，曰铜山，其上多金银铁，其木多楮柞杻粟橘，其兽多矛勺。
>
> （005-099）

## 金银铁

铜山以金属矿产著称——名字本身就是「铜」：

| 矿物 | 记载 |
|------|------|
| 金 | 多 |
| 银 | 多 |
| 铁 | 多 |

山名「铜」——山上多金银铁——这是一座名副其实的金属之山。金银铁三种金属并列——从贵金属到实用金属一应俱全。（005-099）

## 丰富的树种

铜山的植被也极为多样：

| 树种 | 类型 |
|------|------|
| 楮 | 造纸树 |
| 柞 | 栎树 |
| 杻 | 硬木 |
| 粟 | 粟树 |
| 橘 | 柑橘 |

五种树木——从造纸用的楮到食用的橘——种类远比周边的山丰富。铜山是一座矿物与植物都极其充沛的山。（005-099）

## 中次八経的矿山地带

铜山处于中次八経一段矿物丰富的山系之中：

| 山 | 矿物 | 其他 | PN |
|----|------|------|-----|
| [[岐山]] | 赤金·白珉·金玉·青雘 | 神涉（人身方面三足） | 005-098 |
| **铜山** | **金·银·铁** | **多树种·矛勺** | **005-099** |
| 美山 | 金·青雘 | 野牛·鹿·豕鹿 | 005-100 |

岐山有神——铜山有矿有树——美山有兽。三座山各有侧重——但都以矿物丰富为共同底色。铜山与岐山相比没有神灵——与美山相比没有大型野兽——它的特色是矿物与植物的双重丰饶。（005-099）
