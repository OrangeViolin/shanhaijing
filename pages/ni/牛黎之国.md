# 牛黎之国

**牛黎之国**是《山海经·[[大荒北经]]》所载的邦国。国中有无骨之人，是[[儋耳之国]]的后代。（017-031）

## 原文出处

《[[大荒北经]]》：

> 有牛黎之国。有人无骨，儋耳之子。
>
> （017-031）

## 无骨之人

牛黎之国的居民最极端的特征——没有骨头：

| 特征 | 描述 |
|------|------|
| 身体 | 无骨 |

「有人无骨」——没有骨骼的人。《山海经》海外大荒诸国以身体异变定义民族——三首（多头）、长臂（长手）、大踵（大脚）。但无骨是最极端的一种——不是多了或少了某个器官，而是丧失了整个骨骼系统。一个没有骨头的人是什么样子？柔软如水母，没有形状——人形的极限。（017-031）

## 儋耳之子

「儋耳之子」——牛黎之国是儋耳之国的后裔：

| 世代 | 特征 |
|------|------|
| 儋耳之国 | 大耳下垂 |
| **牛黎之国** | **无骨** |

从大耳到无骨——身体的变异在代际间加深。儋耳之国的人只是耳朵异常，到了后代却丧失了整个骨骼。变异的方向不是趋于正常，而是越来越极端——边缘的民族越走越远。（017-031）

## 烛龙之前

牛黎之国紧接在烛龙之前——这是一个极为重要的位置：

| 位置 | 内容 |
|------|------|
| 前 | 衡石山、九阴山、洞野之山——若木（赤树青叶赤华） |
| **此** | **牛黎之国——无骨之人** |
| 后 | 章尾山——烛龙（人面蛇身而赤，其视乃明其瞑乃晦） |

烛龙是《山海经》中最宏大的宇宙级存在——睁眼为昼、闭眼为夜、不食不寝不息。牛黎之国是烛龙前面最后一个人间国度——从无骨之人到宇宙之蛇，叙事从人的极限跨入了神的领域。无骨是人形的瓦解，烛龙是人形的超越——两者之间是从人到神的断裂带。（017-031）

## 极简记述

牛黎之国的全部信息只有两句——国名和居民特征：

| 项目 | 有无 |
|------|------|
| 姓氏 | 无 |
| 食物 | 无 |
| 方位 | 无 |

没有姓、没有食物、没有方位——大荒北经的远方邦国被剥离到只剩最核心的信息。牛黎之国的核心就是「无骨」二字——骨是人的框架，无骨则人形崩塌。（017-031）

## 大荒北経における人体変異の漸進構造

牛黎之国の「無骨」は大荒北経の身体変異記述の中で最も極端な位置にある。大荒北経の邦国を身体変異の程度で整理すると、烛龍に向かって人間性が段階的に解体される構造が見える：

| 邦国 | 変異部位 | 変異程度 | 烛龍までの距離 |
|------|---------|---------|-------------|
| [[叔歯之国]] | 歯（植物食） | 軽（食性の変化） | 遠 |
| [[儋耳之国]] | 耳（垂耳） | 中（外形の誇張） | 中 |
| **牛黎之国** | **全身（無骨）** | **極（構造の喪失）** | **直前** |
| 烛龍 | 人面蛇身 | 超越（人形の放棄） | — |

変異は局所（歯・耳）から全身（骨格喪失）へ、そして人形そのものの放棄（蛇身）へと段階的に深化する。牛黎之国が「儋耳之子」と明記されるのは、この漸進が偶然ではなく世代的な必然——辺境に住むほど人間の形が崩れていく——であることを示す。「無骨」は人間の最終形態であり、次の烛龍はもはや人間ではない。大荒北経はこの配列によって、北の果てにおける「人」の定義の限界を描いている。（017-031）
