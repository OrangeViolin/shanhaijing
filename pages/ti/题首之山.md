# 题首之山

**题首之山**是《山海经·[[北山经]]》北次三经所载的山峰，位于景山与绣山之间。有玉，多石，无水——全山记述仅六字，是《山海经》中最简洁的山之一。（003-069）

## 原文出处

《[[北山经]]》北次三经：

> 又北百里，曰题首之山，有玉焉，多石，无水。
>
> （003-069）

## 六字尽山

题首之山的全部信息只有六个字——「有玉焉，多石，无水」：

| 要素 | 内容 |
|------|------|
| 矿产 | 有玉 |
| 岩石 | 多石 |
| 水系 | 无水 |
| 草木 | 未记 |
| 异兽 | 未记 |

《山海经》的山通常伴有「某水出焉」的定型句——山是水的源头。题首之山明确标注「无水」，是对这一常式的否定。不是省略不记，而是特意声明此山没有水——「无水」本身就是信息。（003-069）

## 三山玉谱

题首之山夹在景山与绣山之间，三山都产玉，但描述方式各不相同：

| 山 | 玉的记述 | 水 | 间距 |
|----|---------|-----|------|
| [[景山]] | 有美玉 | 景水东南流注于海泽 | — |
| **题首之山** | **有玉焉** | **无水** | **北百里** |
| 绣山 | 有玉、青碧 | 洧水东流注于河 | 北百里 |

景山的玉是「美玉」——加了品质修饰；绣山的玉细分为「玉」和「青碧」——加了品类区分；题首之山只说「有玉焉」——最简素的表述。三座山各间隔百里，玉的描述却从丰富到简素再到丰富——题首之山是玉谱的低谷。（003-069）

## 无水地带

题首之山的「无水」在前后文脉中形成鲜明的空白：

| 山 | 水系 |
|----|------|
| 锡山 | 牛首之水出焉，东流注于滏水 |
| 景山 | 景水出焉，东南流注于海泽 |
| **题首之山** | **无水** |
| 绣山 | 洧水出焉，东流注于河 |
| 松山 | 阳水出焉，东北流注于河 |

前后四座山都有水——牛首之水、景水、洧水、阳水依次奔流。唯独题首之山是水系的断裂带。有玉却无水——石多而水绝——这座山像一块被水系遗忘的干燥岩丘。（003-069）

## 「多石」

「多石」在《山海经》中是一个低价值标记——石不同于玉、金、铜等有名目的矿产，是最朴素的物质：

| 产物 | 价值 |
|------|------|
| 美玉 | 高 |
| 黄金 | 高 |
| 青碧 | 中 |
| **多石** | **低** |

「有玉焉，多石」——有少量玉，但石头更多。玉被石所淹没——题首之山是一座以石为主体、以玉为点缀的荒山。（003-069）

## 北次三経の「極簡山」：题首之山の六字記述が示す山海経の情報最小値

题首之山の記述「有玉焉、多石、無水」は僅か六字であり、五藏山経の山の中で情報量が最小級である。同程度の極簡山と比較すると：

| 山 | 記述字数（山名除外） | 内容 | 出処 |
|----|-------------------|------|------|
| **题首之山** | **6字** | **有玉、多石、無水** | **003-069** |
| [[北单之山]] | 6字 | 無草木、多葱韭 | 003-022 |
| [[阳夹之山]] | 4字 | 無草木、多水 | 001-035 |

阳夹之山（4字）が五藏山経最短だが、题首之山（6字）も同等の極簡である。しかし题首之山は「無水」を含む点で独特——五藏山経の大多数の山は水系情報を持つ（「X水出焉」）が、题首之山は水系の不在を積極的に宣言する。

さらに题首之山は前後を景水・洧水・陽水など豊富な水系を持つ山に挟まれており、その「無水」は連続する水系帯の中の孤立した断裂点となる。[[乾山]]の「無水」（003-226）が東流水系帯の断裂点であったのと同じ構造が、北次三経の別の箇所でも繰り返されている——北次三経は四十六山の最大経脈であり、その中に複数の水系断裂点を含む。（003-069）
