# 挺木牙交

**挺木牙交**是《山海经·[[海内西経]]》所载的灵树。[[圣木曼兑]]的异名——位于[[昆仑]][[開明獣]]的北方——名意为「直立之木、枝牙交错」。（012-020）

## 原文出处

《[[海内西経]]》：

> 圣木曼兑，一曰挺木牙交。
>
> （012-020）

## 两个名字

同一棵树有两个名字——从不同角度描述：

| 名 | 含义 |
|----|------|
| 圣木曼兑 | 圣洁之木，曼妙而悦 |
| 挺木牙交 | 直立之木，枝牙交错 |

「圣木曼兑」强调神圣与美感——「挺木牙交」强调形态与结构。「挺」是挺拔直立——「牙」是分枝——「交」是枝条交错。一个名字说它美——另一个名字说它长什么样。（012-020）

## 开明北的神木群

挺木牙交是昆仑开明北方神木群的一员——与多种灵树并列：

| 神木/灵物 | 性质 |
|-----------|------|
| 视肉 | 不死灵肉 |
| 珠树 | 结珠之树 |
| 文玉树 | 玉质之树 |
| 不死树 | 食之长生 |
| 木禾 | 神谷 |
| **圣木曼兑/挺木牙交** | **圣洁灵树** |

开明北是昆仑山上灵树最密集的区域——不死树、珠树、文玉树等齐聚于此。凤凰、鸾鸟栖于其间。挺木牙交是这片圣域的一棵——在不死与珍宝之间生长。（012-020）

## 昆仑的四方结构

开明獣守昆仑之东——四方各有不同的存在：

| 方位 | 内容 |
|------|------|
| 东 | 开明獣（虎身九首） |
| **北** | **神木群（含挺木牙交）** |
| 西 | 凤凰·鸾鸟 |
| 南 | 树鸟·蛟蝮蛇 |

北方是植物的领地——南方是动物的领地。挺木牙交属于昆仑北面的植物圣域——与南面的蛟蛇形成对比。（012-020）
