**天穆之野**，西南海之外，[[赤水]]之南，流沙之西。高二千仞。[[夏后开]]上三嫔于天，得《[[九辩]]》与《[[九歌]]》以下。开焉得始歌《[[九招]]》。

== 地理 ==

西南海之外，赤水之南，流沙之西。高二千仞。

== 事件 ==

夏后开乘两龙，珥两青蛇，上三嫔于天，得《九辩》与《九歌》以下。于天穆之野始歌《九招》。

== 天穆之野の地理的意味 ==

天穆之野は西南海之外、赤水之南、流沙之西という三重の境界の向こう側に位置する。高二千仞という数値は大荒経の地名で具体的な高度が記される稀有な例であり、この野が天に近い高地であることを強調する。赤水と流沙はいずれも[[昆仑之丘]]圏の地標であり、天穆之野は昆仑の西南延長上に置かれた天界への通路と読める。

== 夏后开の天界往還 ==

夏后开は乗龍と珥蛇という神人の装束で天に三度嫔（朝見）し、《九辩》《九歌》という天上の楽を地上に持ち帰った。この天穆之野で始めて《九招》を歌ったとされ、天界の音楽が地上に降りる接点がこの野である。「珥両青蛇」は蛇を耳飾りとする神的表象であり、大荒経に頻出する蛇との共生モチーフの一例。

== 大荒西経の構造上の位置 ==

天穆之野の前後には[[一臂民]]（三面一臂の不死者）や[[互人之国]]（炎帝の孫・霊恝の子孫で天を上下する）が配置される。いずれも天と地を往来する能力を持つ存在であり、大荒西経のこの一帯は天地交通の密集地帯として構成されている。
