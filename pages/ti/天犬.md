# 天犬

**天犬**是《山海经·大荒西经》所载的赤色神犬，从天而降，降落之处必发生战争。天犬以「天」冠名，暗示其来源于天界；「所下者」的「下」字则清晰表明它是从上方降临人间的天降异兽，而非地面游走的普通猛兽。

## 原文出处

引注：（016-035）

> 有赤犬，名曰天犬，其所下者有兵。

## 形象描述

《山海经》对天犬的描述极度简约，仅有三个信息点：

**赤色**：全身赤红。赤色在《山海经》的预兆体系中频繁出现于凶兆之兽，与火、血、战争等意象的关联深入神话底层。赤犬之「赤」是视觉上的警示色，看见者即知凶险。

**犬形**：犬（狗）是上古神话中与天界、狩猎、战争均有联系的动物，相比其他异兽，犬作为凶兆的载体更具有贴近人居生活的恐惧感。

**从天而降**：「所下者」明确指出天犬的运动方向是从上到下，它不是被人遇见，而是主动降临。这是主动的神圣干预，而非被动的自然预兆。天犬的降临本身就是兵祸的触发器，不只是信号。

## 「天」字前缀的神话意义

《山海经》中以「天」冠名的存在并不多，每一个都有特殊含义：

| 存在 | 原文 | 「天」的含义 |
|------|------|-------------|
| **天犬** |（016-035）| 来自天界的赤犬，降则有兵 |
| [[天吴]] |（015-021）| 八首虎身的水神，居于东海 |
| 天马 |（003-046）| 状如白犬黑头，见人则飞 |
| 天虞 |（016-029）| 反臂之人，大荒西经异人 |
| 天井 |（005-144）| 夏有水冬竭的神井 |

天犬的「天」指明了其来源：它不是自然界的猛犬，而是来自天界的神犬，是某种天帝意志的具身化投射。其降临不是随机的，而是被派遣的，是上界对下界某种局势的回应。

## 预兆类型学：兵祸之兆

《山海经》构建了一套精密的「见则」预兆体系，不同的异兽预示不同类型的灾祸。天犬属于其中的「战争-兵祸」类：

| 形象 | 出处 | 预兆类型 |
|------|------|----------|
| **天犬** |（016-035）| 兵祸（战争） |
| 天神（牛形八足） |（002-045）| 有兵 |
| 似鸡自叫之鸟 |（002-027）| 有兵 |
| 狐形白尾长耳狼 |（005-119）| 国内有兵 |
| 屏蓬 |（016-034）| 大荒西经同段异兽 |

战争预兆类的异兽数量相对少于旱涝、疫病类，天犬是其中唯一从天而降的，强调的是兵祸的来源超越人间，有天命属性。

相比「见则有兵」（人类看见后才触发预兆），天犬是「所下者有兵」（它降落的地点直接发生战争），是更强烈的因果关系：天犬不是警告，而是战争的前导力量，其降临本身参与了战争的发生。

## 赤色与战争的神话联系

赤色在上古神话中与火和血的双重意象紧密捆绑：

火是战争的物质符号（焚城、火攻），血是战争的人体代价。

赤色的犬从天降落，是一个语义叠加的意象：天界起源（天犬）+ 战争颜色（赤）+ 主动降临（所下者），三重符码指向同一结果——人间战乱。

与赤色相关的预兆在《山海经》中还有赤水（界定神圣区域）、赤文（毕方的花纹），赤色兼具神圣性和危险性，天犬的赤色是危险属性的压倒性体现。

## 天犬与天狗

《山海经》另载有「天狗」（002-054）：

引注：（002-054）

> 有兽焉，其状如狸而白首，名曰天狗，其音如榴榴，可以御凶。

天狗的功能是「御凶」，是防御性的吉兽；天犬的功能是带来「兵祸」，是进攻性的凶兆。

两者形象完全不同（天狗如狸、白首，天犬为赤色），却以相近的名称共存于《山海经》，揭示了上古犬形神异存在的内部矛盾性：同属「天犬/天狗」系列，一保护一带祸，是神圣存在的双面性格在命名层面的具体体现。

## 大荒西经的语境

天犬的记载（016-035）所在段落是大荒西经中的一段密集异物列举：

- 巫山
- 壑山
- 金门之山（有黄女巨之尸）
- 比翼之鸟
- 白鸟（青翼黄尾玄喙）
- **天犬（赤犬，所下者有兵）**

紧接其后（016-036）是昆仑之丘和西王母的记载。

天犬的位置在大荒西经的兵祸/凶兆异物列举中，紧邻最重要的神圣地标昆仑，这一空间排布将天犬的「天界来源」与昆仑作为「帝之下都」的通天地位形成了隐性关联：天犬可能是从昆仑一线的天界通道降下的。

## 神话意义

**战争的天命化**：天犬将人间战争归因于天界的主动干预，战争不只是人类之间的争斗，而是天帝意志的落地执行。这一叙事将战争的起源超越化，为古代战争提供了神圣解释框架。

**来自上方的恐惧**：普通的「见则」预兆是人类看见异兽，异兽是被动对象。天犬是主动降临的，人类是它选择落点的承受者而非主体。这种「被选中的受害」逻辑比普通凶兆更令人恐惧，因为人类没有「避开视线」的自救可能。

**犬的神圣地位**：在上古中国，犬是祭祀和守卫的重要动物，也是人类最早驯化的伙伴动物之一。天犬将犬的形象推向另一极端，从人类的忠诚护卫变成天界的战争使者，是同一物种神话意义的两极张力。
