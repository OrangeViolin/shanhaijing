# 貊国

**貊国**是《山海经·[[海内西经]]》所载的邦国，位于汉水东北。因地近于燕而被燕国所灭——《山海经》中唯一明确记载国家灭亡的条目。（012-011）

## 原文出处

《[[海内西经]]》：

> 貊国在汉水东北。地近于燕，灭之。
>
> （012-011）

## 唯一的灭亡

「地近于燕，灭之」——因为靠近燕国而被消灭：

| 要素 | 内容 |
|------|------|
| 位置 | 汉水东北 |
| 邻国 | 燕 |
| 结果 | 被燕灭 |

《山海经》记载了数百个国家和民族，几乎全部以「有X国」的方式永恒存在。只有貊国被明确标注了终结——「灭之」。这两个字打破了《山海经》的时间静止——在其他国家永远存在的世界中，貊国曾经存在，然后消失了。（012-011）

## 三层信息

貊国的记述虽短，却包含三层完整的地理政治信息：

| 层次 | 内容 |
|------|------|
| 方位 | 汉水东北 |
| 关系 | 地近于燕 |
| 结果 | 灭之 |

位置→关系→后果——一条因果链。靠近强邻就是灭亡的原因——「地近」二字既是地理描述也是命运判决。（012-011）

## 东北方位链

貊国位于海内西经东北方向的四点连锁之中：

| 位置 | 内容 | 信息量 |
|------|------|--------|
| [[东胡]] | 在大泽东 | 方位 |
| 夷人 | 在东胡东 | 方位 |
| **貊国** | **汉水东北，地近于燕，灭之** | **方位+政治+历史** |
| 孟鸟 | 在貊国东北，文赤黄青 | 方位+视觉 |

四个条目从西向东排列——东胡→夷人→貊国→孟鸟。信息密度逐步变化：东胡只有方位，夷人只有方位，貊国有方位+政治+灭亡，孟鸟有方位+色彩。貊国是这条链中信息最丰富的一环——也是最悲剧的一环。（012-011）

## 历史痕迹

貊国的记载具有明显的历史地理志性格——这不是神话，是记录：

| 比较 | 神话型 | 地志型 |
|------|--------|--------|
| 国民描述 | 三首、无骨、长臂 | 无 |
| 位置 | 模糊方位 | 汉水东北 |
| 政治关系 | 无 | 地近于燕 |
| 时间性 | 永恒存在 | 灭之（有终结） |

貊国没有奇异的身体、没有超自然的特征——它只是一个在汉水东北、被燕国灭掉的普通国家。这是《山海经》中最接近正史的一条记载。（012-011）

## 山海経における時間性の記述

「地近于燕灭之」は山海経全篇で唯一の「滅亡」記述であり、山海経に稀少な「時間性」を導入する：

| 記述類型 | 時間性 | 出現頻度 | 例 |
|----------|--------|----------|-----|
| 有X国 | 無時間（恒存） | 大多数 | 有朝鮮、有犬封国 |
| X生Y | 神話的過去 | 系譜のみ | 帝俊生黒歯 |
| **灭之** | **歴史的過去** | **貊国のみ** | **地近于燕灭之** |

山海経の邦国は通常「有」の一字で永遠に存在する。貊国だけが「灭」の一字で終結を記される。この記述は山海経の成書年代推定にも利用される——燕が貊を滅ぼしたのは戦国期（紀元前4-3世紀）の出来事と推定され、海内西経のこの条目が戦国以降の追加であることを示唆する。「有X国」が空間の記録であるのに対し、「灭之」は時間の記録であり、山海経の文法的例外である。（012-011）
