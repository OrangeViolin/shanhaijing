# 独山

**独山**は《山海经》东山经所記の資源豊かな山。

## 地理与物产

东山经に記す：「又南三百里，曰独山，其上多金玉，其下多美石。末涂之水出焉，而东流注于沔。」（004-010）独山は东山经第一列山系の中、前山から南行三百里に位置する。山上は金と玉を多く産し、山下は美石が多い。末涂之水がここから東流して沔水に注ぐ。

## 水中の異獣

末涂之水の中には囗【虫庸】が棲む。黄蛇のような姿で魚の翼を持ち、出入りするとき光を放つ。出現すると邑に大旱が起きる旱兆の異獣である。

| 項目 | 内容 |
|------|------|
| 名称 | 囗【虫庸】 |
| 外見 | 黄蛇の姿、魚翼 |
| 光 | 出入りの際に発光 |
| 兆候 | 出現すると大旱 |

蛇の体に魚の翼を持つ複合形態は水陸の境界的存在を示す。発光と旱魃の組み合わせは、光（火・熱）と乾燥の連想に基づく。

## 東山経における位置

独山は東山経第一列山系の中で金・玉・美石と鉱物が豊かな山として記される。水系（末涂之水→沔水）を持ち、異獣（旱兆）を伴う。東山経の山は概して簡潔な記述が多い中、独山は鉱物・水系・異獣の三要素を備えた比較的充実した条目である。
