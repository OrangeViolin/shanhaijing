# 独山

**独山**是《山海经·[[东山经]]》東次一経所载的山。山上多金玉，山下多美石——末涂之水东流注于沔。水中有囗【虫庸】——见则大旱。（004-010）

## 原文出处

《[[东山经]]》東次一経：

> 又南三百里，曰独山，其上多金玉，其下多美石末涂之水出焉，而东流注于沔，其中多囗【虫庸】，其状如黄蛇，鱼翼，出入有光，见则其邑大旱。
>
> （004-010）

## 囗【虫庸】

独山水中的异兽——形态极为特殊：

| 属性 | 内容 |
|------|------|
| 形态 | 如黄蛇、鱼翼 |
| 异能 | 出入有光 |
| 凶兆 | 见则大旱 |

黄蛇的身体——鱼的翅翼——出入水中时发光。蛇加鱼加光——三种属性叠加在一个生物上。发光的水中异物预示旱灾——水里的东西反而带来旱。（004-010）

## 水害与旱害的对

独山的前一站是[[【犭才】山]]——那座山的异兽「见则天下大水」：

| | [[【犭才】山]] | 独山 |
|--|------------|------|
| 异兽凶兆 | 见则天下大水 | 见则大旱 |
| 灾害类型 | 水害 | 旱害 |
| 范围 | 天下 | 其邑 |

前一座山预示水灾——这一座山预示旱灾。東次一経末尾把水害和旱害排在相邻的位置——灾异成对出现。（004-010）

## 金玉美石

独山的矿产分上下两层：

| 位置 | 物产 |
|------|------|
| 山上 | 金玉 |
| 山下 | 美石 |

金玉在上、美石在下——东山经常见的矿产分层写法。富裕的山——水中却住着旱灾的凶兽。（004-010）
