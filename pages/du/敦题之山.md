# 敦题之山

**敦题之山**是《山海经·[[北山経]]》北次二経的末山。无草木——多金玉——临北海。北次二経十七山的终点。（003-042、003-043）

## 原文出处

《[[北山経]]》北次二経：

> 又北三百里，曰敦题之山，无草木，多金玉。是【钅享】于北海。
>
> （003-042）

> 凡北次二经之首，自管涔之山至于敦题之山，凡十七山，五千六百九十里。其神皆蛇身人面。其祠：毛用一雄鸡彘瘗；用一璧一【王圭】，投而不糈。
>
> （003-043）

## 北海之山

「是【钅享】于北海」——这座山面对北海。「【钅享】」意为临、向。敦题之山是北次二経的最北端——从内陆的[[管涔之山]]出发，走了五千六百九十里，终于到达北海边缘。

## 从河源到海边

北次二経的首尾形成一条从内陆到海的线路：

| | 首山 | 末山 |
|--|------|------|
| 山名 | [[管涔之山]] | 敦题之山 |
| 地标 | 汾水源头（黄河支流） | 北海 |
| 物产 | 多木 | 无草木，多金玉 |

从有草木的河源走到无草木的海边——越走越荒——矿物越走越多。（003-042、003-043）

## 北次二経总括

| 属性 | 内容 |
|------|------|
| 首山 | [[管涔之山]] |
| 末山 | 敦题之山 |
| 山数 | 十七山 |
| 里程 | 五千六百九十里 |
| 山神 | 皆蛇身人面 |
| 祭品 | 雄鸡+彘（猪），瘗入地中 |
| 玉器 | 一璧一【王圭】，投入（不用糈） |

蛇身人面的山神——和北次一経的人面蛇身一样。整个北山経都是蛇身的神灵世界。祭祀不用糈（谷物）——用鸡、猪和玉。「投而不糈」——把玉投出去，不供谷物。北方的祭祀方式和其他经脉不同。（003-043）

## 荒金之山

无草木——多金玉。草木越少、矿物越多——这是北山経荒山的共同特征。到了北海边——连最后一棵草都没有了——只剩金和玉。一座纯矿物的山守在大陆的尽头。（003-042）
