# 敦薨之山

北山経に属する山。棕・木丹が山上に、茈草が山下に生える。

## 水系

**敦薨之水**が発し、西へ流れて氵幼沢に注ぐ。

## 河水の源

> 出于昆仑之东北隅，实惟河原。

[[昆仑之丘]]の東北隅に位置し、黄河の源とされる。山海経における河源伝説の重要な記述。

## 動物

水中に赤鮭が多く、獣類では兕（犀）・旄牛が棲み、鳥類は柝鳩が群れる。

## 周辺

北山経の山系に位置し、昆仑と黄河を結ぶ地理的要衝。

## 河源としての特殊な位置

敦薨之山は「出于昆仑之东北隅，实惟河原」と記され、山海経全体の中でも河（黄河）の源流を明示する稀有な条目である。

| 項目 | 内容 |
|------|------|
| 位置 | 昆仑の東北隅 |
| 水系 | 敦薨之水（西流して氵幼沢に注ぐ） |
| 河源宣言 | 「実に惟れ河の原なり」 |
| 植物 | 棕・木丹（上）、[[茈草]]（下） |
| 水中 | 赤鮭 |
| 獣 | 兕・旄牛 |
| 鳥 | 柝鳩 |

昆仑は山海経の宇宙の中心であり、黄河の源がその東北隅に発するという記述は、昆仑と中原を結ぶ水脈の起点を示す。敦薨之水自体は西流して氵幼沢に注ぐが、「河原」の宣言はこの山が黄河水系の始発地であることを述べる。地理的水流と神話的河源が同一の山に重なる二重構造を持つ。

## 産物の多様性

敦薨之山は植物・魚・獣・鳥の全カテゴリにわたる産物を記す。赤い鮭、兕と旄牛という大型獣、茈草という薬効植物が共存する豊かな山として、河源の地にふさわしい充実した生態系を描く。
