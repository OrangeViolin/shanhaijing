# 旄山

**旄山**是《山海经》中同时出现在两部经文中的山。[[东山经]]東次三経——无草木的荒山，蒼体之水西流注于展水（004-012）。[[南山经]]南次三経——旄山之尾南有谷曰[[育遗]]，多怪鸟，凯风自是出（001-033）。

## 原文出处

### 东山经（旄山）

> 又南三百里，曰旄山，无草木。苍体之水出焉，而西浪注于展水，其中多鱬鱼，其状如鲤而大首，食者不疣。
>
> （004-012）

### 南山经（旄山之尾）

> 又东四百里，至于旄山之尾。其南有谷，曰育遗，多怪鸟，凯风自是出。
>
> （001-033）

## 两部经文中的旄山

同一个「旄山」——在两部经文中呈现完全不同的面貌：

| | 东山经 | 南山经 |
|--|--------|--------|
| 经脉 | 東次三経 | 南次三経 |
| 名称 | 旄山 | 旄山之尾 |
| 特征 | 无草木 | 南有谷（[[育遗]]） |
| 水系 | 蒼体之水→展水 | 凯风自是出 |
| 物产 | 鱬鱼（食者不疣） | 多怪鸟 |
| PN | 004-012 | 001-033 |

东山经写的是山体本身——荒芜无草木。南山经写的是山的末端——「尾」字说明是山体的尽头。两者一写山、一写尾，也许是同一座大山的不同部位。（004-012、001-033）

## 蒼体之水与鱬鱼

东山经的旄山虽然荒芜——水中却有药鱼：

| 属性 | 内容 |
|------|------|
| 水名 | 蒼体之水 |
| 流向 | 西流 |
| 注入 | 展水 |
| 水产 | 鱬鱼 |
| 药效 | 食者不疣 |

无草木的荒山——流出有药鱼的水。山上一片荒凉，水里却能治病。旄山的荒与水的药形成反差。（004-012）
