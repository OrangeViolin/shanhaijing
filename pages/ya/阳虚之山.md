# 阳虚之山

**阳虚之山**是《山海经·[[中山経]]》中次五経（薄山山系）的末山。多金——临于[[玄扈之水]]。薄山山系十六山、二千九百八十二里的最后一站。（005-055）

## 原文出处

《[[中山経]]》中次五経：

> 又东二十里，曰阳虚之山，多金，临于玄扈之水。
>
> （005-055）

> 凡薄山之首，自苟林之山至于阳虚之山，凡十六山，二千九百八十二里。
>
> （005-056）

## 临水末山

阳虚之山「临于玄扈之水」——末山以水为终：

| 属性 | 内容 |
|------|------|
| 矿产 | 金（多） |
| 水系 | 临于玄扈之水 |
| 地位 | 薄山山系末山 |

「临」不是「出」——水不是从山里流出来的——而是山临近水边。阳虚之山站在玄扈之水旁边——像一座守望水的山。末山临水——整条山系从山地走向水域——以水为句号。中山経的末山常以水系收束——阳虚之山遵循这个模式。（005-055）

## 薄山山系

薄山山系（中次五経）以阳虚之山为末——规模可观：

| 项目 | 内容 |
|------|------|
| 首山 | 苟林之山 |
| 末山 | **阳虚之山** |
| 山数 | 十六山 |
| 里程 | 二千九百八十二里 |
| 冢山 | [[升山]] |
| 【鬼申】山 | [[首山]] |

十六山——将近三千里——中山経中规模较大的山系。有一座冢山（升山）和一座【鬼申】山（首山）——两个祭祀中心。冢山用太牢和吉玉——【鬼申】山用黑牺和干舞——两种不同等级的祭祀并存——薄山山系的祭祀体系是中山経中最复杂的之一。（005-056）

## 阳虚之名

「阳虚」——阳是明亮——虚是空无。明亮的空虚——或者向阳面的低洼处：

| 属性 | 内容 |
|------|------|
| 阳 | 山南/明亮 |
| 虚 | 空/低洼/废墟 |

向阳面的低地——或者曾经繁华现在空了的阳面。作为末山——「虚」有收束之意——从丰满到空虚——山系走到尽头。金多但名带虚——富饶却空——末山的名字暗示结束。（005-055）
