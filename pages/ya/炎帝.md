# 炎帝

**炎帝**是《山海经》中的上古帝王，[[精卫]]之父。在《山海经》中，炎帝不以个人事迹著称，而是以庞大的后裔谱系定义存在——从[[祝融]]（火神）到[[共工]]（水神）到[[后土]]（土地神）到[[夸父]]（追日者），炎帝一系贯穿了《山海经》最重要的多条叙事线。

## 原文出处

引注：（003-065）

> 是炎帝之少女名曰女娃，女娃游于东海，溺而不返，故为精卫。

引注：（018-037）

> 炎帝之妻，赤水之子听訞生炎居，炎居生节并，节并生戏器，戏器生祝融。祝融降处于江水，生共工。共工生后土，后土生噎鸣，噎鸣生岁十有二。

引注：（018-030）

> 炎帝之孙伯陵……缘妇孕三年，是生鼓、延、殳。始为侯，鼓、延是始为钟，为乐风。

引注：（016-046）

> 有互人之国。炎帝之孙名曰灵恝生百互人，是能上下于天。

## 炎帝世系

```
炎帝
├── 女娃（精卫）——溺死化鸟，填海至今
├── 炎居 → 节并 → 戏器 → 祝融 → 共工 → 后土 → 噎鸣（岁十二）
│                                    └── 术器（首方颠，复土穰）
│                                              └── 信 → 夸父
├── 伯陵 → 鼓、延、殳（发明钟乐）
└── 灵恝 → 百互人（能上下于天）
```

这条世系链贯穿了《山海经》中最重要的几条叙事：

- **[[精卫填海]]**：炎帝少女溺死化鸟
- **[[祝融]]杀[[鲧]]**：奉天帝命处决窃息壤者
- **[[共工触山]]**：怒触不周山致天倾
- **[[后土]]**：土地之神，时间秩序的源头
- **[[夸父逐日]]**：追日渴死，弃杖化桃林

## 精卫之父

「炎帝之少女名曰女娃」。这一句是[[精卫填海]]叙事的起点。女娃游东海溺死，化为精卫鸟，日夜衔石填海。帝王之女的身份使精卫的悲剧多了一层意味：即使是天帝的血脉也无法免于溺亡，而帝王之女的不屈同样超越了帝王的权力。

## 被遗漏的支系：术器与灵恝

炎帝世系中有两条常被忽略的支线，却涉及极重要的神话功能。

**术器**：共工之子，「首方颠，是复土穰，以处江水」（018-037）。术器的神话功能是「复土穰」——恢复大地的丰饶。[[共工]]触山之后，天地倾斜，江水泛滥；术器「以处江水」，是洪水之后、[[大禹治水]]之前的土地神功能承接者。他头顶方形，与[[后土]]（土地之神）的土地属性一脉相承。

**灵恝**：炎帝之孙，生百互人，「能上下于天」。[[互人之国]]的人能够自由往来天地，这与炎帝系其他后裔（共工的反抗、夸父的追日）共享同一母题：炎帝系始终在挑战天地之间的边界。

## 炎帝系与黄帝系

《山海经》中两大帝系的对比：

| 维度 | 炎帝系 | 黄帝系 |
|------|--------|--------|
| 核心叙事 | 失败与不屈（精卫、夸父、共工） | 征服与秩序（战蚩尤、定九州） |
| 代表后裔 | 祝融、共工、后土、夸父 | 颛顼、鲧、禹 |
| 基调 | 悲剧英雄 | 秩序建立者 |
| 交叉点 | 祝融杀鲧（炎帝系执行黄帝系的惩罚） | — |

两个体系在祝融杀鲧处交叉：[[祝融]]（炎帝系）奉天帝命杀[[鲧]]（黄帝系），显示了神话叙事中帝系之间复杂的权力关系。

另一个交叉点在于[[赤水]]：炎帝之妻是「赤水之子」，而赤水同时出现在[[昆仑之丘]]的地理体系中，暗示炎帝系的起源与昆仑神山存在地理上的关联。

## 神话意义

**谱系型天帝**：炎帝在《山海经》中不以个人事迹定义（不同于[[黄帝]]战蚩尤、[[帝俊]]赐弓），而是以后裔的成就与悲剧定义。他是一棵树的根——你看不见根，但每一根枝条（精卫、祝融、共工、夸父）都从他生长出来。

**从火到水到土**：炎帝→[[祝融]]（火）→[[共工]]（水）→[[后土]]（土）→[[术器]]（复土）。这条世系链完成了从火到水到土的五行演变，暗示炎帝系承担了自然力从一种形态向另一种形态转化的神话功能。
