# 雅山

**雅山**は[[中山経]]中次十二経に記載される山である。（005-171）

## 原文出処

> 又東三十里，曰雅山。澧水出焉，東流注於視水，其中有大魚。其上多美桑，其下多苴，多赤金。
> （005-171）

## 地理描述

雅山は[[鲵山]]の東三十里に位置する。澧水がこの山から出て東に流れ視水に注ぐ。水中には大魚がいる。山上には美しい桑が多く、山下には苴と赤金が多い。

## 水系構造

澧水は雅山から発し、東へ流れて視水に注ぐ。中次十二経では視水が主要な集水河川として機能し、複数の支流が東流して合流する。

| 要素 | 内容 |
|------|------|
| 水源 | 雅山 |
| 河川 | 澧水 |
| 流向 | 東 |
| 注入 | 視水 |

## 美桑と大魚

山上の美桑は良質な桑の木。東方の[[宣山]]には「帝女之桑」（大五十尺、枝四衢）という巨大桑が記され、この一帯が桑の産地であることを示す。澧水の大魚は種名を記さず、単に「大魚」とのみある。

## 前後の山

| 前 | [[鲵山]]（鲵水、美垩、金、青【镬钅換丹】） |
|------|------|
| **当項** | **雅山（澧水、大魚、美桑、苴、赤金）** |
| 後 | [[宣山]]（沦水、蛟、帝女之桑） |

雅山は鲵山と宣山に挟まれ、三山とも東流して視水に合流する河川を持つ。この区間は視水流域に沿った連続的な山列。
