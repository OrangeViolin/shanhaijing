# 羊患

**羊患**是《山海经·[[南山経]]》所载的异兽。栖息于洵山——状如羊而无口——不可杀。（001-023）

## 原文出处

《[[南山経]]》：

> 有兽焉，其状如羊而无口，不可杀也，其名曰羊患。
>
> （001-023）

## 无口与不死

羊患的两个特征构成一个逻辑闭环：

| 特征 | 内容 |
|------|------|
| 形态 | 状如羊 |
| 异形 | 无口 |
| 属性 | 不可杀 |

无口——不能进食——也不能发声。不可杀——无法被杀死。一个不吃东西的生物不依赖外部能量维持生命——所以无法被杀。无口是原因——不死是结果。这是《山海经》中最极端的身体缺失型异兽——缺失本身成为力量的来源。（001-023）

## 洵山的环境

羊患栖息的洵山位于南次二経：

| 属性 | 内容 |
|------|------|
| 阳面 | 多金 |
| 阴面 | 多玉 |
| 水 | 洵水南流注于阏之泽 |
| 水产 | 多芘蠃（卷贝） |

洵山阳面多金、阴面多玉——是一座矿产丰富的山。洵水从此南流——注入阏之泽——泽中多卷贝。一座富矿之山上住着一头无口不死的羊——物质的丰饶与生命的极简共存于同一座山。（001-023）

## 南次二経的生死对照

洵山前后的山构成了一组荒寂地带——然后突然出现不死之兽：

| 顺序 | 山 | 特征 |
|------|-----|------|
| 前 | 仆勾之山 | 金玉多，无草木无鸟兽无水 |
| **洵山** | **金玉·洵水·芘蠃·羊患（不可杀）** | |
| 后 | 咸阴之山 | 无草木无水 |
| 再后 | [[鹿吴之山]] | [[蛊雕]]（食人） |

仆勾之山和咸阴之山都是无草木无水的荒山——洵山夹在其间却有水有金玉还有不死之兽。再往东的鹿吴之山有食人的蛊雕——「不可杀」的羊患与「杀人」的蛊雕形成极端对照。（001-023）
