# 博父

**博父**（博父国）是《山海经·[[海外北経]]》所载的国。在[[聂耳]]的东面——其为人大，右手操青蛇，左手操黄蛇。邓林在其东。一曰博父。（008-010）

## 原文出处

《[[海外北経]]》：

> 博父国在聂耳东，其为人大，右手操青蛇，左手操黄蛇。邓林在其东，二树木。一曰博父。
>
> （008-010）

## 双蛇之国

博父国的人——大，双手各握一条蛇：

| 属性 | 内容 |
|------|------|
| 体型 | 大（巨人） |
| 右手 | 青蛇 |
| 左手 | 黄蛇 |
| 方位 | 聂耳东 |

青蛇和黄蛇——一青一黄，青是东方之色，黄是中央之色。双手操蛇是山海経中神格人物的标配，[[西王母]]、[[禺强]]等都有蛇饰。博父国的人不只是操蛇，而且体型巨大，神人的特征。（008-010）

## 夸父与博父

博父和[[夸父]]——音近，可能是同一人/同一国的异传：

| 要素 | 夸父 | 博父 |
|------|------|------|
| 篇章 | 海外北経 | 海外北経 |
| PN | 008-009 | 008-010 |
| 特征 | 与日逐走、渴死 | 为人大、操双蛇 |
| 邓林 | 杖化为邓林 | 邓林在其东 |

两条紧邻——夸父逐日渴死，杖化邓林，紧接着就是博父国，东面有邓林。邓林把两者连在一起，夸父的遗迹就在博父国旁边。「博」和「夸」上古音相近，可能本来就是一个人的两种叫法。（008-009—008-010）

## 邓林

邓林是夸父的杖化成的林——也是博父国东面的地标：

| 属性 | 内容 |
|------|------|
| 来源 | 夸父弃杖所化 |
| 位置 | 博父国东 |
| 描述 | 二树木 |

「二树木」——两棵树。夸父的杖变成了两棵树，这就是邓林。邓林既是夸父传说的结尾，也是博父国的地理坐标。一个神话遗迹成为一个国家的方位参照。（008-010）
