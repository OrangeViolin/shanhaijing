# 勃垒之山

**勃垒之山**是《山海经·[[东山经]]》东次一经所载的山峰。无草木，无水——什么都没有的山。《山海经》中荒漠记述的最小形式。（004-004）

## 原文出处

《[[东山经]]》东次一经：

> 又南三百里，曰勃垒之山，无草木，无水。
>
> （004-004）

## 八字之山

勃垒之山的全部信息只有八个字：

| 特征 | 有无 |
|------|------|
| 草 | 无 |
| 木 | 无 |
| 水 | 无 |
| 兽 | — |
| 鸟 | — |
| 矿 | — |

无草、无木、无水——连矿石都不提。这是一座绝对的空山，《山海经》能用的否定词全用上了。勃垒之山是「无」的极致。（004-004）

## 生态断裂

勃垒之山是东次一经从丰饶到荒凉的分界线：

| 位置 | 山 | 生态 |
|------|-----|------|
| 前 | 【木旬】状之山 | 从从（六足犬）、【上此下虫】鼠（旱兆鸡）、箴鱼 |
| **此** | **勃垒之山** | **什么都没有** |
| 后 | 番条之山 | 【氵咸】水、【鱼感】鱼 |

前山有三种异物，后山有水有鱼——勃垒之山是中间的一片空白。它像一道分隔线，把前山的丰富和后山的复苏隔开。经过勃垒之山，一切归零，然后重新开始。（004-003至004-005）

## 无水vs多水

勃垒之山与东次二经的杜父之山形成极端对比：

| 山 | 草木 | 水 |
|----|------|-----|
| **勃垒之山** | **无** | **无** |
| 杜父之山 | 无 | 多 |

同样无草木——一座完全无水，一座多水。勃垒之山是彻底的干枯，杜父之山是矛盾的丰水。东山经用两种不同的「无草木」来展示荒凉的两种面貌。（004-004、004-020）
