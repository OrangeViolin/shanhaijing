# 陶唐之丘

**陶唐之丘**是《山海经·[[海内经]]》所载的九丘之首。九丘以水相络，黄帝所为。丘上有巨木——青叶紫茎、玄华黄实、百仞无枝。（018-034）

## 原文出处

《[[海内经]]》：

> 有九丘，以水络之：名曰陶唐之丘、有叔得之丘、孟盈之丘、昆吾之丘、黑白之丘、赤望之丘、参卫之丘、武夫之丘、神民之丘。有木，青叶紫茎，玄华黄实，百仞无枝，有九属，下有九枸，其实如麻，其叶如芒。大皋爰过，黄帝所为。
>
> （018-034）

## 九丘之首

陶唐之丘排在九丘之首——这个位置并非随机：

| 序号 | 丘名 | 名义 |
|------|------|------|
| **1** | **陶唐之丘** | **尧帝（陶唐氏）** |
| 2 | 叔得之丘 | 人名 |
| 3 | 孟盈之丘 | 充盈 |
| 4 | 昆吾之丘 | 古国 |
| 5 | 黑白之丘 | 色彩 |
| 6 | 赤望之丘 | 色彩 |
| 7 | 参卫之丘 | 星宿/地名 |
| 8 | 武夫之丘 | 武人 |
| 9 | 神民之丘 | 神与民 |

「陶唐」即尧帝的称号——陶唐氏。九丘以圣王之名开头，以「神民」收尾——从帝王到神民，九丘的名序本身就是一个从统治到被统治、从天上到人间的秩序。（018-034）

## 以水络之

「以水络之」——用水网将九丘连接起来。「络」是网络、脉络——九丘之间不是孤立存在，而是被水系像经脉一样贯通相连。这不是九个独立的山丘，而是一个由水路连结的整体——九个丘、一张水网、一个系统。（018-034）

## 百仞神木

九丘上生长着一棵非凡的巨木：

| 特征 | 描述 |
|------|------|
| 叶 | 青色 |
| 茎 | 紫色 |
| 花 | 玄色（黑） |
| 实 | 黄色 |
| 高度 | 百仞（约三百米），无枝 |
| 结构 | 九属（九节）、下有九枸（九曲） |

青叶、紫茎、玄华、黄实——四种颜色在一棵树上交替。百仞无枝——三百米高的笔直树干，没有一根侧枝。九节、九曲——树的结构中反复出现「九」，与「九丘」呼应。这棵树是九丘的灵魂——九丘为根基、神木为中枢、水络为经脉。（018-034）

## 黄帝所为

「大皋爰过，黄帝所为」——大皋经过此地，这是黄帝创造的。九丘不是天然的地形，而是黄帝的造物。黄帝创造了九个丘、用水把它们连起来、在上面种了百仞神木——九丘是一个人工的圣域、帝王的杰作。（018-034）

## 陶唐与尧

陶唐氏即尧帝。九丘是黄帝所造，却以尧帝之名冠其首——两代圣王在九丘中交汇：黄帝建造、尧帝命名。这暗示九丘是一个跨越世代的圣域——从黄帝到尧，圣王的法统在九丘中延续。（018-034）
