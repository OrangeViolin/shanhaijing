# 陶唐

**陶唐**（陶唐之丘）是《山海经·[[海内经]]》所载[[九丘]]中排在第一位的丘。九丘以水相络——水把九座丘连成一体。丘上有百仞神木，青叶紫茎，玄华黄实。黄帝所造。（018-012）

## 原文出处

《[[海内经]]》：

> 有九丘，以水络之：名曰陶唐之丘、有叔得之丘、孟盈之丘、昆吾之丘、黑白之丘、赤望之丘、参卫之丘、武夫之丘、神民之丘。有木，青叶紫茎，玄华黄实，百仞无枝，有九【木属】，下有九枸，其实如麻，其叶如芒。大【白皋】爰过，黄帝所为。
>
> （018-012）

## 九丘之首

陶唐在九丘排名中居首位：

| 序 | 丘名 |
|----|------|
| **一** | **陶唐之丘** |
| 二 | 有叔得之丘 |
| 三 | 孟盈之丘 |
| 四 | 昆吾之丘 |
| 五 | 黑白之丘 |
| 六 | 赤望之丘 |
| 七 | 参卫之丘 |
| 八 | 武夫之丘 |
| 九 | 神民之丘 |

九座丘以水相连——「以水络之」。水像网一样把九丘织在一起。陶唐排第一——不是因为最大或最高，而是因为「陶唐」是帝尧的号。帝尧居首，天经地义。（018-012）

## 帝尧之号

「陶唐」即陶唐氏——帝尧的称号：

| 帝 | 号 |
|----|-----|
| 尧 | 陶唐氏 |

九丘用「陶唐」为首丘命名——将帝尧放在九丘之首。九丘是黄帝所造——「黄帝所为」。黄帝造的九丘，第一座以尧的名字命名——两位最伟大的帝王在一个条目中相遇：一个造了它，另一个命名了它。（018-012）

## 四色神木

九丘上的神木用四种颜色装饰自己：

| 部位 | 颜色 |
|------|------|
| 叶 | 青 |
| 茎 | 紫 |
| 华（花） | 玄（黑） |
| 实（果） | 黄 |

青、紫、玄、黄——四种颜色从下到上排列。「百仞无枝」——一百仞高的树干上没有一根枝条。只有树顶有九【木属】——九根分叉。这棵树像一根百仞高的柱子，顶端开出四色的花果——它不是树，是天地之间的一根彩色柱子。（018-012）
