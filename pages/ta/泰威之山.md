# 泰威之山

**泰威之山**是《山海经·[[中山経]]》中次一経所载的山。山中有谷名曰枭谷——多铁。无草木水系獣鸟记载——纯粹的铁矿山。（005-008）

## 原文出处

《[[中山経]]》中次一経：

> 又东七十里，曰泰威之山。其中有谷，曰枭谷，其中多铁。
>
> （005-008）

## 枭谷：谷中铁矿

泰威之山的铁产于谷中——不在山上也不在山阴：

| 属性 | 内容 |
|------|------|
| 谷名 | 枭谷 |
| 矿产 | 铁 |
| 草木 | 无记载 |
| 水系 | 无记载 |
| 獣鸟 | 无记载 |

山海経记矿产通常说「其上多X」「其阴多Y」——泰威之山用谷名来定位铁矿——「其中有谷曰枭谷其中多铁」。矿脉在谷间——不在山体。这种以谷定矿的写法在山海経中极少见。全文只有铁——一个字都不浪费在别的东西上。（005-008）

## 铜铁三连矿产带

泰威之山前后三座山连续产铜铁——形成中次一経中段的矿产密集区：

| 山 | 矿产 | PN |
|----|------|-----|
| [[【氵委】山]] | 赤铜（山上）、铁（山阴） | 005-005 |
| **泰威之山** | 铁（枭谷） | 005-008 |
| [[囗谷之山]] | 赤铜 | 005-009 |

【氵委】山铜铁兼产——泰威之山专产铁——囗谷之山专产铜。三座山从混合到分化——铜铁各有归属。这是山海経中最密集的金属矿产带之一。（005-005—005-009）

## 极简之山

泰威之山的记述是中山経中最简短的之一——全文二十一字：

| 对比 | 泰威之山 | 同经其他山 |
|------|----------|-----------|
| 草木 | 无 | 通常有 |
| 水系 | 无 | 通常有 |
| 獣鸟 | 无 | 通常有 |
| 药效/预兆 | 无 | 通常有 |
| 矿产 | 铁 | 多项 |

只有铁——别无他物。「泰威」是大威之意——铁的用途是兵器农具——大威力来自铁。山以铁命名——铁以山为尊——极简的记述反而突出了铁的重要性。（005-008）
