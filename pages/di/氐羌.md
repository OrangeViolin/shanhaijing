# 氐羌

**氐羌**是《山海经·[[海内经]]》所载的族群。[[炎帝]]系谱末端——[[伯夷父]]生[[西岳]]，西岳生[[先龙]]，先龙始生氐羌。氐羌乞姓。（018-027）

## 原文出处

《[[海内经]]》：

> 伯夷父生西岳，西岳生先龙，先龙是始生氐羌，氐羌乞姓。
>
> （018-027）

## 炎帝系谱末端

氐羌处于炎帝系谱最远端——十数代之后：

```
炎帝 → 炎居 → 节并 → 戏器 → 祝融 → 共工 → … → 伯夷父 → 西岳 → 先龙 → 氐羌
```

从炎帝到氐羌——山海经中最长的系谱链。越长的系谱意味着越远的分支。氐羌是炎帝中心向西北辐射的最远一支。（018-027）

## 西岳的孙

「西岳」不是一般人名——是西方山岳的神格。西岳生先龙，先龙生氐羌：

| 世代 | 人物 | 含义 |
|------|------|------|
| 祖 | [[西岳]] | 西方山岳神格 |
| 父 | [[先龙]] | 龙之先祖 |
| 子 | 氐羌 | 西北山岳民族 |

西岳→先龙→氐羌——从山神到龙到民族。山海经用这条血脉把西北山地的民族纳入炎帝体系。实际的氐族和羌族分布在陇西到青海一带——正是「西」的方位。（018-027）

## 乞姓

「氐羌乞姓」——海内经给族群确定姓氏的定型句。同系谱中其他分支也各有其姓：

| 族群 | 姓 |
|------|-----|
| **氐羌** | 乞 |
| [[互人]] | 能 |

姓是族群身份的标记。海内经在系谱末端逐一标注姓氏——这是族群分化完成的信号。（018-027）
