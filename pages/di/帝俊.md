# 帝俊

**帝俊**是《山海经》中出现频率最高的天帝——日月之父、诸族始祖、文明发明的源头、英雄的授权者。他几乎只存在于《山海经》中，在其他先秦典籍中几乎不见踪迹，这使他成为上古神话研究中最具谜团的核心人物。

> 惟帝俊下友。帝下两坛，采鸟是司。

## 四重神格

### 一、日月之父

帝俊有两位妻子分掌日月：
- [[羲和]]生十日——太阳历的起源
- [[常羲]]生十二月——太阴历的起源

帝俊是天文秩序的生物学基础——日月不是自然天体，而是他的子嗣。

### 二、诸族始祖

帝俊的后裔散布天下，各成国族：

| 后裔 | 所建国/族 |
|------|----------|
| 中容 | 中容之国 |
| 晏龙 | 司幽之国 |
| 帝鸿 | （后世与黄帝关联） |
| 黑齿 | 黑齿之国 |
| 季厘 | 季厘之国 |
| 三身 | 三身之国→义均→百巧 |

帝俊不仅是天帝，更是一个「超级始祖」——天下诸族都是他的后裔。

### 三、文明赐予者

通过后裔传播文明：
- **义均**——始作「巧倕」（精巧器具），是「下民百巧」的发明者
- **后稷**——播种百谷，农业的起源
- **叔均**（后稷之孙）——始作牛耕
- **番禺**——始作舟
- **吉光**——始作车

帝俊家族囊括了舟、车、农耕、手工业——几乎所有文明基础技术。

### 四、英雄的授权者

帝俊赐[[羿]]彤弓素矢，命其「恤下地之百艰」。这是《山海经》中天帝直接干预人间事务的典型案例——帝俊不是远离人间的抽象至上神，而是会主动派遣代理人解决人间问题的行动型天帝。

## 「帝俊下友」

「惟帝俊下友」是一句意味深长的描写——帝俊「下」（降临/交往于下界）「友」（结交/亲善）。他在下界设有「两坛」，由采鸟管理。这一细节暗示帝俊有自己的祭祀体系，与黄帝的[[帝之下都]]（昆仑）并行。

## 帝俊之谜

帝俊是《山海经》的核心天帝，但在其他先秦典籍中几乎「失踪」。可能的解释：

| 假说 | 论据 |
|------|------|
| 帝俊 = 帝喾 | 音近，帝喾也是天帝/始祖 |
| 帝俊 = 舜 | 「俊」「舜」古音通假 |
| 帝俊 = 黄帝 | 两者神格高度重叠 |
| 帝俊独立于儒家帝系 | 儒家整理五帝系统时将其排除 |

最后一种假说最具解释力：帝俊可能属于一个被儒家正统化过程淘汰的古老天帝信仰。《山海经》恰好保存了儒家编辑之前的原始形态。

## 父亲的悖论

帝俊同时是十日之父和射日授权者——他命[[羿]]射杀自己的九个儿子。这一结构与[[黄帝]]命[[祝融]]杀[[鲧]]（黄帝四世孙）异曲同工：天帝维护秩序的代价是牺牲自己的血脉。

## 神话意义

**全能天帝**：帝俊是《山海经》中最「全能」的天帝——管天文（日月之父）、管人间（赐弓恤百艰）、管文明（后裔发明百巧）、管血脉（诸族始祖）。黄帝主「统」，帝俊主「生」。

**被遗忘的天帝**：帝俊在《山海经》之外几乎不存在，这一事实本身就是上古神话史最重要的线索——它证明了先秦存在一个被后世正统叙事边缘化的独立天帝信仰。
