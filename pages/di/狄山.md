# 狄山

**狄山**是《山海经·[[海外南经]]》所载的圣山，一名汤山。帝[[尧]]葬于阳（南面），帝[[喾]]葬于阴（北面）。吁咽、文王亦葬于此。山上群聚熊、罴、文虎、离朱、视肉等瑞兽。（006-023）

## 原文出处

《[[海外南经]]》：

> 狄山，帝尧葬于阳，帝喾葬于阴。爰有熊、罴、文虎、【虫隹】、豹、离朱、视肉；吁咽、文王皆葬其所。一曰汤山。一曰爰有熊、罴、文虎、【虫隹】、豹、离朱、【丘鸟】久、视肉、【上虍下乎】交。
>
> （006-023）

## 双帝合葬

狄山最非凡之处是两位古帝同葬一山，且严格按阴阳分位：

| 帝王 | 葬位 | 方位属性 |
|------|------|---------|
| 帝[[尧]] | 阳（南面） | 光明、主位 |
| 帝[[喾]] | 阴（北面） | 幽暗、从位 |

帝尧在阳、帝喾在阴——尧是圣君中的极致（尧舜并称），居主位；喾为尧之先代帝王，居从位。阳阴的分配不是随意的，而是反映了两位帝王在古人心目中的地位高下。这种阴阳葬制在《山海经》中另见于[[务隅之山]]（颛顼葬阳，九嫔葬阴），是帝王葬地的固定模式。（006-023）

## 瑞兽群集

狄山上聚集了大量瑞兽和灵物：

| 瑞兽 | 性质 |
|------|------|
| 熊 | 力量之兽 |
| 罴 | 力量之兽 |
| 文虎 | 有花纹的虎 |
| 【虫隹】 | 鸷鸟 |
| 豹 | 猛兽 |
| 离朱 | 传说中目力极佳者 |
| 视肉 | 食之不尽的灵肉 |

帝王葬地上瑞兽群集，不是偶然——这些生物是帝王灵气的外显。帝尧和帝喾的神圣力量弥漫在狄山上，吸引瑞兽前来栖息。视肉——食之即复生长的神奇肉块——是不死的象征，暗示葬于此山的帝王也获得了某种永恒。（006-023）

## 四帝合葬

除尧、喾外，「吁咽、文王皆葬其所」——吁咽和文王也葬在狄山。一座山上葬了四位帝王/圣人：

| 葬者 | 身份 |
|------|------|
| 帝尧 | 五帝之一 |
| 帝喾 | 五帝之一 |
| 吁咽 | 未详（可能为古帝） |
| 文王 | 周文王 |

从帝喾到帝尧到文王，跨越了夏商周三代——狄山是一座跨越数千年的帝王公墓。多位圣人选择同一座山为葬地，说明狄山的神圣性超越了时代，是一个被反复确认的永恒圣地。（006-023）

## 「狄山」与「汤山」

经文注明「一曰汤山」——狄山又名汤山。「狄」可能指北方的狄族或远方之意，「汤」可能指商汤或热汤（温泉）。两个名字指向不同的联想：狄山偏地理/族群，汤山偏历史/自然。一座山有两个名字，可能反映了不同传说系统对同一圣地的不同称呼。（006-023）

## 海外南经的位置

| 序号 | 条目 | 特征 |
|------|------|------|
| 006-022 | 长臂国 | 捕鱼水中 |
| **006-023** | **狄山** | **双帝合葬、瑞兽群集** |
| 006-024 | 范林 | 方三百里 |
| 006-025 | 南祝融 | 兽身人面乘两龙 |

狄山之后是「范林方三百里」——三百里的大林。帝王陵山旁配一片广袤森林，陵山与林苑构成帝王葬地的完整格局。再之后是南方之神祝融——从帝葬到神居，空间的神圣性在递进。（006-023）

## 山海经中「阴阳合葬」模式的三例比较

狄山的帝尧葬阳、帝喾葬阴不是孤例。山海经中以阴阳分位合葬的帝王陵山共有三处，每处的阴阳分配逻辑不同：

| 陵山 | 葬于阳 | 葬于阴 | 阴阳分配逻辑 | PN |
|------|--------|--------|------------|-----|
| **狄山** | **帝尧** | **帝喾** | **继承者居阳，先代居阴** | **006-023** |
| [[苍梧之山]] | 帝[[舜]] | 帝[[丹朱]] | 受禅者居阳，被弃之子居阴 | 010-008 |
| [[务隅之山]] | [[颛顼]] | 九嫔 | 帝王居阳，妃嫔居阴 | 010-008 |

苍梧之山的阴阳分配是政治性的（禅让的赢家 vs 被弃的太子），务隅之山是性别性的（帝 vs 妃），狄山则是时间性的（后世之帝 vs 先代之帝）。三种逻辑都指向同一个结论：阳是「更重要的那个」，阴是「次要的那个」。但「重要」的判断标准因山而异——在苍梧是政治合法性，在务隅是性别等级，在狄山是历史声望。阴阳葬制不是机械的规则，而是每座陵山各自编码的权力叙事（006-023, 010-008）。
