# 砥励

**砥励**は[[西山経]]に記載される砥石である。[[崦嵫之山]]から西に流れて海に注ぐ苕水の中に多く産する。（002-080）

## 原文出処

《[[西山経]]》：

> 苕水出焉，而西流注于海，其中多砥勵。
> （002-080）

## 解説

砥と励（礪）はともに研磨用の石を指す。砥は細かい砥石、励は粗い砥石で、合わせて研磨石の総称。崦嵫之山の苕水中に豊富に産する。

## 崦嵫之山の文脈

砥励は[[崦嵫之山]]の苕水に産する。崦嵫之山は西山経西次四経の末山であり、太陽が沈む山として知られる日没山の一つである。

| 崦嵫之山の要素 | 内容 |
|---------------|------|
| 位置 | 西次四経の末山 |
| 天文 | 日没の地 |
| 植物 | 丹木（赤符黒理、食して瘅を治す） |
| 水系 | 苕水（西流して海に注ぐ） |
| 水中産物 | **砥励**（研磨石） |
| 獣 | [[孰湖]]（馬身鳥翼人面蛇尾） |
| 鳥 | 【号鸟】に似て人面、旱兆 |

日没の聖地である崦嵫之山の水に研磨石が産する点は、実用的な鉱物資源が神話的空間にも記される山海経の特徴を示す。砥励は日常の道具材料であり、聖地と生活圏が未分化であることを物語る。
