# 帝女之桑

**帝女之桑**是《山海经·[[中山経]]》中次十一経[[宣山]]上的巨大桑树。大五十尺——枝四衢——叶大尺余——赤理黄华青【木付】。以帝之女命名。（005-171）

## 原文出处

《[[中山経]]》中次十一経：

> 其上有桑焉，大五十尺，其枝四衢，其叶大尺余，赤理黄华青【木付】，名曰帝女之桑。
>
> （005-171）

## 巨木形态

帝女之桑的尺寸和形态——山海经中最大的植物之一：

| 属性 | 内容 |
|------|------|
| 大小 | 五十尺 |
| 枝 | 四衢（四方伸展如十字路） |
| 叶 | 大尺余 |
| 木理 | 赤色 |
| 花 | 黄色 |
| 果实 | 青色 |

五十尺——四方伸展——叶大一尺多。这不是普通的桑树——是一棵巨木。枝如十字路口向四方展开——宇宙树般的全方位性。（005-171）

## 三色神桑

赤理——黄华——青【木付】。一棵树上三种颜色分配在三个部位：

| 部位 | 色 |
|------|-----|
| 木理（纹理） | 赤 |
| 花 | 黄 |
| 果实 | 青 |

普通桑树的果实是白色或紫色——帝女之桑的果实是青色。三色各居其位——这棵树自带五行的色彩编码。（005-171）

## 帝女之名

「帝女」——帝的女儿。中山经另有帝女的记载——中次七経姑囗之山：「帝女死焉，其名曰女尸，化为囗草」（005-073）。帝女死后化为草——帝女之桑以帝女命名。

| 出处 | 帝女相关 |
|------|---------|
| 姑囗之山 | 帝女死后化囗草 |
| **宣山** | 巨桑名「帝女之桑」 |

帝女和植物之间反复出现关联——死后化草、巨木以其命名。神话中的女性和植物之间有某种转化通道。

## 宣山的环境

帝女之桑生长的宣山——沦水之源，水中多蛟：

| 属性 | 内容 |
|------|------|
| 水系 | 沦水，东南流注于视水 |
| 水产 | 多蛟 |
| 树木 | 帝女之桑 |

山上是帝的女儿命名的神桑——山下是蛟龙栖息的水。天上的名字和水中的猛兽同居一山。（005-171）
