# 丹山

**丹山**是《山海经·[[海内南经]]》所载的山峰。[[夏后启]]之臣[[孟涂]]在巴地司神，在丹山之西以血衣断罪。丹山在丹阳之南。（010-012）

## 原文出处

《[[海内南经]]》：

> 夏后启之臣曰孟涂，是司神于巴。人请讼于孟涂之所，其衣有血者乃执之。是请生，在丹山西。丹山在丹阳南，丹阳居属也。
>
> （010-012）

## 血衣断罪

孟涂在丹山之西施行一种原始的神判，以血迹定罪：

| 要素 | 内容 |
|------|------|
| 法官 | 孟涂（夏后启之臣） |
| 地点 | 丹山西 |
| 判决方式 | 衣有血者乃执之 |
| 性质 | 请生（请求生死裁决） |

「其衣有血者乃执之」，衣服上有血的人就会被抓捕。这是最原始的司法，不问理由、不听辩词，只看血迹。血是罪的物证，丹（红色）是血的颜色，丹山之西以血的红色来裁断人的生死。（010-012）

## 丹山与丹阳

丹山的位置被两重定位锚定：

| 层级 | 内容 |
|------|------|
| 丹山 | 审判之地 |
| 丹阳 | 丹山在丹阳南 |
| 属 | 丹阳居属也 |

「丹山在丹阳南，丹阳居属也」，从丹山到丹阳到属（行政归属），三层地名逐步缩小范围。两个地名都带「丹」字，丹山、丹阳，这是一片以「丹」（红色/丹砂）命名的区域。丹砂产地、红色的山、血的审判，「丹」字贯穿了地名和神判。（010-012）

## 司神于巴

孟涂「司神于巴」，在巴地主管神事。巴是古代西南地区（今重庆四川一带）的地名：

| 要素 | 内容 |
|------|------|
| 人物 | 孟涂 |
| 身份 | 夏后启之臣 |
| 职能 | 司神（主管神事） |
| 管辖 | 巴地 |

孟涂是夏朝开国之君启的大臣，中央王朝派出的官员在边远的巴地代行神判。这是王权向边疆延伸的一种形式，通过司法来统治远方。（010-012）

## 前后文脉

丹山夹在两种异物之间：

| 位置 | 内容 |
|------|------|
| 前 | 兕兕，知人名的兽，如豕而人面 |
| **此** | **丹山，孟涂血衣断罪** |
| 后 | 【上穴下契】窳，龙首，居弱水中，食人 |

知人名的兽→血衣断罪→食人的龙，海内南经在丹山前后安排了一串与人的生死相关的记载。兕兕能叫出人的名字（知死），孟涂裁断人的生死（判死），【上穴下契】窳吃人（致死），丹山是这条死亡序列的中间环节。（010-012）

## 山海経の「神判」制度：孟涂の血衣裁判と山海経中の司法記録

丹山の孟涂による血衣神判は《山海経》中で最も具体的な司法制度の記録である。山海経には神や帝が裁きを行う記述が散在するが、判決の具体的手続き（血の有無で有罪判定）まで記すのは丹山だけである：

| 司法記録 | 裁判者 | 手続き | 判定基準 | 出処 |
|---------|--------|--------|---------|------|
| **丹山** | **孟涂** | **衣有血者乃執之** | **物証（血痕）** | **010-012** |
| 鍾山 | 帝 | 戮之鍾山東 | 帝の意志 | 002-043 |
| 海内経 | 禹 | 殺相繇 | 帝の命令 | 018-010 |

鍾山の帝が鼓と欽【丕鸟】を戮したのは帝権による裁断であり、手続きは記されない。丹山の孟涂だけが「衣有血者乃執之」という明確な判定基準を持つ，血痕の有無が有罪/無罪を分ける。「是請生」（生死を請い求める）という表現は、この裁判が死刑を含む重大審判であったことを示す。

「丹」の字の三重の反響も注目に値する：丹山（山名）→丹陽（地名）→丹（血の赤）。地名から場所から裁判の物証まで、全てが「赤」で統一されている。（010-012）
