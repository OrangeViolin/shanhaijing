# 待山

**待山**は[[大荒东经]]に記載される山である。[[摇山]]・綦山・[[门户山]]・[[盛山]]とともに列挙される。（015-031）

## 原文出処

《[[大荒东经]]》：

> 有【土熏】民之国。有綦山。又有摇山。有【融虫换曾】山，又有门户山，又有盛山。又有待山。有五采之鸟。
> （015-031）

## 地理描述

待山は大荒東経の山群に属し、列挙の末尾に位置する。五彩の鳥がこの地帯に棲む。

## 大荒東経六山密集地帯

待山は[[【土熏】民之国]]の近傍に密集する六山の一つである。

| 山名 | 位置 |
|------|------|
| 綦山 | 列挙の先頭 |
| [[摇山]] | 二番目 |
| 【融虫换曾】山 | 三番目 |
| [[门户山]] | 四番目 |
| [[盛山]] | 五番目 |
| 待山 | 末尾 |

六山はいずれも産物・水系の記載がなく名のみで列挙される。末尾の待山の直後に「有五采之鳥」と記され、この山群全体に五彩の鳥が棲息するという瑞鳥の記述で締めくくられる。五彩の鳥は山海経において吉兆の標識であり、六山密集地帯が神聖な空間であることを示す。
