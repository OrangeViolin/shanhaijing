# 单狐之山

**单狐之山**是《山海经·[[北山经]]》北次一経的首山。多机木——山上多华草，逢水西流注于[[【氵幼】水]]，多芘石文石。（003-001）

## 原文出处

《[[北山经]]》北次一経：

> 北山经之首，曰单狐之山，多机木，其上多华草。逢水出焉，而西流注于【氵幼】水，其中多芘石文石。
>
> （003-001）

## 北次一経总括

> 凡北山经之首，自单狐之山至于【阝是】山，凡二十五山，五千四百九十里。
>
> （003-026）

## 北方世界的入口

单狐之山是北次一経的起点——统领二十五山、五千四百九十里：

| 属性 | 内容 |
|------|------|
| 经脉 | 北次一経 |
| 山数 | 二十五 |
| 里程 | 五千四百九十里 |
| 末山 | [[【阝是】山]] |
| 山神形态 | 皆人面蛇身 |

人面蛇身的山神——北次一経整条经脉的神都是同一个样子。单狐之山是进入这个蛇身神灵世界的第一座山。（003-001、003-026）

## 生食不火

北次一経的总括有一条独特记载——「其山北人，皆生食不火之物」：

| 经脉 | 民俗记载 |
|------|----------|
| 南山经 | 无 |
| 西山经 | 无 |
| **北山经** | 生食不火 |
| 东山经 | 无 |

只有北山经记载了山北之人的饮食习俗——生食、不用火。四部山经中唯一的民俗信息，北方的特殊。（003-026）

## 逢水

单狐之山的水系——逢水：

| 属性 | 内容 |
|------|------|
| 水名 | 逢水 |
| 流向 | 西流 |
| 注入 | [[【氵幼】水]] |
| 水产 | 芘石、文石 |

芘石和文石——石头而非生物。首山的水中住着的不是鱼，是石头。北方世界从石头开始。（003-001）
