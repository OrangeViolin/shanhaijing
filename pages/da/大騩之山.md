# 大騩之山

**大騩之山**是《山海经·[[中山经]]》中次一经所载的山，位于前山以东五十七里。山多瑾瑜之玉、麋玉。山上生有药草[[牛伤]]——形如榆，方茎苍伤，服之致厥但可御兵。山阳之处狂水出焉，西南流注于伊水，水中多[[三足龟]]，食之无大疾且可已肿。（004-003）

## 原文出处

《[[中山经]]》：

> 又东五十七里，曰大騩之山，多瑾瑜之玉，多麋玉。有草焉，其状如榆，方茎而苍伤，其名曰牛伤，其根苍文，服者为厥，可以御兵。其阳狂水出焉，西南流注于伊水，其中多三足龟，食者无大疾，可以已肿。
>
> （004-003）

## 玉的双重品级

大騩之山开篇即以玉定调：「多瑾瑜之玉，多麋玉」。瑾瑜是《山海经》中反复出现的高级美玉，被列为品质上乘、质地坚密的正统玉石；麋玉则较为少见，具体品类难以考证，但与瑾瑜并列说明大騩之山是一座高价值矿藏之地。

《西山经》中专门有一段对瑾瑜之玉的评语：「瑾瑜之玉为良，坚粟精密，浊泽有而色。五色发作，以和柔刚。天地鬼神，是食是飨；君子服之，以御为祥。」这意味着大騩之山所产的瑾瑜玉不仅是装饰品，而是具有沟通神灵、保佑君子的神圣器物。（004-003）

## 牛伤：御兵的毒草

[[牛伤]]是大騩之山最具争议性的物产——一种「以毒换护」的军事药草：

| 特征 | 描述 |
|------|------|
| 形态 | 状如榆，方茎苍伤 |
| 根部 | 苍文（青色纹路） |
| 服用后 | 为厥（昏厥） |
| 军事功效 | 可以御兵（防御兵器） |

「服者为厥」说明牛伤有强烈的神经毒性，服用导致昏厥。但「可以御兵」意味着同一毒草具有使身体抵御刀兵的效果。这种「致厥即御兵」的逻辑暗示：昏厥不是副作用，而是御兵的前提——身体进入异常状态（厥）才能获得超自然的物理防御力。

牛伤的名字本身也透露其性质：「苍伤」反复出现于形态描述（方茎苍伤、根苍文），「伤」字贯穿名与形，暗示这种草带着天然的创伤质感。（004-003）

## 三足龟：治病的祥瑞

与牛伤形成鲜明对比的是狂水中的[[三足龟]]——同样来自大騩之山，但药效截然不同：

| 特征 | 描述 |
|------|------|
| 栖息地 | 狂水中（发源于大騩之山阳） |
| 形态 | 三足 |
| 食用后 | 无大疾（不生大病） |
| 医疗功效 | 可以已肿（消肿） |

三足龟的药效是正向的，无副作用，对应日常医疗需求（防病消肿）。与牛伤的「致厥御兵」相对，三足龟的「无大疾已肿」是温和的健康保障。

「三足」是《山海经》异龟的标志性形态，三足龟在中国上古文化中具有祥瑞含义。大騩之山的三足龟以食疗形式出现，是异兽具有医疗功效这一《山海经》叙事模式的典型案例。（004-003）

## 双重药效的对称结构

大騩之山是《山海经》中极少数在单一山条内同时提供两种截然不同医疗用途的山峰：

| 药物资源 | 来源 | 使用方式 | 主要效果 | 副作用/代价 |
|---------|------|---------|---------|-----------|
| **牛伤** | 山上草 | 服（内服） | 御兵（军事防御） | 为厥（昏厥） |
| **三足龟** | 狂水中 | 食（内食） | 无大疾、已肿（医疗） | 无 |

这一对称并非偶然。中次一经的叙事重心之一是物产的实用性，而大騩之山恰好提供了军事用途与医疗用途各一的双重资源。牛伤指向战场，三足龟指向日常；牛伤有代价，三足龟无害处——两种药物构成一个完整的功能互补体系，使大騩之山成为中次一经中资源配置最为平衡的山峰之一。（004-003）

## 狂水与伊水的水系连接

大騩之山阳面出狂水，西南流注于伊水。伊水是中山经重要的水系基准，多座中山经山峰都与伊水产生水文联系。大騩之山通过狂水与伊水相连，将其三足龟的栖息地纳入中山经的水文网络之中。

「狂水」的水名本身颇为特别——以「狂」命名的水，在《山海经》中暗示水势急猛或具有异常属性。三足龟栖于狂水之中，以「狂」为家，本身就是一个意味深长的对比：祥瑞的三足龟选择了名为「狂」的水域为居所。（004-003）

## 在中次一经中的位置

中次一经以苦山为首，大騩之山居其中段。其前后山峰皆以丰富的药物、玉石和异兽著称，大騩之山的牛伤与三足龟延续了中次一经重视物产实用性的叙事传统。

## 「御兵」药效与山海经中的军事防护物

牛伤草「服之不厥，可以御兵」（004-003）属于《山海经》中一类特殊的军事防护类药效物产。这类物产的功能不是治病，而是在战斗中保护使用者：

| 物产 | 药效 | 代价 | 山名 | 出处 |
|------|------|------|------|------|
| **牛伤** | 御兵 | 为厥（昏厥） | 大騩之山 | 004-003 |
| [[迷榖]] | 佩之不迷 | 无 | [[招摇之山]] | 001-003 |
| [[蠪蚔]] | 可以御兵 | 无 | [[放皋之山]] | 001-009 |
| [[文鳐鱼]] | 可以御兵 | 无 | [[令丘之山]] | 001-012 |

大多数御兵物产无副作用，牛伤是罕见的「有代价的防护」——使用者获得刀枪不入的效果，但会陷入昏厥。这一设定暗示牛伤的御兵机制不是让身体变硬，而是让使用者进入无知觉的状态从而不被伤害所影响——一种以失去意识为代价的无敌状态。同山的三足龟「食之无大疾」则完全没有副作用，两种药效资源的有代价/无代价对比，使大騩之山成为《山海经》中「药效经济学」最精密的案例之一。
