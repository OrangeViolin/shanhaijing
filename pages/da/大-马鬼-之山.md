# 大【马鬼】之山

**大【马鬼】之山**是《山海经·[[中山经]]》中次七经（苦山之首）的末山。阴多铁、美玉、青垩。有草[[【上艹下狼】]]——服之不夭，可以为腹病。自休舆之山至于大【马鬼】之山，凡十九山，千一百八十四里。（005-088、005-089）

## 原文出处

### 中山经（山体）

> 又東三十里，曰大【馬鬼】之山，其陰多鐵、美玉、青垩。有草焉，其狀如蓍而毛，青華而不實，其名曰【上艹下狼】，服之不夭，可以爲腹病。
>
> （005-088）

### 中山经（总括）

> 凡苦山之首，自休輿之山至于大【馬鬼】之山，凡十有九山，千一百八十四里。其十六神者，皆豕身而人面。其祠：毛【牛全】用一羊羞，嬰用一藻玉瘞。苦山、少室、太室皆冢也，其祠之，太牢之具，嬰以吉玉。
>
> （005-089）

## 【上艹下狼】草

大【马鬼】之山的特产药草——长生且治腹：

| 属性 | 内容 |
|------|------|
| 形态 | 如蓍而有毛 |
| 花 | 青花不结实 |
| 药效一 | 服之不夭（不早死） |
| 药效二 | 可以为腹病（治腹疾） |

像蓍草但有绒毛——开青花不结果。吃了不早夭——还治肚子疼。双重药效——长寿+治病。青花不实——只开花不结果——但药效极强。（005-088）

## 阴面三宝

大【马鬼】之山的矿产——全在阴面：

| 矿物 | 位置 |
|------|------|
| 铁 | 阴 |
| 美玉 | 阴 |
| 青垩 | 阴 |

三种矿物都在山的北面——铁、美玉、青垩。青垩是青色的白垩土——可做颜料。阴面同时出金属（铁）、宝石（美玉）、颜料（青垩）——三类矿物齐聚。（005-088）

## 十九山之末

大【马鬼】之山是中次七经（苦山之首）十九山的终点：

| 要素 | 内容 |
|------|------|
| 首山 | 休舆之山 |
| 末山 | 大【马鬼】之山 |
| 总计 | 十九山 |
| 里程 | 千一百八十四里 |
| 冢山 | 苦山、[[少室之山]]、[[泰室之山]] |

十九山中三座是冢山——享太牢大祭。十六位山神豕身人面——三位冢山神人面三首。大【马鬼】之山作为末山——以药草收束整条经脉。（005-089）

## 中山経における「末山薬草」のパターン

大【马鬼】之山は中次七経十九山の末山であり、【上艹下狼】草（不夭＋治腹病）で山系を収束させる。中山経の末山に薬草が配置されるのは一つのパターンである：

| 経 | 末山 | 薬効物 | 効能 |
|----|------|--------|------|
| **中次七経** | **大【马鬼】之山** | **【上艹下狼】草** | **不夭・治腹病** |
| 中次一経 | 鼓鍾之山 | — | 金玉で終結 |
| 中次五経 | 囗举之山 | 肠之物 | 不明 |

【上艹下狼】草の「服之不夭」は長寿の薬効であり、山系の末尾に「死なない」薬草を配置することで、十九山の旅路が「不死」で閉じる構造を作る。中次七経は苦山・[[少室之山]]・[[泰室之山]]の三冢山を擁する格式高い山系であり、その末山に長寿草を置くのは、冢山の祭祀と不死の薬効が同一の生命観に基づくことを示唆する。（005-088、005-089）
