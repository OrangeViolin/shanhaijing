# 丹木

**丹木**是[[昆仑之丘]]上受[[玉膏]]灌溉的神木。每五年一个周期，花色由杂转清，气味由淡转馨，成为百神食物链中承上启下的关键一环。玉膏养丹木，丹木养百神，神圣生态从矿物到植物再到神灵，一脉相承。

## 原文出处

引注：（002-042）

> 其上多丹木，员叶而赤茎，黄华而赤实，其味如饴而不伤。
>
> （002-042）

同见：（002-042）

> 河水出焉……丹水出焉，西流注于稷泽，其中多白玉，是有玉膏，其原沸沸汤汤，黄帝是食是飨。是生玄玉……瑾瑜之玉为良……玉膏所出，以灌丹木，丹木五岁，五色乃清，五味乃馨。

另见：（002-080）

> 崦嵫之山……其上多丹木，其叶如谷，其实大如瓜，赤符而黑理。

丹木至少在两处出现。（002-042）是昆仑之丘的丹木，与玉膏形成完整的供养体系。（002-080）是[[崦嵫山]]的丹木，果实大如瓜，赤表黑纹，属性描述更偏实物。

## 形态特征

经文对丹木的描述包含两套系统：

### 昆仑丹木（002-042）

| 部位 | 特征 |
|------|------|
| 叶 | 圆叶（员叶） |
| 茎 | 赤色 |
| 花 | 黄色 |
| 果 | 赤色 |
| 味 | 如饴（甜），不伤身 |

### 崦嵫丹木（002-080）

| 部位 | 特征 |
|------|------|
| 叶 | 如谷（楮树叶形） |
| 果 | 大如瓜 |
| 表皮 | 赤底黑纹 |

两处丹木共享「赤」的底色，但形态差异明显。昆仑丹木是精致的神圣植物，崦嵫丹木更接近巨型果树。可能是同一物种在不同环境中的变异，也可能是同名异物。

值得注意的是，昆仑丹木的果实「其味如饴而不伤」（002-042），特别强调了「不伤」二字。在《山海经》的药物体系中，许多植物的食用功效都附带限定条件（食之不饥、食之不疫等），但「不伤」的表述独属丹木。这暗示丹木的甜味浓烈到需要特别说明它不会伤人，或者丹木外观如此接近某种有毒植物，需要明确标注其安全性。

## 五岁五色五味

（002-042）「丹木五岁，五色乃清，五味乃馨」是丹木最核心的属性。

「五岁」是一个完整的成熟周期。每五年丹木完成一次从生长到极盛的循环。「五色乃清」意为五种颜色变得纯净澄明，「五味乃馨」意为五种味道变得芬芳浓郁。五色对应五行（青赤黄白黑），五味对应五感（酸苦甘辛咸），丹木在成熟时聚合了天地间全部的色与味。

这个「五」不是随机数字，而是与天地五行的结构对应。丹木通过五年的吸收和转化，将玉膏中的精华凝聚为完整的五行之色和五行之味。它是矿物精华向生命精华的转化器。

## 玉膏到丹木到百神

丹木在昆仑生态链中处于中间位置：

玉膏（矿物精华）→ 灌溉丹木（植物转化）→ 五色清五味馨（完成态）→ 百神食飨

（002-042）明确记载「黄帝是食是飨」，[[黄帝]]亲自食用玉膏。而丹木受玉膏灌溉后结出的果实，「其味如饴而不伤」，也是可食的。这条从矿物到植物再到神灵的食物链，构成了昆仑之丘神圣性的物质基础。

神不是凭空存在的，神也需要吃东西。《山海经》对神圣生态的描述始终保持着唯物主义的底色：神力来源于特定的物质（玉膏），经过特定的转化（丹木），才能维持神灵的存在。

## 丹与丹水

丹木之「丹」与丹水之「丹」同出一源。（002-042）记载「丹水出焉」，丹水从昆仑流出。丹木生长在丹水之畔，受丹水和玉膏的双重滋养。「丹」的本义是朱砂的颜色，赤红色，在《山海经》中指向一种特定的矿物属性。丹木的赤茎赤实，正是这种矿物属性在植物体内的显现。

## 神木谱系中的位置

《山海经》记载了多种神木，各有不同的宇宙功能：

| 神木 | 功能 | 位置 |
|------|------|------|
| [[建木]] | 天地通道 | 都广之野 |
| [[扶桑]] | 十日栖息之所 | 东海之外 |
| [[若木]] | 日落之处 | 西极 |
| **丹木** | 玉膏转化器 | 昆仑之丘、崦嵫山 |
| [[不死树]] | 赋予不死 | 昆仑之丘 |

建木连接天地，扶桑和若木标定日出日落，不死树赐予永生。丹木的功能没有这些树那么戏剧性，但更为基础：它维持着神灵赖以存在的营养供给。没有丹木，昆仑的神圣生态链就会断裂。

## 两地丹木的地理意义

昆仑在西方之极，崦嵫山是日落之山（002-080），同样在极西。丹木只出现在西方，这不是偶然。「丹」属火色，火在五行中对应南方，但丹木却生长在西方。这种方位上的「错位」可能暗示丹木是西方大地对火元素的补偿：西方属金、属肃杀，丹木以火色植入金境，使西方不至于纯粹冷寂。

## 神话意义

丹木的价值不在于它自身，而在于它所连接的上下文。它是玉膏与百神之间的桥梁，是矿物精华转化为生命能量的中间站。没有丹木，玉膏只是一种矿物；有了丹木，玉膏变成了神灵的食物来源。

「五岁五色清五味馨」揭示了一个关键信息：神圣性需要时间。不是种下就能用，需要五年的积累和转化。《山海经》对神圣事物的描述从来不取消时间维度，即便是神木也需要遵循成熟的节律。这种对时间的尊重，让《山海经》的奇幻世界保留了一层朴素的真实感。
