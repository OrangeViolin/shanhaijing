# 大物

**大物**是[[大荒北经]]记载的[[附禺之山]]瑞兽，与[[小物]]成对出现。附禺之山是[[帝颛顼]]与九嫔的葬地，大物与小物是帝王墓域护卫生物群的一部分，以「大」「小」之名概括一切有形之物。（017-001）

## 原文出处

《[[大荒北经]]》：

> 爰有【丘鸟】久、文贝、离俞、鸾鸟、皇鸟、大物、小物。
> （017-001）

## 大物与小物：万物的二分

山海经中绝大多数生物都有具体的形态描述（如人面虎身、赤喙白尾），但大物和小物没有任何形态特征的记载。它们的名字就是全部的定义：一个大，一个小。

| 属性 | 大物 | [[小物]] |
|------|------|--------|
| 名称 | 大物 | 小物 |
| 形态 | 未记 | 未记 |
| 位置 | 附禺之山 | 附禺之山 |
| 性质 | 瑞物 | 瑞物 |

这种无形态的命名暗示大物和小物不是某种具体的动物，而是概念性的存在：它们代表「大的万物」和「小的万物」，是附禺之山上所有生灵的总称。帝王葬地需要万物护卫，大物和小物就是这种「万物皆来」的文字化表达。

## 附禺之山的护卫生物群

大物所在的附禺之山拥有山海经中最庞大的护卫生物列表：

| 类别 | 存在 |
|------|------|
| 鸟类 | 【丘鸟】久、鸾鸟、皇鸟、青鸟、[[琅鸟]]、玄鸟、黄鸟 |
| 兽类 | 虎、豹、熊、罴 |
| 蛇类 | 黄蛇 |
| 灵物 | [[视肉]]、琅玕、瑶碧、文贝 |
| 概括类 | **大物**、[[小物]] |

所有这些存在「皆出卫于山」，围绕帝颛顼的墓域形成护卫圈。大物和小物位于列表末尾，以「大小」二字兜底，将清单未及列举的一切生物都纳入护卫之中。

## 附禺之山的空间结构

大物栖息的附禺之山丘方圆三百里，是一个完整的帝王墓域：

| 方位 | 地物 |
|------|------|
| 丘上 | 帝颛顼与九嫔葬所 |
| 丘南 | [[帝俊]]竹林（大可为舟） |
| 竹南 | 封渊（赤泽水）、[[三桑无枝]] |
| 丘西 | 沈渊（颛顼所浴） |
| 丘上 | 护卫生物群（含大物、小物） |

大物作为护卫群的一员，与鸾鸟、虎豹、视肉等共同构成这座三百里大丘的生态。
