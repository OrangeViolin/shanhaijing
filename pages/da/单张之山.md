# 单张之山

**单张之山**是《山海经·[[北山经]]》北次一经所载的山峰。无草木。有异兽[[诸犍]]——豹形、人首、牛耳、一目，行走时衔着自己的尾巴。有药鸟白【夜鸟】，治咽痛又治【疒制】。[[栎水]]南流注于[[杠水]]。（003-012）

## 原文出处

《[[北山经]]》北次一经：

> 又北八百里，曰单张之山，其上无草木。有兽焉，其状如豹而长尾，人首而牛耳，一目，名曰诸犍，善吒，行则衔其尾。有鸟焉，其状如雉，而文首、白翼、黄足，名曰白【夜鸟】，食之已嗌痛，可以已【疒制】。栎水出焉，而南流注于杠水。
>
> （003-012）

## 诸犍

单张之山最奇异的存在——衔着尾巴走路的独目豹：

| 特征 | 描述 |
|------|------|
| 基本形 | 如豹，长尾 |
| 首 | 人首 |
| 耳 | 牛耳 |
| 目 | 一目 |
| 习性 | 善吒（善叫），行则衔其尾 |

「行则衔其尾」——走路的时候叼着自己的尾巴。这是《山海经》中最独特的行为描写之一。诸犍不是用尾巴飞（耳鼠），不是善于潜伏（孟极），不是笑着躺下（幽【安鸟】），它叼着自己的尾巴走路。一只独目的人面豹，长长的尾巴在嘴里。（003-012）

## 白【夜鸟】

单张之山的药鸟——一鸟双药效：

| 特征 | 描述 |
|------|------|
| 形态 | 如雉 |
| 首 | 文首（有花纹） |
| 翼 | 白翼 |
| 足 | 黄足 |
| 药效一 | 食之已嗌痛（治咽痛） |
| 药效二 | 可以已【疒制】（治痔疾） |

一只鸟治两种病——咽痛和【疒制】。《山海经》中大多数药用异兽只治一种病，白【夜鸟】是罕见的双药效药鸟。从咽喉到肛门，白【夜鸟】治的是人体管道两端的疾病。（003-012）

## 北八百里

单张之山与前山[[蔓联之山]]相距八百里——北次一经中最长的间距：

| 区间 | 间距 |
|------|------|
| 丹熏之山→石者之山 | 北二百八十里 |
| 石者之山→边春之山 | 北百一十里 |
| 边春之山→蔓联之山 | 北二百里 |
| **蔓联之山→单张之山** | **北八百里** |

八百里的跳跃——远远超过周围任何一段间距。这是一次突然的远距位移，仿佛北次一经在这里跳过了一大片空白的荒野。八百里的空白之后，出现了一座无草木的山，上面住着叼尾巴的独目豹。（003-011、003-012）

## 栎水入杠水

栎水南流汇入杠水——形成边春之山→单张之山的水系连锁：

| 山 | 水 | 去向 |
|----|-----|------|
| [[边春之山]] | [[杠水]] | 西流入【氵幼】泽 |
| **单张之山** | **[[栎水]]** | **南流入杠水** |

栎水汇入杠水，杠水汇入【氵幼】泽——单张之山虽然与边春之山隔了八百里，但水系依然相连。距离的断裂被水的流向弥合，栎水是那八百里空白中唯一的线索。（003-010、003-012）

## 「衔尾」行为：诸犍与山海经中的自体交互异兽

诸犍「行则衔其尾」是《山海经》中罕见的「自体交互」行为描写——异兽对自身身体部位的主动操作。大多数异兽的行为指向外部（善飞、善走、食人），诸犍的行为指向自身：

| 异兽 | 行为 | 交互对象 | 出处 |
|------|------|----------|------|
| **[[诸犍]]** | 行则衔其尾 | 自身尾巴 | 北次一经（003-012） |
| [[耳鼠]] | 以其尾飞 | 自身尾巴 | 北次三经（003-033） |
| [[天狗]] | 可以御凶 | 外部（凶邪） | 西次三经（002-027） |
| [[孟极]] | 善伏 | 外部（猎物/环境） | 北次一经（003-007） |

诸犍和耳鼠都以尾巴为行为核心——一个衔，一个飞。但耳鼠用尾巴实现超常功能（飞行），诸犍的衔尾却没有功能性解释。它不是为了飞、不是为了攻击、不是为了防御，它就是衔着。这种无功能的习性描写让诸犍成为《山海经》中最具「肖像感」的异兽之一：读者记住的不是它能做什么，而是它走路的样子。（003-012）
