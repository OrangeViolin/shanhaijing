# 南类之山

**南类之山**是《山海经·[[大荒南経]]》所载的山。遗玉——青马，三骓，[[视肉]]，甘华，百谷所在。五类物产齐备，山海経中最豊饒的山之一。（011-029）

## 原文出处

《[[大荒南経]]》：

> 有南类之山。爰有遗玉、青马、三骓、视肉、甘华。百谷所在。
>
> （011-029）

## 五类物产

南类之山的物产覆盖了古人需要的一切：

| 物产 | 类别 | 意义 |
|------|------|------|
| 遗玉 | 财宝 | 珍贵玉石 |
| 青马 | 交通 | 良马 |
| 三骓 | 交通 | 三色骏马 |
| [[视肉]] | 肉食 | 食之不尽的再生肉 |
| 甘华 | 果蔬 | 甘美之果 |
| 百谷 | 主食 | 所有谷物 |

财——交通，肉，果，粮，全都有了。山海経中同时具备这么多物产的山极少，南类之山像一座天然的仓库，什么都不缺。（011-029）

## 百谷所在

「百谷所在」在山海経中极其稀有——意味着所有谷物都在这里生长：

| 百谷产地 | 篇章 | 特征 | PN |
|----------|------|------|-----|
| **南类之山** | 大荒南経 | 百谷所在 | 011-029 |
| [[都广之野]] | 大荒南経 | 百谷自生冬夏播琴 | 011-032 |

两处「百谷」圣地都在大荒南経——相距不远。[[都广之野]]有[[后稷]]葬于此，百谷因圣人而生。南类之山没有圣人，百谷无因而在，纯粹的自然豊饒。不需要理由，不需要圣人，谷物自己就长在那里。（011-029、011-032）

## 与盖犹之山的物产共享

南类之山前面的盖犹之山也产青马、三骓、视肉：

| 物产 | 盖犹之山 | 南类之山 |
|------|----------|----------|
| 青马 | ✓ | ✓ |
| 三骓 | ✓ | ✓ |
| 视肉 | ✓ | ✓ |
| 遗玉 | — | ✓ |
| 甘华 | — | ✓ |
| 百谷 | — | ✓ |

两座山共享三种物产——南类之山在此基础上多出遗玉、甘华、百谷。像是同一个豊饒区域的两座山，盖犹之山是前奏，南类之山是高潮。大荒南経在这一段集中展示了南方的极致丰饶。（011-029）
