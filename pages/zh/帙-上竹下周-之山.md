# 帙【上竹下周】之山

**帙【上竹下周】之山**是《山海经·[[中山经]]》中次十一経所载的山。多松柏机柏——仅此而已。（005-151）

## 原文出处

《[[中山经]]》中次十一経：

> 又东北五十里，曰帙【上竹下周】之山，其上多松柏机柏。
>
> （005-151）

## 极简之山

一句话写完一座山——只有树木：

| 有 | 无 |
|----|-----|
| 松、柏、机柏 | 无矿产 |
| | 无异兽 |
| | 无水系 |

松柏和机柏都是常绿乔木——没有异兽、没有水系、没有矿产。这是中次十一経中最简洁的山之一。（005-151）

## 松柏之山

山海经中记载松柏的山不少——但大部分同时有矿产或异物。帙【上竹下周】之山只有松柏——是纯粹的树木山。三种都是坚木——松、柏、机柏——这座山的特征就是坚固的树。（005-151）
