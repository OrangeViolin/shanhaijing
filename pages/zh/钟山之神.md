# 钟山之神

**钟山之神**是《山海经·[[海外北経]]》所载的巨神。名烛阴（即[[烛龙]]）——人面蛇身赤色——视为昼瞑为夜——吹为冬呼为夏——身长千里。（008-003）

## 原文出处

《[[海外北経]]》：

> 钟山之神，名曰烛阴，视为昼，瞑为夜，吹为冬，呼为夏，不饮，不食，不息，息为风。身长千里。在无【綮糸换月】之东。其为物，人面，蛇身，赤色，居钟山下。
>
> （008-003）

## 身体即天象

烛阴的身体动作直接等于天象变化：

| 动作 | 天象 |
|------|------|
| 视（睁眼） | 昼 |
| 瞑（闭眼） | 夜 |
| 吹 | 冬 |
| 呼 | 夏 |
| 息 | 风 |

昼夜不是天体运行的结果——是一位神的眼皮开合。四季不是日照角度的变化——是一位神呼吸的方向。整个宇宙的时间节律寄托在一个身体上。（008-003）

## 不饮不食不息

烛阴「不饮，不食，不息」——不喝水、不吃东西、不呼吸。一个完全自足的存在——不需要从外部获取任何东西。但「息为风」——他不需要呼吸，可一旦呼吸就是风。不呼吸是常态——呼吸是例外——例外就是风。（008-003）

## 身长千里

山海经中最大的生物。千里——不是一座山的大小——是一条经脉的长度。人面蛇身赤色——红色的千里长蛇，顶着一张人脸。居钟山下——这座山装得下千里的身体。（008-003）

## 两部经文

烛阴在海外北经和[[大荒北経]]都有记载：

| | 海外北経 | 大荒北経 |
|--|---------|---------|
| 名 | 烛阴 | 烛龙 |
| 形态 | 人面蛇身赤色 | 人面龙身而无足 |
| 山 | 钟山 | 章尾山 |

蛇身和龙身——同一存在的两个版本。海外经和大荒经记载了同一素材的不同传承。
