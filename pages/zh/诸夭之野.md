**诸夭之野**，[[鸾鸟]]自歌，[[凤鸟]]自舞。皇卵，民食之；甘露，民饮之。所欲自从也。百兽相与群居。在四蛇北。

== 地理 ==

诸夭之野在四蛇北。

== 物产 ==

鸾鸟自歌，凤鸟自舞。有皇卵，民食之。有甘露，民饮之。所欲自从。百兽相与群居。其人两手操卵食之，两鸟居前导之。

== 語義 ==

「諸夭」は諸々の夭（若い・美しい）の意で、万物が若々しく生い茂る野を示す。海外西経に属する。

== 経路上の位置 ==

海外西経の地理配列：[[轩辕之国]]→[[穷山]]（四蛇が巡る丘）→**诸夭之野**（四蛇北）→[[龙鱼]]（夭野北）→[[白民之国]]→[[肃慎之国]]→[[长股之国]]。诸夭之野は穷山の四蛇の北に位置し、轩辕之国圏の楽園的空間。

「所欲自从」（欲するものが自ずと従う）は欲望が自然に満たされる理想郷の描写で、山海経における楽園類型の一つ。鸾鸟・凤鸟が前を導き、民が卵を食し甘露を飲むという構造は、人と瑞鳥が共生する祝福された空間を示す。

== 四蛇との関係 ==

「在四蛇北」の四蛇は、直前の[[穷山]]に記される「四蛇相繞」（四匹の蛇が丘を巡る）を指す。穷山は「不敢西射、畏轩辕之丘」（西に矢を射ることを恐れる）場所であり、四蛇が結界のように丘を囲む。その北に広がる诸夭之野は、この蛇の結界の向こうに存在する楽園として位置づけられる。
