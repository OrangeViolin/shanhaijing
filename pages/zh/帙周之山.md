# 帙周之山

**帙周之山**是《山海经·[[中山経]]》中次十一経所载的山。山上多松柏机柏——是一座以常绿针叶林为特征的山。（005-151）

## 原文出处

《[[中山経]]》：

> 又东北五十里，曰帙周之山，其上多松柏机柏。
>
> （005-151）

## 松柏机柏

帙周之山的全部记载只有一个信息——植被：

| 属性 | 内容 |
|------|------|
| 位置 | 支离之山东北五十里 |
| 植被 | 多松柏机柏 |
| 动物 | 无 |
| 水系 | 无 |
| 矿物 | 无 |

松——柏——机柏——三种常绿针叶树。没有兽、没有鸟、没有水、没有矿——只有密密的针叶林。帙周之山是中次十一経中记载最简的山——一座纯粹的松柏之山。（005-151）

## 前后山的对照

帙周之山夹在两座内容丰富的山之间：

| 山 | 特产 | PN |
|----|------|-----|
| [[支离之山]] | 济水源头·嬰勺鸟·牛·羊 | 005-150 |
| **帙周之山** | **松柏机柏（仅此）** | **005-151** |
| [[堇理之山]] | 松柏·美梓·丹·金·豹虎·青耕鸟 | 005-152 |

支离之山有水有鸟有兽——堇理之山有矿有兽有能御疫的青耕鸟——帙周之山只有松柏。它像一个安静的间隔——前后是喧闹的生态世界——中间是一片沉默的针叶林。（005-151）
