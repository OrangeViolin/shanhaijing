# 周饶国

**周饶国**是《山海经·[[海外南经]]》所载的邦国。国民身形短小，却冠带齐备——是《山海经》中唯一明确标注文明礼仪的异族。后世称为僬侥国。（006-021）

## 原文出处

《[[海外南经]]》：

> 周饶国在东，其为人短小，冠带。一曰周饶国在三首东。
>
> （006-021）

## 短小冠带

周饶国的核心矛盾——身体异于常人，文化却正统无缺：

| 特征 | 描述 |
|------|------|
| 身形 | 短小 |
| 装束 | 冠带 |

「冠带」是中华文明的标志——戴冠系带意味着遵守华夏礼制。《山海经》海外诸国大多以身体异形定义（三首、长臂、一目），周饶国是唯一在异形之外加注文明标记的国家。身体虽小，礼仪不缺——小人国却是大文明。（006-021）

## 异形国三连

周饶国夹在两个身体异变国之间：

| 国 | 异变 | 特征 |
|----|------|------|
| [[三首国]] | 一身三首 | 头的数量异常 |
| **周饶国** | **短小** | **体型异常 + 冠带** |
| [[长臂国]] | 长臂 | 臂的长度异常 |

三首（多头）→短小（矮身）→长臂（长手）——三个国家分别在头、身、臂上偏离常态。但异变的性质完全不同：三首国和长臂国是身体结构的变异，周饶国只是尺寸的缩小——形态正常，只是小。（006-021）

## 冠带的意义

在海外南经的异族序列中，「冠带」二字极为特殊：

| 国 | 文化标记 |
|----|---------|
| 三首国 | 无 |
| **周饶国** | **冠带** |
| 长臂国 | 捕鱼水中 |
| 结匈国 | 胸前结突 |

其他国家要么没有文化描述，要么以行为（捕鱼）定义。只有周饶国被赋予了「冠带」——这不是生存行为，是文明身份。《山海经》的作者特意告诉读者：别因为他们矮小就看低他们，他们是文明人。（006-021）

## 方位与别说

原文提供了两种定位——「在东」和「在三首东」：

| 定位 | 内容 |
|------|------|
| 主说 | 周饶国在东 |
| 别说 | 周饶国在三首东 |

「一曰周饶国在三首东」——别说精确了周饶国与三首国的相对位置。两种说法并存说明传本有异，但核心信息一致：周饶国在三首国的东面。（006-021）

## 后世传承

周饶国是后世小人国传说的源头：

| 文献 | 名称 | 描述 |
|------|------|------|
| 《山海经》 | 周饶国 | 短小，冠带 |
| 《列子》 | 僬侥国 | 人长三尺 |

从「短小」到「三尺」——后世给出了具体尺寸。「僬侥」成为中国古代小人族的通称，而它的原型就是《山海经》中这个冠带齐备的周饶国。（006-021）

## 海外经的「异形-文明」评价矩阵：周饶国作为唯一的异形文明国

海外经诸国可以按两个维度分类——身体是否异形、是否有文明标记。周饶国是唯一一个同时具备「异形」和「文明」双重标签的邦国：

| 邦国 | 身体 | 文明标记 | 类型 |
|------|------|---------|------|
| [[君子国]] | 正常 | 衣冠带剑，好让不争 | 正常+文明 |
| **周饶国** | **短小（异形）** | **冠带** | **异形+文明** |
| [[三首国]] | 一身三首（异形） | 无 | 异形+无文明 |
| [[长臂国]] | 长臂（异形） | 捕鱼（行为） | 异形+无文明 |
| [[交胫国]] | 交胫（异形） | 无 | 异形+无文明 |

[[君子国]]的文明标记建立在正常身体之上——符合常识。周饶国的文明标记建立在异形身体之上——这才是真正的信息：身体的大小不影响文明的高度。

海外经中大量异形国（三首、长臂、交胫、贯匈等）都只有身体描写，没有文化评价。周饶国的「冠带」二字打破了这个模式——编纂者刻意在异形描写之后补充了文明标记，仿佛在提醒读者：异形≠野蛮。周饶国是《山海经》对「身体决定文明」偏见的唯一一次明确反驳。（006-021）
