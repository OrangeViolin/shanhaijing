# 中车扁

**中【车扁】**是《山海经·[[大荒北経]]》所载的国。西北海外——流沙之东，颛顼之子。（017-027）

## 原文出处

《[[大荒北経]]》：

> 西北海外，流沙之东，有国曰中【车扁】，颛顼之子。
>
> （017-027）

## 颛顼之子

中【车扁】的核心信息是系谱——「颛顼之子」：

| 属性 | 内容 |
|------|------|
| 国名 | 中【车扁】 |
| 系谱 | [[颛顼]]之子 |
| 位置 | 西北海外，流沙之东 |

没有形态描写——没有食性，没有其他信息。只有位置和系谱。「颛顼之子」四字确立了这个国的正统性，它属于帝王血脉。（017-027）

## 颛顼系四方分布

大荒経中颛顼之子的邦国分布在四方：

| 国 | 篇章 | 方位 |
|----|------|------|
| **中【车扁】** | 大荒北経 | 西北海外 |
| 叔歜国 | 大荒北経 | 北方 |
| 季禺之国 | 大荒南経 | 南方 |
| [[淑士国]] | 大荒西経 | 西方 |

颛顼的后代遍布大荒四方——每个方向都有颛顼系邦国。中【车扁】是北方要素之一，与叔歜国共同构成大荒北経的颛顼系。（017-027）

## 前后文脉

中【车扁】处于大荒北経的一段密集叙述中——颛顼系与异族交替出现：

| 顺序 | 内容 |
|------|------|
| **中【车扁】** | 颛顼之子 |
| [[赖丘国]] | 仅有国名 |
| [[犬戎]]国 | 有神，人面兽身 |
| [[苗民]] | 有翼，颛顼之孙 |

颛顼之子→无名之国→兽身之神→颛顼之孙——从帝系到无系到异形再回帝系，叙述在正统与异族之间摆动。中【车扁】是这一摆动的起点。（017-027）
