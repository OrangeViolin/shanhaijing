# 中父之山

**中父之山**是《山海经·[[东山经]]》东次三经所载的山峰。无草木，多沙。需水行七百里才能到达，海上航行的荒漠之岛。（004-034）

## 原文出处

《[[东山经]]》东次三经：

> 又南水行七百里，曰中父之山，无草木，多沙。
>
> （004-034）

## 水行七百里

「又南水行七百里」，需要在水上行走七百里才能到达：

| 要素 | 内容 |
|------|------|
| 方向 | 南 |
| 交通方式 | 水行 |
| 距离 | 七百里 |

「水行」意味着这不是陆地上的山，需要乘船才能到达。中父之山可能是海上的岛屿或海岸边的砂山。东次三经大量使用「水行」来标注距离，这是一条海上的山经。（004-034）

## 八字极简

「无草木，多沙」，中父之山的全部描述只有八个字：

| 项目 | 有无 |
|------|------|
| 草木 | 无 |
| 沙 | 多 |
| 水系 | 无 |
| 异兽 | 无 |
| 矿产 | 无 |

没有水、没有兽、没有矿，只有沙。中父之山是《山海经》中信息密度最低的山之一。一座只有沙的山，甚至不能叫山，只是海上的一个沙丘。（004-034）

## 三山荒漠带

中父之山处于东次三经一段连续的荒漠地带中：

| 山 | 距离 | 描述 |
|----|------|------|
| 诸【钅句】之山 | 南水行七百里 | 无草木，多沙石，广员百里 |
| **中父之山** | **南水行七百里** | **无草木，多沙** |
| 胡射之山 | 东水行千里 | 无草木，多沙石 |

三座山连续无草木、多沙，东次三经在这里画出了一条漫长的荒漠海岸线。七百里→七百里→千里，水行距离越来越远，荒漠越来越深。中父之山是这条荒漠带的中心点。（004-033至004-035）

## 两片绿洲之间

荒漠三山被两座丰饶的山夹在中间：

| 山 | 性质 |
|----|------|
| 岐山 | 多桃李，多虎（丰饶） |
| **诸【钅句】→中父→胡射** | **荒漠三连** |
| 孟子之山 | 梓桐、桃李、麋鹿，广员百里（乐土） |

从桃李之山到荒漠三连再到百里乐土，东次三经的地景如同穿越沙漠：先是绿洲，然后是漫长的沙地，然后又是绿洲。中父之山是沙漠最深处的那个点。（004-032至004-036）
