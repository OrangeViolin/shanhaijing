# 颛顼国

**颛顼国**是《山海经·[[大荒南经]]》所载的邦国，以[[颛顼]]帝之名直接命国。生伯服，食黍。辖苕山、宗山、姓山、壑山、陈州山、东州山、[[白水山]]等七山，白水出焉生白渊，昆吾之师所浴也。（011-021）

## 原文出处

《[[大荒南经]]》：

> 有国曰颛顼，生伯服，食黍。有鼬姓之国。有苕山。又有宗山。又有姓山，又有壑山。又有陈州山，又有东州山。又有白水山，白水出焉，而生白渊，昆吾之师所浴也。
>
> （011-021）

## 以帝名命国

颛顼国是大荒经中唯一直接以帝名为国名的邦国——不是「颛顼之国」「颛顼之后」，而就叫「颛顼」：

| 其他颛顼系邦国 | 命名方式 |
|--------------|---------|
| [[颛顼之国]] | 「之国」后缀 |
| [[叔歜国]] | 以后裔命名 |
| [[北齐之国]] | 间接关联 |
| **颛顼国** | **帝名直接等于国名** |

帝名就是国名——这种命名方式意味着颛顼国不是颛顼的后裔之国，而是颛顼本人的领地。（011-021）

## 七山广域

颛顼国条下列举了七座山——这在大荒经邦国中极为罕见：

| 山名 | 描述 |
|------|------|
| 苕山 | 无 |
| 宗山 | 无 |
| 姓山 | 无 |
| 壑山 | 无 |
| 陈州山 | 无 |
| 东州山 | 无 |
| [[白水山]] | 白水出焉，白渊，昆吾之师所浴 |

前六山只有名字，白水山有详细记载。七座山的列举表明颛顼国不是一个小邦国，而是一个统辖广大山域的帝国——七山是其领土的骨架。（011-021）

## 伯服与食黍

颛顼国「生伯服，食黍」——两个关键信息：

| 信息 | 内容 | 含义 |
|------|------|------|
| 生伯服 | 颛顼生下伯服 | 系谱 |
| 食黍 | 以黍为主食 | 农业文化 |

伯服是颛顼的后代。食黍——黍是中国北方最古老的粮食作物，以黍为主食标志着颛顼国属于北方农耕文化圈。大荒南经中多个邦国记载饮食——食黍将颛顼国定位在以黍为粮的华北文化系统中。（011-021）

## 白渊与军团净身

颛顼国的白水山是全条最丰富的记述——白水出焉、生白渊、昆吾之师所浴也。白渊是昆吾氏军团的净身圣地——颛顼国境内不仅有帝王的领地，还有军事集团的祭祀空间。白渊作为颛顼国七山中唯一被具体描述的地标，是这片广域圣域的核心。（011-021）

## 大荒経の「帝名邦国」：颛顼国の直接命名が示す帝権の領土化

颛顼国は大荒経の邦国の中で帝名がそのまま国名となる唯一の例であり、山海経における帝と領土の関係の最も直接的な表現である：

| 邦国 | 命名方式 | 帝との距離 | 出処 |
|------|---------|----------|------|
| **颛顼国** | **帝名＝国名** | **直接同一** | **011-021** |
| [[颛顼之国]] | 帝名＋「之国」 | 所有格（帝の国） | — |
| [[叔歜国]] | 後裔名 | 間接（帝の子孫） | — |
| [[黒齿国]] | 身体特徴 | 無関係 | 008-003 |

「之国」という所有格すらなく、帝名がそのまま国名——これは「颛顼が統治する国」ではなく「颛顼そのものである国」を意味する。領土が帝の身体の延長として概念化されている。

七山の列挙も大荒経の邦国では破格である。通常の大荒経邦国は一条一山か山なしだが、颛顼国は七山を擁する広域国家として記述される。六山は名のみで白水山だけが詳述される構造は、七山の中に聖俗の階層があることを示す——[[白水山]]の白渊で「昆吾之師所浴也」（軍団が浄身する）記述は、颛顼国が祭祀空間と軍事空間を兼ねる帝権の拠点であったことを物語る。（011-021）
