# 长沙

**长沙**是《山海经·[[海内经]]》所载的地名。[[九嶷山]]在长沙[[零陵]]界中——[[舜]]葬于此。（018-024）

## 原文出处

《[[海内经]]》：

> 南方苍梧之丘，苍梧之渊，其中有九嶷山，舜之所葬，在长沙零陵界中。
>
> （018-024）

## 一条五地

这一条目密度极高——一句话里塞了五个地名：

| 地名 | 类型 |
|------|------|
| [[苍梧之丘]] | 丘 |
| 苍梧之渊 | 渊 |
| [[九嶷山]] | 山 |
| **长沙** | **行政区** |
| [[零陵]] | **行政区** |

从丘到渊到山到行政区——从自然地理到人文地理。苍梧是大的范围，九嶷山是具体的山，长沙零陵是行政界线——三层坐标逐步精确，最终把舜的葬地锁定在两个郡的交界处。山海经中最像地理志的一条。（018-024）

## 长沙与零陵

「在长沙零陵界中」——两个行政区的交界：

| 区 | 今地 |
|----|------|
| 长沙 | 湖南省长沙一带 |
| 零陵 | 湖南省永州一带 |

长沙在北，零陵在南——九嶷山在两者之间。「界中」是交界地带——舜葬在两个地区的边界上。这种行政地名的使用方式反映了汉代的郡县制——山海经的这一段可能是较晚加入的注释性文字。（018-024）

## 舜葬南方

舜葬在南方——远离中原：

| 要素 | 内容 |
|------|------|
| 方位 | 南方 |
| 地区 | 苍梧 |
| 具体位置 | 九嶷山 |

「南方苍梧之丘」——开篇就说南方。舜是北方的帝——禅让得位、巡狩天下——最终葬在南方最远的山里。从黄河流域到湘南——舜的死亡之旅跨越了整个中国。海内东经也说「湘水出舜葬东南陬」——舜的葬地和湘水相连，南方的大河从帝王墓旁流出。（018-024；014-012）
