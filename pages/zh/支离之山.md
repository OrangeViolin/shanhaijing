# 支离之山

**支离之山**是《山海经·[[中山経]]》中次十一経所载的山。济水南流注于汉——有婴勺——赤目赤喙白身——尾若勺。多【牛乍】牛、【羊咸】羊。（005-150）

## 原文出处

《[[中山経]]》中次十一経：

> 又东四十里，曰支离之山。济水出焉，南流注于汉。有鸟焉，其名曰婴勺，其状如鹊，赤目、赤喙、白身，其尾若勺，共鸣自呼。多【牛乍】牛，多【羊咸】羊。
>
> （005-150）

## 婴勺

婴勺是一只赤白二色的鸟：

| 属性 | 内容 |
|------|------|
| 形状 | 如鹊 |
| 眼 | 赤目 |
| 喙 | 赤喙 |
| 身 | 白身 |
| 尾 | 若勺（勺子形） |
| 鸣声 | 共鸣自呼（叫自己名字） |
| 预兆/药效 | 无 |

白色的身体——红色的眼和嘴——勺子形的尾巴。没有预兆——没有药效——是一只纯粹的异鸟。山海経的鸟通常「见则」或「食之」——婴勺什么都不是。（005-150）

## 毒鸟与瑞鸟之间

婴勺夹在两种极端的鸟之间：

| 山 | 鸟 | 性质 | PN |
|----|-----|------|-----|
| [[瑶碧之山]] | 鸩 | 毒鸟（恒食蜚） | 005-149 |
| **支离之山** | 婴勺 | 中性（无毒无药） | 005-150 |
| [[堇理之山]] | 青耕 | 瑞鸟（可以御疫） | 005-152 |

前面是毒鸟——后面是瑞鸟——中间是什么都不是的婴勺。从有害到中性到有益——中次十一経用三座山排出一条鸟的光谱。（005-149—005-152）

## 济水入汉

济水从支离之山发源——南流注于汉水。中次十一経的山属于汉水流域——支离之山的济水是汉水的上游支流之一。山上多【牛乍】牛【羊咸】羊——牧畜型的山——有水有牧——实用之地。（005-150）
