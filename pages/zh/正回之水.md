**正回之水**，出[[【马鬼】山]]，北流注于[[河]]。其中多[[飞鱼]]，状如豚而赤文，服之不畏雷，可以御兵。

== 地理 ==

正回之水出【马鬼】山，北流注于河。【马鬼】山上有美枣，阴有【王雩】【王孚】之玉。

== 物产 ==

水中多飞鱼，其状如豚而赤文。服之不畏雷，可以御兵。

== 語義 ==

「正回」は正しく回るの意で、水の流れが正しい道筋で回帰することを示す。正回之水は【马鬼】山から北流して河に注ぐ。中次三経の【上艹下负】山系に属する。

== 経路上の位置 ==

中次三経・【上艹下负】山系の山列：[[青要之山]]（又東十里）→**【马鬼】山**（又東十里）→[[宜苏之山]]（又東四十里）→[[和山]]（又東二十里）。正回之水は【马鬼】山から発する。【上艹下负】山系は全五山、四百四十里と短い山系だが、帝之密都（青要之山）や河之九都（和山）を含む神話的に重要な山列。

飞鱼は豚の形をした赤い模様の魚で、雷と兵の両方を防ぐ護身の霊魚。「服之」は食すのではなく身につけるの意で、護符としての使用を示唆する。同じ山系の前山[[青要之山]]には[[荀草]]（服すると美人になる草）があり、この山域に「服す」ことで効能を得る霊物が集中する。

== 【马鬼】山の物産 ==

【马鬼】山は「上有美枣、阴有【王雩】【王孚】之玉」と記される。美枣（良い棗）は山海経では珍しい記載で、食用果実としての実用性が高い。前山の[[青要之山]]は「帝之密都」（帝の秘密の都）で、【鬼申】武罗が司る神聖な山であり、【马鬼】山はその隣に位置する。
