# 诸犍

**诸犍**是《山海经·北次二经》中的异兽——「状如豹而长尾，人首而牛耳，一目，善吒，行则衔其尾」。豹的身体赋予敏捷，人首赋予智慧表征，牛耳增强听觉，独目集中视力。而它最独特的特征是行走时必须衔住自己的长尾，否则无法行动。

## 原文出处

引注：（003-012）

> 有兽焉，其状如豹而长尾，人首而牛耳，一目，名曰诸犍，善吒，行则衔其尾。

## 「衔尾而行」的独特性

《山海经》中绝大多数异兽的尾巴是武器或装饰，只有诸犍的尾巴是行动的障碍——长到必须衔在口中才能走路。这个缺陷与它的凶猛外表形成反差：

| 特征 | 暗示 |
|------|------|
| 豹身 | 速度与力量 |
| 人首 | 智慧 |
| 善吒 | 威慑力 |
| **衔尾而行** | **自我束缚** |

一个善吼叫的兽，却要用嘴衔住尾巴才能行走——吼叫与行走不可兼得。

## 神话意义

诸犍是《山海经》中罕见的「带缺陷的凶兽」。它的长尾既是形态标志也是功能障碍，暗示力量总伴随代价——善吒者不能边吼边走，长尾者必须以口代手。这种「天赋附带诅咒」的设计在《山海经》中并不多见。
