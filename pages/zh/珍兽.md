# 珍兽

**珍兽**是《山海经·[[海内北経]]》所载的[[林氏国]]之兽。大若虎——五采毕具——尾长于身——名曰[[驺吾]]——乘之日行千里。（013-017）

## 原文出处

《[[海内北経]]》：

> 林氏国有珍兽，大若虎，五采毕具，尾长于身，名曰驺吾，乘之日行千里。
>
> （013-017）

## 五采之兽

珍兽的外观极其华丽：

| 属性 | 内容 |
|------|------|
| 大小 | 若虎 |
| 色彩 | 五采毕具 |
| 尾 | 长于身 |
| 别名 | 驺吾 |

虎那么大——五色齐全——尾巴比身体还长。「五采毕具」——青赤黄白黑五色全部具备——山海経中色彩描述最华丽的兽。长尾暗示速度和力量——尾长于身的动物通常善于奔跑。（013-017）

## 日行千里

珍兽的核心能力是速度：

| 功能 | 效果 |
|------|------|
| 乘之 | 日行千里 |

不是食之治病——不是见之知吉凶——而是可以骑乘——一天跑一千里。山海経中的异兽多数功能是药效或预兆——珍兽的功能是交通工具——实用到极致。五色华丽+日行千里——又美又快——理想的坐骑。（013-017）

## 林氏国

珍兽属于林氏国——海内北経中的一个国家：

| 属性 | 内容 |
|------|------|
| 国 | 林氏国 |
| 宝物 | 珍兽（驺吾） |

一个国家以拥有一种兽为特征——「林氏国有珍兽」——这头兽是国宝级的存在。「珍兽」本身就是形容词——经文直接说它是珍贵的兽——不需要读者自己判断。（013-017）
