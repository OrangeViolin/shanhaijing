# 踵臼之山

**踵臼之山**是《山海经·[[中山经]]》中次十二经所载的山。无草木。（005-181）

## 原文出处

《[[中山经]]》中次十二经：

> 又东十里，曰踵臼之山，无草木。
>
> （005-181）

## 三字之山

踵臼之山的记载只有三个字——「无草木」。这是中次十二经四十八山中最简洁的记述：

| 要素 | 记载 |
|------|------|
| 矿产 | 无 |
| 草木 | 无草木 |
| 水系 | 无 |
| 兽鸟 | 无 |
| 灵物 | 无 |
| 兆应 | 无 |

没有金，没有玉，没有水，没有兽，没有鸟——甚至连草木都没有。踵臼之山被经文彻底清空了，只留下一个名字和「无草木」三个字。（005-181）

## 踵臼之名

「踵臼」——「踵」是脚跟，「臼」是石臼。踵臼可能描述山的形状——如同脚跟踩出的臼形凹坑，或山顶有臼状的凹地。这是一个纯粹的地形命名，没有植物、动物或矿物的修饰。（005-181）

## 矿山间的空隙

踵臼之山夹在两座矿产丰富的山之间：

| 山 | 矿产 | 灵物 |
|----|------|------|
| 大【马鬼】之山 | 赤金、砥石 | — |
| **踵臼之山** | **（空白）** | **—** |
| 历石之山 | 黄金、砥石 | [[梁渠]]（见则大兵） |

大【马鬼】之山有赤金和砥石，历石之山有黄金和砥石——前后两座山都富含矿产。踵臼之山在它们之间，什么都没有。更值得注意的是距离——踵臼之山距前山仅十里，这在中次十二经中是最短的间距。（005-181）

## 十里之近

「又东十里」——踵臼之山距离前一座山只有十里。中次十二经的山间距离通常在数十到数百里，十里是极近的：

| 区间 | 距离 |
|------|------|
| 声匈之山→大【马鬼】之山 | — |
| 大【马鬼】之山→**踵臼之山** | **十里** |
| **踵臼之山**→历石之山 | 东北七十里 |

十里之近——踵臼之山几乎贴着大【马鬼】之山。如此近的距离上出现一座完全空白的山，像是大山脚下的一个小突起——脚跟踩出的臼坑，恰如其名。（005-181）
