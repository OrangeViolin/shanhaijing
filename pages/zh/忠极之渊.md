# 忠极之渊

**忠极之渊**是《山海经·[[海内北経]]》所载的深渊。[[从极之渊]]的异名——深三百仞——[[冰夷]]（河伯）常居于此——人面乘两龙。（013-019）

## 原文出处

《[[海内北経]]》：

> 从极之渊深三百仞，维冰夷恒都焉，冰夷人面，乘两龙。一曰忠极之渊。
>
> （013-019）

## 河伯之渊

忠极之渊/从极之渊是冰夷的独占领地——水神的居所：

| 属性 | 内容 |
|------|------|
| 名 | 从极之渊（一曰忠极之渊） |
| 深 | 三百仞 |
| 居者 | 冰夷 |
| 冰夷形态 | 人面，乘两龙 |

「维冰夷恒都焉」——「维」强调唯一性——只有冰夷常居于此。三百仞的深渊——被一位人面双龙的水神独占。冰夷即后世传说中的河伯（黄河之神）。（013-019）

## 昆仑南方水系

忠极之渊处于海内北経的昆仑南方地理带中——与黄河源头密切相关：

| 顺序 | 内容 |
|------|------|
| 前 | 泛林方三百里（昆仑虚南） |
| **当** | **从极之渊/忠极之渊（冰夷居此）** |
| 后 | [[阳汗之山]]（河山其中）+[[凌门之山]]（河出其中） |

从昆仑南面的泛林→冰夷的深渊→黄河穿过的二山——叙述从昆仑出发——经过河神的居所——到达河水的物理通道。忠极之渊是昆仑与黄河之间的神话枢纽。（013-019）

## 「从极」与「忠极」

两个名字是音近的异写——含义微异：

| 名 | 可能含义 |
|----|----------|
| 从极 | 至于极处 |
| 忠极 | 忠于极处 |

无论哪种写法——「极」字表明这是世界的极限之处。三百仞深的渊——河神独居——极深之处只有神能抵达。（013-019）
