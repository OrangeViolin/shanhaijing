# 帙谷

**帙谷**是《山海经·[[中山経]]》中次六経[[【外疒内鬼】山]]西面的谷。多柳楮——有[[【令鸟】【要鸟】]]——丹火色赤身青喙——服之不眯。（005-059）

## 原文出处

《[[中山経]]》中次六経：

> 又西十里，曰【外疒内鬼】山，其阴多【王雩】【王孚】之玉。其西有谷焉，名曰帙谷，其木多柳楮。其中有鸟焉，状如山鸡而长尾，赤如丹火而青喙，名曰【令鸟】【要鸟】，其鸣自呼，服之不眯。
>
> （005-059）

## 丹火之鸟

帙谷中的【令鸟】【要鸟】是极其鲜艳的鸟：

| 属性 | 内容 |
|------|------|
| 体形 | 如山鸡，长尾 |
| 颜色 | 赤如丹火 |
| 喙 | 青色 |
| 鸣声 | 自呼其名 |
| 药效 | 服之不眯（食之明目） |

赤如丹火——不是普通的红——是烈焰般的红。配上青色的喙——红与蓝的极端对比。一只燃烧着的鸟——吃了它反而能让眼睛清明。丹火般鲜艳的鸟保护视觉——色彩与药效之间有内在逻辑。（005-059）

## 【外疒内鬼】山的四面

帙谷是【外疒内鬼】山西面的谷——整座山的四个方向各有不同：

| 方位 | 内容 |
|------|------|
| 阴（北面）| 多【王雩】【王孚】之玉 |
| 阳（南面）| 交觞之水出，南流注于洛 |
| 阴（北面）| 俞随之水出，北流注于谷水 |
| 西 | 帙谷（柳楮 + 【令鸟】【要鸟】） |

北面产玉——南面出水入洛——北面出水入谷水——西面是有鸟的绿谷。四个方向都有东西——但帙谷是唯一以植物和鸟类为特征的方向。在「无草木」的山接连出现的中次六経里——帙谷的柳树和楮树是罕见的绿色。（005-059）
