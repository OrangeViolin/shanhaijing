# 长垣

**长垣**是《山海经·[[海内東経]]》所载的地名。郁郅之长垣——[[泾水]]源头长城北山在其北方。北方边境防御设施的地名。（014-012）

## 原文出处

《[[海内東経]]》：

> 泾水出长城北山，山在郁郅长垣北，北入渭。戏北。
>
> （014-012）

## 边防地名

长垣——字面意思是「长的城墙」——是郁郅地区的防御设施：

| 属性 | 内容 |
|------|------|
| 所属 | 郁郅 |
| 含义 | 长城/城墙 |
| 功能 | 泾水源流域的方位标记 |

「长城北山」+「郁郅长垣」——两个防御性地名叠加——泾水源流域是军事边境。长垣标记了农耕世界与游牧世界的分界线——泾水从这条分界线的北面流出。（014-012）

## 泾水水系

长垣是泾水源头的定位基准：

| 要素 | 关系 |
|------|------|
| 泾水源 | 长城北山 |
| 山位置 | 郁郅长垣北 |
| 泾水流向 | 北入渭 |

泾水出长城北山——山在长垣北——泾水北入渭水。海内東経紧接着写「渭水出鸟鼠同穴山东注河入华阴北」——泾渭二水是关中平原的双河——一组记载。（014-012）
