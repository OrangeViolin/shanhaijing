**诸怀之水**，出[[北岳之山]]，西流注于[[嚣水]]。水中多[[【鱼旨】鱼]]，鱼身而犬首，音如婴儿，食之已狂。

== 地理 ==

诸怀之水出北岳之山，西流注于嚣水。北岳之山多枳棘刚木。

== 物产 ==

水中多【鱼旨】鱼，鱼身而犬首，其音如婴儿。食之已狂。山有兽名[[诸怀]]，状如牛而四角，音如鸣雁，食人。

== 語義 ==

「諸懐」は山に棲む食人獣[[诸怀]]と同名で、山名・水名・獣名が一致する。水が獣の名を冠するのは、この獣の棲む山から発する水であることを示す。北山経北次三経に属する。

== 経路上の位置 ==

北次三経の山列：[[狱法之山]]（又北二百里）→**北岳之山**（又北二里）→[[浑夕之山]]（又北百八十里）→[[北单之山]]（又北五十里）。诸怀之水は北岳之山から発し、西流して嚣水に注ぐ。嚣水はさらに下流の浑夕之山からも発して西流し海に注ぐ。

魚身犬首という形態は山海経の異魚の中でも独特で、犬の警戒心と魚の水棲性を合わせた姿。「音如嬰児」は山海経で頻出する異類の声の類型で、人間の幼児の泣き声に似る声は不気味さと霊験を同時に表す。

== 北岳之山の危険と恩恵 ==

北岳之山は食人獣の[[诸怀]]と薬効魚の[[【鱼旨】鱼]]を同時に産する。牛の形で四角、鳴雁の声の诸怀は山海経有数の食人獣であり、一方で水中の【鱼旨】鱼は狂疾を治す薬魚である。同じ山から危険と治癒が並存する構造は山海経の特徴的な世界観を示す。
