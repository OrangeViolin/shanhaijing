# 卑山

**卑山**是《山海经·[[中山经]]》中次十一经所载的山。山上多桃、李、苴、梓，又多【儽去亻】（一种树木）。无水系记载，无矿产，无异兽，以果树和实用材为全部物产。（005-167）

## 原文出处

《[[中山经]]》中次十一经：

> 又东四十里，曰卑山，其上多桃李苴梓，多【儽去亻】。
>
> （005-167）

## 中次十一经中的位置

卑山处于大孰之山与倚帝之山之间：

| 山 | 距离 | 特征 |
|----|------|------|
| 大孰之山 | 卑山西五十里 | 杀水出，东北注视水，多白垩 |
| **卑山** | **大孰之山东四十里** | **桃李苴梓** |
| 倚帝之山 | 卑山东三十里 | 多玉多金，有狙如（大兵兆兽） |
| 鲵山 | 倚帝之山东三十里 | 鲵水潜流，美垩金青丹 |

卑山上下两山：一座是水系山（大孰），一座是异兽山（倚帝）。卑山自身只有植物。（005-167）

## 四种植物

卑山的物产全为植物，分两类：

| 植物 | 类型 |
|------|------|
| 桃 | 果树 |
| 李 | 果树 |
| 苴 | 麻类，可得麻纤维 |
| 梓 | 用材树，木质优良 |

桃和李提供食物，苴提供纤维，梓提供建材和器材。这是一座以人类日常所需为主导的山食、用兼备。（005-167）

## 无水系的山

卑山没有任何水系记载在周围视水流域山群中是例外：

| 山 | 水系 |
|----|------|
| 大孰之山 | 杀水→视水 |
| **卑山** | **无** |
| 鲵山 | 鲵水潜流 |
| 雅山 | 澧水→视水 |

同一经中多数山都有水系，卑山是无水的孤岛。「多桃李苴梓」是这座山的全部记述简洁到极点。（005-167）

## 山名的含义

「卑」有低矮、谦卑之意。卑山的物产记述在中次十一经中是最朴素的无神兽、无矿石、无水系。山名「卑」与内容的低调一致。（005-167）
