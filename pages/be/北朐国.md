# 北朐国

**北朐国**是[[海内南经]]中记载的南方异族国家，与[[伯虑国]]、[[离耳国]]、[[雕题国]]同处郁水以南地带。四国合并叙述，无个别描写，但北朐国在四国中居末，且是后续[[枭阳国]]方位描述的空间基准。（010-005）

## 原文

《[[海内南经]]》：

> 伯虑国、离耳国、雕题国、北朐国皆在郁水南。郁水出湘陵南海。一曰相虑。
> 枭阳国在北朐之西。其为人人面长唇，黑身有毛，反踵，见人笑亦笑手操管。
> （010-005）

## 郁水南的四国格局

北朐国是郁水南四国之一，四国被一句话打包叙述："伯虑国、离耳国、雕题国、北朐国皆在郁水南"。这种集体叙述方式在山海经中不多见，通常意味着文献来源对这些国家缺乏详细信息，或者这些国家在地理认知中共属同一文化圈，以郁水南岸作为共同的地理标识。

郁水是本条记述的核心地理参照。海内南经明确"郁水出湘陵南海"，即郁水发源于湘陵，流入南海。《海内西经》另有一条记录："郁水出象郡，而西南注南海，入须陵东南"（来自后文的水系总汇），与本条"郁水出湘陵南海"可相互印证：郁水源出岭南腹地，向南注入南海，今天的西江、郁江流域与此吻合。

四国并立于郁水南岸，共享岭南的地理背景：

| 国名 | 文献中的特征 | 可能的对应族群 |
|------|------|------|
| [[伯虑国]] | 无独立描述 | 别名"相虑"，疑与百越有关 |
| [[离耳国]] | 无独立描述 | 以耳部特征（大耳、穿耳）命名，疑为百越诸部 |
| [[雕题国]] | 无独立描述 | "雕题"即纹面，与今越南、南亚纹面习俗相关 |
| **北朐国** | 无独立描述 | "朐"含弯曲之义，可能指身体特征或地名 |

## 北朐国作为枭阳国的方位基准

北朐国在四国中排列最末，且在文本中承担了特殊的功能：后文"枭阳国在北朐之西"以北朐为方位参照。在海内南经的叙述中，北朐是四国中唯一一个被用来定位其他国家的存在，由此获得超出共同叙述范畴的方位意义。

[[枭阳国]]的人"人面长唇，黑身有毛，反踵，见人笑亦笑手操管"，是海内南经中描述最为详细的异人形象之一。反踵（脚后跟朝前）是山海经南方异人的典型标志，此前已见于南方赣巨人（"反踵，见人笑亦笑"）。枭阳国与赣巨人的相似描述，显示海内南经对南方异人形象存在类型化的记录模式，而北朐国作为枭阳国的定位参照，将其纳入这一南方异人地理圈的中心。

## 嶺南地理序列中的位置

海内南经整体从海内东南陬（东南角）向西叙述，北朐国所在段落处于该章中部，前后地理序列如下：

| 条目 | 特征 |
|------|------|
| 三天子鄣山 | 在闽西海北，山体在海中 |
| 桂林八树 | 在番隅（今广州）以东 |
| 郁水南四国（含北朐国） | 郁水南岸诸族 |
| [[枭阳国]] | 北朐之西，反踵异人 |
| 兕 | 在舜葬东，湘水南，苍黑一角 |
| 苍梧之山 | 帝舜葬于阳，帝[[丹朱]]葬于阴 |
| [[穰窳]] | 龙首，居弱水中，食人 |
| 建木 | 在穰窳西弱水上 |

郁水南四国嵌入嶺南、闽越到苍梧（帝舜葬地）的地理序列，位于南中国海沿岸的民族地理记录带。北朐国与伯虑、离耳、雕题同处于这一南方民族带的核心地段，以郁水为界，与北方的汉文明世界相隔。

## 北朐之名的文字分析

"北朐"中的"朐"字，《说文解字》释为"曲"、"挛曲"之义，指弯曲、屈曲的状态。"朐"字从"月"（肉）从"句"，本义与肌肉弯曲相关。

作为国名，"北朐"可能有以下来源：

**身体特征说**：与周边"离耳"（耳部特征）、"雕题"（纹面特征）的命名方式类似，"北朐"或指该族具有某种弯曲的身体特征，如弓身习俗或体型特点。

**地名说**："朐"在先秦文献中亦见于地名，如"朐山"（今江苏连云港）、"朐县"，但海内南经的北朐国地处岭南，与山东海岸的朐地无直接关联，"北朐"的"北"可能是区别于南方更多朐系地名而加的方位词。

**方位补缀说**："北朐"的"北"字或指该国在某地理参照物以北，但郁水南的叙述语境使这一解读存疑。

## 郁水南与先秦南方民族史

海内南经对郁水南四国的记录，是先秦时期中原对岭南地区民族分布的宝贵地理文献。雕题（纹面）、离耳（大耳或穿耳）是有明确民族学对应的特征，与越南、泰国、缅甸等地的东南亚古民族习俗相吻合。北朐国与伯虑国（别名"相虑"，含"百越"之音）并列，处于百越诸族的地理范围之内。这四国的集体记录，折射出先秦地理志书面对南方民族时信息量有限、以族群标志代替详细描写的写作特点。
