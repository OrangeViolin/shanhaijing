# 杯木

**杯木**是《山海经·[[西山经]]》西次四经所载的神木。生于[[中曲之山]]「其状如棠，而员叶赤实，实大如木瓜，食之多力」。吃了它的果实就力气大增。（002-077）

## 原文出处

《[[西山经]]》西次四经：

> 有木焉，其状如棠，而员叶赤实，实大如木瓜，名曰杯木，食之多力。
>
> （002-077）

## 如棠而异

杯木以棠（海棠）为基础，加上独特的形态：

| 部位 | 特征 |
|------|------|
| 形 | 如棠 |
| 叶 | 员（圆） |
| 实 | 赤（红），大如木瓜 |
| 效 | 食之多力 |

棠是常见的果树杯木长得像棠，但叶是圆的、果是红的、果实有木瓜那么大。同样的树形，更大的果实、更鲜的颜色杯木是棠的强化版。（002-077）

## 食之多力

「食之多力」吃了力量增大：

| 效用 | 多力 |
|------|------|
| 类型 | 增强体力 |

不治病、不解毒、不延寿只管「力」。《山海经》中的药效植物各管各的功能有治疟的、有不劳的、有不蛊的杯木只管力气。一种木瓜大的红果，吃了就变有力这是最直接的效果。（002-077）

## 【马交】与杯木

杯木和同山的[[【马交】]]构成武力搭配：

| 名 | 类型 | 效用 |
|-----|------|------|
| [[【马交】]] | 兽（马形，虎牙爪） | 可以御兵 |
| **杯木** | **木（棠形，赤实）** | **食之多力** |

【马交】能防御兵器，杯木能增加力量御兵+多力，一守一攻。中曲之山是一座武装之山：兽管防御，木管力量。一座山把战士需要的两样东西都备齐了。（002-077）

## 中曲之山

杯木所在的中曲之山矿物丰富：

| 位置 | 产物 |
|------|------|
| 阳面 | 玉 |
| 阴面 | 雄黄、白玉、金 |
| 兽 | 【马交】 |
| 木 | 杯木 |

玉、雄黄、白玉、金四种矿物齐备。加上御兵之兽和多力之木中曲之山是西次四经中物产最丰富的山之一。（002-077）
