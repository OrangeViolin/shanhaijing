# 贲闻之山

**贲闻之山**是《山海经·[[北山经]]》北次三经所载的山峰。山上多苍玉，山下多黄垩和涅石。没有异兽、没有水系、没有草木纯粹的矿物之山。（003-050）

## 原文出处

《[[北山经]]》北次三经：

> 又东三百五十里，曰贲闻之山，其上多苍玉，其下多黄垩，多涅石。
>
> （003-050）

## 三矿

贲闻之山的三种矿物从贵到实用的垂直分布：

| 位置 | 矿物 | 用途 |
|------|------|------|
| 山上 | 苍玉 | 贵石（青色美玉） |
| 山下 | 黄垩 | 实用（黄色粘土，涂料） |
| 山下 | 涅石 | 实用（黑色染料石） |

苍玉在上，黄垩和涅石在下贵重的在高处，实用的在低处。这是一个微型的价值分层：山顶属于美和贵重，山脚属于实用和功能。（003-050）

## 色彩

三种矿物三种颜色：

| 矿物 | 颜色 |
|------|------|
| 苍玉 | 青/暗绿 |
| 黄垩 | 黄 |
| 涅石 | 黑 |

青→黄→黑从山顶到山脚，颜色越来越深沉。贲闻之山是一座从冷色到暖色到暗色的渐变之山。（003-050）

## 繁简交替

贲闻之山在北次三经中处于「繁-简」交替节奏的简拍位置：

| 山 | 内容量 | 记载 |
|----|--------|------|
| [[阳山]] | 繁（三兽一水） | 领胡、象蛇、囗父之鱼、留水 |
| **贲闻之山** | **简（三矿）** | **苍玉、黄垩、涅石** |
| 王屋之山 | 中（一水一矿） | 【氵联】水入泰泽，多石 |

阳山有三种异生物加一条河信息极密。贲闻之山只有三种矿物信息极疏。北次三经在这里用一座纯矿物的山来制造节奏上的休止从热闹的生命之山到安静的石头之山。（003-049至003-051）

## 纯粹

贲闻之山没有任何非矿物的记载：

| 项目 | 有无 |
|------|------|
| 草木 | 无 |
| 水系 | 无 |
| 异兽 | 无 |
| 异鸟 | 无 |

没有生命的痕迹贲闻之山上只有石头。苍玉、黄垩、涅石一座山被简化成了三种矿物标本。在满是异兽异鸟的北次三经中，贲闻之山是一个纯粹的地质节点。（003-050）
