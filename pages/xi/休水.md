**休水**，出[[少室之山]]，北流注于[[洛]]。其中多[[【鱼帝】鱼]]，状如囗【虫隹】而長距，足白而対，食者無蛊疾，可以御兵。

== 地理 ==

休水出少室之山，北流注于洛。少室之山百草木成囷。

== 物产 ==

水中多【鱼帝】鱼，食者無蛊疾，可以御兵。山有木名[[坏木]]，五衢，黄華黒実，服者不怒。

== 語義 ==

「休」は休息・吉祥の意。少室之山から発し北流して洛水に注ぐ河川。中次七経の水系に属する。

== 経路上の位置 ==

中次七経において：[[半石之山]]（又東七十里）→[[少室之山]]（又東五十里）→[[泰室之山]]（又東三十里）。休水は少室之山から発する主要水系で、北流して[[洛]]に合流する。同じ少室之山には坏木（五衢、黄華黒実、服者不怒）も産し、山全体が百草木成囷（草木が倉のように茂る）と記される豊穣の山である。

「足白而対」は魚でありながら足をもつ異魚の典型で、水陸両棲の性質を暗示する。「無蛊疾、可以御兵」という二重の防御薬効は、蛊毒（呪術的毒）と兵禍（物理的暴力）の両方を退ける護身の力を示す。

== 洛水支流としての位置づけ ==

中次七経では複数の河川が洛水に注ぐ。[[谢水]]（瞻諸之山より東南流注于洛）、[[交觴之水]]（【外疒内鬼】山より南流于洛）、休水（少室之山より北流注于洛）と、洛水は中次七経の主要集水域として機能している。
