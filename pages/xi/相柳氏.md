# 相柳氏

**相柳氏**是《山海经·[[海外北経]]》所载的[[共工]]之臣。九首——蛇身——面青。以食于九山——所到之处变为泽溪。[[禹]]杀之——血腥不可树五谷种——禹筑众帝之台以镇之。（008-006）

## 原文出处

《[[海外北経]]》：

> 共工之臣曰相柳氏，九首，以食于九山。相柳之所抵，厥为泽溪。禹相柳，其血腥，不可以树五谷种。禹厥之，三仞三沮，乃以为众帝之台。在昆仑之北，柔利之东。相柳者，九首人面，蛇身面青。不敢北射，畏共工之台。台在其东。台四方，隅有一蛇，虎色，首冲南方。
>
> （008-006）

## 九首食九山

相柳的九个头在九座山上进食——身体横跨国土规模：

| 属性 | 内容 |
|------|------|
| 身份 | 共工之臣 |
| 首数 | 九 |
| 面 | 人面 |
| 身 | 蛇身 |
| 面色 | 青 |
| 食域 | 九山 |

九个头各吃一座山——不是一座山上吃东西——而是九座山同时被吃。一个生物覆盖九座山——这是山海経中体量最大的存在之一。蛇身九首——每个首都是人面青色——九张青色的人脸。（008-006）

## 禹杀相柳

禹杀相柳的过程充满困难：

| 阶段 | 事件 |
|------|------|
| 杀 | 禹杀相柳 |
| 血腥 | 不可树五谷种 |
| 掘地 | 三仞三沮（三次掘三次崩） |
| 最终 | 筑众帝之台 |

杀了还不算完——血流出来——腥到五谷都种不了——大地被毒血污染。禹挖了三次——塌了三次——最后索性在上面筑台。毒血→不毛→掘地失败→建台——从破坏到建设的转换。杀一个怪物——代价是一片废土变成一座祭台。（008-006）

## 共工体系

相柳是共工体系的核心成员——共工的破坏力通过相柳具体化：

| 角色 | 功能 | 破坏方式 |
|------|------|----------|
| [[共工]] | 主 | 触不周山、洪水 |
| **相柳** | 臣 | 蹂躏大地、血污不毛 |

共工触山引发天倾——是宇宙级的破坏。相柳食九山——是大地级的蹂躏。主管天——臣管地——上下配合。禹治水制共工——杀相柳净地——水治理与地净化是一对行为。（008-006）

## 方位

相柳和众帝之台的地理位置：

| 地标 | 方位 |
|------|------|
| 昆仑 | 南 |
| 柔利 | 西 |
| 共工之台 | 北（不敢北射） |
| 众帝之台 | 东 |

在昆仑之北、柔利之东。不敢北射——因为畏惧共工之台。台在其东——四方形——四角各有一蛇——虎色——首冲南方。蛇色如虎——蛇身的相柳死后——台上还有蛇——蛇的意象贯穿始终。（008-006）
