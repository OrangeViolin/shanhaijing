# 枭谷

**枭谷**是《山海经·[[中山经]]》中次二经所载的谷地，位于泰威之山内部。谷中多铁。（005-008）

## 原文出处

《[[中山经]]》中次二经：

> 又东七十里，曰泰威之山。其中有谷，曰枭谷，其中多铁。
>
> （005-008）

## 山中有谷

《山海经》通常记载山和水，山中有命名谷地的情况极为罕见：

| 谷 | 所在山 | 特产 |
|----|--------|------|
| **枭谷** | **泰威之山** | **铁** |
| [[机谷]] | 首山（阴面） | 【鸟大】鸟 |

枭谷和机谷是《山海经》中仅有的几个被单独命名的山中谷地。机谷在首山北面，产药效鸟；枭谷在泰威之山中，产铁——一谷产生物，一谷产矿物。（005-008）

## 枭之名

「枭」是猫头鹰——古代被视为凶鸟：

| 要素 | 内容 |
|------|------|
| 枭 | 猫头鹰 |
| 象征 | 凶鸟、暗夜 |
| 谷名 | 枭谷 |

以凶鸟命名的谷——暗示这是一个幽深阴暗的所在。铁矿藏在凶鸟之谷的深处——暗谷产暗铁。铁在《山海经》中出现频率远低于金银铜，枭谷是罕见的铁矿记录之一。（005-008）

## 三山矿物带

枭谷位于中次二经一个连续三山的矿物带中：

| 山 | 矿物 | 间距 |
|----|------|------|
| 金星之山 | 天婴（如龙骨，已痤） | — |
| **泰威之山（枭谷）** | **铁** | **东七十里** |
| 囗谷之山 | 赤铜 | 东十五里 |

天婴（药石）→铁→赤铜——三座山各产不同的矿物。金星之山的天婴可以治疮（已痤），是药用矿物；枭谷的铁是工业矿物；囗谷之山的赤铜是金属矿物——从药到铁到铜，矿物的用途从治病到制器递变。（005-008）

## 泰威之山

泰威之山的全部记载只有一句——「其中有谷，曰枭谷，其中多铁」：

| 要素 | 记载 |
|------|------|
| 山上 | 无 |
| 山下 | 无 |
| 水系 | 无 |
| 草木 | 无 |
| **谷** | **枭谷，多铁** |

泰威之山没有阳面阴面的矿产描述，没有水系，没有草木——整座山的全部意义被压缩到了谷中。泰威之山存在的唯一理由就是枭谷——山是谷的外壳，谷是山的核心。（005-008）
