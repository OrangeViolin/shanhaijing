# 夏州之国

**夏州之国**是《山海经·[[大荒东经]]》所载的邦国，与盖余之国并列记载。无系谱、无描述。（015-031）

## 原文出处

《[[大荒东经]]》：

> 有夏州之国。有盖余之国。
>
> （015-031）

## 极简双国

夏州之国与盖余之国以最简洁的方式并列——各用五字，没有任何附加信息：

| 国名 | 系谱 | 姓氏 | 饮食 | 描述 |
|------|------|------|------|------|
| **夏州之国** | 无 | 无 | 无 | 无 |
| 盖余之国 | 无 | 无 | 无 | 无 |

这是大荒东经中信息量最低的邦国记载——只知道它们存在，其他一无所知。（015-031）

## 夹在详述之间

夏州之国的特殊之处在于它的位置——夹在两段详细记述之间：

| 行 | 条目 | 信息量 |
|----|------|--------|
| 前 | [[黑齿之国]] | 帝俊生黑齿、姜姓、黍食、使四鸟 |
| **中** | **夏州之国、盖余之国** | **仅国名** |
| 后 | [[天吴]] | 八首人面、虎身十尾 |

黑齿之国有完整的系谱（帝俊之后）、姓氏（姜姓）、饮食（黍食）和神使（四鸟）。天吴是八首十尾的壮观神人。两段丰富的记述之间，夏州之国和盖余之国如同两个空白的留白——它们的极简与前后的丰富形成强烈反差。（015-031）

## 夏州之名

「夏州」——夏朝的州域。「夏」是中国第一个王朝的名号，「州」是行政区域。以「夏州」命名东方大荒中的邦国，暗示中原的政治地理概念被投射到了远方——也许这个国是夏人后裔在东方的遗民，也许只是编纂者用中原的地名去标记未知的远方。（015-031）

## 大荒东经的多族世界

夏州之国处于大荒东经一段密集的邦国列举区间：嬴土之国→黑齿之国→夏州之国→盖余之国→天吴。这些邦国来源多元：嬴土可能指秦人先祖之地，黑齿是帝俊系后裔，夏州指向夏人。东方大荒中聚集了来自不同氏族谱系的邦国——这里不是某一族群的领地，而是多族混居的边境世界。（015-031）
