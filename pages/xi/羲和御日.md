# 羲和御日

**羲和御日**是《山海经》中太阳运行的神话解释。[[羲和]]每日在[[东海]]甘渊为太阳沐浴，然后驾六龙之车将太阳送上天空——日出不是自然现象，而是一位母亲的日常工作。

## 原文出处

引注：（011-026）

> 东海之外，甘水之间，有羲和之国。有女子名曰羲和，方日浴于甘渊。羲和者，帝俊之妻，生十日。

引注：（009-011）

> 汤谷上有扶桑，十日所浴，在黑齿北。居水中，有大木，九日居下枝，一日居上枝。

## 事件描述

[[羲和]]居于[[东海]]之外甘水之间的「羲和之国」，她是[[帝俊]]之妻，生育了十个太阳。[[十日]]栖居于[[扶桑]]神木之上：九日居下枝待命，一日升上枝当值。羲和的工作包含两个环节：

1. **浴日**：在甘渊中为当值的太阳沐浴，恢复其光热——如同擦亮一面每日蒙尘的铜镜
2. **御日**：驾驭六龙之车载日从东方升起，横跨天穹，至西方[[崦嵫山]]降落

「方日浴于甘渊」——原文定格了「正在进行」的瞬间，与[[常羲浴月]]的「此始浴之」形成呼应。《山海经》善于捕捉神话的日常态而非戏剧态。

## 十日轮值制度

十日体系是《山海经》天文神话的核心设计：

| 要素 | 描述 |
|------|------|
| 数量 | [[十日]]（构成一旬，太阳历基本单位） |
| 栖所 | [[扶桑]]神木，位于东海汤谷 |
| 分工 | 九日居下枝休息，一日居上枝当值 |
| 维护 | 羲和每日浴日恢复光热 |
| 运输 | 六龙车载日从东到西 |
| 终点 | [[崦嵫山]]（日落之处） |

这一制度的精妙之处在于：太阳不是一个而是十个，日出日落不是天体自转而是轮班制度。当这套轮值制度崩溃——十日同时升空——就触发了[[后羿射日]]的灾难。

## 从东到西：太阳的一天

羲和御日勾勒了太阳的完整日程——从东方甘渊出发，到西方崦嵫山结束。沿途经过的地理节点构成《山海经》的太阳之路：

| 时段 | 地点 | 事件 |
|------|------|------|
| 黎明前 | 甘渊 | 羲和浴日 |
| 日出 | [[扶桑]] | 日从上枝出发 |
| 日行 | 天穹 | 六龙车载日横渡 |
| 日落 | [[崦嵫山]] | 日入崦嵫 |
| 夜间 | [[扶桑]]下枝 | 归栖等候 |

这条路线从东海到西极，横贯《山海经》的整个地理空间。太阳不是在空中循环，而是每天走一条单程线路——日出是出发，日落是抵达。

## 羲和的劳作——最被忽视的创世行为

在《山海经》的神话体系中，许多英雄事迹是一次性的（[[女娲补天]]、[[后羿射日]]、[[大禹治水]]），而羲和御日是日复一日的。每一个日出都是羲和的一次劳作——一年三百六十五次浴日、三百六十五次驾车。这种重复性劳动在叙事上不如一次性的壮举引人注目，却是宇宙运转的根基。

| 行为 | 次数 | 性质 |
|------|------|------|
| [[女娲补天]] | 一次 | 危机应对 |
| [[后羿射日]] | 一次 | 危机应对 |
| **羲和御日** | **每日** | **日常维护** |
| [[常羲浴月]] | 每月 | 日常维护 |

英雄的一次性壮举解决危机，羲和的日常劳作维持秩序。没有羲和的每日浴日，就没有秩序可以崩溃，也就没有英雄的用武之地。

## 神话意义

**秩序依赖于恪尽职守**：十日轮值制度的运转依赖于两个条件——九日自觉在下枝等待、羲和每日按时浴日御日。当前者失效（十日并出），灾难发生。这暗示宇宙秩序不是天然稳定的，而是需要持续维护的——正如人间秩序需要治理者的日复一日的劳作。

**从正常到灾难**：羲和御日描述的是常态，[[后羿射日]]描述的是失序。《山海经》先建立秩序的蓝图，再描写秩序的崩溃，使灾难获得了叙事深度。没有羲和御日的「日常」，后羿射日的「非常」就失去了参照系。

**母亲的宇宙**：日月运行由两位母亲掌管——[[羲和]]御日，[[常羲]]浴月。宇宙最基本的时间节律是母性劳动的产物。在一个充满争斗（[[黄帝战蚩尤]]）、窃取（[[鲧窃息壤]]）、反抗（[[刑天舞干戚]]）的文本中，羲和御日是最安静的页面——没有冲突，只有一位母亲在做她每天都做的事。
