# 羲和御日

**羲和御日**是《山海经》中太阳运行的神话解释。[[羲和]]每日在[[东海]]甘渊为太阳沐浴，然后驾六龙之车将太阳送上天空。日出不是自然现象，而是一位母亲的日常工作。

## 原文出处

引注：（011-026）

> 东海之外，甘水之间，有羲和之国。有女子名曰羲和，方日浴于甘渊。羲和者，帝俊之妻，生十日。

引注：（009-011）

> 汤谷上有扶桑，十日所浴，在黑齿北。居水中，有大木，九日居下枝，一日居上枝。

## 十日轮值与御日之程

[[羲和]]居于[[东海]]之外甘水之间的「羲和之国」，她是[[帝俊]]之妻，生育了十个太阳。[[十日]]栖居于[[扶桑]]神木之上：九日居下枝待命，一日升上枝当值。羲和的工作包含两个环节：

1. **浴日**：在甘渊中为当值的太阳沐浴，恢复其光热，如同擦亮一面每日蒙尘的铜镜
2. **御日**：驾驭六龙之车载日从东方升起，横跨天穹，至西方[[崦嵫山]]降落

「方日浴于甘渊」定格了「正在进行」的瞬间，与[[常羲浴月]]的「此始浴之」形成呼应。《山海经》善于捕捉神话的日常态而非戏剧态。

十日体系的核心设计如下：

| 要素 | 描述 |
|------|------|
| 数量 | [[十日]]（构成一旬，太阳历基本单位） |
| 栖所 | [[扶桑]]神木，位于东海汤谷 |
| 分工 | 九日居下枝休息，一日居上枝当值 |
| 维护 | 羲和每日浴日恢复光热 |
| 运输 | 六龙车载日从东到西 |
| 终点 | [[崦嵫山]]（日落之处） |

太阳不是一个而是十个，日出日落不是天体自转而是轮班制度。当这套轮值制度崩溃，十日同时升空，就触发了[[后羿射日]]的灾难。

## 太阳的一日路线

羲和御日勾勒了太阳的完整日程，从东方甘渊出发到西方崦嵫山结束。沿途经过的地理节点构成《山海经》的太阳之路：

| 时段 | 地点 | 事件 |
|------|------|------|
| 黎明前 | 甘渊 | 羲和浴日 |
| 日出 | [[扶桑]] | 日从上枝出发 |
| 日行 | 天穹 | 六龙车载日横渡 |
| 日落 | [[崦嵫山]] | 日入崦嵫 |
| 夜间 | [[扶桑]]下枝 | 归栖等候 |

这条路线从东海到西极，横贯《山海经》的整个地理空间。太阳不是在空中循环，而是每天走一条单程线路：日出是出发，日落是抵达。

## 羲和之国的地理位置

「东海之外，甘水之间」——羲和之国在东海以外更远处，甘水（甘渊）之间。这个位置与[[扶桑]]所在的「汤谷」方向一致，都在《山海经》地理轴线的东端极点。

羲和之国是日月体系的东方锚点，对应西端的[[崦嵫山]]（日落之所）。东西两个极点之间，是太阳每日横渡的路径。[[帝俊]]的另一位妻子[[常羲]]也居于东方，「生月十有二」，月亮的轮值体系与太阳平行运作。

## 秩序崩溃：从常态到灾难

羲和御日体系存在两个失效节点：

**一：十日不听调度**。若十日不服从轮值规则，同时升上天空，则系统崩溃。这正是[[后羿射日]]灾难的根源。[[女丑]]以身祈天、被十日炙杀，是灾难中最早的人间受难者。[[羿]]最终射落九日，恢复了单日当值的秩序。但从十日变为一日，体系本身也发生了不可逆的收缩。

**二：羲和怠于浴日**。《尚书·胤征》记载「羲和湎淫，废时乱日」，贵州帝颛顼遣胤侯征讨羲和，因其不尽浴日御日之职。《山海经》中并无此记载，但两个文本共享同一神话前提：日出的秩序依赖羲和的尽职，失职即乱时。

| 失效情形 | 起因 | 后果 |
|---------|------|------|
| 十日同升 | 十日自主决定 | 旱灾，羿射日 |
| 羲和怠职 | 羲和失职 | 历法乱，时序乱 |

## 神话意义

**日常维护即创世**。在《山海经》的神话体系中，许多英雄事迹是一次性的（[[女娲补天]]、[[后羿射日]]、[[大禹治水]]），而羲和御日是日复一日的。每一个日出都是羲和的一次劳作，一年三百六十五次浴日、三百六十五次驾车。这种重复性劳动在叙事上不如壮举引人注目，却是宇宙运转的根基。

| 行为 | 次数 | 性质 |
|------|------|------|
| [[女娲补天]] | 一次 | 危机应对 |
| [[后羿射日]] | 一次 | 危机应对 |
| **羲和御日** | **每日** | **日常维护** |
| [[常羲浴月]] | 每月 | 日常维护 |

英雄的一次性壮举解决危机，羲和的日常劳作维持秩序。没有羲和的每日浴日，就没有秩序可以崩溃，也就没有英雄的用武之地。

**秩序依赖于恪尽职守**。十日轮值制度的运转依赖于两个条件：九日自觉在下枝等待、羲和每日按时浴日御日。当前者失效（十日并出），灾难发生。宇宙秩序不是天然稳定的，而是需要持续维护的，正如人间秩序需要治理者的日复一日的劳作。

**从正常到灾难**。羲和御日描述的是常态，[[后羿射日]]描述的是失序。《山海经》先建立秩序的蓝图，再描写秩序的崩溃，使灾难获得了叙事深度。没有羲和御日的「日常」，后羿射日的「非常」就失去了参照系。

**母亲的宇宙**。日月运行由两位母亲掌管：[[羲和]]御日，[[常羲]]浴月。宇宙最基本的时间节律是母性劳动的产物。在一个充满争斗（[[黄帝战蚩尤]]）、窃取（[[鲧]]窃息壤）、反抗（[[刑天]]舞干戚）的文本中，羲和御日是最安静的页面。没有冲突，只有一位母亲在做她每天都做的事。
