# 西胡

**西胡**是《山海经·[[海内东经]]》所载的地名。作为西北方的地理座标基准点，串联大夏、白玉山、苍梧、昆仑虚、昆仑山等西方地标。昆仑山在西胡之西。（014-005）

## 原文出处

《[[海内东经]]》：

> 西胡白玉山在大夏东，苍梧在白玉山西南，皆在流沙西，昆仑虚东南。昆仑山在西胡西。皆在西北。
>
> （014-005）

## 七地物一条

一条经文中串联了七个地名，用多重方位关系连接：

| 地物 | 方位关系 |
|------|---------|
| [[大夏]] | 基准（最西） |
| 白玉山 | 在大夏东 |
| 苍梧 | 在白玉山西南 |
| 流沙 | 诸地皆在流沙西 |
| 昆仑虚 | 诸地皆在昆仑虚东南 |
| [[昆仑山]] | 在西胡西 |
| **西胡** | **昆仑山以东** |

七个地名像一张网——每个地名都用方位关系锚定其他地名的位置。「皆在西北」——最后一句总括，所有这些地方都在西北方。（014-005）

## 昆仑之东

西胡最关键的定位是「昆仑山在西胡西」——昆仑山在西胡的西面，也就是说西胡在昆仑山的东面：

| 方位 | 地物 |
|------|------|
| 最西 | 大夏 |
| 中 | 昆仑山 |
| **东** | **西胡** |

西胡虽然名含「西」字，但在这个地理网络中它是昆仑以东的存在——「西胡」之「西」是相对于中原而言的西方，在昆仑体系中却是东端。（014-005）

## 海内东经中的西北

海内东经本应记载海内的东方，但开篇却描述了西北方的地理——这是因为海内东经从流沙外的西方国度（大夏、竖沙、居繇、月支）开始，经由西胡和昆仑过渡到东方：

| 位置 | 内容 | 方向 |
|------|------|------|
| 014-004 | 大夏、竖沙、居繇、月支 | 西北 |
| **014-005** | **西胡、昆仑、白玉山** | **西北** |
| 014-006 | 雷泽（雷神，龙首人头） | 东方转折 |

西胡是海内东经从西北向东方转折的枢纽——过了西胡和昆仑，经文开始描写东方的雷泽和各地水系。（014-005）
