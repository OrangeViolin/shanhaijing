# 相柳

**相柳**是《山海经·[[海外北経]]》所载[[共工]]之臣。九首人面——蛇身面青——以食于九山。所到之处地面塌陷为泽溪——血液腥臭使土地不能种五谷。[[禹]]杀相柳——三填三陷——最终建[[众帝之台]]镇压。（008-006）

## 原文出处

《[[海外北経]]》：

> 共工之臣曰相柳氏，九首，以食于九山。相柳之所抵，厥为泽溪。禹杀相柳，其血腥，不可以树五谷种。禹厥之，三仞三沮，乃以为众帝之台。在昆仑之北，柔利之东。相柳者，九首人面，蛇身面青。
>
> （008-006）

## 九首食九山

相柳有九个头——同时在九座山上进食：

| 属性 | 内容 |
|------|------|
| 首 | 九首人面 |
| 身 | 蛇身面青 |
| 食 | 以食于九山 |
| 主人 | 共工 |

九个头——九座山——一一对应。九首不是为了看——是为了吃。一个头吃一座山——同时吃九座山——这是空间级别的吞噬。山海経中九头之兽极少——相柳的九首代表的是对九方之地的控制。（008-006）

## 毒化土地

相柳的毒不杀生命——毁灭生存的基础：

| 现象 | 描述 |
|------|------|
| 触地 | 所抵之处塌陷为泽溪 |
| 血液 | 腥臭，不可树五谷种 |
| 死后 | 禹填土三仞，三次塌陷 |
| 解决 | 建众帝之台镇压 |

踩过的地方变成沼泽——血渗入的土地种不出粮食。相柳不是杀人的怪物——是毁灭土地的怪物。杀人只死一人——毁土则毁一方生计。这种破坏比任何凶兽都深——深到三次填土都压不住——只有以众帝之台这种最高等级的神圣建筑才能镇压。（008-006）

## 治水叙事的尾声

相柳是[[共工]]的臣属——共工触山导致洪水——相柳污染土地——水患与土毒是共工阵营的双重灾害：

| 阶段 | 事件 | 灾害类型 |
|------|------|----------|
| 起因 | [[共工触山]] | 洪水 |
| 治水 | [[禹]]治水 | 水患平定 |
| 尾声 | 禹杀相柳 | 土地净化 |
| 镇压 | 建众帝之台 | 秩序重建 |

禹治水后还不算完——必须杀相柳才算彻底清除共工的遗毒。治水治的是表——杀相柳清的是根。众帝之台建在昆仑之北——把共工残党的污染之地变成帝王的神圣建筑——从极污到极圣的翻转。（008-006）

## 昆仑之北

相柳「在昆仑之北柔利之东」——位于昆仑秩序的外缘：

| 方位 | 意义 |
|------|------|
| 昆仑之北 | 帝都秩序之外 |
| 柔利之东 | 海外北経国列中的精确定位 |

昆仑是帝之下都——相柳在昆仑北面——是秩序之外的存在。禹杀相柳后在原地建众帝之台——把反秩序的空间重新纳入帝的版图。（008-006）
