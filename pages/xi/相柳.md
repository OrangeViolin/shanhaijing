# 相柳

**相柳**是[[共工]]的臣属——九首人面、蛇身青色，《山海经》中毒性最烈的存在。它触碰的土地即塌陷为沼泽，血液渗入土壤后寸草不生。[[禹]]杀相柳后，以土回填三次都塌陷，最终在其处建造众帝之台方才稳定。

## 原文出处

引注：（008-006）

> 共工之臣曰相柳氏，九首，以食于九山。相柳之所抵，厥为泽溪。禹杀相柳，其血腥，不可以树五谷种。禹厥之，三仞三沮，乃以为众帝之台。在昆仑之北，柔利之东。相柳者，九首人面，蛇身面青。

## 相柳的毒性

| 现象 | 描述 |
|------|------|
| 触地 | 所抵之处即化为泽溪（沼泽） |
| 血液 | 腥臭异常，不可种五谷 |
| 死后 | 禹填土三丈，三次塌陷 |
| 解决 | 建众帝之台，以神圣建筑镇压 |

相柳的毒不是「伤害生命」，而是「破坏土地」——它使大地本身丧失承载能力。这是比杀人更深层的破坏：毁灭生存的基础。

## 在治水叙事中的位置

相柳是共工的残余势力。共工触山导致洪水（[[共工触山]]），共工之臣相柳则污染土地——水患与土毒是同一阵营的双重灾害。禹治水之后必须杀相柳，才算彻底清除水患的根源。

## 神话意义

**毒化的忠诚**：相柳是「共工之臣」——它的破坏力来源于对共工的忠诚。共工失败后，相柳继续以自身毒性延续共工的破坏遗产。这不是独立的恶，而是「失败者的执念」。

**众帝之台——以神圣镇压污秽**：禹杀相柳后，血腥之地三填三沮，直到建造众帝之台——以最高等级的神圣建筑压制最深层的污染。污染的深度决定了需要的神圣等级。
