# 县【属斤】之山

**县【属斤】之山**是《山海经·[[中山経]]》中次五経所载的山。无草木——多文石。山海経中最简短的山之一。（005-044）

## 原文出处

《[[中山経]]》中次五経：

> 又东三百里，曰县【属斤】之山，无草木，多文石。
>
> （005-044）

## 极简之山

县【属斤】之山的全部信息只有两条——无草木、多文石：

| 属性 | 内容 |
|------|------|
| 草木 | 无 |
| 矿物 | 文石（有花纹的石头） |
| 水 | 无记载 |
| 兽鸟 | 无记载 |

没有草——没有树，没有水，没有兽，没有鸟，只有文石。山海経中大多数山都有丰富的物产记录，县【属斤】之山什么都没有，只剩石头。越简的条目越说明这是纯粹的地理记录，不加修饰。（005-044）

## 文石

文石是有花纹的石头——装饰性矿物：

| 属性 | 内容 |
|------|------|
| 名 | 文石 |
| 特征 | 有天然花纹 |
| 类型 | 装饰性矿物 |

「文」是花纹——文石就是带天然纹路的石头。无草木的荒山上全是带花纹的石头，地表的荒凉和石头的美丽形成反差。（005-044）
