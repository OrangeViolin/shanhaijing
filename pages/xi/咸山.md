# 咸山

**咸山**是《山海经·[[北山经]]》北次三经所载的山峰。上有玉，下多铜，多松柏茈草——条菅之水出焉，水中多器酸，三岁一成，食之已疠。（003-047）

## 原文出处

《[[北山经]]》北次三经：

> 又東北七十里，曰咸山，其上有玉，其下多銅，是多松柏，草多茈草。條菅之水出焉，而西南流注于長澤。其中多器酸，三歲一成，食之已癘。
>
> （003-047）

## 三岁一成

器酸——山海经唯一有时间条件的药物：

| 属性 | 内容 |
|------|------|
| 名称 | 器酸 |
| 产地 | 条菅之水中 |
| 熟成 | 三岁一成 |
| 药效 | 食之已疠 |

三年才成熟一次——山海经其他药物都是即效的「食之已X」，只有器酸需要等三年。疠——恶疫，最严重的疾病之一。最难治的病配最慢的药——重症需要时间。（003-047）

## 上下之产

咸山的矿物和植物——层次分明：

| 位置 | 产物 |
|------|------|
| 山上 | 玉 |
| 山下 | 铜 |
| 山体 | 松柏、茈草 |
| 水中 | 器酸 |

玉在上、铜在下、松柏在山间、器酸在水中——从高到低，四层产物。松柏是长寿之木，茈草是药用之草——咸山是一座从上到下都有用的山。（003-047）

## 天马与飞鼠之间

咸山前后——飞行异兽的包围：

| 位置 | 山 | 异物 | PN |
|------|-----|------|----|
| 前 | [[马成之山]] | 天马——如白犬黑头，见人则飞 | 003-046 |
| **此** | **咸山** | **器酸——三岁一成** | **003-047** |
| 后 | [[天池之山]] | 飞鼠——如兔鼠首，以背飞 | 003-048 |

天马会飞，飞鼠会飞——中间的咸山没有飞行动物，只有需要三年才成熟的水中药物。两座飞行之山夹着一座等待之山——动与静的对比。（003-046至003-048）
