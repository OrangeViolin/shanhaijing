# 鲜野山

**鲜野山**是《山海经·[[大荒北经]]》所载的山峰，与[[齐州之山]]、[[君山]]、【上两先下鬲】山、[[鱼山]]五山并列。无地形、物产、生物的描述——只有名字。（017-024）

## 原文出处

《[[大荒北经]]》：

> 有山名曰齐州之山、君山、【上两先下鬲】山、鲜野山、鱼山。
>
> （017-024）

## 五山之四

鲜野山是五山并列中的第四座：

| 序号 | 山 | 命名类型 |
|------|-----|---------|
| 一 | [[齐州之山]] | 地域名 |
| 二 | [[君山]] | 权威 |
| 三 | 【上两先下鬲】山 | 难解字 |
| **四** | **鲜野山** | **景观描写** |
| 五 | [[鱼山]] | 动物 |

「鲜野」——鲜亮的原野。五座山中只有鲜野山的名字是形容词＋名词的结构——其他山名都是名词或专名。鲜野山以风景命名——它不指向一个地方、一种生物或一位统治者，而是指向一种视觉印象：鲜亮的、开阔的野。（017-024）

## 名即全部

与[[君山]]一样，鲜野山没有任何实质性描述：

| 项目 | 有无 |
|------|------|
| 地形 | 无 |
| 矿产 | 无 |
| 水系 | 无 |
| 草木 | 无 |
| 鸟兽 | 无 |

大荒经的山常常只存在于名字中——五藏山经的山有矿、有水、有兽，大荒经的山只有名。鲜野山的全部信息就是「鲜野」二字——一片鲜亮原野中的山。（017-024）

## 异族界标

五山夹在犬戎和一目人之间，充当异族之间的地理界标：

| 位置 | 内容 |
|------|------|
| 前 | 犬戎——黄帝后裔，白犬有牝牡，肉食 |
| **此** | **五山（齐州、君、【上两先下鬲】、鲜野、鱼）** |
| 后 | 一目人——面中生一目，少昊之子，食黍 |

一族食肉，一族食黍；一族出自黄帝，一族出自少昊——两个完全不同的异族被五座山隔开。鲜野山作为界标的一部分，标记着从肉食文明到谷食文明的过渡。（017-024）
