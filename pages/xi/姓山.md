# 姓山

**姓山**是《山海经·[[大荒南経]]》所载的山。与[[苕山]]、[[宗山]]、壑山、[[陈州山]]、[[东州山]]、[[白水山]]并列——七座山紧随颛顼之国之后。（011-021）

## 原文出处

《[[大荒南経]]》：

> 有国曰颛顼，生伯服，食黍。有鼬姓之国。有苕山。又有宗山。又有姓山，又有壑山。又有陈州山，又有东州山。又有白水山，白水出焉，而生白渊，昆吾之师所浴也。
>
> （011-021）

## 七山之三

姓山是颛顼之国近旁七座山的第三座：

| 序号 | 山 | 特征 |
|------|-----|------|
| 1 | [[苕山]] | 无 |
| 2 | [[宗山]] | 无 |
| **3** | **姓山** | **无** |
| 4 | 壑山 | 无 |
| 5 | [[陈州山]] | 无 |
| 6 | [[东州山]] | 无 |
| 7 | [[白水山]] | 白水出焉·白渊·昆吾之师所浴 |

七山中只有白水山有具体描写（白水·白渊·昆吾之师）——其余六座包括姓山都只有名字。姓山是一座仅以名字存在的山。（011-021）

## 宗与姓

姓山与宗山紧邻——「宗」是宗庙——「姓」是氏族之姓：

| 山 | 名义 |
|----|------|
| [[宗山]] | 宗庙·祖宗 |
| **姓山** | **姓氏·氏族** |

宗庙与姓氏——两个与氏族制度直接相关的名字连续出现——而且紧跟在颛顼之国和鼬姓之国之后。「鼬姓之国」有「姓」——「姓山」也有「姓」——两者在同一段文字中呼应。这片区域的山名暗示着一个以宗族和姓氏为核心的社会结构。（011-021）

## 颛顼之国的周边

姓山所在的七山群围绕着颛顼之国展开：

| 内容 | 性质 |
|------|------|
| 颛顼之国（生伯服·食黍） | 邦国 |
| 鼬姓之国 | 邦国 |
| 苕山→宗山→**姓山**→壑山→陈州山→东州山→白水山 | 山群 |

两个国加七座山——构成一个完整的颛顼系地理区域。颛顼是五帝之一——他的领地不是孤零零的一个国——而是国与山交织的广阔地带。（011-021）
