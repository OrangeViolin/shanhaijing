# 小物

**小物**是《山海经·[[大荒北経]]》所载的生物。栖息于[[附禺之山]]——帝颛顼与九嫔的葬地——与[[大物]]并列。（017-001）

## 原文出处

《[[大荒北経]]》：

> 爰有丘久、文贝、离俞、鸾鸟、皇鸟、大物、小物。
>
> （017-001）

## 大物与小物

大物和小物以体型对举——一大一小——是附禺之山生物群的总括：

| 名 | 含义 |
|----|------|
| [[大物]] | 大型生物 |
| **小物** | **小型生物** |

没有具体形态描写——只有「大」和「小」。这不是特定的一种兽——而是对附禺之山全部大小生物的概括。大物涵盖大型——小物涵盖小型——山上的一切生灵都被这两个词收尽。（017-001）

## 附禺之山的瑞物群

小物是附禺之山一整套瑞物群的成员：

| 类别 | 瑞物 |
|------|------|
| 鸟 | 丘久·鸾鸟·皇鸟·青鸟·琅鸟·玄鸟·黄鸟 |
| 贝 | 文贝 |
| 兽 | 离俞·虎·豹·熊·罴 |
| 蛇 | 黄蛇 |
| 其他 | 视肉·瑰·瑶碧 |
| **总括** | **大物·小物** |

鸾鸟·皇鸟是瑞鸟——虎豹熊罴是猛兽——视肉·瑶碧是灵物——最后用「大物·小物」兜底——山上所有生物无论大小都是帝颛顼葬地的护卫。「皆出卫于山」——它们全部从山中出来守护这座山。（017-001）

## 帝王葬地的生态

附禺之山是帝颛顼与九嫔的墓地——不是荒凉的陵墓——而是生机勃勃的圣地：

| 要素 | 内容 |
|------|------|
| 位置 | 东南海之外·大荒之中·河水之间 |
| 葬者 | 帝颛顼与九嫔 |
| 瑞物 | 鸟兽贝蛇灵物——皆出卫于山 |
| 林 | 帝俊竹林（大可为舟） |
| 水 | 赤泽水（封渊）·沈渊（颛顼所浴） |

帝王的葬地被瑞物环绕——被竹林覆盖——有泽水有深渊。小物与大物一起守护这片圣地——从最小的生灵到最大的猛兽——无一缺席。（017-001）
