# 女和月母之国

**女和月母之国**是《山海经·[[大荒東経]]》所载之国。国中有人名【上鸟下宛】——处东极隅以止日月——使无相间出没——司其短长。（015-034）

## 原文出处

《[[大荒東経]]》：

> 有女和月母之国。有人名曰【上鸟下宛】——北方曰【上鸟下宛】，来之风曰【犭炎】——是处东极隅以止日月，使无相间出没，司其短长。
>
> （015-034）

## 日月的管理者

【上鸟下宛】的职责——管理日月的运行：

| 职能 | 内容 |
|------|------|
| 位置 | 处东极隅 |
| 止日月 | 让日月停下 |
| 无相间 | 使日月不互相干扰 |
| 司短长 | 管理昼夜长短 |

不是制造日月——是管理日月的交替运行。让太阳和月亮不同时出没——让白天和黑夜有规律地变长变短。这是一个天文调度员。（015-034）

## 与羲和对称

女和月母之国和[[羲和之国]]构成日月对称：

| | 羲和之国 | 女和月母之国 |
|--|---------|-------------|
| 管理对象 | 太阳 | 日月（偏月） |
| 活动 | 方日浴于甘渊 | 止日月、司短长 |
| 管理方式 | 具体照料（浴日） | 系统调度（交替、长短） |
| 出处 | 大荒南経 | 大荒東経 |

羲和亲自给太阳洗澡——是太阳的保姆。女和月母之国的【上鸟下宛】管理日月交替系统——是天文的调度员。一个照料个体——一个管理规则。

## 国名的结构

「女和月母」四个字可以拆成两组：

| 词 | 含义 |
|----|------|
| 女和 | 调和的女性 |
| 月母 | 月亮之母 |

「和」是调和——「母」是生育。这个国的名字里同时包含了「协调」和「生育」——管理日月交替的职能和月亮之母的身份融在一起。

## 东极隅

【上鸟下宛】「处东极隅」——住在东方的极端角落。大荒東経的终盤是太阳升起的地方——日月从这里出发。管理日月运行的人住在日月出发的地点——位置和职能完全吻合。（015-034）
