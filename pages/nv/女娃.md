# 女娃

**女娃**是[[炎帝]]的小女儿。游东海——溺而不返——化为[[精卫]]。精卫衔西山木石，以堙于东海。（003-065）

## 原文出处

《[[北山经]]》北次三経：

> 又北二百里，曰发鸠之山，其上多柘水。有鸟焉，其状如乌，文首、白喙、赤足，名曰精卫，其鸣自【讠交】。是炎帝之少女名曰女娃，女娃游于东海，溺而不返，故为精卫。常衔西山之木石，以堙于东海。漳水出焉，东流注于河。
>
> （003-065）

## 死后化生

女娃→精卫——山海经最著名的死后化生：

| 阶段 | 内容 |
|------|------|
| 生前 | 炎帝少女 |
| 死因 | 游东海溺死 |
| 化身 | 精卫（乌形、文首白喙赤足） |
| 行为 | 衔西山木石填东海 |
| 栖息地 | [[发鸠之山]] |

溺死于东海——化鸟后填东海。死因和化身后的行为直接因果相连：杀死她的海，她要把它填平。（003-065）

## 不屈的结构

「常衔」——不是偶尔衔，是一直衔。西山的木石填东海——永远填不满，但永远不停：

| 元素 | 对比 |
|------|------|
| 工具 | 木石（微小） |
| 对象 | 东海（无限） |
| 频率 | 常（永不停歇） |

微小对无限——这是不屈意志的极端表达。精卫不在乎填不满——她在乎的是不停止。（003-065）

## 炎帝系谱中的位置

女娃是「炎帝之少女」——少女即末女。炎帝的子孙在山海经中多为统治者或神灵——女娃是唯一在「游」中死去的：

| 炎帝后裔 | 结局 |
|----------|------|
| [[祝融]] | 降处江水 |
| [[共工]] | 触不周山 |
| **女娃** | 游海溺死→化鸟 |

帝王之女化为一只鸟——从人间跌入自然界。但这只鸟的执念超越了所有帝王后裔的功业。（003-065）
