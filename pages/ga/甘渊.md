# 甘渊

**甘渊**是《山海经》所载的圣渊，二見于経文——一在[[大荒南経]]（[[羲和]]日浴于甘渊、帝俊之妻生十日），一在[[大荒東経]]（甘山甘水生甘渊）。太阳从水中升起的神话场所。（011-026、015-002）

## 原文出处

《[[大荒南経]]》：

> 东南海之外，甘水之间，有羲和之国，有女子名曰羲和，方日浴于甘渊。羲和者，帝俊之妻，生十日。
>
> （011-026）

《[[大荒東経]]》：

> 有甘山者，甘水出焉，生甘渊。
>
> （015-002）

## 日浴之渊

甘渊最核心的功能——羲和在此浴日：

| 属性 | 内容 |
|------|------|
| 位置 | 东南海之外、甘水之间 |
| 行为 | 羲和日浴于甘渊 |
| 羲和 | 帝俊之妻 |
| 十日 | 羲和所生 |

[[羲和]]是[[帝俊]]的妻子——生了十个太阳。她每天在甘渊里给太阳洗澡——太阳从水中洗净后升上天空。这是太阳每朝从水面升起的神话解释——不是自然现象——是母亲给孩子洗澡。（011-026）

## 山→水→渊

大荒東経记录了甘渊的地理成因——三段式：

| 阶段 | 内容 |
|------|------|
| 山 | 甘山 |
| 水 | 甘水出焉 |
| 渊 | 生甘渊 |

甘山生甘水——甘水生甘渊。山→水→渊——地形的因果链。三者共享「甘」字——甘是甜美——太阳洗浴的水是甜的。日出的光温暖甘美——所以水也甘美——名字本身就是神话的感觉投射。（015-002）

## 东方双圣地

甘渊和[[扶桑]]构成东方日出的双重圣地——一水一木：

| 圣地 | 形态 | 功能 |
|------|------|------|
| **甘渊** | 水（渊） | 十日浴处 |
| [[扶桑]] | 木（树） | 十日居处 |

水洗净太阳——树承载太阳。先浴后栖——甘渊是日出的第一步——扶桑是日出的第二步。水和树共同构成太阳升起的完整过程。（011-026）
