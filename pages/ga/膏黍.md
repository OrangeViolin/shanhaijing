# 膏黍

**膏黍**是《山海经·[[海内经]]》所载[[都广之野]]自生的穀物。膏是肥沃之意——膏黍即肥美的黍，四穀之第三。（018-008）

## 原文出处

《[[海内经]]》：

> 西南黑水之间，有都广之野，后稷葬焉。爰有膏菽、膏稻、膏黍、膏稷，百谷自生，冬夏播琴。鸾鸟自歌，凤鸟自儛，灵寿实华，草木所聚。爰有百兽，相群爰处。此草也，冬夏不死。
>
> （018-008）

## 四穀序列

膏黍是四穀的第三种——四穀从豆到米到黍到粟：

| 序 | 穀物 | 本义 |
|----|------|------|
| 一 | 膏菽 | 肥大豆 |
| 二 | [[膏稻]] | 肥稻 |
| **三** | **膏黍** | **肥黍** |
| 四 | [[膏稷]] | 肥粟 |

每种穀物前都加「膏」——不是普通的五谷，是肥沃到极致的穀物。黍是北方旱地主粮——黄色、黏性、可酿酒。四穀合起来南北兼备：稻是南方的，黍和稷是北方的，菽南北通用。都广之野什么粮食都长。（018-008）

## 后稷墓旁

四穀自生于后稷墓旁——穀神之墓长出穀物：

| 要素 | 内容 |
|------|------|
| 地点 | [[都广之野]] |
| 方位 | 西南黑水之间 |
| 墓主 | 后稷（穀神） |
| 穀物 | 百谷自生 |

后稷是周人始祖、穀物之神——他葬在哪里，哪里就百谷自生。这不是人种的，是自己长出来的——「百谷自生，冬夏播琴」。播琴是播种之意——冬天夏天都可以种，四季无休。穀神死后，穀物替他活着。（018-008）

## 乐园图景

都广之野不只有穀物——鸾凤自歌自舞、草木四季不死：

| 层次 | 内容 |
|------|------|
| 穀物 | 膏菽、膏稻、膏黍、膏稷——百谷自生 |
| 鸟 | 鸾鸟自歌、凤鸟自儛 |
| 草木 | 灵寿实华、草木所聚、冬夏不死 |
| 兽 | 百兽相群爰处 |

从穀物到鸟到草木到兽——都广之野是完整的乐园。一切都是「自」的——自生、自歌、自儛——不需要人的参与，万物自足。膏黍是这座乐园里最基本的一粒粮食。（018-008）
