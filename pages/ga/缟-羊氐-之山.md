# 缟【羊氐】之山

**缟【羊氐】之山**是《山海经·[[中山経]]》中次六経所载的山。无草木——多金玉。中次六経以「缟【羊氐】山之首」冠名——此山是整个山系的名号之山。（005-058）

## 原文出处

《[[中山経]]》中次六経：

> 西十里，曰缟【羊氐】之山，无草木，多金玉。
>
> （005-058）

## 山系名山

中次六経的全称是「缟【羊氐】山之首」——缟【羊氐】之山是山系名的来源：

| 属性 | 内容 |
|------|------|
| 山系 | 缟【羊氐】山之首（中次六経） |
| 首山 | [[平逢之山]] |
| 缟【羊氐】之山 | 平逢之山西十里 |
| 山数 | 十四山 |
| 里程 | 七百九十里 |

首山是平逢之山——但山系不叫「平逢山系」——叫「缟【羊氐】山系」。山系的命名用第二座山而非首山——这在中山経中不常见。缟【羊氐】之山虽然不是首山——却是山系的名号——地位特殊。（005-058）

## 极简之山

缟【羊氐】之山的记述极简——只有十二个字：

| 有 | 无 |
|-----|------|
| 金、玉 | 草、木 |

无草木——有金玉。荒凉的地表下是贵重的矿物。距首山平逢之山仅西十里——非常近。平逢之山也是「无草木无水多沙石」——两座荒山紧邻——中次六経的开头是一片荒凉的矿区。（005-058）
