# 甘枣之山

**甘枣之山**是《山海经·[[中山経]]》中次一経（薄山山系）的首山。[[共水]]出焉西流注于河。有箨草——可以已懵。有㔿兽——食之已瘿。中山経的第一座山。（005-001）

## 原文出处

《[[中山経]]》中次一経：

> 中山经薄山之首，曰甘枣之山，共水出焉，而西流注于河。其上多杻木。其下有草焉，葵本而杏叶，黄华而荚实，名曰箨，可以已懵。有兽焉，其状如鼠而文题，其名曰㔿，食之已瘿。
>
> （005-001）

## 中山経第一山

甘枣之山是中山経的起点——薄山山系的首山：

| 属性 | 内容 |
|------|------|
| 地位 | 中次一経首山 |
| 水 | 共水（西流注河） |
| 木 | 杻木 |
| 草 | 箨（已懵） |
| 兽 | 㔿（已瘿） |

中山経从甘枣之山开始——共水西入黄河。一座有水有木有药草有药兽的完整之山——作为中山経的开篇恰如其分。（005-001）

## 双药效

甘枣之山有两种药——一草一兽：

| 药物 | 类型 | 形态 | 药效 |
|------|------|------|------|
| 箨 | 草 | 葵本杏叶黄华荚实 | 已懵（治昏聩） |
| 㔿 | 兽 | 鼠形文题 | 已瘿（治甲状腺肿） |

草治头脑的病（懵=昏聩糊涂）——兽治脖子的病（瘿=甲状腺肿）。从头到颈——两种药物各治一个部位。草是服用——兽是食用——用法不同但都是摄入型。（005-001）

## 薄山山系

甘枣之山开启的薄山山系规模宏大：

| 项目 | 内容 |
|------|------|
| 首山 | 甘枣之山 |
| 末山 | [[鼓镫之山]] |
| 山数 | 十五山 |
| 里程 | 六千六百七十里 |
| 冢山 | [[历儿]] |
| 冢山祭祀 | 太牢+吉玉 |

六千六百七十里——中山経各山系中里程最长的之一。十五座山中只有历儿是冢山——用太牢和吉玉祭祀——其余十三山用羊一头和桑封。甘枣之山是首山但不是冢山——起点不等于最高点。（005-001）
