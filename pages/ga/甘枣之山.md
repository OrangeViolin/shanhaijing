# 甘枣之山

**甘枣之山**は[[中山経]]中次一経（薄山山系）の首山である。（005-002）

## 原文出処

> 中山经薄山之首，曰甘枣之山，共水出焉，而西流注于河。其上多杻木。其下有草焉，葵本而杏叶，黄华而荚实，名曰箨，可以已懵。有兽焉，其状如鼠而文题，其名曰㔿，食之已瘿。
> （005-002）

## 地理描述

甘枣之山は中山経の冒頭、中次一経の首山として記される。共水がここから流れ出て、西に流れて河（黄河）に注ぐ。山上には杻木が多い。

山下には箨という草があり、葵の根・杏の葉・黄色い花・莢の実を持つ。服用すると懵（めまい・ぼんやり）を治す。

また㔿という獣が棲む。鼠に似て文様のある額を持ち、食べると瘿（甲状腺腫）を治す。

## 薄山山系の総括

甘枣之山を首山とする薄山山系は[[鼓镫之山]]まで十五山、六千六百七十里に及ぶ（004-070）：

| 項目 | 内容 |
|------|------|
| 経名 | 中次一経薄山之首 |
| 首山 | 甘枣之山 |
| 末山 | [[鼓镫之山]] |
| 山数 | 十五山 |
| 総距離 | 六千六百七十里 |
| 冢山 | [[历儿]] |
| 冢山祭祀 | 太牢＋吉玉 |
| 他十三山祭祀 | 羊一頭、桑封＋金 |

冢山の[[历儿]]のみ太牢（牛・羊・豚の三牲）と吉玉を用いる最高級祭祀を受け、残る十三山は羊一頭と桑封（桑の木主、下方で上が尖り中央に穴を開けて金を加える）で祭る。甘枣之山は首山として経の起点を示すが、祭祀上の最高位は历儿が占める。
