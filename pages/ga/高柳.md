# 高柳

**高柳**是《山海经·[[海内西経]]》所载的地名。在代之北方。山海経中最简短的条目之一——全文四字。（012-005）

## 原文出处

《[[海内西経]]》：

> 高柳在代北。
>
> （012-005）

## 四字之条

「高柳在代北」——山海経全书最短的条目之一：

| 属性 | 内容 |
|------|------|
| 地名 | 高柳 |
| 方位 | 代之北 |
| 矿产 | 无记载 |
| 动植物 | 无记载 |
| 水系 | 无记载 |

没有山——没有水——没有兽——只有一个名字和一个方位。山海経通常对每个条目都写物产或异兽——高柳什么都没有。四个字就是全部信息——在代国的北面有一个叫高柳的地方。越简短越说明这是纯粹的地理记录——不需要修饰。（012-005）

## 代之北

高柳在「代」的北方——代是战国时期的诸侯国/地名：

| 属性 | 内容 |
|------|------|
| 基准 | 代（今河北蔚县一带） |
| 方位 | 北 |
| 后世 | 汉代置高柳县（今山西阳高） |

代在燕赵之间——高柳在代的北面——是北方游牧民族与中原的接触地带。汉代在此设县——成为抵御匈奴的军事前线。山海経用四个字记录了这个后来非常重要的地点——简洁的地理记录预示了后世的战略价值。（012-005）

## 海内西経北段文脉

高柳在海内西経北段的地名序列中：

| 前后 | 内容 | PN |
|------|------|-----|
| 前 | [[雁门山]]（雁出其间） | 012-004 |
| **高柳** | 在代北 | 012-005 |
| 后 | 后稷之葬（山水环之） | 012-006 |

雁门山有雁——高柳只有名字——后稷之葬有山水。从自然（雁）到人文（地名）到神圣（圣人之墓）——海内西経北段从自然景观过渡到人文地理再到神话圣地。高柳是中间的过渡——最简单的一个名字。（012-004—012-006）
