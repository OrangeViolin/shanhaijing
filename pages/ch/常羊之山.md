# 常羊之山

**常羊之山**是《山海经》中两部经文记载的山。[[海外西経]]——[[刑天]]与帝争神，帝断其首，葬之常羊之山（007-008）。[[大荒西経]]——大荒西南隅有偏句、常羊之山（016-049）。

## 原文出处

### 海外西経

> 形天与帝至此争神，帝断其首，葬之常羊之山。乃以乳为目，以脐为口，操干戚以舞。
>
> （007-008）

### 大荒西経

> 西南，大荒之中隅，有偏句、常羊之山。
>
> （016-049）

## 刑天的首级

常羊之山埋着[[刑天]]被砍下的头——但刑天没有停下：

| 阶段 | 内容 |
|------|------|
| 争 | 形天与帝争神 |
| 败 | 帝断其首 |
| 葬 | 首葬常羊之山 |
| 不屈 | 以乳为目，以脐为口，操干戚以舞 |

头被砍了、被埋了——身体还在舞。乳房当眼睛、肚脐当嘴巴、手持干戚继续跳——失去头颅的身体拒绝死亡。常羊之山是首级的坟——不是刑天的坟。（007-008）

## 两部经文

海外西経写神话——大荒西経写地理：

| | 海外西経 | 大荒西経 |
|--|---------|---------|
| 内容 | 刑天争神、断首、葬山 | 地名列举 |
| 写法 | 故事 | 「有偏句、常羊之山」 |
| 位置 | 刑天传说之中 | 大荒西南隅 |
| PN | 007-008 | 016-049 |

同一座山——一处是传说的舞台，一处是地图上的标记。海外西経让常羊之山有了灵魂——大荒西経让它有了坐标。（007-008、016-049）

## 西南隅

大荒西経把常羊之山放在「西南、大荒之中隅」——西南是死亡的方向。断首之神的首级葬在死亡方位——位置和故事完全吻合。（016-049）

## 无形之山

两部经文都没有描写常羊之山的山形、物产、水系——什么都没有。这座山不靠自身存在——靠刑天的故事存在。山海经中最有名的山之一——却是最空白的山之一。
