# 赤鲑

**赤鲑**は[[北山経]]に記載される魚である。[[敦薨之山]]から流れ出る敦薨之水の中に多く棲む。（003-017）

## 原文出処

《[[北山経]]》：

> 敦薨之水出焉，而西流注于【氵幼】澤。出于昆侖之東北隅，實惟河原。其中多赤鮭。
> （003-017）

## 解説

敦薨之山の水中に多く棲む赤い色の鮭魚。この水は昆侖の東北の隅から出て、河の源流でもある。

## 河源の魚

赤鲑が棲む敦薨之水は「出于昆侖之東北隅、實惟河原」と記され、黄河の源流とされる聖なる水系である。赤鲑はこの河源水系の特産魚として、単なる淡水魚以上の意味を持つ。

| 要素 | 内容 |
|------|------|
| 棲息地 | 敦薨之水 |
| 水源 | 昆仑之東北隅 |
| 水系的意味 | 河の源流（河原） |
| 注入先 | 【氵幼】澤 |

## 敦薨之山の生態系

敦薨之山には赤鲑のほか、獣として兕・旄牛、鳥として[[柝鸠]]が棲む。高原的な動物相を示す。

| 種類 | 名前 | 特徴 |
|------|------|------|
| 魚 | **赤鲑** | 赤い鮭 |
| 獣 | 兕 | 犀に似た大型獣 |
| 獣 | 旄牛 | ヤク |
| 鳥 | [[柝鸠]] | 鳩の一種 |

## 「赤」の色彩

山海経には「赤」を冠する生物・鉱物が多数あるが、赤鲑の「赤」は実際の体色を反映する。鮭魚が産卵期に赤色を帯びる生態的事実と重なる。
