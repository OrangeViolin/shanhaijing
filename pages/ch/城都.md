# 城都

**城都**是《山海经·[[海内東経]]》所载的城邑。岷三江南江的源头——高山在城都的西面。今四川省成都市。（014-012）

## 原文出处

《[[海内東経]]》：

> 高山在城都西，入海，在长州南。
>
> （014-012）

## 高山之东

城都的位置由高山来定义——「高山在城都西」：

| 属性 | 内容 |
|------|------|
| 名 | 城都 |
| 位置 | 高山东 |
| 功能 | 岷三江地理的基准点 |
| 今名 | 成都 |

「高山在城都西」——高山在城都的西面——反过来说——城都在高山的东面。城都是一个已知的地名——用它来定位高山的位置——说明编者认为读者知道城都在哪里。（014-012）

## 蜀地的中心

城都是古蜀国的核心城邑——在海内東経的水系目录中它是唯一的蜀地地名：

| 水系 | 相关地名 |
|------|----------|
| 岷三江 | 汶山·曼山·高山·**城都**·长州 |
| 浙江 | 三天子都·闽 |
| 淮水 | 余山·朝阳·义乡 |

从蜀地（城都）到浙闽——从西到东——海内東経的水系目录也是一份城邑地名录。城都排在最前——是西南角的锚点。（014-012）

## 「城都」与「成都」

原文写「城都」——今通行「成都」：

| 写法 | 来源 |
|------|------|
| 城都 | 山海経原文 |
| 成都 | 后世通行 |

「城」与「成」音近——古代文献中常互用。城都是中国最古老的城市名之一——从山海経到今天——三千年未曾改名（只变了一个字）。（014-012）
