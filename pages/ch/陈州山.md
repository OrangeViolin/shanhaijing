# 陈州山

**陈州山**是《山海经·[[大荒南経]]》所载的山。[[颛顼]]国近旁七山系列之一——与[[东州山]]共用「州」字。（011-021）

## 原文出处

《[[大荒南経]]》：

> 有国曰颛顼，生伯服，食黍。有鼬姓之国。有苕山。又有宗山。又有姓山，又有壑山。又有陈州山，又有东州山。又有白水山，白水出焉，而生白渊，昆吾之师所浴也。
>
> （011-021）

## 七山序列

颛顼国周围连续排列七座山——陈州山排第五：

| 序 | 山名 | 记述 |
|----|------|------|
| 1 | 苕山 | 无 |
| 2 | 宗山 | 无 |
| 3 | 姓山 | 无 |
| 4 | 壑山 | 无 |
| 5 | **陈州山** | 无 |
| 6 | [[东州山]] | 无 |
| 7 | [[白水山]] | 白水出焉，生白渊，昆吾之师所浴 |

前六山只有名字——没有任何地理描写。第七座白水山突然有了水系、有了渊、有了人。六座沉默的山为白水山的叙事做铺垫——抑扬结构。（011-021）

## 州字对

陈州山和东州山共用「州」字——形成一对：

| 山 | 前缀 | 含义 |
|----|------|------|
| 陈州山 | 陈（古地名/西方） | 西方之州 |
| 东州山 | 东（方位） | 东方之州 |

「陈」和「东」——一个可能指西方古地名，一个明确指东方。两座「州」山暗示东西方向的对称。（011-021）

## 颛顼的地理骨架

七山围绕颛顼国排列——构成颛顼势力范围的地形骨架。这些山不需要各自有特征——它们的功能是标示领地的边界。真正重要的信息在首尾：颛顼国（生伯服、食黍）和白水山（昆吾之师所浴）。中间的山是骨架——不是主角。（011-021）
