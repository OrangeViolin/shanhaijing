# 杻阳之山

**杻阳之山**是《山海经·[[南山经]]》南次一经所载的山。阳面多赤金（铜），阴面多白金（银）。山上有瑞兽[[鹿蜀]]（宜子孙）和灵龟[[旋龟]]（不聋）。怪水东流注于宪翼之水。（001-004）

## 原文出处

《[[南山经]]》南次一经：

> 又东三百七十里，曰杻阳之山，其阳多赤金，其阴多白金。又兽焉，其状如马而白首，其文如虎，而赤尾，其音如谣，其名曰鹿蜀，佩之宜子孙。怪水出焉，而东流注于宪翼之水。其中多玄龟，其状如龟而鸟首虺尾，其名曰旋龟，其音如判木，佩之不聋，可以为底。
>
> （001-004）

## 鹿蜀

杻阳之山的第一种瑞兽——鹿蜀：

| 特征 | 描述 |
|------|------|
| 体形 | 如马 |
| 头部 | 白首 |
| 花纹 | 如虎 |
| 尾巴 | 赤尾 |
| 声音 | 如谣（如歌谣） |
| 功效 | 佩之宜子孙 |

马的身体、虎的花纹、白色的头、红色的尾——配色极为华丽。声音「如谣」——像在唱歌。佩戴它（的皮毛或骨角）可以多子多孙。鹿蜀是《山海经》中最具吉祥色彩的瑞兽之一。（001-004）

## 旋龟

杻阳之山的第二种灵物——旋龟：

| 特征 | 描述 |
|------|------|
| 体形 | 如龟 |
| 头部 | 鸟首 |
| 尾巴 | 虺尾（蛇尾） |
| 声音 | 如判木（如劈木之声） |
| 功效 | 佩之不聋，可以为底（治脚病） |

龟的身体、鸟的头、蛇的尾——三种不同动物的拼合。旋龟的药效是「不聋」和「为底」（治脚底之疾）——从耳朵到脚底，覆盖了人体的上下两端。（001-004）

## 赤金与白金

杻阳之山的矿产呈现鲜明的阳阴对称：

| 面 | 矿产 | 颜色 |
|----|------|------|
| 阳面 | 赤金（铜） | 红色 |
| 阴面 | 白金（银） | 白色 |

阳面红、阴面白——矿产的颜色恰好呼应了山的朝向。赤金配阳（热、明），白金配阴（冷、暗）——这是五行思维在地理记载中的投射。（001-004）

## 危险之后的恩赐

杻阳之山的前一座山是【犭爰】翼之山——「多怪兽、水多怪鱼、多蝮虫、多怪蛇，不可以上！」经文甚至用了感叹号式的「不可以上」来警告。紧接着杻阳之山就出现了瑞兽和灵龟：

| 山 | 特征 |
|----|------|
| 【犭爰】翼之山 | 怪兽怪蛇，不可以上（危险） |
| **杻阳之山** | **鹿蜀宜子孙，旋龟不聋（恩赐）** |

从极度危险到极度吉祥——南次一经在两座相邻的山之间完成了从恐惧到祝福的转换。（001-004）

## 南次一经的「凶吉交替」结构：杻阳之山作为恩赐的模板

杻阳之山紧接「不可以上」的【犭爰】翼之山出现，从极度危险到极度吉祥。这种凶吉交替不是孤例，而是南次一经的结构性节奏——经脉中反复出现「危险山→恩赐山」的配对：

| 凶山 | 凶兆/危险 | 吉山 | 恩赐 | 出处 |
|------|---------|------|------|------|
| 【犭爰】翼之山 | 怪兽怪蛇，不可以上 | **杻阳之山** | **鹿蜀宜子孙，旋龟不聋** | 001-003→001-004 |
| 亶爰之山 | 多怪兽 | 基山 | 多玉 | 001-005→001-006 |

杻阳之山的恩赐是双重的——鹿蜀（宜子孙）给予繁衍之福，旋龟（不聋）给予身体之治。两种恩赐分别作用于族群延续和个体健康，覆盖了古人最核心的两种需求。更精妙的是两者的药效模式：鹿蜀是「佩之」宜子孙（佩戴即可），旋龟是「佩之」不聋（同样佩戴即可）——两种灵物的使用方式完全一致，不需要食用，只需贴身携带。

鹿蜀的感官描写也是南次一经中最华丽的：马身、白首、虎纹、赤尾、声如歌谣——五种特征涵盖了形、色、声三个维度。相比之下，【犭爰】翼之山的「怪兽怪蛇」完全不具名、不描写。凶险之山信息匮乏（不可接近，无法描写），恩赐之山信息丰饶（可以接近，详细观察）——信息密度本身就是安全距离的指标：描写越详细，说明记录者距离越近，说明这座山越安全、越友善。（001-004）
