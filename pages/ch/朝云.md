# 朝云

**朝云**（朝云之国）是《山海经·[[海内経]]》所载的邦国。流沙之东——黑水之西——与[[司彘之国]]并记。同条展开[[黄帝]]五代帝系谱系。（018-005）

## 原文出处

《[[海内経]]》：

> 流沙之东，黑水之西，有朝云之国、司彘之国。黄帝妻雷祖，生昌意。昌意降处若水，生韩流。韩流擢首、谨耳、人面、豕喙、麟身、渠股、豚止，取淖子曰阿女，生帝颛顼。
>
> （018-005）

## 帝系发源地

朝云之国的真正重量不在国本身——在紧接其后的帝系谱系：

| 世代 | 人物 | 事迹 |
|------|------|------|
| 一 | [[黄帝]] | 妻雷祖（嫘祖） |
| 二 | 昌意 | 降处若水 |
| 三 | 韩流 | 人兽混合之形 |
| 四 | 阿女 | 韩流之妻 |
| 五 | [[颛顼]] | 五帝之一 |

从黄帝到颛顼——五代帝系——起点就在朝云之国所在的「流沙之东、黑水之西」。朝云之国是帝系地理的锚点。（018-005）

## 韩流的异形

帝系第三代韩流——容貌极其怪异：

| 部位 | 形态 |
|------|------|
| 首 | 擢首（长颈） |
| 耳 | 谨耳（小耳） |
| 面 | 人面 |
| 嘴 | 豕喙（猪嘴） |
| 身 | 麟身（鳞片之身） |
| 股 | 渠股（弯腿） |
| 足 | 豚止（猪蹄） |

黄帝的孙子——长着猪嘴、鳞片和猪蹄。帝系始祖中出现这样的人兽混合体——说明在山海经的世界里——帝和兽的界限本来就不清楚。（018-005）

## 朝云之名

「朝云」——早晨的云。流沙和黑水之间升起的晨云——朝霞弥漫之地——帝系从这里诞生。名字有一种开天辟地的意味——朝云散去——帝系登场。（018-005）
