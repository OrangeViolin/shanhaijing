# 精精

**精精**是《山海经·[[东山経]]》東次三経[[【足每】隅之山]]所载的兽。如牛——马尾——鸣声自呼其名。（004-038）

## 原文出处

《[[东山経]]》東次三経：

> 又南水行九百里，曰【足每】隅之山，其上多草木，多金玉，多赭。有兽焉，其状如牛而马尾，名曰精精，其鸣自【讠交】。
>
> （004-038）

## 牛身马尾

精精的形态——两种家畜的混合：

| 属性 | 内容 |
|------|------|
| 身体 | 如牛 |
| 尾巴 | 马尾 |
| 鸣声 | 自呼其名 |

牛的身体配马的尾巴——两种最常见的大型家畜各取一部分。不是猛兽——不是异物——是日常动物的重新组合。（004-038）

## 自呼其名

「其鸣自【讠交】」——叫声就是自己的名字「精精」。山海经中大量生物有此特征——名字来自叫声：

| 生物 | 出处 | 有无预兆 |
|------|------|---------|
| **精精** | 東次三経 | 无 |
| [[当康]] | 東次三経 | 见则天下大穰 |
| [[犰狳]] | 東次二経 | 见则螽蝗害 |

精精和当康同在東次三経——都自呼其名——但当康有丰收预兆，精精什么预兆都没有。纯粹的形态记录——存在即全部。（004-038）

## 【足每】隅之山

精精栖息的山——草木、金玉、赭（红土）皆丰：

| 物产 | 内容 |
|------|------|
| 植物 | 多草木 |
| 矿产 | 多金玉 |
| 土 | 多赭 |
| 兽 | 精精 |

一座丰饶的山——草木矿物红土齐全。精精住在这样富足的环境里——可能正因为环境太正常，精精本身也没什么异常——只是牛换了条马尾巴。（004-038）
