# 堇理之山

**堇理之山**是《山海经·[[中山経]]》中次十一経所载的山。多松柏、美梓——阴多丹【镬钅换丹】和金——兽多豹虎。有鸟青耕——可以御疫。（005-152）

## 原文出处

《[[中山経]]》中次十一経：

> 又西北一百里，曰堇理之山，其上多松柏，多美梓，其阴多丹【镬钅换丹】，多金，其兽多豹虎。有鸟焉，其状如鹊，青身白喙，白目白尾，名曰青耕，可以御疫，其鸣自叫。
>
> （005-152）

## 青耕：御疫之鸟

青耕是堇理之山最重要的异物——一只能防疫病的鸟：

| 属性 | 内容 |
|------|------|
| 形状 | 如鹊 |
| 身色 | 青 |
| 喙 | 白 |
| 目 | 白 |
| 尾 | 白 |
| 鸣声 | 自叫（叫自己的名字） |
| 功能 | 可以御疫 |

青身配三白（喙、目、尾）——鹊的黑白配色被替换为青白配色。「御疫」不是治疗——是防御——比治病更高级的功能。「其鸣自叫」——叫自己的名字——山海経中自报名号的鸟。（005-152）

## 隣山防病分工

堇理之山与直后的[[依轱之山]]构成防病组合：

| 山 | 异物 | 防护对象 | PN |
|----|------|----------|-----|
| **堇理之山** | 青耕（鸟） | 御疫（疫病） | 005-152 |
| [[依轱之山]] | 【麟鹿換犭】（兽） | 食之不风（中风） | 005-153 |

一鸟一兽——一防疫一防风——相邻两山分工防护不同的疾病。鸟是被动防护（御=抵御）——兽是主动摄入（食之）——防护方式也不同。中次十一経在这个区间安排了一个医药走廊。（005-152—005-153）

## 物产

堇理之山物产丰富——中次十一経中算充实的山：

| 类别 | 产物 |
|------|------|
| 木 | 松柏、美梓 |
| 矿 | 丹【镬钅换丹】、金 |
| 兽 | 豹、虎 |
| 鸟 | 青耕 |

松柏是长青树——美梓是良材。丹【镬钅换丹】和金是贵重矿物。豹和虎是猛兽。木+矿+兽+鸟四类齐全——加上御疫的青耕——堇理之山是一座资源完备的山。（005-152）
