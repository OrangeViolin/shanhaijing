# 即公之山

**即公之山**是《山海经·[[中山経]]》中次十二経（洞庭山系）的冢山之一。多黄金——多瑀玞之玉，有蓐，龟形白身赤首，可以御火。（005-198、005-204）

## 原文出处

《[[中山経]]》中次十二経：

> 又东南二百里，曰即公之山，其上多黄金，其下多瑀玞之玉，其木多柳杻檀桑。有兽焉，其状如龟，而白身赤首，名曰蓐，是可以御火。
>
> （005-198）

> 凡洞庭山之首……凡夫夫之山、即公之山，尧山、阳帝之山皆冢也，其祠：皆肆瘗，祈用酒，毛用少牢，婴毛一吉玉。
>
> （005-204）

## 蓐：御火之龟

蓐是一只能防火的龟：

| 属性 | 内容 |
|------|------|
| 形状 | 如龟 |
| 身 | 白色 |
| 首 | 赤色 |
| 能力 | 御火 |

龟——水中之物，能克火。白身赤首，白是水的清净，赤是火的颜色，一只兽同时携带水和火两种属性。龟形暗示水，赤首暗示火，用水克火，五行逻辑。（005-198）

## 四冢山

洞庭山系有四座冢山——祭祀格式高于普通山：

| 冢山 | PN |
|------|-----|
| [[夫夫之山]] | — |
| **即公之山** | 005-198 |
| [[尧山]] | — |
| [[阳帝之山]] | — |

四座冢山用少牢（羊和豕）+ 酒 + 吉玉祭祀——普通山只用雄鸡和牝豚。洞庭山系有四座冢山，比其他山系都多，洞庭山系的祭祀密度最高。（005-204）

## 物产

即公之山物产丰富——上下各有宝物：

| 位置 | 物产 |
|------|------|
| 山上 | 黄金 |
| 山下 | 瑀玞之玉 |
| 树木 | 柳、杻、檀、桑 |

黄金在上——美玉在下，四种树木繁茂。冢山的物产通常丰富，即公之山也不例外。（005-198）
