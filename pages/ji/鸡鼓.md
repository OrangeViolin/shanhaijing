# 鸡鼓

**鸡鼓**は[[中山経]]中次十二経に記載される植物である。夫夫之山の草として竹と共に記録されている。（005-195）

## 原文出処

《[[中山経]]》：

> 其草多竹、鸡鼓
> （005-195）

## 形態描述

夫夫之山に竹と共に多く生える草の一種。同山には黄金・青雄黄が産し、桑・楮などの木も多い。[[神于儿]]が居する神山の植生の一つ。

## 夫夫之山の環境

鸡鼓が生える夫夫之山は中次十二経（洞庭山之首）の山列に属する。山上に黄金、山下に青雄黄があり、木は桑と楮が多い。草は竹と鸡鼓の二種が挙げられる。

| 区分 | 内容 |
|------|------|
| 木 | 桑・楮 |
| 草 | 竹・鸡鼓 |
| 鉱物（上） | 黄金 |
| 鉱物（下） | 青雄黄 |
| 神 | [[神于儿]] |

この山には神于儿が居し、人身で両手に蛇を操り、常に江淵に遊び、出入りするたびに光を放つ。鸡鼓はこの神が居する聖山の植生として記録される。

## 「鸡鼓」の名

「鸡」は鶏、「鼓」は太鼓を意味し、鶏の冠や太鼓のような形状の穂を持つ草と推定される。竹と対で記されることから、禾本科（イネ科）に近い草本と考えられる。
