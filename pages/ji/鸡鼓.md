# 鸡鼓

**鸡鼓**是《山海经·[[中山経]]》中次十二経（洞庭山系）所载的草。生于[[夫夫之山]]——与竹并生。（005-195）

## 原文出处

《[[中山経]]》中次十二経：

> 又东一百五十里，曰夫夫之山，其上多黄金，其下多青雄黄，其木多桑楮，其草多竹、鸡鼓。神于儿居之，其状人身而身操两蛇，常游于江渊，出入有光。
>
> （005-195）

## 竹与鸡鼓

鸡鼓和竹并列——「其草多竹、鸡鼓」：

| 草 | 特征 |
|----|------|
| 竹 | 禾本科 |
| 鸡鼓 | 鸡冠/鼓状穗形？ |

「鸡」是鸡——「鼓」是鼓——名字暗示穗形如鸡冠或圆如鼓面。与竹并列——可能也是禾本科植物。洞庭山系（中次十二経）位于湖南洞庭湖区域——竹和鸡鼓共生的湿润植被环境。（005-195）

## 神于儿之山

鸡鼓生长的夫夫之山——有一位神住在这里：

| 属性 | 内容 |
|------|------|
| 山 | 夫夫之山 |
| 山上 | 黄金 |
| 山下 | 青雄黄 |
| 木 | 桑、楮 |
| 草 | 竹、鸡鼓 |
| 神 | [[神于儿]] |
| 神状 | 人身操两蛇、游江渊、出入有光 |

人的身体——两手握着蛇——常在江中的深渊游泳——进出时发光。鸡鼓和竹是这位光之神居住的山上的植被——圣山的草。夫夫之山是洞庭山系的冢山之一——鸡鼓是冢山的植物。（005-195）
