# 骄山

**骄山**是《山海经·[[中山経]]》中次八経（荊山山系）的冢山（主祭山）。神[[蚳蝮]]居于此——人面羊角虎爪——常在睢漳之渊游走——出入有光。（005-092）

## 原文出处

《[[中山経]]》中次八経：

> 又东北百五十里，曰骄山，其上多玉，其下多青丹，其木多松柏，多桃枝钩端。神蚳蝮处之，其状如人面，羊角虎爪，恒游于睢漳之渊，出入有光。
>
> （005-092）

> 凡荆山之首，自景山至琴鼓之山，凡二十三山，二千八百九十里。……骄山，冢也，其祠：用羞酒少牢祈瘗，婴毛一璧。
>
> （005-113）

## 冢山祭祀

骄山是荊山山系二十三山唯一的冢山——祭祀格式与普通山截然不同：

| 项目 | 普通山 | 骄山（冢山） |
|------|--------|-------------|
| 牲畜 | 雄鸡一只 | 少牢（羊、豕） |
| 供品 | 藻圭 | 羞酒（酒） |
| 玉器 | 无 | 璧一枚 |
| 糈 | 【禾余】 | — |

少牢加酒加璧——三重供品。普通山只需一只鸡和一块藻圭。冢山的格式是普通山的数倍。（005-113）

## 蚳蝮：山水两栖之神

神蚳蝮住在骄山——却常在睢水与漳水的深渊游走：

| 属性 | 内容 |
|------|------|
| 面 | 人面 |
| 角 | 羊角 |
| 爪 | 虎爪 |
| 活动范围 | 骄山 + 睢漳之渊 |
| 特征 | 出入有光 |

人面羊角虎爪——三种动物混合。山海经的山神多为鸟身人面——蚳蝮是人面兽形——住山游水——出入发光。山神不只守山——还在水中出没——山与水的边界在这里消失。（005-092）

## 骄山物产

山上多玉——山下多青丹——木多松柏——还有桃枝钩端。玉和青丹是矿物——松柏桃枝是植物——物产从山顶排到山脚。骄山的物产丰富程度与其冢山地位一致。（005-092）
