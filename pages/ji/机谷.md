# 机谷

**机谷**是《山海经·[[中山经]]》中次五经所载的谷地，位于首山的阴面（北面）。谷中多【鸟大】鸟——形如鹿，食之可治眩晕（已垫）。（005-043）

## 原文出处

《[[中山经]]》中次五经：

> 东三百里，曰首山，其阴多楮柞，其草多【上艹下术】芫，其阳多【王雩】【王孚】之玉，木多槐。其阴有谷，曰机谷，多【鸟大】鸟，其状如录，食之已垫。
>
> （005-043）

## 山中有谷

《山海经》通常记载山和水，谷地被单独命名极为少见。机谷是其中之一：

| 要素 | 内容 |
|------|------|
| 位置 | 首山阴面（北面） |
| 名称 | 机谷 |
| 灵鸟 | 【鸟大】鸟 |

机谷藏在首山的北面——阳面是玉石和槐树的明亮世界，阴面是楮柞和机谷的幽暗世界。一座山的南北两面是两个不同的空间。（005-043）

## 【鸟大】鸟

机谷中栖息着一种药效鸟——【鸟大】鸟：

| 特征 | 描述 |
|------|------|
| 形态 | 如录（如鹿） |
| 药效 | 食之已垫（治疗眩晕） |

像鹿的鸟——一种体形较大的地栖鸟类。「已垫」——治愈眩晕。在幽暗的北面谷地中，栖息着一种能治眩晕的鸟——进入昏暗的谷地可能会感到头晕，而谷中恰好就有治晕的鸟。病因与药物共存于同一空间。（005-043）

## 首山

机谷所在的首山是中次五经中的重要山峰——经末祭祀规定中首山被标记为「【鬼申】」（神山）：

| 面 | 产物 |
|----|------|
| 阳面 | 【王雩】【王孚】之玉、槐 |
| 阴面 | 楮、柞、【上艹下术】芫 |
| **阴面谷地** | **机谷（【鸟大】鸟）** |

阳面光明贵重（玉和槐），阴面幽深实用（楮柞和药草）——首山的南北对称结构十分完整。机谷是阴面最深处的秘密——隐藏在神山北面的药鸟之谷。（005-043）
