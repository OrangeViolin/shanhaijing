# 九钟

**九钟**是《山海经·[[中山经]]》中次十一经所载的神器。在丰山，有九钟焉，是知霜鸣。（005-146）

## 原文出处

《[[中山经]]》中次十一经（荆山之首）：

> 有九鐘焉，是知霜鳴。
>
> （005-146）

## 知霜鸣

九钟的能力，感知霜降而自鸣：

| 属性 | 内容 |
|------|------|
| 数量 | 九 |
| 能力 | 知霜 |
| 行为 | 自鸣 |

不是人去敲，是钟自己响。钟感知到霜要来了，就开始鸣叫。这是一组气象感应器，九口钟同时感知季节的变化。霜来意味着秋冬到来，九钟宣告的是寒冷的降临。（005-146）

## 九之圣数

九钟，不是一口，是九口：

| 山海经中的「九」 |
|-----------------|
| 九丘 |
| 九嬪 |
| 九辩九歌 |
| **九钟** |

「九」在山海经中反复出现，是圣数、极数。九口钟不是随意的数量，是丰山灵力的九重集约。一口钟鸣是声音，九口钟齐鸣是天地的信号。（005-146）

## 丰山三凶

九钟所在的丰山，一座集齐三种凶兆的山：

| 存在 | 凶兆 | PN |
|------|------|----|
| [[雍和]] | 见则国有大恐 | 005-146 |
| [[耕父]] | 见则其国为败 | 005-146 |
| **九钟** | **知霜鸣** | **005-146** |

兽出现，国家大恐。神出现，国家败亡。钟鸣，霜降。三种凶兆集中在一座山上，山海经中没有第二座山这么密集。但九钟与前两者不同，雍和和耕父是灾祸的信号，九钟只是季节的信号。霜不是灾，九钟是三凶中唯一中立的存在。（005-146）
