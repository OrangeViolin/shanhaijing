# 季厘

**季厘**（季厘之国）是《山海经·大荒南经》所载的邦国，为[[帝俊]]之子所建。

## 原文出处

> 有人食兽，曰季厘。帝俊生季厘，故曰季厘之国。（012-014）

## 谱系与特征

季厘为帝俊之子，食兽（以野兽为食）。"帝俊生季厘，故曰季厘之国"——以始祖之名命国名，是《山海经》帝俊后裔诸国的典型模式（012-014）。

帝俊后裔建国众多：[[中容之国]]、[[司幽之国]]、[[白民之国]]、[[黑齿之国]]等，季厘是其中位于大荒南方的一支。季厘之国附近有缗渊，[[少昊]]生倍伐降处缗渊，暗示此区域是帝俊和少昊两大谱系的交汇地带。

## 地理环境

季厘之国出现在一段密集的地理叙事中（012-014）：

| 地标 | 说明 |
|------|------|
| [[襄山]] | 紧邻季厘之国 |
| [[重阴之山]] | 同一区域 |
| 缗渊 | 少昊之子倍伐降处此渊 |
| 俊坛 | 四方形水域，以帝俊命名 |

"有水四方，名曰俊坛"——四方形的水域以帝俊为名，印证此区域是帝俊势力的核心地带。季厘之国与缗渊（少昊系）、俊坛（帝俊系）共处，是大荒南方两大神系交汇的枢纽。
