# 鲛鱼

**鲛鱼**是[[中山经]]中次八经记载的鱼类，群栖于[[荆山]]的漳水中。鲛即鲨鱼类，与黄金同产于漳水。鲛皮在古代是制作剑鞘和装饰品的珍贵材料。（005-091）

## 原文出处

《[[中山经]]》中次八经：

> 漳水出焉，而东南流注于睢，其中多黄金，多鲛鱼，其兽多闾麋。
> （005-091）

## 黄金与鲛鱼

漳水中「多黄金，多鲛鱼」，矿物与水生动物并列记载。黄金沉积于河床沙砾中，鲛鱼游弋于水流中，一静一动共存于同一条河。金色的矿砂与灰色的鲛鱼构成漳水的双重价值：一为矿产，一为水产。

| 要素 | 内容 |
|------|------|
| 栖息水域 | 漳水 |
| 水源山 | [[荆山]] |
| 流向 | 东南流注于睢水 |
| 同产物 | 黄金 |
| 同山兽 | 闾麋 |

## 鲛皮之用

鲛即鲨鱼或鳐鱼的古称。鲛鱼的皮肤（鲛革）表面粗糙如砂纸，古代常用于剑柄的缠裹（防滑）和剑鞘的外饰。「鲛鞘」是先秦两汉文献中常见的武器配件。漳水多鲛鱼的记载暗示荆山一带是鲛皮的重要产地，具有军事物资的供给意义。

## 荆山的丰饶生态

鲛鱼所在的荆山是中次八经的第二山，物产极为丰富：

| 类别 | 物产 |
|------|------|
| 矿（阴） | 铁 |
| 矿（阳） | 赤金 |
| 水矿 | 黄金 |
| 水产 | **鲛鱼** |
| 兽 | 闾麋、牛、豹、虎 |
| 木 | 松柏、竹、橘 |

铁、赤金、黄金三种金属集于一山，加上鲛鱼提供的鲛皮，荆山是一座兼具冶炼和军备材料的战略性山。

## 漳水与睢水流域

漳水东南流注于睢水。中次八经的首山景山也有水流入睢水，水中多丹粟和文鱼。鲛鱼从漳水进入睢水后，与文鱼共处于同一流域，构成睢水的水产生态圈。

荆山东北的骄山有山神游于睢漳之渊，出入有光。鲛鱼在这位发光山神的领地中游弋，是骄山神域水域生态的一部分。
