# 鲛鱼

**鲛鱼**は[[中山経]]に記載される魚である。[[荆山]]から東南に流れて睢水に注ぐ漳水の中に多く棲む。（005-091）

## 原文出処

《[[中山経]]》：

> 漳水出焉，而東南流注于睢，其中多黃金，多鮫魚。
> （005-091）

## 解説

鮫魚は鮫（サメ）の古称。荆山の漳水中に黄金とともに多く棲息する。鮫の皮は古代中国で剣の鞘や装飾品に用いられた。

## 鮫皮の実用価値

鮫の皮（鮫革）は粗い質感を持ち、剣の柄や鞘に巻く材料として珍重された。漳水に鮫魚が多いという記述は、この地域が鮫皮の供給地であったことを示唆する。

## 荆山と漳水

鮫魚が棲む漳水は[[荆山]]から発し、東南に流れて睢水に注ぐ。荆山は中次八経の首山で、陰に鉄、陽に赤金が多く、漳水中には黄金と鮫魚が多い。鉱物と水産物の両方が豊かな山。

| 要素 | 内容 |
|------|------|
| 棲息水域 | 漳水 |
| 水源の山 | [[荆山]] |
| 流向 | 東南 |
| 注入 | 睢水 |
| 併産物 | 黄金 |
