# 贾超之山

**贾超之山**是《山海经·[[中山経]]》中次九経（岷山山系）的末山。阳多黄垩——阴多美赭——多果木与美修。岷山山系十六山的总括在此收束。（005-129、005-130）

## 原文出处

《[[中山経]]》中次九経：

> 又东一百七十里，曰贾超之山，其阳多黄垩，其阴多美赭，其木【木且】栗橘【木繇】【木酋】杻，其中多美修。
>
> （005-129）

> 凡岷山之首，自女几山至于贾超之山，凡十六山，三千五百里。其神状皆马身而龙首。其祠：毛用一雄鸡瘗。糈用【禾余】。
>
> （005-130）

## 阴阳二色

贾超之山的南北两面各产不同颜色的矿物：

| 面 | 矿产 | 色 |
|----|------|-----|
| 阳（南） | 黄垩 | 黄 |
| 阴（北） | 美赭 | 赤 |

黄垩是黄色粘土——美赭是赤色氧化铁。山的南面黄、北面赤——阴阳二分不仅是方位概念，也是色彩概念。（005-129）

## 果木之山

贾超之山的树木种类异常丰富——六种果木加美修：

| 树木 | 类型 |
|------|------|
| 【木且】（柤） | 果树 |
| 栗 | 坚果 |
| 橘 | 柑橘 |
| 【木繇】 | 果树 |
| 【木酋】（楸） | 材木 |
| 杻 | 材木 |
| 美修（竹） | 竹类 |

六种树加竹——岷山地区的亚热带植被。这是中次九経中植物记载最丰富的山之一。（005-129）

## 岷山山系总括

贾超之山作为末山承载了整条经脉的祭祀总括：

| 属性 | 内容 |
|------|------|
| 山系 | 岷山 |
| 首山 | [[女几山]] |
| 末山 | 贾超之山 |
| 山数 | 十六山 |
| 里程 | 三千五百里 |
| 山神 | 马身龙首 |
| 祭品 | 雄鸡一只（瘗），【禾余】（稌） |

马身龙首——马的身体、龙的头。岷山山系十六座山共享同一种山神形态。祭祀用雄鸡埋入地中——用稌米为糈。（005-130）

## 冢与席

岷山山系的十六山中有等级之分——冢山和席山：

| 等级 | 山 | 祭祀规格 |
|------|-----|---------|
| 席（最高） | [[熊山]] | 太牢具，一璧 |
| 冢 | 文山、勾【木尔】、风雨、【马鬼】之山 | 少牢具，一吉玉 |
| 普通 | 贾超之山等 | 雄鸡一只 |

贾超之山虽是末山——但不是冢山也不是席山。它的角色是地理终点——不是祭祀中心。（005-130）

## 中次九経の「末山総括機能」：贾超之山が示す山系の閉合構造

贾超之山は岷山山系（中次九経）十六山の末山として山系総括（凡～之首）を承載する。五藏山経では末山が山系の祭祀・山神・里程の総括文を担うが、贾超之山は末山でありながら冢山でも席山でもない点で、「地理的閉合点」と「祭祀的中心」の分離を示す：

| 役割 | 該当山 | 祭祀規格 | 位置 | 出処 |
|------|--------|---------|------|------|
| 席（最高祭地） | [[熊山]] | 太牢具＋一璧 | 山系中部 | 005-130 |
| 冢（副祭地） | 文山・勾【木尔】・風雨・【馬鬼】 | 少牢具＋吉玉 | 散在 | 005-130 |
| **末山（総括点）** | **贾超之山** | **雄鶏一隻（普通）** | **山系末端** | **005-129、005-130** |

岷山の山神は「馬身龍首」——馬の身体に龍の頭という複合神格。贾超之山は地理的終点として十六山三千五百里の全行程を閉じるが、祭祀上は最も低い普通山である。この「地理的重要性と祭祀的平凡さの乖離」は、五藏山経の末山が必ずしも聖地ではなく、あくまで「測量・記録の終端」であることを示す。（005-129、005-130）
